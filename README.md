# 完全直方体を探せ

3本の辺をドラッグして伸ばし、対角線が整数になる直方体を探すブラウザゲームです。

- 面対角線が整数になると、その線を赤く表示
- 空間対角線が整数になっても赤く表示
- `44 × 117 × 240` のオイラー直方体を見本として収録
- 数値欄からの直接入力にも対応
- スマートフォンのタッチ操作に対応

## 数学的な条件

辺を `a, b, c` とすると、面対角線は `√(a²+b²)`、`√(a²+c²)`、`√(b²+c²)`、空間対角線は `√(a²+b²+c²)` です。面対角線3本が整数ならオイラー直方体、さらに空間対角線も整数なら完全直方体です。完全直方体は現在も未発見です。

GitHub Pages: https://fizawa460-bit.github.io/perfect-cuboid-game/


## 数学研究室

画面下部の研究室では、現在の辺から `S = a²+b²+c²` を素因数分解し、証明済みの条件を自動判定します。

- 原始オイラー直方体の奇偶則
- `p ≡ 3 (mod 4)` の素数は `S` に偶数指数で現れる
- オイラー直方体では `v₅(S) ≠ 1`
- 研究対象の例を切り替え、結果をセッション内の研究ログへ保存
- 条件を満たさない一般の直方体は「反例」ではなく「反例候補」として区別

このモードは完全直方体の発見を断定するものではなく、固定された定理を使って数値変更→仮説→検証→記録を繰り返す数学研究シミュレーションです。
