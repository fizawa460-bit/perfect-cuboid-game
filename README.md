# 完全直方体を探せ

3本の辺をドラッグして伸ばし、対角線が整数になる直方体を探すブラウザゲームです。

- 面対角線が整数になると、その線を赤く表示
- 空間対角線が整数になっても赤く表示
- `44 × 117 × 240` のオイラー直方体を見本として収録
- 数値欄からの直接入力にも対応
- スマートフォンのタッチ操作に対応

## 数学的な条件

辺を `a, b, c` とすると、面対角線は `√(a²+b²)`、`√(a²+c²)`、`√(b²+c²)`、空間対角線は `√(a²+b²+c²)` です。面対角線3本が整数ならオイラー直方体、さらに空間対角線も整数なら完全直方体です。完全直方体は現在も未発見です。

GitHub Pages: https://fizawa460-bit.github.io/perfect-cuboid-game/


## 数学研究室

画面下部の研究室では、現在の辺から `S = a²+b²+c²` を素因数分解し、証明済みの条件を自動判定します。

- 原始オイラー直方体の奇偶則
- `p ≡ 3 (mod 4)` の素数は `S` に偶数指数で現れる
- オイラー直方体では `v₅(S) ≠ 1`
- 研究対象の例を切り替え、結果をセッション内の研究ログへ保存
- 条件を満たさない一般の直方体は「反例」ではなく「反例候補」として区別

このモードは完全直方体の発見を断定するものではなく、固定された定理を使って数値変更→仮説→検証→記録を繰り返す数学研究シミュレーションです。

## 原始オイラー分布

画面下部に、3辺が1万以下の原始オイラー直方体19種類を正確な点として表示する3D分布図があります。

- 「実際の辺」では `(a, b, c)` を共通スケールで表示
- 「形の比率」では最大辺を1として形状を比較
- 空白部分をドラッグして回転
- 赤い点を押すと3辺と最大辺に対する比率を表示
- 拡大コピーは含めず、最大公約数1の原始形だけを収録

点の密集は既知19点の分布であり、未知の候補が存在する確率を示すものではありません。

## 面2本成立群（d ≤ 100000）

研究ビュー⑭では、空間対角線 `d` と面対角線2本以上が整数になる点だけを事前計算データから3D表示します。母集団の灰色点は表示しません。

- 探索範囲：`d ≤ 100000`
- 辺の順序：`a < b < c`
- 原始条件：`gcd(a,b,c)=1`（拡大コピーを除外）
- 列挙法：ピタゴラス三角形を共通辺で二段接続し、辺の置換と重複を除外
- 正規化座標：`(a/d, b/d, c/d)`
- 累積件数：`d≤20000` は42件、`d≤50000` は62件、`d≤100000` は89件
- カテゴリ（10万以下）：`ab+ac` 33件、`ab+bc` 33件、`ac+bc` 23件、3面成立候補0件
- 増加分：`20000<d≤50000` は20件、`50000<d≤100000` は27件

この件数は上記の生成・原始・並べ替え条件による列挙結果です。無制限範囲の「すべて」を意味せず、完全直方体の不存在や新規性を主張するものでもありません。

## 89件の数論解析

研究ビュー⑮では、上記89件について辺比率ではなく、未成立の1面を数論的に比較します。

- 未成立面の平方和 `N` と、`Δ = 最寄り平方数 - N`
- `Δ/N` と、平方数間隔で規格化した `Δ/(2√N)`
- `N` と `|Δ|` の素因数分解、主要素数の出現件数と最大指数
- `mod 4, 8, 16, 3, 5, 7, 9, 11, 13` の全体・3カテゴリ別集計
- 成立している各ピタゴラス面を `k(m²-n²), 2kmn, k(m²+n²)` に戻した `m,n,k`

表示は観察用の有限集計であり、偏りを定理・証明・新規性として主張するものではありません。
