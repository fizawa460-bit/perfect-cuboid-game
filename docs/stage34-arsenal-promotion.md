# 1. Formal Stage34 weapons

## S34-W01 — successive exact factor squareclass descent

**Weapon type:** `SUCCESSIVE_EXACT_FACTOR_SQUARECLASS_DESCENT`

**Lineage:** formal successor of provisional historical `A2-W01`.

### Reusable statement / procedure

Suppose a receiver condition can be rewritten, after denominator clearing and a primitive projective parameter choice, as a product of a small number of low-degree forms being a square. Do not immediately send the full high-genus cover to generic machinery. Instead:

```text
1. factor the receiver numerator exactly into primitive low-degree forms;
2. derive exact gcd/resultant identities controlling which primes can occur in more than one factor;
3. separate odd-prime valuation parity from the 2-adic/sign problem;
4. enumerate the finite admissible squareclass patterns factor-by-factor;
5. kill squareclasses by exact local/projective obstructions where possible;
6. parameterize a surviving conic or low-degree square condition;
7. factor the reconstructed condition again if a second exact factor layer appears;
8. only then send the finite residual branches to genus-one, genus-two, Chabauty, MW-sieve, or other complete arithmetic closure.
```

Stage34 instantiated the second factor layer as

```text
H = U*V*A*B
```

with exact pairwise-prime support control and a complete odd/2-adic squareclass theorem. This converted an infinite rational-point problem into a finite, mathematically exhaustive over-cover before any expensive quotient classification.

### Required hypotheses

- exact rational/integral reconstruction formulas;
- primitive numerator coordinates after clearing denominators;
- exact factorization into a bounded number of low-degree forms;
- pairwise gcd/resultant or equivalent valuation-support control;
- complete sign and 2-adic bookkeeping;
- proof that every receiver point enters one enumerated squareclass branch;
- exact handling of zero factors, poles, infinities, and other receiver boundaries.

### Output / credit

The output is a **finite exhaustive branch family representing the receiver**, not a proof that every branch has or lacks rational points. Local elimination of a branch is theorem credit only for that branch under the exact local predicate used.

### Applicability

- square conditions factoring into binary quadratic/quartic pieces;
- norm forms with finite shared-prime support;
- repeated descent where the first conic parameterization exposes a second useful factorization;
- receiver problems where generic high-genus treatment is too coarse before arithmetic decomposition.

### Firewalls

```text
factorization != complete squareclass list
local survivor != rational point
finite over-cover != receiver closure
same factor shape != same arithmetic adapter
StageA2 coefficients/ranks/family theorem do not transfer
Stage34 concrete branch counts do not transfer
```

- Common-Jacobian transport inside the later closure routes to `S31-W01` and `S31-WF01`, not to a duplicate Stage34 card.

## S34-W02 — global Mordell--Weil congruence exclusion

**Weapon type:** `GLOBAL_MORDELL_WEIL_CONGRUENCE_EXCLUSION`

**Lineage:** fresh authoritative realization of the generic method that had appeared only as quarantined historical `A1-WF01` evidence.

### Reusable statement / procedure

Let an auxiliary elliptic quotient have a certified full Mordell--Weil decomposition

```text
E(Q) = Z*P + E(Q)_tors
```

(or the corresponding finitely generated lattice form), and let the omitted parent/receiver equations impose necessary residue conditions at good primes. For each torsion translate `T`, reduce

```text
n*P + T
```

modulo selected good primes. Because the reduced group is finite, the receiver predicates become exact congruence conditions on `n` modulo finite periods. Intersect those admissible residue classes using exact CRT/generalized CRT.

If the final admissible integer residue set is empty for **every** torsion translate, then no rational point in the complete Mordell--Weil group can lift to the parent receiver.

This is global in the Mordell--Weil parameter. It is not a bounded search in `|n|`.

### Required hypotheses

- a proved full MW basis/generator and complete torsion subgroup (`S31-WF01` is the preferred certification workflow);
- exact quotient-to-parent receiver functions;
- primes of good reduction for every reduction used;
- exact group reduction/order computations;
- conservative treatment of poles, zero denominators, and degenerate residues;
- all torsion translates included;
- exact CRT intersection, including non-coprime moduli when present.

### Output / credit

An empty global residue set proves absence of parent-compatible rational points on that quotient branch. A nonempty residue set is only a survivor set and earns no rational-point existence credit.

### Why this is now formal

The old StageA1 implementation lived on the later-quarantined auxiliary `-8` source, so its numerical result and mainline applicability could not be promoted. Stage34 independently rebuilt and applied the method on the correct audited receiver and used it as a load-bearing global closure step (`76 -> 52`). Therefore the reusable method is now supported by a nonquarantined closed-stage proof.

### Firewalls

```text
nonempty congruence class != Q-point

rank statement != full MW group
```

## S34-W03 — receiver-restricted intersection exclusion

**Weapon type:** `RECEIVER_RESTRICTED_INTERSECTION_EXCLUSION`

### Reusable statement / procedure

To close an exact receiver represented inside a larger auxiliary factor cover, it is not always necessary to classify the full rational point set of the factor cover.

Suppose a branch variety `B` contains all candidate lifts from an algebraic factorization, while the true receiver imposes an additional exact condition `K`. If one proves

```text
B(Q) intersect K(Q) = empty
```

(or that every point in the intersection is receiver-degenerate), then that branch is closed **for the receiver**, even if `B(Q)` itself is unknown or nonempty.

A valid proof may use a single exact local witness when the extra receiver condition has a residue obstruction. Stage34 Candidate B is the model example: the four-factor branch equations admitted local projective residues, but adding the exact `K` square condition made every surviving residue impossible modulo one prime. The factor-cover rational-point set was deliberately left unclaimed.

### Required hypotheses

- an exact source/receiver contract showing every target point lies on `B` and also satisfies `K`;
- an exact local or global test for the **joint** `B + K` system;
- exhaustive treatment of the relevant projective residue classes or quotient points;
- explicit classification of zero-factor/pole/infinity/degenerate points;
- scope wording that credits only the receiver intersection.

### Output / credit

```text
receiver branch closed = allowed
factor cover Q-pointset complete = not implied
factor cover empty = not implied
parent route closed = not implied
```

### Existing Arsenal relation

`S30-WF03` already supplies the generic credit-layer firewall. `S34-W03` supplies the missing mathematical weapon: prove exactly the receiver intersection is empty rather than solving an unnecessarily larger auxiliary point-set problem.

This is distinct from `S31-W03`: `S31-W03` starts from a **complete auxiliary point set** and pulls it back exhaustively; `S34-W03` may close the receiver without ever completing the larger auxiliary point set.

## S34-WF01 — Class-3 receiver replacement-theorem pipeline

**Workflow type:** `CLASS3_RECEIVER_REPLACEMENT_THEOREM_PIPELINE`

**Lineage:** formal successor of provisional `A2-C3P01 RECEIVER_SPECIFIC_CLOSURE_THEOREM_PIPELINE`.

### Reusable workflow

A Stage29-style Class-3 kernel identifies a theorem-shaped residual, not necessarily a requirement to prove the originally named theorem species. If the exact receiver can be closed by a different theorem with the same quantified target, use this pipeline:

```text
1. freeze the exact receiver population and all quantifiers;
2. distinguish the originally suggested theorem species from the actual receiver obligation;
3. permit a replacement theorem only if its conclusion is exactly strong enough for that receiver;
4. derive the receiver equation/cover from scratch and classify every pole/boundary exception;
5. apply S34-W01 or another exhaustive finite reduction when available;
6. certify all MW groups/bases needed for quotient methods (S31-WF01);
7. use a mixed closure funnel: local witnesses, rank-zero point sets, S34-W02 global MW congruence exclusion, genus-two/elliptic Chabauty, quotient torsion, or other proof-capable finite methods;
8. use S31-W03 when a complete auxiliary point set is available;
9. use S34-W03 when only the receiver intersection needs to be excluded;
10. reconstruct every terminal survivor and degenerate landmark;
11. promote only the exact receiver implication through S30-WF03.
```

### What Stage34 established

The original kernel name asked for a primitive-divisor/all-multiples theorem. Stage34 did **not** prove that named primitive-divisor theorem. Instead it proved a replacement receiver theorem by direct finite-cover arithmetic and thereby discharged the kernel for its actual Stage29 receiver. This is the decisive validation that the earlier StageA2 theorem-construction pattern is a genuine Class-3 strategy, not merely historical analogy.

### Applicability

- exact one-dimensional or finitely decomposable receivers;
- Class-3 walls where algebraic structure admits a globally exhaustive finite-cover/quotient reduction;
- cases where the named missing theorem is stronger or differently shaped than the actual receiver obligation.


## Complete quotient point-set pullback

Rank-zero genus-one and genus-two quotient closures, Chabauty completions, and the terminal Q(i) quotient classifications grant receiver credit only after exact reverse substitution into all parent square equations and boundary classification. This is a strong second use of:

```text
S31-W03 COMPLETE_POINT_SET_PARAMETER_PULLBACK
```

No duplicate card is created.

## Finite sign-orbit transfer

The exact sign involution pairing terminal branches is ordinary exact equivariant finite transport. Generic action-identification/credit discipline already routes through Stage30's finite-action and credit-firewall machinery. No Stage34-specific sign-orbit card is needed.

## Local projective residue tests

The good-prime/support-prime projective tests are integral components of `S34-W01` and the receiver-intersection specialization `S34-W03`. A separate generic local-obstruction card would over-fragment the router.
