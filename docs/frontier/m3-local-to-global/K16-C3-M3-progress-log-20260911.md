## 1. 実行した finite-field 実験(A2寄り、Section P対応)

### 1.1 セットアップ
Master-Hit座標 `(r,s,m,n) mod p` を全数列挙し、以下を測定:

- `M = (V1*U2)^2 + (U1*V2)^2`  (third-face / Euler-brick条件)
- `H = (U1*U2)^2 + (V1*U2)^2 + (U1*V2)^2`  (space-diagonal条件)
- `Pr(H is square | M is square)`

admissibility条件: `r,s,m,n ∈ F_p^*`, `s≠±r`, `n≠±m`, かつ **`r²+s²≠0`, `m²+n²≠0`**(後述の理由で追加)。

### 1.2 発見したバグ(重要・要記録)
最初の実行で `p=5,11,13` の `Pr(M square)` が厳密に0または1になった。
原因はバグではなく、**hypotenuse縮退状態 `W1=r²+s²≡0 mod p` を admissible から除外し忘れていたこと**。
`p≡1 mod4` の小さい素数では、admissibility の残り2択(`s≠±r`)がたまたま `s≡±ir` (`i=√-1`)
と一致してしまい、全サンプルが縮退する。修正後は上記1.1のadmissibility条件で再実行。

**教訓**: 小さい素数(このケースでは概ね `p<41` あたりまで)は縮退の影響が抜けきらず、
一般論の証拠として使えない。指示書自身が `p=2,3` を別扱いしているのと同じ理由。

### 1.3 見つかった恒等式
```
H = M + (U1*U2)^2
```
（evidence-pack Section Cの `g²(X²+Y²+Z²)=H`, `g²(Y²+Z²)=M` の直接の系。新事実ではないが
実験設計上、明示しておく価値がある。）

### 1.5 解釈(実験であり定理ではないことを明記)
- `Pr(H sq | M sq)` はノイジーだが概ね **0.32〜0.50** の範囲に収まり、`p` が大きくなるにつれ
  **1/2 に近づく傾向**が見える。
- これは ambient `Delta_p ≈ 1/64 ≈ 0.016`(evidence-pack Section G)とは**桁が2つ以上違う**。
- → evidence-pack **Section Jの警告を初めて数値的に裏付けた**: 「M3で条件づけた後の
  space-diagonal局所確率」は「ambient seven-form Delta_p」と全く別物であり、後者よりずっと大きい。
- **注意**: これは「fixed prime `p` を固定して `(r,s,m,n) mod p` を一様に走らせた場合」の統計であり、
  まだ `M3(B)` 自体(`R≤B`, primitive, canonical)上の統計に翻訳されていない。禁止1(ambient local
  productをそのままglobal densityとする)には該当しないが、**まだA1の橋渡しがない状態の生データ**
  であることは明記する。

### 1.6 次の一手として提案する候補定理(未証明、Level 1候補)
`H = M + K²`(`K=U1*U2`)という単純な代数関係を使うと、指標和で以下が狙えるはず:

```
Pr(H sq | M sq) = 1/2 + O(p^{-1/2})   (p → ∞)
```

根拠: `indicator(square) = (1+χ(・))/2`(`χ`=mod p平方剰余指標)と書けば、主要項からのズレは
`Σχ(M)`, `Σχ(H)`, `Σχ(M(M+K²))` という `(r,s,m,n)∈F_p^4` 上の低次数指標和に帰着する。
これらがWeil型評価で `O(p^{4-1/2})` に抑えられれば上記が従う。**標準的な指標和技術の範囲内と
思われるが、今回のセッションでは着手していない。**

## 2. A1(パラメータ多重度・R≤B変換)の状況

### 2.1 確定していること(evidence-pack Section Cから)
primitive triple標準表示 `(U,V,W)=(r²-s²,2rs,r²+s²)`, `r>s>0`, `gcd(r,s)=1`, 逆パリティ、は一意
(教科書レベル)。したがって primitive Euler brick `(X,Y,Z)` から:

```
d = gcd(X,Y),  e = gcd(X,Z)
(U1,V1) = (X/d, Y/d)  -> 一意に (r,s) が定まる
(U2,V2) = (X/e, Z/e)  -> 一意に (m,n) が定まる
```

これは一意。残る自由度は「どちらの面を triple1/triple2 と呼ぶか」の2択(`(r,s,m,n)↔(m,n,r,s)`、
`Y`と`Z`の入れ替えに対応)のみ。

### 2.2 予想している結論(未証明)
`Y≠Z` である限り multiplicity は厳密に **2**。

### 2.3 完了(このセッションで証明済み)

**多重度 = 厳密に2、例外なし。** 証明の概要:
1. 補題: primitive Euler brick の3辺のうちちょうど1つが奇数(2辺同時奇数は`X²+Y²≡2 mod4`で矛盾、
   全偶数は`gcd=1`に矛盾)。奇数辺を`X`とする。
2. `d=gcd(X,Y)`, `e=gcd(X,Z)`とすると `(X/d,Y/d,・)`, `(X/e,Z/e,・)` は共に原始的
   (Pythagorean tripleの`gcd(leg1,leg2)=gcd(leg1,hyp)=gcd(leg2,hyp)`という標準事実を使用)。
3. `gcd(d,e)=1`(共通素因数があれば`gcd(X,Y,Z)=1`に反する)。
4. これらから `U1=X/d=ek`, `U2=X/e=dk`, `g:=gcd(U1,U2)=k` となる`k`の存在が従い、
   evidence-pack Section Cの `X=U1U2/g, Y=V1U2/g, Z=U1V2/g` が**導出**できる(天下りでなく証明)。
5. 物理brick`{a,b,c}`(`a<b<c`)は`X`を除いた残り`{Y,Z}`が常に相異なる(`a<b<c`の狭義単調性より
   `Y=Z`は原理的に起こらず、境界ケース自体が存在しない)。`Y,Z`のラベル付け2通りが
   `(r,s,m,n)↔(m,n,r,s)`という一意な2つのパラメータタプルに対応。
   → `(44,117,240)`の実例(`(r,s,m,n)=(11,2,8,5)`)で `(m,n,r,s)=(8,5,11,2)` が `Y↔Z` を
   交換して同じbrickに戻ることを検算済み。

**`R≤B`の必要条件(下界、無条件で証明済み)**:
`g≤min(|U1|,|U2|)`(gcdは割る数を超えない)から `X=U1U2/g ≥ max(|U1|,|U2|)` が`g`の値に
よらず常に成立。ゆえに
```
R ≥ X ≥ max(|r²-s²|, |m²-n²|)
```
→ `R≤B ⟹ |r²-s²|≤B かつ |m²-n²|≤B`、すなわち探索範囲は `r,s,m,n = O(√B)` の箱に収まる
(これは指示書に明記されていなかった具体的な一次情報)。

**上界(gが絡み、まだ甘い)**:
```
R ≤ √2(r²+s²)(m²+n²)/g   (g=1の最悪ケースでも無条件で成立)
```
だが上記boxの中に「実際に`R≤B`」を満たさない点(`g`が小さいせいで`R`が想定より大きい)が
混ざりうるため、この不等式だけでは箱の中の正確なカウントに直結しない。

## 5. gcd分布制御(Farey/Möbius反転)— セッション3(2026-09-11続き)

### 5.1 gcdを追い出す変数変換(証明済み・検証済み)
`g=gcd(U1,U2)`, `a=U1/g`, `b=U2/g`(`gcd(a,b)=1`)とおくと

```
X = gab,  Y = V1 b,  Z = a V2
R² = (b·W1)² + (a·V2)²     ← 恒等式(U1²+V1²=W1²を使用)
```

検証: 62個の実在するprimitive Euler brick(ランダムに`r,s,m,n<40`で生成)全てで
`R²=(bW1)²+(aV2)²`が厳密一致することを brute-force で確認済み(`/home/claude/verify.py`)。

### 5.2 Möbius反転による層別化(標準手法、枠組みのみ構築)
`N(e):=#{(r,s):e|U1}×#{(m,n):e|U2}`(`(r,s)`と`(m,n)`が独立なので**積に分離できる**)。
`𝟙[gcd(U1,U2)=g]=Σ_{g|e}μ(e/g)𝟙[e|U1]𝟙[e|U2]` の標準Möbius反転で
4変数の絡み合った条件を`N(e)`の和に変換する枠組みまで構築。

`e|r²-s²` を数える古典量 `ρ(p^k):=#{(r,s) mod p^k : p^k|(r-s)(r+s)}` を導出・検証:
```
ρ(p^k) = p^(k-1)・(k(p-1)+p)     (奇素数p、k≥1)
```
`u=r-s,v=r+s`の変数変換で導出。`p=3,5,7 × k=1,2,3`全てでbrute-forceと完全一致を確認済み。
`p=2`は未対応(七形式のSection Iと同様、別扱いが必要と予想)。

### 5.3 疎性へのheuristic(未証明、定性的な整合性チェックのみ)
`R≤B`は`bW1≤B`かつ`aV2≤B`をほぼ強制する。典型的なパラメータ(`r,s,m,n=O(√B)`)では
`U1,U2=O(B)`で典型gcdは`O(1)`(古典的なgcd期待値の収束性)。`g=O(1)`だと
`b·W1=O(B^{1.5})≫B`となり`R≤B`を満たせない。したがって`R≤B`を満たすには
`g`が異常に大きい(`g≳√B`程度、確率`O(1/√B)`程度の稀な事象)必要がある。
→ **`M3(B)~B^{1/3}`という既知の疎さは「gcdが異常に大きい稀な事象」で定性的に説明がつく**
(数値の精密な整合は未確認、方向性のみ)。
