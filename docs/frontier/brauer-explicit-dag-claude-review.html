監査してほしい主張

弱い主張： BRAUER-EXPLICIT-DAG は、現時点で残る「物理open / K3 二次(primary-2) Brauer obstruction」を具体化する計算DAGであり、最初の壁は新定理ではなく exact algebra / Galois / CAS / certificate work である。

強い主張： DAGを完走し、最終的に physical adelic Brauer / étale-Brauer set = ∅、または同値な endpoint-lift obstruction を厳密に証明できれば、完全直方体の非存在が従う。

監査上の禁止： 「DAGを完走した」だけでは非存在証明ではない。最終集合が非空なら、このrouteは解決を与えない。

非存在へ至る論理鎖 — ここを独立に壊してほしい

perfect cuboid exists
⇒ physical endpoint rational point exists
⇒ exact audited map/lift sends it into the relevant physical-open / quotient arithmetic object
⇒ its adelic image survives every valid Brauer/étale-Brauer condition

Therefore, if the exact physical Brauer/étale-Brauer set (or required endpoint lift set) is certified empty
⇒ no physical endpoint rational point
⇒ no perfect cuboid.
