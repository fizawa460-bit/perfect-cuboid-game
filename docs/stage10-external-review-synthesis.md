# Stage10 外部AIレビュー統合メモ

Stage9後に7件の独立AIレビューを比較した。外部AIの結論は証拠として採用せず、数式・監査コード・固定データへ戻して個別に検算する。

## 共通して支持された点

- Stage9の二段階約数鎖、oriented chainの重複度、追加平方条件は妥当
- 有限通過率や合同被覆率を漸近値へ読み替えない
- 現在の約数鎖変数を独立boxとみなす標準square sieveは未準備
- 次の短期候補として、固定合同類に属するprimitiveな一面のみ成立無限族を試す

## 採用した研究判断

法7の合同証明書と、共有面対角線を持つ二つのPythagorean tripleを組み合わせ、明示的な一面のみ成立族を最初に監査する。成功時は高さ成長と単射性まで証明し、無条件な `N1(B)` 下界として記録する。

## 次段階へ残す提案

Claudeのレビューで提案された、共有面対角線 `p` を軸に「斜辺としての表現数」と「脚としての表現数」を畳み込む古典解析数論ルートは、Stage10後の主候補とする。

## 採用しない飛躍

- 次元差だけから `N2(B)=o(N1(B))` が従うという議論
- Pila–Wilkie、Manin予想、toric性の未検証な直接適用
- K3曲面であることだけを根拠とした点数の希少性
- 一様Mordell–Weil rank上界の仮定
- determinant methodが直ちに線形以下の上界を与えるという見積もり

本メモは研究判断の履歴であり、数学的主張の根拠は研究メモ4.19節、監査スクリプト、生成JSONに限定する。
