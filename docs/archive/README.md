# Documentation archive

This directory contains retired research-status, roadmap, reentry, operating and historical-analysis documents.

They are preserved for provenance. They are **not current project authority** after the Stage29 close.

## Layout

- `status/` — former CURRENT/status snapshots.
- `roadmaps/` — completed stage/cycle/reentry roadmaps.
- `operations/` — retired controller, execution, closeout and write-policy documents tied to completed stages.
- `research-notes/` — historical broad research notes superseded as current entrypoints.

Historical Arsenal material is kept separately under `../arsenal/history/` because it remains useful when checking duplication, failed routes and supersession chains.

## Authority warning

A file here may contain words such as `CURRENT`, `NEXT`, `OPEN`, `PENDING`, `ADVANCE_ALLOWED` or old stage numbers. Read those statements as historical state at the time the file was written.

For current high-level mathematical state use [`../stage16-29-overview.md`](../stage16-29-overview.md). For reusable tools use [`../arsenal/README.md`](../arsenal/README.md). For the final endpoint handoff use [`../../stages/stage29/29-17/result.md`](../../stages/stage29/29-17/result.md).
