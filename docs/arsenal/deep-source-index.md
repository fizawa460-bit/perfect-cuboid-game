## 2. Stage14 giant source family

### 2.1 Main Arsenal — theorem/obstruction registry

Read in this order:

1. [`../stage14-arsenal-index.md`](../stage14-arsenal-index.md) — search by obstruction shape;
2. [`../stage14-arsenal.md`](../stage14-arsenal.md) — read the exact `AR-*` entry;
3. only then open the canonical source named by that entry.

The search index already groups material such as:

- Pythagorean / Euclid decomposition;
- Gaussian integer and squareclass methods;
- moving-modulus / residue-class / character-sum gates;
- divisor reconstruction and finite multiplicity;
- elliptic / genus-one fibers;
- local congruence and overlap sieve;
- incidence graphs and two-face gluing;
- primitive-first / Möbius / scale conversion;
- warning classes for same-kernel-different-measure, average-vs-pointwise and no-double-charge mistakes.

Do not treat an old `AR-*` item as current merely because it is strong. Later Stage20-28 promotions may supersede its quantitative role.

### 2.2 Stage14 Toolbox — normalized reusable cards

Start at [`../stage14-toolbox/README.md`](../stage14-toolbox/README.md).

The Toolbox is not another proof route. It repackages already-proved mathematics as:

- `FORMULA`;
- `LEMMA`;
- `BOUND`;
- `DICTIONARY`;
- `RECIPE`;
- `LEDGER`;
- `WARNING`.

Useful high-level guides include:

- [`../stage14-toolbox/barrier-obstruction-atlas.md`](../stage14-toolbox/barrier-obstruction-atlas.md) — obstruction/barrier map;
- [`../stage14-toolbox/collision-dispersion-interface.md`](../stage14-toolbox/collision-dispersion-interface.md) — collision/dispersion interface;
- [`../stage14-toolbox/compact-torsion-half-angle-atlas.md`](../stage14-toolbox/compact-torsion-half-angle-atlas.md) — compact torsion / half-angle identities;
- [`../stage14-toolbox/cards/`](../stage14-toolbox/cards/) — canonical extracted cards.

Files with historical names such as `current-*` inside this old subsystem are **not project-current status documents** after Stage29 close. Use them only as Stage14 Toolbox artifacts.

### 2.3 Stage14 numerical observatory

Use [`../stage14-num-reuse-index.md`](../stage14-num-reuse-index.md) before rerunning finite searches.

Its `NUM-R*` assets include exact census/regression oracles, accelerated enumerators, fingerprints, moving-window diagnostics and matched finite transition panels. Always match population, face mask, cutoff and space-diagonal condition before reuse.

Finite zero counts remain finite evidence only.
