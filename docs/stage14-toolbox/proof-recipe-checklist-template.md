# Stage14 proof recipe checklist template

Copy this block into a new main/s research stage before combining toolbox results.

```text
RECIPE_STATUS=PROVED|CONDITIONAL|HEURISTIC
SOURCE_STAGE=
SOURCE_PR=
SOURCE_MERGE_SHA=

INPUT_RECEIVER_LEVEL=L0|L1|L2|L3|L4|L5|L6|L7|L8
OUTPUT_RECEIVER_LEVEL=
COUNTED_UNIVERSE=
FIXED_CONDITIONING=
MOVING_VARIABLES=
EXPONENT_SCALE=M|B|OTHER

MERGED_THEOREM_INPUTS=
REQUIRED_TOOLBOX_CARDS=

CHECK_SOURCE_MERGED=true|false
CHECK_QUANTIFIERS_MATCH=true|false
CHECK_SAME_COUNTED_UNIVERSE=true|false
CHECK_CONDITIONING_COMPATIBLE=true|false
CHECK_TRANSFER_THEOREM_PRESENT=true|false
CHECK_COMPLEMENTARY_SECTORS_CLOSED=true|false
CHECK_EXACT_FRACTION_ARITHMETIC=true|false

MISSING_THEOREM_GATE=
STOP_CONDITION=
LEGAL_OUTPUT=
FORBIDDEN_PROMOTION=

CURRENT_WHOLE_FAMILY_EXPONENT=15/16
CURRENT_GAP_TO_SQRT=7/16
CURRENT_CONDITIONAL_TWO_CELL_TARGET=13/14
```

For a conditional recipe, `MISSING_THEOREM_GATE` must be nonempty and the current theorem ledger must remain unchanged.
