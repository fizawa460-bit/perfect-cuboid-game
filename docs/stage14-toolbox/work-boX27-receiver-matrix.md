## Common X27 principle

For an outer weighted family `Y_B`, subpolynomial inner fibers `F_y`, and Boolean physical acceptance `A(y,f)`, define

```text
H = sum_y w_y |F_y|,
M = sum_y w_y sum_{f in F_y} A(y,f),
S = {y : exists f with A(y,f)=1}.
```

Then

```text
M >= sum_{y in S} w_y,
H <= B^o(1) sum_y w_y.
```

Hence

```text
M <= B^(-delta) H
```

forces

```text
sum_{y in S} w_y
 <= B^(-delta+o(1)) sum_y w_y.
```

Therefore a fixed-power loss cannot be attributed to a nonempty `B^o(1)` inner fiber as though it were a new polynomial coordinate. It must appear as a deficit of the polynomial outer support carrying accepted fibers.
