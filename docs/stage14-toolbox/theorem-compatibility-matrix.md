# Stage14 theorem-compatibility matrix and import-rejection audit

This document classifies live Stage14 results against the collision/dispersion interface frozen in toolbox-ao. It proves no new incidence or dispersion theorem.

## Import classes

- **DIRECT**: exact algebraic or support reduction on the same physical state space; all masks and signed aggregation remain attached.
- **ADAPTER_ONLY**: reusable after an explicit relabeling, but it does not supply the target estimate.
- **CONDITIONAL**: may cross only after its named receiver is proved on the exact physical coefficient space.
- **REJECT**: loses a required selector, diagonal subtraction, shared modulus/coupling, or uses the desired energy circularly.

## Cross-route conclusions

### Main 4cd to s7-17

The maximal-k endpoint makes the s7-17 determinant/no-alias statement compatible as geometry. This is an **adapter**, not a proof of `PrimePairProjectiveSlopeDispersion`. The four-root congruence lattice must remain attached if the s-route is imported back to main.

### s7-17 to toolbox-ao

The projective centered identity is compatible with ao only after matching the same exact physical labels and subtracting the state diagonal exactly once. The deterministic `O(H^2/m)` correction is admissible. Moduluswise absolute values before the joint prime-pair average fail G4 and G6.

### t53/t54 to toolbox-ao

The residue diagonal is already closed, while the t53/t54 shared-U family lies inside principal squareclass coherence. The fixed-U divisor fan is directly reusable, but `SharedUBipartiteSquareclassEnergy` remains an independent two-coordinate theorem. Row and column energy bounds are insufficient.

### Main/s versus t principal receivers

`PrimePairProjectiveSlopeDispersion` and `SharedUBipartiteSquareclassEnergy` are not interchangeable. They may eventually share a larger theorem only after an explicit bijection preserves:

1. the exact state diagonal;
2. signed common-refinement coefficients;
3. shared U/V modulus and divisor hyperbola;
4. canonical, branch, interval and reconstruction selectors;
5. joint distinct-prime averaging.

No such equivalence is currently proved.

## Mechanical import gates

An import is accepted only when all answers are true:

1. Same physical state set after an explicit bijection?
2. Same signed coefficients before the norm?
3. Exact state diagonal subtracted once?
4. Residue diagonal kept distinct from principal coherence?
5. Shared U/V modulus and divisor coupling retained?
6. Sparse physical selector retained?
7. Angular/projective completion performed before pair collapse?
8. No target energy used as an assumption?
9. Claimed conclusion no stronger than the source theorem?
10. Uniformity covers the critical strip used by the receiver?

Failure routes the candidate back to its owner and never blocks toolbox main.

## Current boundary

The matrix licenses three reductions—4cd endpoint localization, s7-17 projectivization, and t54 divisor fan—but licenses no new global second moment. The open receivers remain:

- `PrimePairProjectiveSlopeDispersion`;
- `DualSplitKCenteredDispersion`;
- `SharedUBipartiteSquareclassEnergy`;
- shared-V and U/V-transverse principal incidences;
- nonprincipal selector dispersion.

The unconditional physical whole-family exponent remains `7/8`.
