# Stage14 external theorem import checklist template

Copy this block into a research stage before any literature theorem is used as a proof input.

```text
IMPORT_STATUS=CANDIDATE|HYPOTHESIS_MAPPED|REJECTED|IMPORTED
THEOREM_AUTHOR=
THEOREM_TITLE=
THEOREM_YEAR=
THEOREM_LOCATOR=
THEOREM_ROLE=
EXACT_CONCLUSION_USED=

BASE_FIELD_AND_CHARACTERISTIC=
NUMBER_OF_MOVING_VARIABLES=
ADDITIVE_CHARACTER=
MULTIPLICATIVE_CHARACTERS=
CHARACTER_ORDERS=
DOMAIN_OR_TORUS=
DIVISOR_OR_NEWTON_SUPPORT=
SMOOTHNESS_OR_SNC_CONDITION=
NONDEGENERACY_CONDITION=
LOCAL_MONODROMY_CONDITION=
INFINITY_OR_COMPACTIFICATION_CONDITION=
FREQUENCY_OR_PARAMETER_CHAMBERS=
EXCEPTIONAL_PARAMETERS=
BAD_PRIMES=
UNIFORMITY_PARAMETERS=
COMPLEXITY_CONSTANT_DEPENDENCE=
OUTPUT_SCALE=

STAGE14_OBJECT_MAP=
GENERIC_CHAMBER_RECEIVER=
EXCEPTION_RECEIVERS=
POST_THEOREM_TRANSFER_CHAIN=

CHECK_EXACT_THEOREM_LOCATOR=true|false
CHECK_ALL_REQUIRED_HYPOTHESES_MAPPED=true|false
CHECK_UNIFORMITY_MATCHES=true|false
CHECK_EXCEPTIONAL_STRATA_CLOSED=true|false
CHECK_BAD_PRIMES_CHARGED=true|false
CHECK_OUTPUT_QUANTIFIER_LEVEL_MATCHES=true|false
CHECK_POST_THEOREM_TRANSFER_PROVED=true|false
CHECK_FINITE_EVIDENCE_NOT_USED_AS_THEOREM=true|false

REJECTION_REASON=
LEGAL_OUTPUT=
FORBIDDEN_PROMOTION=
```

`IMPORTED` is allowed only when every required check is true. A failed required hypothesis gives `REJECTED`, not an informal partial import.
