# Stage12-N1-2b：乗法重みの共有素因子補正

Stage12-N1-2 の双曲線座標

\[
C_{\mathrm{raw}}(B)=
\sum_{\substack{h\ge1,\ 1\le r<s,\ (r,s)=1\\
h(r^2+s^2)\le2B\\
h(r^2+s^2)\equiv0\ (2)}}
\bigl(G(hrs)-1\bigr)
\]

に対し、\(G(hrs)\) の分離障害を局所補正へ縮約する。

\[
G(n)=\prod_{q\mid n,\ q\equiv1\ (4)}(2v_q(n)+1)
\]

とし、\((r,s)=1\) を用いる。\(t=rs\) と置けば、厳密に

\[
\boxed{
G(ht)=G(h)G(r)G(s)K(h,t)
}
\]

であり、補正因子は

\[
K(h,t)=
\prod_{\substack{q\equiv1\ (4)\\q\mid\gcd(h,t)}}
\frac{2(v_q(h)+v_q(t))+1}
{(2v_q(h)+1)(2v_q(t)+1)}.
\]

したがって \(0<K\le1\) で、\(K=1\) は \(1\pmod4\) の素数が \(h\) と \(rs\) に共有されない場合に一致する。共有される素数が 2 または \(3\pmod4\) のみなら \(G\) には影響しない。

有限監査では \(B\le20{,}000\) の全閾値でこの分解を検証し、Stage11 の raw 畳み込み値を完全再現した。有限割合を漸近密度とは解釈しない。

解析上は、非分離性が明示的な Euler 局所因子 \(K\) に隔離された。次に必要なのは、二次高さ領域上の積重み \(G(h)G(r)G(s)\) の平均、\(1\pmod4\) 共有素因子による補正損失の総和評価、および global Möbius 反転に耐える一様誤差項である。

漸近式、補正損失が低次であること、Stage11を超える下界、N2上界は主張しない。
