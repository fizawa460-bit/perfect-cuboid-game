# Frozen Stage12 workflows

These workflows are retained verbatim as Stage12 audit/build history. Stage12 is frozen at R09, so they are intentionally stored outside `.github/workflows/` and do not run automatically on Stage13 or repository-organization changes.

If Stage12 is deliberately reopened for a concrete mathematical issue or publication task, copy only the required workflow back into `.github/workflows/` and update its paths to the current archive/canonical layout before running it.
