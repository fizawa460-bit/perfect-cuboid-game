1. Definitions and counting convention

1.1 Hyperbolic parameters

p = h r s,
c = h(s^2-r^2)/2,
d = h(r^2+s^2)/2,

1 <= r < s, gcd(r,s)=1.

正整数Bに対し、admissible parameter setを

D_B = {(h,r,s) in N^3:
       1 <= r < s,
       gcd(r,s)=1,
       h(r^2+s^2) <= 2B,
       h(r^2+s^2) = 0 mod 2}.

とする。r,sがodd--oddならhに追加偶奇条件はなく、opposite parityならhは偶数である。

1.2 Multiplicity

G(n) = product over q|n, q=1 mod 4 of (2 v_q(n)+1).

空積は1。raw multiplicityはG(hrs)-1である。

1.3 Raw oriented count

C_raw(B) = sum over (h,r,s) in D_B of {G(hrs)-1}.

r<sとdistinguished-face conventionを保持するためoriented countである。全辺置換のcanonical quotientは行わない。repeated-side contributionは恒等的に0なのでC_distinct,raw=C_raw。

1.4 Primitive count

C_raw(B) = sum_{k<=B} C_prim(floor(B/k)),

C_prim(B) = sum_{k<=B} mu(k) C_raw(floor(B/k)).

これはglobal contentによるobject-level exact Möbius relationであり、解析近似ではない。

1.5 Primitive-first exact formula

A_{r,s}(m) = sum_{k|m} mu(k){G((m/k)rs)-1}.

lambda(r,s) = 2  for odd--odd,
              1  for opposite parity.

C_prim(B)
 = sum_{1<=r<s, gcd(r,s)=1}
   sum_{m<=lambda(r,s)B/(r^2+s^2)} A_{r,s}(m).

m=1ではA_{r,s}(1)=G(rs)-1。m>1では、mの全素因数が1 mod 4の場合だけ非零で、

A_{r,s}(m)
 = G(rs) product_{p|m} 2/(2 v_p(rs)+1).

1.6 Residue functions

beta(1)=1.

beta(q^j)=2(q-1)/(q+1)  for q=1 mod 4, j>=1.
beta(p^j)=0             for p=2 or p=3 mod 4, j>=1.

gamma(n)=(1/pi) sum_{d|n} beta(d).
g(n)=pi gamma(n)=(1*beta)(n).
rho(n)=product_{p|n} p/(p+1).

1.7 Fixed-height sum

sum_{m<=X} A_{r,s}(m)
 = gamma(rs) X - 1 + R_{r,s}(X).

R_{r,s}(X) << G(rs) H_abs(rs) X^(1/2).

retained regionはX_{r,s}=lambda B/(r^2+s^2) >= X_0、X_0=exp((log B)^(1/4))。それ以外をshallow regionとする。

2. Constant sheet

2.1 Three-variable constant kappa

F_q(s)=1+2/(q^s-1)+4q/((q+1)(q^s-1)),
F_q(1)=(q^2+6q+1)/(q^2-1).

kappa
 = (pi/4)^3 (1/2)^3
   product_{p=3 mod 4}(1-p^-2)^3
   product_{q=1 mod 4} F_q(1)(1-q^-1)^6.

2.2 Two-variable constant eta

eta
 = (pi/4)^2 (1/2)^2
   product_{p=3 mod 4}(1-p^-2)^2
   product_{q=1 mod 4}
      (1+4q/(q+1)^2)(1-q^-1)^4.

2.3 Local comparison

eta_p/kappa_p = (1-p^-2)^-1  for p=3 mod 4.
eta_q/kappa_q = (1-q^-2)^-1  for q=1 mod 4.
eta_front/kappa_front = 8/pi.

product over odd primes l of (1-l^-2)^-1 = pi^2/8.

Therefore eta/kappa = (8/pi)(pi^2/8)=pi,
so eta=pi kappa.

3. Selberg--Delange reference lock

主引用はG. Tenenbaum, Introduction to Analytic and Probabilistic Number Theory, Third Edition, GSM 163, Chapter II.5, Theorem II.5.2, p.281。

特定のexp{-c(log x)^(3/5)(log log x)^(-1/5)} remainderはclosureに必要なinputとして採用しない。finite-order expansionの次数Jを十分大きく固定し、任意の固定log-power savingを使う。

z=1 input:
sum_{n<=x} beta(n)
 = c_beta x + O_A(x (log(2x))^-A).

z=2 input for g=1*beta:
sum_{n<=x} g(n)
 = x(c_g log x+d_g) + O_A(x (log(2x))^-A).

Hypothesis checklist

  • 0<=beta(n)<=2^omega(n)<=tau(n)。
  • g(n)=sum_{d|n}beta(d)は固定次数divisor majorantで支配される。
  • B_beta(s)=zeta(s)L(s,chi_4)J_beta(s)。
  • J_betaはRe s>1/2+epsilonで局所一様絶対収束し正則。
  • L(s,chi_4)はs=1近傍で正則、固定stripで標準的多項式growth。
  • coprime cross correctionはRe(s1+s2)>1で絶対収束。

retained scaleS_0=exp((log B)^(1/4)/2)では(log S_0)^-A=(log B)^(-A/4)。box数とkernel variationで失う固定log-powerよりAを大きく取れば十分である。

4. Repaired proof chain

4.1 Fixed-circle remainder — MAJOR-02

base circle partial sumをA_0(Y)=Y/pi+E_0(Y)、|E_0(Y)|<<Y^(1/2)とし、finite Euler correction h_{r,s}(l)を畳み込む。omega(X/l)をomega(X)として引き出さず、

|sum_{l<=X} h_{r,s}(l) E_0(X/l)|
 << X^(1/2) sum_l |h_{r,s}(l)|/l^(1/2),

X |sum_{l>X} h_{r,s}(l)/l|
 << X^(1/2) sum_{l>X}|h_{r,s}(l)|/l^(1/2).

これによりR_{r,s}(X)<<G(rs)H_abs(rs)X^(1/2)。retained regionでq=r^2+s^2<=2B/X_0を用い、dyadic q-shellを足すと総誤差は

O(B X_0^(-1/2) (log B)^O(1))
 = o(B (log B)^-A)

for every fixed A。

4.2 Residue main

g=pi gammaとg(rs)=g(r)g(s)を用いるとexact residue mainは

M(B)
 = (B/pi){
   2 sum_{r<s, gcd=1, odd--odd, r^2+s^2<=2B}
       g(r)g(s)/(r^2+s^2)
   + sum_{r<s, gcd=1, opposite, r^2+s^2<=B}
       g(r)g(s)/(r^2+s^2)}.

common cutoff harmonic sumをH_lambda(B)とすると、odd--odd annulusのharmonic massはO((log B)^2)なので

M(B)=(B/pi) H_lambda(B)+O(B(log B)^2).

4.3 Parity-weighted coprime rectangle

a_lambda(r,s)=lambda(r,s)g(r)g(s) 1_{gcd(r,s)=1}.
T_lambda(R,S)=sum_{r<=R,s<=S} a_lambda(r,s).

D_lambda(s1,s2)=G_g(s1)G_g(s2)C_lambda(s1,s2).

C_lambdaは(1,1)近傍で正則で、その係数はweighted absolute normを持つ。z=2 inputを二回適用すると

T_lambda(R,S)
 = C_lambda^(0) RS log R log S
   + RS{C10 log R+C01 log S+C00}
   + Error(R,S),

C_lambda^(0)=8 eta/pi^2.

修正版tailは

Error_power
 << log(2R)log(2S)
     {R^(3/4+epsilon)S + R S^(3/4+epsilon)},
0<epsilon<1/8.

旧文書のR^(1/2+delta)Sへの不成立な強化は使用しない。

4.4 Radial Stieltjes transfer — MAJOR-03

H_tilde_lambda(B)
 = integral integral_{x^2+y^2<=B}
   1/(x^2+y^2) dT_lambda(x,y).

leading rectangle termのmixed derivativeはC_lambda^(0)(log x+1)(log y+1) dx dy。cubic termは

I(B)=integral_{x,y>=1, x^2+y^2<=B}
     log x log y/(x^2+y^2) dx dy.

Using x=t cos(theta), y=t sin(theta):
I(B)=pi(log B)^3/48+O((log B)^2).

係数とkernelの対称性、およびprimitive diagonalが(1,1)のみであることからorientation r<sはleading termを正確に半分にする。

H_lambda(B)
 = pi C_lambda^(0)(log B)^3/96
   + o((log B)^3)
 = eta(log B)^3/(12 pi)
   + o((log B)^3).

従って

M(B)
 ~ eta B(log B)^3/(12 pi^2)
  = kappa B(log B)^3/(12 pi).

4.5 Error transfer

dyadic boxB(R,S)上でK(x,y)=1/(x^2+y^2)のpartial-summation normはO(1/(R^2+S^2))。retained boxesではpower tail寄与は

O((log B)^2 min(R,S)^(-1/4+epsilon)),

よって全box合計でもo((log B)^3)。Selberg--Delange remainderもJを十分大きく固定して同様。shallow boxesはO((log B)^(3/2))、arc boxesとlower polynomialはO((log B)^2)。
