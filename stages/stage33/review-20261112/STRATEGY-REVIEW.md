## C. 最終判定の見込み — 空にはならない（見積もりではなく定理）

記号：Sbar ⊂ P⁶ は Stoll–Testa の曲面、S はその最小解消、U ⊂ S は物理的な開集合（退化した点と境界曲線を除いたもの）。

**補題 0 [proved、スクリプトで確認]。** P₀ = (a₁,a₂,a₃; b₁,b₂,b₃; c) = (3,4,0; 4,3,5; 5) は Sbar の Q 有理点で、滑らかな点です（ヤコビ行列の階数 4）。したがって S(Q) の点です。P₀ は U には入りません（a₃ = 0）。また、すべての素点 v で、P₀ は U(Q_v) の点の極限です（実数では a₃ > 0 の正の箱の極限）。

*証明。* 前半は直接計算（`check_degenerate_point.py` の (1)）。後半：S(Q_v) は P₀ の近くで 2 次元の v 進多様体で、U の補集合は真の閉部分集合なので内点を持たず、U(Q_v) は P₀ の近くで稠密です。具体的には Q_ε = (3,4,ε; √(16+ε²), √(9+ε²), 5; √(25+ε²)) が曲面上にあり、ε が v 進的に小さければ 3 つの根号は Q_v に入ります（スクリプトの (3)(4)）。□

**定理 1 [conditional]。** B を Br(U) の任意の有限部分群とします。このとき、U のアデール点 (M_v) で、B のすべての元と直交するものが存在します。さらに、有限個の素点（実素点を含む）では、M_v を P₀ の任意に小さい近傍の中の U(Q_v) の点（実素点では正の箱）に取れます。とくに、**物理的な開集合の Brauer–Manin 集合は、どんな有限の類の一覧に対しても空ではありません。**

*証明。*
1. (P_v) を次のように取ります。各素点 v で、P_v ∈ U(Q_v) を P₀ の十分近くに取ります（補題 0）。
2. A ∈ B ∩ Br(S) とします。評価写像 S(Q_v) → Br(Q_v) は局所定数なので（引用 (i)）、P_v が P₀ に十分近ければ A(P_v) = A(P₀) です。「十分近く」は v ごとに、有限個の A について決めれば足ります。
3. P₀ は有理点なので、相互法則により Σ_v inv_v A(P₀) = 0（引用 (ii)）。よって (P_v) は B ∩ Br(S) と直交します。S は固有なので、(P_v) は S のアデール点です。
4. Harari の形式補題（引用 (iii)）を X = S、U、B、(P_v) に適用します。任意の有限集合 Σ に対して、U(Q_v) の点の族 (M_v) で、v ∈ Σ では M_v = P_v、かつ B のすべての元と直交するものが得られます。□

引用した事実（**文言は記憶によるもので、監査で原典と照合してください**）：
- (i) 評価写像の局所定数性：Colliot-Thélène–Skorobogatov, *The Brauer–Grothendieck Group* (2021), 第 10 章（局所体上の評価写像の連続性）。
- (ii) Brauer–Manin の対と相互法則：同書 第 13 章 冒頭（有理点は Brauer–Manin 集合に入る）。
- (iii) Harari の形式補題：D. Harari, *Méthode des fibrations et obstruction de Manin*, Duke Math. J. 75 (1994), Corollaire 2.6.1。同書 §13.4（"Harari's formal lemma"）。内容：k は数体、X は滑らかで幾何的に整な多様体、U ⊂ X は稠密な開集合、B ⊂ Br(U) は有限部分群。(P_v) ∈ ∏ U(k_v) が B ∩ Br(X) と直交する X のアデール点なら、任意の有限集合 Σ に対し、v ∈ Σ で M_v = P_v となる (M_v) で B と直交するものがある。
  - 補足：原論文の形が「有限集合 Σ′ ⊃ Σ の上の和が 0」の場合は、Σ′ の外で M_v を整数点（そこでは B の評価が 0）に取れば、同じ結論になります。この補足も監査の対象です。

**系。**
- 契約の 3 択のうち、EMPTY は起こりません。類の一覧が空なら TRIVIAL-OR-VACUOUS、空でなければ NONEMPTY です。どちらも「この仕組みでは否定的」です。

- 契約の但し書きどおり、これは「全 Brauer–Manin 集合が空でない」ことや有理点の存在を意味しません。U(Q) については何も言っていません。

## 自己監査

**弱点。**

1. 引用 (iii) の文言を原典で確認できていません（書籍の PDF は取得に失敗しました）。Harari 1994 の Cor. 2.6.1 が形式補題の出典であることは、arXiv:1210.4190 がそう引用していることで確認しました。仮定（X の固有性の要否、和の範囲）は要照合です。
2. 「物理的なアデール集合」の定義を、Stage29 の文書で 1 行（`29-16/decision-frontier.md`：「an empty physical-open Brauer--Manin set is decisive」）しか確認していません。もし各素点で U(Q_v) より狭い集合（P₀ の近傍を含まない集合）に制限する定義なら、定理 1 はそのままでは使えません。有理点を逃さない定義である限り、そのような制限は入らないはずです。
3. 範囲に入る類が、U 上ではなく別の開集合や被覆の上で定義されている場合。別の稠密な開集合なら、共通部分に取り替えれば同じ議論が通ります。被覆の上の類なら対象外です（§C の最後）。
4. B が無限群の場合は扱っていません。契約は有限の一覧を前提にしていると読みました。
5. §B2 の「単連結・torsion なし」は概略です。結論には使っていません。

**hostile audit が突きそうな点。**

- 「P₀ は境界の点で、U の点ではない。なぜ使えるのか。」→ 使うのは S(Q) の点であることと、U(Q_v) の点の極限であることだけです。形式補題の仮定は「B ∩ Br(S) と直交する」ことで、これは S の有理点から出ます。
- 「分岐する類（BR0G の留数類）は P₀ の近くで評価が定数でない。」→ そのとおりで、だから手順 2 では B ∩ Br(S) だけを扱い、分岐する類は形式補題に任せています。
- 「NONEMPTY の証明には完全な一覧が要る、と契約にある。」→ 数学的には、任意の有限部分群について示したので一覧は不要です。契約上の扱いは提案 2 のとおり、そちらの判断です。
