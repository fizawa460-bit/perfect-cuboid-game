# Exact Campedelli quotient adapter

## 1. Full sign deck group

Write the seven branch inertia generators as `e_A1,...,e_C`. In the projective sign cover the simultaneous sign reversal is trivial, hence

```text
Gamma = F2^7 / <1^7>, dim Gamma = 6.
```

The seven inertia classes satisfy the unique displayed relation

```text
e_A1+e_A2+e_A3+e_B3+e_B2+e_B1+e_C = 0.
```

## 2. Degree-8 quotient

A rank-3 quotient `q: Gamma -> F2^3` is specified by seven labels

```text
g_L = q(e_L) in F2^3.
```

For a classical Campedelli branch cover we require these labels to be exactly the seven nonzero vectors of `F2^3`. This automatically respects the projective relation because the sum of all seven nonzero vectors of `F2^3` is zero.

Let `H=ker q`. Then

```text
dim H=3,
|H|=8,
Gamma/H ~= F2^3.
```

## 3. Local inertia criterion

The seven-line arrangement has six triple points:

```text
(A1,A2,B3)
(A1,A3,B2)
(A1,B1,C)
(A2,A3,B1)
(A2,B2,C)
(A3,B3,C)
```

and three remaining ordinary double points.

At a branch stratum supported on lines `L_1,...,L_r`, the sign-cover stabilizer is generated by their inertia classes. The kernel action is free above that stratum whenever

```text
H ∩ <e_L1,...,e_Lr> = 0,
```

equivalently whenever their images under `q` are linearly independent.

For one line this follows from `g_L != 0`. For a double point it follows because distinct nonzero vectors over `F2` are independent. For a triple point it is equivalent to

```text
g_L1 + g_L2 + g_L3 != 0.
```

This is precisely the Campedelli-arrangement condition used by Khar'lamov--Kulikov for seven-line `(Z/2)^3` covers with canonical singularities.

## 4. Resolution-level statement to audit

For an admissible labeling, the quotient canonical model has the Campedelli local branch type. The full sign cover has eight `A1` nodes above each base triple point; the order-8 kernel permutes these eight points transitively when the local inertia maps isomorphically to `F2^3`.

Therefore the expected resolved diagram is


where `C_H` is a smooth classical Campedelli surface and `Cbar_H` its canonical model.

## 5. Invariants

Conditional on the free resolved action,

```text
K(S~)^2=16       => K(C_H)^2=2,
chi(O_S~)=8      => chi(O_C_H)=1.
```

The Campedelli source theorem then supplies `pg=q=0` and the universal-cover interpretation.

## 6. Rational-point direction

The quotient map is defined by rational coordinate sign involutions. Hence

```text
S~(Q) -> C_H(Q)
```

for every admissible Q-defined kernel `H`.

This gives a one-way obstruction transfer:

```text
C_H(Q)=empty => S~(Q)=empty.
```

No converse is asserted. Lifting a `Q`-point from `C_H` to `S~` is an order-8 elementary-2 torsor problem retained in `R29-CAMP2`.
