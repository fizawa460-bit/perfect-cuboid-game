1. Scope and physical populations

物理対象は原始・標準化された整数辺直方体

0 < a < b < c, gcd(a,b,c)=1, R(a,b,c)=√(a²+b²+c²).

ℬ₂(B) は R≤B かつ3つの面対角線のうちちょうど2つが整数である直方体、𝒜₂(B) はそのうちさらに R∈ℤ を満たすものです。

M₂(B)=#ℬ₂(B), N₂(B)=#𝒜₂(B).

生存者では空間対角線を d=R と書けるため、R≤B ⇔ d≤B は完全に同一です。Stage14分子とStage15分母の比較に定数倍のheight置換は入りません。

2. Ambient exactly-two theorem

2つの整数面が共有する一意の辺を e とし、残りを x<y と置くと、共有辺曲面は

u²=e²+x², v²=e²+y².

その滑らかな split toric resolution は Y=Bl₄(P¹×P¹)、Picard rank は6です。Stage15のheight R 自体が anticanonical adelic height になります。第三面まで整数となる locus は geometrically integral degree-two thin image として下位項に除去され、

M₂(B) ∼ CM₂ B(log B)⁵, CM₂>0.

が得られます。共有辺が最小・中間・最大の各方向でも M₂,j(B)∼Cj B(log B)⁵、Cj>0 です。

3. Exact Gaussian squareclass survivor normal form

正の互いに素な toric pair (m,n), (r,s) を用いて

A=m²r²+n²s²=N(mr+i·ns), B=m²s²+n²r²=N(ms+i·nr).

Stage15-4は raw height identity G²R²=4AB を証明し、そこから次の完全同値を得ます。

R∈ℤ ⇔ AB is a square ⇔ sf(A)=sf(B).

したがって一意な squarefree core k>0 と正整数 P,Q が存在して

A=kP², B=kQ².

となります。k の素因子は2および p≡1 (mod 4) の素数に限られます。正の toric pair は物理的 shared-edge incidence から一意に復元できるため、この表現に隠れた多項式的重複度はありません。

4. Strongest quantitative survival theorem

Stage14 final Theorem 2.1 は、整数空間対角線 d≤B を持つ原始・標準化・ちょうど2面整数の全体について、任意の ε>0 に対し

N₂(B) ≪ε B1/2+ε.

を証明しています。これをStage15-2bの母集団漸近式で割るだけで

N₂(B)/M₂(B) ≪ε B−1/2+ε(log B)−5.

したがって任意の固定 δ<1/2 について N₂/M₂=Oδ(B−δ) です。

出典 firewall。 この半冪はStage15-6の局所 squareclass 機構から再導出されたものではありません。Stage14の分子上界を、Stage15の正確に一致する物理population/cutoffへ適用した結果です。

5. Independent causal zero-density theorem

生存者は全ての素数 p で

vp(A) ≡ vp(B) (mod 2)

を満たします。odd inert prime p≡3 (mod 4) では Gaussian norm valuation が自動的に偶数なので受理密度は1です。一方、good split prime p≡1 (mod 4) では、同じ物理 toric measure 上の厳密な局所受理密度が

ρp = (p⁴+4p³+22p²+4p+1) / ((p+1)²(p²+6p+1))
1−ρp = 4p(p−1)² / ((p+1)²(p²+6p+1)) = 4/p + O(p−2).

固定有限集合 S の good split primes に対し、Stage15-6は

M₂,S(B)=CM₂(∏p∈Sρp)B(log B)⁵ + oS(B(log B)⁵)

を証明します。量化順序は重要です。まず S を固定して B→∞、その後にのみ S を増やします。split primes 上の逆数和の発散と 1−ρp∼4/p により積は0へ行くため、

N₂(B)/M₂(B) → 0.

これはStage15-5の半冪ratio boundを証明の入力に使わない独立な零密度証明です。

内部定量境界。 Stage15-6は内部の固定 δ>0 も σ>0 も証明していません。局所積の自然なスケールは (log z)−2+o(1) です。

10. Relation to the perfect cuboid problem

重要な境界。 完全直方体は3つの面対角線すべてと空間対角線が整数である直方体です。Stage15の主populationは「面対角線がちょうど2つ整数」の層であり、その中で空間対角線を整数にしたときの薄さを研究しています。

したがって N₂/M₂→0 は完全直方体の不存在を意味しません。零密度集合は無限でも有限非空でも空でもあり得ます。また exactly-three stratum は別の算術層です。Stage15は完全直方体問題のopen statusを変更しません。
