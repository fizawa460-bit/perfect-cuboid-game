3. Ambient exactly-two theorem: internal proof chain

3.1 Shared-edge projective surface and singularities

2つの整数面が共有する辺を e、他の辺を x,y、面対角線を u,v とすると projective closure は

X: u²=e²+x², v²=e²+y² in P⁴[e:x:y:u:v].

二つの二次式の完全交叉なので次数4。Jacobian の rank drop は

[0:±1:0:1:0], [0:0:±1:0:1]

の4点だけである。例えば [0:1:0:1:0] では第一式から u を局所的に解け、残る式は v²−e²−y²=0 という非退化二次錐になる。よって4点はいずれも A₁ 特異点で、X は split singular quartic del Pezzo of type 4A1。

3.2 Toric parametrization and minimal resolution

(m:n),(r:s)∈P¹×P¹ に対して

E=4mnrs X₁=2rs(m²−n²) Y₁=2mn(r²−s²) U=2rs(m²+n²) V=2mn(r²+s²)

と置く。5座標はすべて bidegree (2,2) で上の二二次式を恒等的に満たす。この線形系の base points は P¹×P¹ の4つの torus-fixed corners だけである。

その4点を blow up して

Y=Bl₄(P¹×P¹)

とする。ruling classes を F₁,F₂、exceptional divisors を E₁,…,E₄ とすれば

−K_Y = 2F₁+2F₂−E₁−E₂−E₃−E₄.

上の5座標はちょうどこの divisor class の sections なので、解消後の morphism Y→X は anticanonical morphism。四つの境界fiberのstrict transformは self-intersection −2 となり4個の A₁ へ縮約される。blow-up中心はtorus-fixedなので Y は smooth split toric surface のまま。

K_Y²=8−4=4, ρ(Y)=2+4=6.

3.3 Exact Stage15 height as an anticanonical adelic height

primitive integral representative に対して

H_R([e:x:y:u:v])=√(e²+x²+y²)

とする。これは projective coordinates に degree one で homogeneous で、X(R) 上で常に正。archimedean place ではこの Euclidean norm で O_X(1) の連続metricを定め、有限placeでは標準integral projective metricを取る。前節で π*O_X(1)≅−K_Y を証明したので、H_R は Y 上の anticanonical adelic height である。

primitive physical coordinates では H_R=R が文字通り成立する。よって後のtoric countingは「比較可能な別height」ではなくStage15の実際の cutoff を数える。

3.4 Full shared-edge toric count

外部toric counting theorem の working form を smooth split toric surface Y、ρ(Y)=6、anticanonical height H_R に適用すると dense torus で

N_T(B) ∼ c_T B(log B)^(ρ(Y)−1)=c_T B(log B)^5.

physical chamber e,x,y,u,v>0 と x<y の boundary は有限個の real algebraic hypersurfaces に含まれ Tamagawa measure zero。archimedean equidistribution でこのopen chamberへ制限しても

A(B) ∼ C_A B(log B)^5, C_A>0.

A(B) は共有辺を指定した「少なくともその2面が整数」の physical incidences を数える。

3.5 Exact incidence identity

exactly-two box は unique shared edge を持つので1回、三面すべて整数の Euler brick は各辺をshared edgeに選べるので3回数えられる。したがって

A(B)=M₂(B)+3M₃(B).

directional chamber e<x<y, x<e<y, x<y<e ではそれぞれ

A_j(B)=M₂,j(B)+M₃(B).

3.6 Third-face square is a geometrically integral degree-two thin cover

第三面まで整数になる条件は z²=x²+y²。よって

W₀ ⊂ P⁵: u²=e²+x², v²=e²+y², z²=x²+y²

から z を忘れる写像 W₀→X は generic degree 2。幾何学的function field上で x²+y²=(x+iy)(x−iy)。divisor x+iy=0 のgeneric pointでは他因子は非零で valuation は1なので x²+y² は Q̄(Y) のsquareではない。したがってcoverは geometrically integral で、dense torus への rational image は type-II thin subset。

参考として W₀ は三二次式の complete intersection で adjunction により canonical class が trivial、12個の A₁ を解消するとK3になる。ただしK3 rational-point asymptoticは一切使用しない。

3.7 Thin-set subtraction

Browning–Loughran の外部 thin-set theorem のworking contractは「equidistributed anticanonical rational pointsを持つ almost-Fano varietyの dense open において thin subset は bounded-height countでzero density」。現在の Y について

  • smooth, projective, split toric;
  • H¹(Y,O_Y)=H²(Y,O_Y)=0;
  • Pic(Y) torsion free;
  • −K_Y big, K_Y²=4;
  • dense torus上のanticanonical rational pointsは前節の外部toric equidistribution interfaceでequidistributed;
  • third-face imageは geometrically integral degree-two thin subset。

よって

M₃(B)=o(B(log B)^5).

これを incidence identity に代入して

M₂(B)=C_A B(log B)^5+o(B(log B)^5).

したがって

M₂(B) ∼ C_M₂ B(log B)^5, C_M₂=C_A>0.

同じargumentを3つのarchimedean direction chambersへ適用し M₂,j(B)∼C_jB(log B)^5, C_j>0。

4. Exact Gaussian squareclass survivor normal form: internal proof

4.1 Raw toric coordinates, primitive normalization, inverse

positive coprime pairs m>n>0, r>s>0 に対し raw coordinates を

E=4mnrs X=2rs(m²−n²) Y=2mn(r²−s²) U=2rs(m²+n²) V=2mn(r²+s²)

とし

G=gcd(E,X,Y)=gcd(E,X,Y,U,V).

primitive physical incidence は (e,x,y,u,v)=(E,X,Y,U,V)/G。逆に physical incidence から

m/n=(u+x)/e, r/s=(v+y)/e

をcoprime positive numerator/denominatorにreduceすればtoric pairを一意に復元できる。実際

(m²−n²)/(2mn)=x/e, (m²+n²)/(2mn)=u/e

および (r,s) 側の同式が成り立つ。unique shared edge と x<y を固定後、hidden polynomial multiplicity はない。

4.2 Space-diagonal identity

次を定義する。

A=m²r²+n²s²=N(mr+i·ns) B=m²s²+n²r²=N(ms+i·nr).

raw geometric height は

R_raw²=E²+X²+Y².

直接展開すると

E²+X²+Y²=4(m²r²+n²s²)(m²s²+n²r²)=4AB.

primitive coordinates は G で割るので

G²R²=4AB.

G² と4はsquare。もし 4AB=T² なら G²|T² から G|T なので逆向きにもdivisibility gapはない。したがって

R∈ℤ ⇔ AB is a square.

4.3 Squarefree kernel equivalence

正整数 n の squarefree kernel を

sf(n)=∏_{v_p(n) odd} p

とする。AB がsquareであることは全primeで v_p(A),v_p(B) のparityが一致することと同値なので

AB square ⇔ sf(A)=sf(B).

共通squarefree kernelを k とすれば一意に

A=kP², B=kQ², k squarefree, P,Q>0.

Gaussian normでは p≡3 (mod 4) のvaluationは常にevenなので

supp(k) ⊂ {2} ∪ {p : p≡1 (mod 4)}.

これがStage15のminimal exact survivor normal form。

N₂(B) ≪ε B^(1/2+ε) M₂(B) ∼ C_M₂ B(log B)^5

したがって

N₂(B)/M₂(B) ≪ε B^(−1/2+ε)(log B)^(−5).

6. Split-prime local squareclass density: internal proof

6.1 Correct charged measure

survivor conditionは全primeで

v_p(A) ≡ v_p(B) (mod 2).

local event は unique physical toric stateそのものに課す。cell reconstructionでcompletion variableをexistentially消去して「あるcompletionが存在するbase」を数えることはしない。Stage15-4のtoric inverseとcell decompositionにより physical incidence ↔ toric pair ↔ reconstructed state は multiplicity one であり、local densityは同じcharged physical measure上で計算される。

6.2 Inert primes

p≡3 (mod 4) ではGaussian normのvaluationはeven。よって全stateが自動acceptされ

ρ_p=1.

p=2 はbounded local conventionとして分離し、sieve sourceには使わない。

6.3 Split divisor geometry on Y

good split prime p≡1 (mod 4) を固定し、i²=−1 in F_p を選ぶ。

A=(mr+i ns)(mr−i ns) B=(ms+i nr)(ms−i nr).

P¹×P¹ 上でAの2成分は2つのblow-up cornerで交わり、Bの2成分は別の2 cornerで交わる。4 cornerをblow upした Y では：

  • D_A,+ と D_A,− はsmoothかつdisjoint;
  • D_B,+ と D_B,− もsmoothかつdisjoint;
  • exceptional multiplicityは2でsquareclass parityには影響しない;
  • 各A成分と各B成分は2点でtransverseに交わり、A/B intersectionsは合計8点。

各 strict (1,1) transform は p+1 rational points を持ち、smooth toric resolutionは

#Y(F_p)=(p+1)²+4p=p²+6p+1.

residue classesはexactに

N00=p²+2p+5 N10=N01=2p−6 N11=8

へ分かれる。添字はA odd divisor/B odd divisorの有無を表す。

6.4 Parity probability in residue tubes

A-only divisor tubeではunit/even exceptional factorsを除くと A=ux, B∈Z_p×, x∈pZ_p。条件付き分布は

Pr(v_p(x)=n)=(1−p^−1)p^(−(n−1)), n≥1.

よって

Pr(v_p(A) even | A≡0 mod p)=1/(p+1).

B-onlyも同じ。8個のtransverse intersectionでは A=ux, B=vy で x,y∈pZ_p は独立なので

Pr(v_p(A)≡v_p(B) mod 2)=(p²+1)/(p+1)².

6.5 Exact local density

good finite-place anticanonical modelのsmooth residue tubesは同じlocal measureを持つので、actual charged acceptance densityは

ρ_p = [N00 +(N10+N01)/(p+1) + N11 (p²+1)/(p+1)²] / (p²+6p+1).

整理して

ρ_p = (p⁴+4p³+22p²+4p+1) / ((p+1)²(p²+6p+1)).

したがって

1−ρ_p = 4p(p−1)² / ((p+1)²(p²+6p+1)) = 4/p + O(p−2).

つまり各good split primeは正の割合をrejectするが、その割合はfixed positive constantではなく約 4/p。

7. Fixed-prime / fixed-finite-set refinement and ordered limit

7.1 One fixed prime

E_p={v_p(A)≡v_p(B) mod2} は valuation annuli のopen unionで、boundaryは4本のstrict Gaussian divisorsと交点に含まれp-adic measure zero。Stage15 ambient theoremで使用した同じ Y、同じ anticanonical height、同じ physical archimedean chamber に Huang の fixed adelic-neighbourhood equidistribution interfaceを適用し、inside/outside finite residue tubes で近似すると

A_p(B)=ρ_p C_A B(log B)^5 + o_p(B(log B)^5).

triple-face setはlocal conditionを課しても増えないので M₃,p(B)≤M₃(B)=o(B(log B)^5)。incidence identityを局所条件付きで使い

M₂,p(B)=ρ_p C_M₂ B(log B)^5 + o_p(B(log B)^5).

7.2 Fixed finite set

good split primesの有限集合 S を B→∞より先に固定する。distinct finite placesのTamagawa measureはfactorizeするので

ρ_S=∏_{p∈S}ρ_p.

同じfixed adelic-neighbourhood equidistributionで

M₂,S(B)=C_M₂ (∏_{p∈S}ρ_p) B(log B)^5 + o_S(B(log B)^5).

o_S は固定された S に依存してよい。max S, |S|, product modulus にuniformなerrorは証明していない。

7.3 Survivor domination and ordered limits

integral-space-diagonal survivorは全primeでparity条件を満たすので、任意のfixed finite S に対し

N₂(B) ≤ M₂,S(B).

ambient asymptoticで割って

limsup_{B→∞} N₂(B)/M₂(B) ≤ ∏_{p∈S}ρ_p.

ここで初めて B→∞ を終えた後、S を拡大する。split primes上の reciprocal-prime sum は発散し 1−ρ_p=4/p+O(p^−2) なので

∏_{p∈S}ρ_p → 0.

従ってStage15-6はStage15-5を使わず独立に

N₂(B)/M₂(B) → 0.

を証明する。

Quantitative boundary. このargumentには growing modulus uniformity がない。Stage15-6は内部の固定 δ>0 も σ>0 も証明していない。local productの自然なscaleは (log z)^−2+o(1)。
