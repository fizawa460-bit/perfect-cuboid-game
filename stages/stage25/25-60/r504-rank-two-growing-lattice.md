This continues the hostile-audited rank-two physical-coset classification from PR #995.  The fixed-class theorem is already audited:

- the known rank-two basis is `P,R`;
- the physical intersection is exactly `aP+bR` with `a` odd and `b` even;
- the Rosati cross term is `0` and both basis norms are `8`;
- `deg_u(x(aP+bR)/H)=8(a^2+b^2)`;
- every nondegenerate physical class has `n=a^2+b^2>=5`.

The remaining question is whether allowing `(a,b)` to grow with the box cutoff `B` can aggregate enough classes to beat the audited quarter-power lower.  This artifact proves a uniform upper bound that closes that possibility for the known rank-two lattice.

## 1. Twist to the fixed curve and three fixed height asymptotics

Put

\[
E_H:y^2=x^3-4H(u)^2x,
\qquad
E_0:Y^2=X^3-4X.
\]

After adjoining `sqrt(H(u))`, the twist isomorphism is

\[
X=x/H,
\qquad
Y=y/H^{3/2}.
\]

Canonical height is preserved under this isomorphism.  Let `h` be the absolute logarithmic Weil height on `P1`.

For the three **fixed** sections `P`, `R`, and `P+R`, the already audited degree formula gives

\[
\deg_u X(P)=8,
\qquad
\deg_u X(R)=8,
\qquad
\deg_u X(P+R)=16.
\]

For a fixed rational function `f in Q(u)` of degree `d`,

\[
h(f(u))=d\,h(u)+O_f(1).
\]

On the fixed elliptic curve `E0`,

\[
\widehat h_{E_0}(Q)=\frac12 h(X(Q))+O_{E_0}(1)
\]

uniformly for algebraic points `Q`.  Hence, for rational specializations away from the finite bad set,

\[
\widehat h(P_u)=4h(u)+O(1),
\]
\[
\widehat h(R_u)=4h(u)+O(1),
\]
\[
\widehat h(P_u+R_u)=8h(u)+O(1).
\]

The constants here are fixed because only the three fixed sections occur.

Therefore the specialized canonical pairing satisfies

\[
\langle P_u,R_u\rangle
=\frac12\bigl(\widehat h(P_u+R_u)-\widehat h(P_u)-\widehat h(R_u)\bigr)
=O(1).
\]

For

\[
Q_{a,b}=aP+bR,
\qquad n=a^2+b^2,
\]

bilinearity now gives a genuinely uniform estimate

\[
\boxed{
\widehat h(Q_{a,b}(u))=4n\,h(u)+O(n).
}
\]

Equivalently, there is one absolute constant `C0` such that

\[
\boxed{
\widehat h(Q_{a,b}(u))\ge (4h(u)-C_0)n
}
\]

for every integer pair `(a,b)` and every good rational specialization `u`.

This is the key uniformity input: the error is `O(n)`, not a class-dependent uncontrolled constant.

## 2. Physical box height gives a uniform canonical-height upper bound

For a primitive physical box with space diagonal at most `B`, the two guaranteed face identities give

\[
(t/k)^2=\frac{H_X-X}{H_X+X},
\qquad
(kt)^2=\frac{H_Y+Y}{H_Y-Y}.
\]

Since `0<H_X,H_Y<D<=B`, both right-hand rational numbers have logarithmic height at most `log(2B)`.  Therefore

\[
h(t/k)\le\frac12\log(2B),
\qquad
h(kt)\le\frac12\log(2B),
\]

and from `t^2=(t/k)(kt)`,

\[
\boxed{h(t)\le\frac12\log(2B).}
\]

On the physical 2-cover,

\[
X(Q)=\frac{x(Q)}H=-\frac{4t^2}{t^4+1}.
\]

The right side is a degree-four rational map in `t`, so

\[
h(X(Q))\le 4h(t)+O(1)\le2\log(2B)+O(1).
\]

Using the fixed-curve height comparison on `E0`, there is an absolute `C1` with

\[
\boxed{
\widehat h(Q_{a,b}(u))\le \log(2B)+C_1.
}
\]

Combining the lower and upper estimates gives

\[
(4h(u)-C_0)n\le \log(2B)+C_1.
\]

## 3. Uniform coefficient truncation away from bounded base height

Choose a fixed `H0` so that `4H0-C0>0`.  If `h(u)>H0`, then

\[
n\le C_2\log(2B)
\]

for one absolute constant `C2`.

Thus on the unbounded-height part of the base, only coefficient pairs in a Euclidean disk

\[
a^2+b^2\ll\log B
\]

can occur.  The number of integer pairs in this disk is `O(log B)`.

The bounded-height set

\[
\{u\in\mathbf Q:h(u)\le H_0\}
\]

is finite by Northcott.  For each one of these finitely many specializations, the subgroup generated by `P_u,R_u` has free rank at most two.  Distinct subgroup points of canonical height at most `log(2B)+C1` therefore number `O_u(log B)` by the elementary lattice-point bound for a positive-definite quadratic form.  Torsion and rank drop only reduce the count.  Summing over the finite bounded-height base set contributes

\[
O(\log B)
\]

distinct physical points/boxes.

No coefficient truncation is needed on those finitely many fibers.

## 4. Per-class base count

For any fixed coefficient pair of norm `n`, the same two-sided canonical-height estimate gives directly

\[
4n\,h(u)-C_0n\le\log(2B)+C_1,
\]

hence

\[
h(u)\le\frac{\log(2B)}{4n}+\frac{C_0}{4}+O(1/n).
\]

The number of rational numbers of logarithmic height at most `R` is `O(e^{2R})`.  Consequently, with one constant uniform in `(a,b)`,

\[
\boxed{
N_{a,b}(B)\ll B^{1/(2n)}.
}
\]

This is intentionally coarser than the audited fixed-class projective box-degree bound.  Its advantage is complete uniformity over the coefficient lattice.

The exactly-two-face condition, positivity/order restriction, primitive reduction, and box deduplication only decrease this upper count.

## 5. Sum over the entire growing physical rank-two lattice

The hostile-audited physical-coset theorem gives

\[
a\equiv1\pmod2,
\qquad b\equiv0\pmod2,
\]

and the only norm-one classes are the degenerate `+/-P` classes.  Therefore every nondegenerate physical class has

\[
n=a^2+b^2\ge5.
\]

On the unbounded-height base part, Section 3 restricts to only `O(log B)` coefficient pairs.  For each of them, Section 4 gives

\[
N_{a,b}(B)\ll B^{1/(2n)}\le B^{1/10}.
\]

Adding the bounded-height fibers gives

\[
\boxed{
N_{R504,\langle P,R\rangle,\mathrm{all\ physical}}(B)
\ll B^{1/10}\log B.
}
\]

In particular,

\[
\boxed{
N_{R504,\langle P,R\rangle,\mathrm{all\ physical}}(B)
=o(B^{1/4}).
}
\]

So allowing the known rank-two coefficient lattice to grow with `B` cannot improve the audited Stage25 quarter-power lower.  It also cannot produce a power exponent above the already known R504 original-base `3P` exponent `1/10`; the logarithm here is only an upper-bound loss.

This result does **not** claim the rank-two aggregate has exact growth `Theta(B^(1/10))`.  The currently materialized lower inside the new rank direction remains the audited `P+2R` family `Theta(B^(1/12))`.
