# Stage32 command surface

The ordinary operator surface is intentionally minimal.

- `stage32mainbatch` — continue Stage32 from `stages/stage32/MAIN-START-HERE.md`.
- `stage32audit` — hostile audit of a frozen MAIN/final-chain boundary. PASS is not merge authorization.

That is the complete normal command surface.

Lane-specific names retained in historical states, workflows, PRs, or audit receipts are implementation/provenance identifiers, not commands the operator must choose. MAIN dispatches to the required internal execution state according to the current formal roadmap unit.

Routing and startup procedure live only in `MAIN-START-HERE.md`. Mathematical unit definitions and close criteria live only in `ROADMAP.md`. This file is only the compact operator command index.
