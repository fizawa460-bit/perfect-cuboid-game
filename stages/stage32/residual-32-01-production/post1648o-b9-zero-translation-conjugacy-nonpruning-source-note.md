# Stage32 post1648O scratch source note — B9 zero-translation conjugacy

This leaf is scratch-only and carries no MAIN or arithmetic credit.

Koziarz–Rito–Roulleau, Section 4, fixes the Abel–Jacobi embedding `alpha` with infinity sent to 0. For that embedded curve, the affine action of a curve automorphism has translation `[g(infinity)]-[infinity]`. The order-8 Bolza automorphism B.9 / KKK `mu1`, `x -> i*x`, fixes infinity, hence has translation zero before the later change of embedding.

The same source then introduces an automorphism `g` of the Abelian surface with `H48 = g G48 g^{-1}` and explicitly allows changing the curve embedding by composing with this `g`. No marked formula for that conjugating `g` is supplied in the cited passage. Translation-zero is therefore not invariant data across this identification.

post1648N materializes the six possible retained linear order-8 images of B9/mu1. post1648D locks the Deraux affine `G48` action on `A[2]`. For every one of the six N linear images `A`, the unique Deraux affine element with that mod-2 linear part has translation `t` satisfying

` t = (I-A)s `

for exactly two `s in A[2]`.

Thus each Deraux affine candidate is translation-conjugate to the zero-translation linear action. The six candidates split two per retained W-line `L1,L2,L3`. Therefore the fact that B9 has translation zero in the original Abel–Jacobi embedding does not select an absolute retained W-line once the source-permitted unknown embedding conjugacy is respected.

The next load-bearing datum remains a source-bound actual KRR conjugating map `g`, or an equivalent marked theta-divisor / half-period normalization selecting one polarized ppav isomorphism.
