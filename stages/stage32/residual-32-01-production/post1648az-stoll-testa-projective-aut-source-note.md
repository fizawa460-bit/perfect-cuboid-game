## Coordinate identification with the box-variety notation

Stoll–Testa use homogeneous coordinates

`(a1,a2,a3,b1,b2,b3,c)`

with

- `a1^2+b1^2=c^2`,
- `a2^2+b2^2=c^2`,
- `a3^2+b3^2=c^2`,
- `a1^2+a2^2+a3^2=c^2`,

and equivalently

- `a1^2+a2^2=b3^2`,
- `a1^2+a3^2=b2^2`,
- `a2^2+a3^2=b1^2`.

Freitag–Salvati Manni use `(Z1,Z2,Z3,W1,W2,W3,C)` with

- `W1^2+W2^2=Z3^2`,
- `W1^2+W3^2=Z2^2`,
- `W2^2+W3^2=Z1^2`,
- `W1^2+W2^2+W3^2=C^2`.

Therefore the exact naming adapter is

`a_i = W_i`, `b_i = Z_i`, `c = C`.

This also matches the six singular support types:
- `b1=0`: zero-pairs `{a1,c}` or `{a2,a3}`;
- `b2=0`: zero-pairs `{a2,c}` or `{a1,a3}`;
- `b3=0`: zero-pairs `{a3,c}` or `{a1,a2}`.

Hence in the retained AW ordering the semantic names are

- retained `Z0,Z1,Z2` = source `b1,b2,b3`,
- retained `W0,W1,W2,W3` = source `a1,a2,a3,c`.

This is exactly the perfect-matching convention already recovered in AX.

## Explicit source automorphisms

Stoll–Testa Section 2 states that `S3` acts by simultaneously permuting the indices of `a1,a2,a3` and `b1,b2,b3`, fixing `c`.

They also give the order-two linear automorphism

- `a1 -> a1`,
- `a2 -> a2`,
- `a3 -> -i c`,
- `c -> i a3`,
- `b1 -> -i b2`,
- `b2 -> i b1`,
- `b3 -> b3`.

Call it `sigma`.

Proposition 4 states that the full geometric automorphism group is generated by `S3`, `sigma`, and all coordinate sign changes.

The same section states that every element induces a permutation of

`{a1^2,a2^2,a3^2,-c^2}`

and every permutation occurs, giving a surjection `G -> S4`; its kernel is exactly the coordinate sign-change subgroup. The full group has order `1536`.

Important firewall: the source does **not** license replacing this extension by a split `C2^6 semidirect S4`. The retained AY exhaustive Coxeter-lift replay found the fixed recovered extension non-split. The `±i` phases in `sigma` are therefore load-bearing for the next source/retained group-action comparison.

## Source eight-node anchor

`Q1^sing ∩ Sbar = {[0,1,e1,0,e2*i,e3*i,0] : e1,e2,e3 in {±1}}`

in coordinate order `(a1,a2,a3,b1,b2,b3,c)`.

This is the `b1=0`, `{a1,c}=0` eight-node support cell. It supplies a concrete projective base cell for the full 48-node equivariant adapter.
