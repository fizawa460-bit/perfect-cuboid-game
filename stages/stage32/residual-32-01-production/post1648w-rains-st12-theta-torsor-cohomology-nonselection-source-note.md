## Exact retained mod-2 cohomology calculation

Reduce the retained action on `A[2]`.  Since `-1=+1` on `A[2]`, the quotient action is generated by the
mod-2 images of `S,T` with relations

`S^2 = T^3 = (ST)^4 = 1`.

A 1-cocycle is determined by `a=z(S)` and `b=z(T)` in the four-dimensional `F2`-space `A[2]`.
The three presentation relations give the linear constraints

- `(I+S)a=0`,
- `(I+T+T^2)b=0`,
- `(I+ST+(ST)^2+(ST)^3)(a+S b)=0`.

For the retained matrices this 12-by-8 system has rank 3, hence `dim Z^1=5`.
Coboundaries have the form

`((I+S)v,(I+T)v)`

and have dimension 4.  Therefore

`dim H^1(G/<-1>, A[2]) = 1`.

There are exactly 32 cocycles, 16 coboundaries, and 16 representatives of the unique nonzero class.
Moreover `I+T` is invertible on `A[2]`, so changing a cocycle representative by a coboundary makes the
`T`-translation component run through all 16 vectors of `A[2]`.  In particular the same nonzero theta-torsor
class has representatives whose `T`-component is each of the three retained nonzero W-lines `L1,L2,L3`.

Thus Rains supplies a canonical *cohomology class/torsor*, not a canonical point of the theta-characteristic
torsor and not a canonical cocycle representative in the retained basis.  The class itself cannot select one
absolute retained W-line.  Choosing a representative would reintroduce precisely the translation/origin gauge
already shown nonpruning in post1648O/post1648Q.

This is a bounded closure of the specific `Rains natural theta torsor -> explicit retained half-characteristic`
route.  It is not a claim that no external source can ever materialize an actual marked ppav isomorphism,
a distinguished theta characteristic/semicharacter, or another common geometric anchor.
