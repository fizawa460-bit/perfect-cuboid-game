## 異議への裁定

1. **DeepSeek「G2 は循環」→ 不成立。**
   生成点での次数公式 Σ m_X·[k(X):k(D)] = 4 は重複度 m_X を
   含んだ形で定義され、C が生成点で分岐しないことは前提ではない。
   Q_h は「C 以外の水平成分の和」として定義され、勘定の帰結として
   その寄与が合計1になるのであって、結論を前提にしてはいない。
   他3名（Gemini を含む）が公式の成立を認めている。

2. **Gemini「C の既約・被約が明記されていない」→ 指摘は妥当、対処済み。**
   「担体」は既約被約曲線を指す語だが、明示が不足していた。
   KAPPA-R3-EXCLUSION.md §1 に定義を追記し、あわせて π^*D での
   C の係数 e_C は 3·e_C ≤ 4 から e_C = 1 が強制される
   （仮定ではなく帰結）ことを明記した。

3. **Gemini「E_i を互いに交わらない (−1) 曲線と仮定すると P² が
   矛盾」→ 前提が本設定に存在しないため不成立。**
   本設定の E_i はそのようなブローアップ例外因子ではない（交点対の
   実データは verify/ の JSON にあり、H·E の分布は {0:48, 2:32, 4:60}）。
   仮定した数値（E_i²=−1, H·E_i=1 等）は本データのどこにも現れない。
   なお Gemini の展開計算自体は R_l² = −304l² の一致を確認している。

4. **Gemini「D′ の曲線が Q_h と異なる根拠が無い」→ 根拠は検証
   スクリプト機構(iii)にあったが本文に数値が無かった。本文に追記済み。**
   (G·Q_h, F·Q_h) = (12l, 40l/3) に対し構成曲線は (2,0)/(0,0) のみ。
   「D′ の成分が Λ に含まれると D′ ⊥ Λ と矛盾するのでは」という
   懸念については、D′ 自体は G·D′ = 6 ≠ 0 で Λ に属さず、直交性は
   各生成元との交点の話であり矛盾しない（本文に明記）。

5. **Gemini「種数式の導出に Q_h·Q_v ≥ 0 等の暗黙の仮定」→ 不成立。**
   導出は Q_h = R_l − V の直接展開で、κ 項は Λ⊗R 上の2次式の
   厳密な最大値として出る。直交性も非負性も仮定していない
   （本文 §2 に注記を追加）。

6. **「Gram 行列・検証スクリプトが同梱されていない」（Gemini）→
   テキスト版プロンプトで監査したための見落とし。** PR の verify/
