## A. δ = 8 では、曲線の類が既知の格子に入る [proved]

- δ = 8（Q が自明、一般の場合）では C̄ = β^*C（E10 §3 の最大の場合）。B̂ の上の固有変換は **Ĉ = π^*β^*C − Σ_P (m_P/2)·N_P**。ここで N_P は 48 個の節点の (−2) 曲線、m_P = Ĉ·N_P。
- よって Ĉ の数値的な類は、β^*O(1,0)、β^*O(0,1)、N_P の張る格子に入る。**どの曲線 L との交点 Ĉ·L も、(a, b, m_P) で決まる。**
- 帰結:
  - Hodge 指数の不等式は、この格子の中では等号になり、情報がない。
  - 「既知の曲線 L について Ĉ·L ≥ 0」は (a, b, m_P) の一次の不等式になる。L = Klein のグラフの持ち上げのとき、これが補題 K。八面体のグラフ・ファイバー・N_P からは、より弱いものしか出ない（E15 §1 の注意と同じ）。
  - 種数の条件 p_a(Ĉ) ≥ 1 は Σ_P m_P² ≤ 32ab + 16(a + b)（K_B = β^*O(1,1)、C̄² = 16ab、節点ごとに −m_P²/2）。二次だが、核では自動的に満たされる。
- **偶奇の情報は、Ω の数え上げ（E10 §2、E12 Lemma 0）にすべて入っている。** 数の条件として新しく取り出せるものはない。
- 計算の確認: J の点（最小の重複度 1）一つから、節点を通る枝が 8 本出る（Σ_P m_P = 8|J|）。すると (K − ½E)·Ĉ = 8(a + b) − 4|J| となり、補題 K（≥ 0）と RH の和（≤ 4(a + b) − 4(s₁ + s₂)）は、どちらもこの一つの量の上下の評価になる。

## B. 文献 1：積を群で割った曲面の Lang 予想（Grivaux–Restrepo Velasquez–Rousseau）

- 出典: [arXiv:1611.03001](https://arxiv.org/abs/1611.03001)（Ann. SNS Pisa 2018）。要約ページで確認。全文の数式は未確認。
- **内容:** 曲線の積を群で割った曲面で、p_g = 0、c₁² = c₂ = 6 のもの。K_S − E（E は特異点の解消の例外曲線）が big であることを示し、有理曲線・楕円曲線が有限個であると結論する。
- **一般の不等式（要約の Prop 4.2）:** f(C) ⊄ E なら deg f^*(K_S − E) ≤ 2(2g(C) − 2)。
  - 中身は、二つのファイバー構造それぞれの対数版の RH の和。
  - こちらの数え方では |J| ≥ a + b に当たる。窓の RH（|J| ≥ a + b + s₁ + s₂）より弱い。
- **箱の曲面には使えない:** big の判定は、h⁰(m(K − E)) ≈ m²c₁²/2 から、節点ごとに約 m² の条件を引く数え方。
  - 向こうの曲面: 3m² − 2m² > 0（節点 2 個）。
  - 箱の曲面: 8m² − 48m² < 0（c₁² = 16、節点 48 個）。(K − E)² = 16 − 96 < 0。
- 箱の曲面が「積を群で割った曲面」であること（C8×C8 を G で割る）は E10 で使っている。また stage29 には、Beauville の、種数 2 の曲線の積の上のエタールな塔がある。どちらも、出てくるのは RH 型の一次の不等式だけ。

## C. 核の本当の形：負の期待次元での「起こりにくい交わり」[proved ＋ 見立て]

- **数え上げ:** p_i の変形は B の外の分岐の数 r_i ≤ s_i 次元（E10 §5）。一致の条件は |J| 個。源の Möbius 変換が 3 次元。
  - よって期待次元は r₁ + r₂ + 3 − |J| ≤ s₁ + s₂ + 3 − (a + b + s₁ + s₂) = **3 − (a + b) < 0**。
- **補題 R（E19 §19）との関係:** 尖点のない解は、実際に次元 0（孤立）。つまり解は、二つの Hurwitz 空間の像が、期待より多く交わる点（「起こりにくい交わり」）。
- **使えそうな定理の形:** 「Hurwitz 空間どうしの、期待次元が負の一致は、次数が有界なものに限る」という Zilber–Pink 型の主張。これがあれば核は閉じる。**そういう定理は知らない**（記憶。下の D の検索でも見つからない）。

## D. 文献 2：同じ点の集合に写る有理関数（Pakovich ほか）

- 出典: [arXiv:2503.14413](https://arxiv.org/abs/2503.14413)（抄録）、[arXiv:2511.08506](https://arxiv.org/abs/2511.08506)（検索結果の要約）。全文は未確認。
- **内容:**
  - 無限集合 K で A⁻¹(K) ⊆ B⁻¹(K) なら deg B ≥ deg A。
  - 有限集合 K で A⁻¹(K) = B⁻¹(K) が無限個の K について成り立てば、F∘A = F∘B となる F がある。
- **使えない理由:**
  - こちらは、ただ一つの有限集合 B（6 点）についての話。しかも、逆像は等しくなく、一部（J）が重なるだけ。
  - 等号でも、ただ一つの有限集合では、強い結論は知られていない（記憶）。
- 向きは近い。「逆像の大きな割合が重なれば、h₁∘p₁ = h₂∘p₂（h_i の次数は有界）」という安定版があれば、像の曲線は {h₁(x) = h₂(y)} の成分になり、双次数が有界になる。ただし、**そういう安定版は見つからなかった**。また、E19 §18.3 の C_c（Ω だけが破れる模型）が反例の形になりうるので、成り立つとしても偶奇の仮定が要る。

## E. 結論と次の候補

- 偶奇を「数」として使う道は、A により尽きている。新しい入力は、数ではない種類のものが要る。
- 候補（どれも今は道具がない。罠 B の確認つき）:
  1. **存在の問題として扱う:** 一致の条件をモノドロミー（置換の組）で書き、群論で不可能を示す。小さい次数では、E12 の探索がこの種類。一般の次数への道は知らない。
  2. **起こりにくい交わりの定理を探す・作る:** C の形。進めば核が閉じる。ただし、研究の規模が大きい。
  3. **小さい次数の F_p での数え上げ:** 補題 R で意味を持つ。次数の上限は出ない（罠 B）。反証の的を探す用途。
- 正直な位置づけ: E12 §5 の核は「次数に比例する slack の、双有理な窓の解」。その存在を否定する道具は、文献にも手元にもない。
