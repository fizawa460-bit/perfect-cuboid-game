## 0. 一行で

- E13 定理 B は、錐点（アンカー）どうしが距離 ℓ₀（約 3）以内でつながる「クラスター」ごとに、共役の元 g_𝒞 ∈ Comm(Γ₀) を決めます。
- **新しい点:** g_𝒞 は「高さ」が有界な Comm(Γ₀) の元なので、離散性による一様なすき間 δ₁ を持ちます。この性質を使うと、共役の元を、距離 ℓ₀ よりずっと長い（深さ R の 2 倍程度までの）錐点のない帯の向こうへ運べるかもしれません。
- もしこれが言えれば、E13 §6 の 1 の「局所から大域へ」の問題が、次の二つに分かれます。
  1. 錐点のない帯の幅を、深さで抑える問題（写像の幾何）。
  2. 欠損（O₁ Δ O₂、4 点以下）のまわりの、有界な領域の問題（E13 §6 の 1 がもともと述べている局所の問題）。
- **罠 B の判定: 数字はまだ動いていません。** 二つのうち 2 は未解決のまま残るので、「小さい側が片づいて、残りが OPEN」の形になる危険があります。そこで §4 で、最初の一歩を「数字が動くか」で選びます。

## 1. 設定（E13 §4 の記号）

- X∪ = (V₀; O₁ ∪ O₂)、Π = π₁^orb(X∪)、dev_i = P̃_i（ρ_i 同変）、F := dev₂∘dev₁⁻¹（局所）です。
- アンカー = O₁ ∩ O₂ の点です。欠損 = O₁ Δ O₂（4 点以下）です。
- 深さ R(x) = x から欠損までの距離です。E14 命題 L と E15 §10 から、深さ R の点では w = ½ log(g₂/g₁) が |w| ≤ ε(R) を満たします。ε(R) は、おおよそ e^{−2R} の大きさです（E15 §10 の「v_i は Σ e^{−2d(·,q)} のようにふるまう」、[heuristic]）。

## 2. 着想の三つの部品

**(A) すき間の補題（算術）[outline。標準的な議論と思われるが、未確認]**
- g ∈ Comm(Γ₀) を一つ固めます。Γ_g := Γ₀ ∩ gΓ₀g⁻¹ は、Γ₀ と gΓ₀g⁻¹ のどちらでも指数が有限です。
- Fix(Γ₀)（Γ₀ の楕円元の固定点、錐点の持ち上げ）と g·Fix(Γ₀) は、どちらも Γ_g の軌道の有限和です。Γ_g\H はコンパクトなので、**二つの集合の異なる点どうしの距離は δ₁(g) > 0 以上**です。
- したがって、点 x ∈ Fix(Γ₀) と y ∈ g·Fix(Γ₀) が δ₁(g) より近ければ、x = y です。
- E13 補題 B6 の g_𝒞 は、アンカーの対合の積で生成される整環（指数は ℓ₀ で決まる上限以下）の間の共役です。だから、高さが有界な元の有限個の型に入り、δ₁ はクラスターによらず一様に取れる見込みです [outline]。

**(B) 運搬の補題（複素解析）[outline。証明が要る]**
- G := g⁻¹∘F とします。クラスター 𝒞 の上では G ≈ id です（E13 補題 B2：誤差 ε(R, L)）。
- 深さ R 以上の領域を通る道に沿って、G を解析接続します。G は正則で、|log|G′|_hyp| = |w| ≤ ε(R) です。
- 主張したいこと: 直前に G が固定した二つのアンカー（距離 d₀ 以下）から距離 L の点で、G は恒等写像から
  **drift ≲ ε(R)·e^{d₀ + L}**
  しかずれない。
  - 根拠: G の「最良の等長写像」の変化率は、∇w で抑えられます。|w| ≤ ε から、楕円型の評価で |∇w| ≲ ε です。等長写像の小さな誤差は、距離とともに指数的に広がります。
- 注意: 帯の長さ L について指数的です。だから、帯が長いと運べません。

**(C) 次のアンカーでの確定（(A) と (B) から）**
- 道の先のアンカー c で drift < δ₁(g) なら、G(dev₁ c̃) = g⁻¹dev₂ c̃ ∈ g⁻¹Fix(Γ₀) と dev₁ c̃ ∈ Fix(Γ₀) が δ₁ より近いことになります。(A) から、二つは等しくなります。
- **つまり、dev₂ c̃ = g·dev₁ c̃ が、同じ g で正確に成り立ちます。** 誤差はそこで振り出しに戻ります（二つのアンカーで固定されるので）。
- 条件は、おおよそ **ε(R)·e^{2L} < δ₁**、つまり **L < R − C**（C は δ₁ と定数で決まる）です。E13 のクラスターの条件（L ≤ ℓ₀ ≈ 3）より、はるかに長い帯を越えられます。深さ R は、欠損から遠い点ではおよそ log a です。

## 3. これが言えた場合に得られること

- 深い領域（欠損から距離 R₁ 以上）のアンカーが、すき間 < R − C の鎖でつながっていれば、そこにあるすべてのアンカーで、**同じ g について dev₂ = g·dev₁** が成り立ちます。
- そうすると、E13 補題 B5 と同じ計算で、深い領域の中の閉じた道 γ について ρ₂(γ) = g ρ₁(γ) g⁻¹ になります。
- 残るのは、欠損のまわりの半径 R₁ の円板（4 個以下、中のアンカーは有界個）だけです。これは、E13 §6 の 1 の「有界個の錐点を持つ領域を取り替えると、錐点を一つ動かした同じ曲面になるか」という局所の問題そのものです。
- E14 の二重被覆（O₁ Δ O₂ で分岐）の上で、欠損の円板が錐点を含まなければ、E15 の補題 U から P̂₂ = g∘P̂₁ です。すると W は Hecke 曲線 T_g の成分になり、双有理性から、種数 0 の合同部分群の指数の上限（E14 の注記。スペクトルギャップ、引用のみ）で次数が有界になります。**ただし、「欠損の円板が錐点を含まない」は一般には成り立ちません。**

## 4. 弱いところと、最初の一歩の選び方（罠 B）

**弱いところ**
1. (B) の評価は、まだ筋道だけです。とくに ε(R) ≈ e^{−2R} は [heuristic] です（E15 §10）。
2. 錐点のない帯の幅には、面積からの自明な上限 log a + O(1) しかありません。必要なのは「幅 < 深さ − C」です。特別な被覆（塔など）では、幅が log a に近い帯があり得ます [heuristic]。
3. 欠損のまわりの局所の問題（§3 の最後）は、未解決のまま残ります。

**数字が動くかでの選び方**
- (B) の証明（複素解析だけ）は、それだけでは数字を動かしません。部品です。
- **数字が動く最初の候補:** 手元の slack-0 写像（route F の次数 ≤ 6 の写像、L_n の塔、補題 M の族）で、**「アンカーのすき間の最大値」と次数の関係**を測ることです。
  - 小さい次数のデータでは、どの錐点も距離 2ℓ_min 以内に別の錐点を持ち、778 個中 770 個で 2ℓ_min のグラフがつながっています（route-F ANSWER-10）。
  - すき間が次数によらず有界なら、2 の心配は消え、(B) を証明する価値が出ます。すき間が (1/2)·log a のように伸びるなら、この着想はそこで止まります。
  - ただし、計画書の基準 4 のとおり、測定は進歩には数えません。仕様の取捨（この着想を続けるか捨てるか）に使うだけです。
- **既知の族では、すき間は有界です [outline]。**
  - slack 0 なので p は局所等長です。X は、角が π/4 の正三角形 8a 枚の貼り合わせで、錐点は価数 4 の頂点、滑らかな点は価数 8 の頂点です。距離は、三角形の数でほぼ測れます。
  - L_n = x((1 + i)ⁿP) の場合: B の逆像は、トーラスの上の格子 (1 + i)⁻ⁿ·(x⁻¹(B)) です。±i の上の点は、すべて単純（錐点）で、トーラス全体に一様に並びます。だから、錐点のすき間は次数によらず有界です。補題 M の塔も、同じ周期性から有界です。
  - ただし、一般の slack-0 写像では、価数 8 だけの領域（{3,8} の敷き詰めの一部）が半径 c·log a ほどあり得ます。三角形分割のオイラー標数（Σ(6 − 価数) = 12、価数 4 の数 − 価数 8 の数 = 6）は、それを禁じません [heuristic]。
- **見込み [estimate]:** この着想で E12 §5 の混合型の slack (0,0) が閉じる見込みは、低いです（1 割未満）。局所の問題（§3 の最後）が残るからです。それでも、E13 §6 の 1 の問題を「大域」から「局所」へ縮める道になる可能性があります。
