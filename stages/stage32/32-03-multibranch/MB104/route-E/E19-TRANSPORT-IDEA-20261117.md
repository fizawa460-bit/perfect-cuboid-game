### 7.1 補題 T1（すき間）[proved]

g ∈ Comm(Γ₀) を固め、Γ_g := Γ₀ ∩ gΓ₀g⁻¹ とします。Fix(Γ₀) を Γ₀ の楕円元（位数 2）の固定点の集合とします。
**このとき δ₁(g) := inf{d(x, y) : x ∈ Fix(Γ₀), y ∈ g·Fix(Γ₀), x ≠ y} > 0 です。**

*証明。* Fix(Γ₀) は Γ₀ の有限個の軌道の和で、各 Γ₀ 軌道は Γ_g 軌道の有限和です（指数が有限）。g·Fix(Γ₀) = Fix(gΓ₀g⁻¹) も、同じ理由で Γ_g 軌道の有限和です。Γ_g は余コンパクトで真性不連続に作用するので、二つの Γ_g 軌道の距離の下限は達成されます。それが 0 なら二つの軌道は一致し、そのとき異なる 2 点の距離は Γ_g の離散性から正です。有限和なので、最小値は正です。□

- 注意: δ₁ は g ごとに決まります。§7.3 では g を最初のクラスターの元に固めたまま運ぶので、g についての一様性は要りません（§2 の (A) で心配した一様性は、不要でした）。

### 7.2 補題 T2（運搬の誤差）[proved。定数 C は未計算]

U ⊂ H を領域、G : U → H を正則とし、w := log|G′|_hyp（|G′|_hyp = |G′(z)|·Im z / Im G(z)）とします。
z ∈ U で、A_z を「A_z(z) = G(z) で、z での回転部分が G と同じ」等長写像とします。

1. **(2 ジェット)** z ↦ A_z の Maurer–Cartan 形式 X = A_z⁻¹dA_z は、z での Killing 場の大きさで |X|_z ≤ C(|∇w(z)| + |w(z)|) を満たします。
   - *理由:* G′ = e^w·A_z′（z で、偏角も同じ）なので、
     ∂_z w = (G″/G′ − A_z″/A_z′)/2 + (A_z′/(2i·Im A_z))(1 − e^w)
     です（Im G = Im A_z、∂_z log Im G = G′/(2i Im G) を使う）。G の 2 ジェットと A_z の 2 ジェットの差は O(|∂w| + |w|) で、A_{z+dz} は G の z + dz での 1 ジェットに合う等長写像なので、A_z⁻¹A_{z+dz} = exp(X·dz)、|X|_z = O(|∇w| + |w|) です。
2. **(楕円評価)** G^*(hyp) = e^{2w}·hyp も曲率 −1 なので、Δ_hyp w = e^{2w} − 1 です。単位円板 B(z, 1) ⊂ U で |w| ≤ ε ≤ 1 なら、内部の勾配評価から |∇w(z′)| ≤ C·ε（z′ ∈ B(z, 1/2)）です。
3. **(運搬)** 道 z(s)（0 ≤ s ≤ L、長さ L）の 1 近傍で |w| ≤ ε とし、K(s) := A_{z(0)}⁻¹A_{z(s)} とします。点 q を固定すると d/ds(K(s)q) の大きさは、X(s) の q での値の大きさで、それは C·ε·cosh d(q, z(s)) 以下です。q = z(L) と取って積分すると、
   **d(G(z(L)), A_{z(0)}(z(L))) ≤ C·ε·e^{L}**
   です（G(z(L)) = A_{z(L)}(z(L)) = A_{z(0)}K(L)z(L) なので）。□

## 14. Hecke 型の領域：種がないと錐点がまばらになり、曲率で大きさが抑えられる（机上、2026-11-17）[outline]

### 14.1 二つに分ける

- D_good := 欠損の近くでも、運べない深い点でもない頂点（§11.4 の 1・2 以外）。
- 隣り合う D_good の頂点は、定理 T で同じ g を持ちます（一番近いアンカーどうしのすき間が深さ − C₀ より小さいので、§10.2 の係数 1/2 の定義から）。だから **g は D_good の各連結成分の上で一定**です。

### 14.2 Hecke 型の成分には「種」がない

- したがって、**Hecke 型の成分の中では、その距離にある錐点の組は一つもありません。**

滑らかな頂点 v（価数 8）のまわりの星は、敷き詰めの星と等長です。隣の頂点 u_0, …, u_7 どうしの距離は、間の三角形の数 k で決まります（手元で計算）:

| k | 1 | 2 | 3 | 4 |
|---|---|---|---|---|
| 距離 | 1.5286（ℓ_min） | 2.4485 | 2.9140 | 3.0571 |
| 奇素数なし（種）か | はい | はい | いいえ | はい |

- だから、Hecke 型の成分では:
  - **錐点の隣に錐点はない**（距離 ℓ_min）。錐点の 4 つの隣は、すべて滑らかな頂点。

### 14.4 曲率で大きさが抑えられる

## 19. 組の剛性：接空間の補題（17.4 の 2 を証明にしたもの、2026-11-18）[proved（γ = 0）]

**一行で:** 窓の解は、像の曲線に（B×B の外の）尖点がなければ、連続的には動けない。動ける向きの数は、尖点の数（重複度込み）以下。

### 19.1 設定

### 19.2 補題と証明

**補題 R.** 上の一次の変形の空間は H⁰(T_{V₀}(D₁ ∧ D₂))/sl₂ に等しく、その次元は **deg(D₁ ∧ D₂)**（尖点の数、重複度込み）。とくに、尖点のない窓の解は無限小の意味で剛。

1. **一本の脚。** p の一次の変形 δp は p^*T_{P¹} の切断。ξ := −δp/p′ と置くと、ξ は V₀ の有理型ベクトル場で、極は p′ の零点（分岐因子 R_p）以下。B の上の点 v（局所に p = β + u^e）で重複度 e の点が残る条件は、δp ∈ (u^{e−1})、つまり **ξ が v で正則**。よって条件 (i) は ξ ∈ H⁰(T(D_i))。このとき重複度 e の点は v から v + εξ(v) へ動く。

### 21.4 種のない成分：くびれ・穴・二重の辺を含めて係数 121 [proved、§15.2 の枠組みの中で]

§15.2 (b) の種のない成分 H（良い頂点の連結成分で、種がない）について。H° := 隣がすべて H に入る頂点、∂H := H ∖ H°。∂H の頂点は悪い頂点と隣り合う（隣り合う良い頂点は同じ成分）。C = 錐点（価数 4）、S = 滑らかな頂点（価数 8）。辺や頂点の位置は、§14.3 のとおり持ち上げた星の中で数える（多重の辺があってもよい）。

**主張: |H°| ≤ 14|∂H|。** したがって、定理 C で良くない頂点の数は M_bad + Σ_H(|∂H| + |H°|) ≤ M_bad + 15·8·M_bad = **121·M_bad**（Σ_H|∂H| ≤ 8M_bad は、悪い頂点の隣が 8 個以下だから）。

*証明。*
1. **錐点の数。** C° の 4 つの隣はすべて H の S（H の中で C どうしは隣り合えない。距離 ℓ_min は種）。S° のまわりの錐点は 2 個以下（§14.3）。S∂ のまわりでは、悪い頂点 b の位置とその両隣は C° になれない（C° の隣はすべて H）ので、残りは一列に並んだ 5 つの位置で、差が 1、2、4 の組は種なので許されず、2 個以下。辺の端点を数えて **4|C°| ≤ 2(|S°| + |S∂|)**。
2. **複体 D と、くびれの分解。** D := H° の頂点を一つ以上持つ三角形の和。D の頂点は H に入り、D の内部の頂点はちょうど H°（∂H の頂点 v では、b を含む星の二つの三角形が D に入らない＝「すき間」がある）。∂H の頂点 v のまわりで、D の三角形の続きを「扇」と呼ぶ。扇の両端の位置はすき間の端なので H° でなく、**扇は三角形 2 枚以上**（j ≥ 2）。b を含むすき間は 2 辺以上なので、扇の数は S で 2 以下、C で 1 以下。各扇を別の頂点に分けた（くびれをほどいた）複体 D̂ は、球面の中の平面的な曲面になる。

   2|S°| − 2|C°| ≤ Σ_扇(6 − j) − 12 ≤ 8|S∂| + 4|C∂| − 12

### 22.1 補題 P′（等高線の Gauss–Bonnet と角の動き）[proved、補題 P の 1・4 を使う]

記号: X = X₁（p の軌道体、角 π の錐点 O₁ = アンカー ∪ 欠損 ≤ 4）、f := d(·, アンカー)、U_r := {f ≥ r}、A(r) := 面積 U_r、L(r) := 長さ ∂U_r。|∇f| = 1 なので A′ = −L（余面積の公式）。

**(★) 等高線の Gauss–Bonnet。** 普遍被覆 H² では f は離散集合（アンカーの持ち上げ）までの距離なので、一般の r で ∂U_r は**半径 r の円弧**（アンカーの持ち上げを中心とする）で、円弧どうしが横に交わる所が**角**になる。U_r の成分 U（コンパクト、球面の中なので種数 0、境界の円 k_U 個、中に欠損 n_U 個）について、
- 円弧の測地的曲率は U の側から見て −coth r（U から離れる向きに曲がる）、
- 角では U の内角が π − φ（φ := 角の点から二つの中心を見込む角、0 < φ < π）なので、曲がりは φ、
- 欠損（角 π）は π を与える。
したがって −A(U) − coth(r)·L(∂U) + Σφ + πn_U = 2π(2 − k_U)、つまり
**A(U) + coth(r)·L(∂U) = 2π(k_U − 2) + πn_U + Σ_{U の角} φ。**
すべての成分で足して N(r) := A(r) + coth(r)·L(r) = T(r) + Ψ(r)、T := Σ_U(2π(k_U − 2) + πn_U)、Ψ := Σ_角 φ。

**角の動き。** 角は、二つのアンカーの持ち上げ c、c′（距離 d）の垂直二等分線の上で、両方から距離 r の点。二等辺三角形から sinh(d/2) = sinh r·sin(φ/2)。r で微分して **dφ/dr = −2 tan(φ/2)·coth r ≤ −φ·coth r**。

**N は連続。** A は連続（A′ = −L）、L も連続（首がくびれる所で長さは連続）。T と Ψ は出来事のところで逆向きに跳ぶ:
- 局所最大（f の極大、三つのアンカーの外心）で小さな成分（k = 1）が消える: T は +2π、Ψ は −2π（消える三角形の三つの角の和は 2π に近づく）。
- 鞍点（二つのアンカーの中点）で首が切れる: 二本の境界がつながる（k − 1）か、成分が二つに分かれる（k₁ + k₂ = k + 1）。どちらも T は −2π、Ψ は +2π（φ = π の角が二つ生まれる）。
- 欠損が U_r を出る所、三つの円が一点で交わる所は、r の値が離散なので測度 0。
したがって、出来事の間で **N′ = Σφ′ ≤ −coth(r)·Ψ = −coth(r)·(N − T)**。

Q′ = N′ − μL ≤ −k(A + kL) + kαL − μL = −kA − (k² − kα + μ)L。
**c(1 + μ) ≤ 1** かつ **μ ≥ k(α + c − k)（k ∈ [1, k₀]）** なら Q′ ≤ −cQ。Q は連続なので Q(r) ≤ Q(r₀)e^{−c(r − r₀)}、A ≤ Q/(1 + μ) から
