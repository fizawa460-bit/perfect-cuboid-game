### 7.1 補題 T1（すき間）[proved]

g ∈ Comm(Γ₀) を固め、Γ_g := Γ₀ ∩ gΓ₀g⁻¹ とします。Fix(Γ₀) を Γ₀ の楕円元（位数 2）の固定点の集合とします。
**このとき δ₁(g) := inf{d(x, y) : x ∈ Fix(Γ₀), y ∈ g·Fix(Γ₀), x ≠ y} > 0 です。**

*証明。* Fix(Γ₀) は Γ₀ の有限個の軌道の和で、各 Γ₀ 軌道は Γ_g 軌道の有限和です（指数が有限）。g·Fix(Γ₀) = Fix(gΓ₀g⁻¹) も、同じ理由で Γ_g 軌道の有限和です。Γ_g は余コンパクトで真性不連続に作用するので、二つの Γ_g 軌道の距離の下限は達成されます。それが 0 なら二つの軌道は一致し、そのとき異なる 2 点の距離は Γ_g の離散性から正です。有限和なので、最小値は正です。□

- 注意: δ₁ は g ごとに決まります。§7.3 では g を最初のクラスターの元に固めたまま運ぶので、g についての一様性は要りません（§2 の (A) で心配した一様性は、不要でした）。

### 7.2 補題 T2（運搬の誤差）[proved。定数 C は未計算]

U ⊂ H を領域、G : U → H を正則とし、w := log|G′|_hyp（|G′|_hyp = |G′(z)|·Im z / Im G(z)）とします。
z ∈ U で、A_z を「A_z(z) = G(z) で、z での回転部分が G と同じ」等長写像とします。

1. **(2 ジェット)** z ↦ A_z の Maurer–Cartan 形式 X = A_z⁻¹dA_z は、z での Killing 場の大きさで |X|_z ≤ C(|∇w(z)| + |w(z)|) を満たします。
   - *理由:* G′ = e^w·A_z′（z で、偏角も同じ）なので、
     ∂_z w = (G″/G′ − A_z″/A_z′)/2 + (A_z′/(2i·Im A_z))(1 − e^w)
     です（Im G = Im A_z、∂_z log Im G = G′/(2i Im G) を使う）。G の 2 ジェットと A_z の 2 ジェットの差は O(|∂w| + |w|) で、A_{z+dz} は G の z + dz での 1 ジェットに合う等長写像なので、A_z⁻¹A_{z+dz} = exp(X·dz)、|X|_z = O(|∇w| + |w|) です。
2. **(楕円評価)** G^*(hyp) = e^{2w}·hyp も曲率 −1 なので、Δ_hyp w = e^{2w} − 1 です。単位円板 B(z, 1) ⊂ U で |w| ≤ ε ≤ 1 なら、内部の勾配評価から |∇w(z′)| ≤ C·ε（z′ ∈ B(z, 1/2)）です。
3. **(運搬)** 道 z(s)（0 ≤ s ≤ L、長さ L）の 1 近傍で |w| ≤ ε とし、K(s) := A_{z(0)}⁻¹A_{z(s)} とします。点 q を固定すると d/ds(K(s)q) の大きさは、X(s) の q での値の大きさで、それは C·ε·cosh d(q, z(s)) 以下です。q = z(L) と取って積分すると、
   **d(G(z(L)), A_{z(0)}(z(L))) ≤ C·ε·e^{L}**
   です（G(z(L)) = A_{z(L)}(z(L)) = A_{z(0)}K(L)z(L) なので）。□

2. **運べない深い点:** アンカーまでの距離 ≥ (深さ − C₀)/2 の点。
   - 双曲平面の線形の等周不等式（長さ ≥ 面積）から、「アンカーから距離 s 以上の部分」の面積は、単連結な部分では e^{−s} で減ります。
   - 深さ t の点が悪いには、アンカーのない半径 t/2 の円板の中心にいる必要があります。面積は min(e^t, C·a·e^{−t/2}) で抑えられ、合計は **a^{2/3} の程度**です（§10.3 の円板の例と同じ指数）。
   - 単連結でない部分（アンカーのない幅の広い首、閉測地線のまわりの襟）は、襟の幾何から別に見積もる必要があります。一つの首の悪い部分は、欠損が首にあっても ℓ·e^{w/3} の程度（ℓ は首の長さ、w は幅）で、やはり次数より小さい見込みです。**この部分は証明していません。**
3. **種のない領域:** アンカーのどの組も、同じ奇素数 𝔭 を共有する領域（Hecke 型）。そこでは g が N(Γ₀) に入るとは言えず、q′ は p の Hecke 対応（次数 N𝔭 + 1）に近いかもしれません。**この種類の領域がどれだけ大きくなれるかは、分かりません。**

### 11.5 まとめと罠 B の判定

- 定理 C で、混合型の slack (0,0) の次数の上限は、**「悪い頂点が次数より少ないか」という一つの問いに縮みました。** 仮定 H（つながり）も、§9 の「半分」も要りません。
- 残る問い: (i) 単連結でない部分（首）での面積の減り方、(ii) Hecke 型の領域の大きさ、(iii) 定数。
- **罠 B の判定:** (i)・(ii) が言えれば、混合型の slack (0,0) の次数が**無条件で有限**になります（巨大な定数で）。これは核の一部（slack 0 の混合型）を閉じる段です。slack が正の部分は、別に残ります。
- **この §11 は、正しさの監査が特に要ります**（あとの土台になるため）。とくに 11.3 の 2（ほかの類の領域での零点の数え方、T/4 の公式）と 3（不等式の整理）。
