## 1. Corvaja–Zannier の gcd の評価

**出典（本文で確認）。** P. Corvaja、U. Zannier, *Some cases of Vojta's conjecture on integral points over function fields*, J. Algebraic Geom. 17 (2008) 295–333（arXiv math/0512074）、系 2.3。

**主張。**
- κ は標数 0 の代数閉体、C̃ は種数 g の曲線、S は空でない有限集合、χ = #S + 2g − 2 です。
- a、b を S 単数とします（両方が定数ではない）。H(·) は写像としての次数です。
- a、b が（定数を法として）乗法的に独立なら、
  **Σ_{v∉S} min{v(1 − a), v(1 − b)} ≤ 3·2^{1/3}·(H(a)H(b)χ)^{1/3}**
  です。
- 定数 3·2^{1/3} は、(4/3)^{1/3} より小さくはできません（論文の例 a = t³、b = −t(t + 1)）。

**当てはめ。**
- 一致点 (β₁, β₁′) での W の重複度を数えるには、u = (p₁ − β₁)/(p₁ − β₂)、w = (p₂ − β₁′)/(p₂ − β₂′) のような S 単数を使います。
- S は p₁⁻¹{β₁, β₂} ∪ p₂⁻¹{β₁′, β₂′} を含まなければならないので、χ ≈ 2(a + b) です。
- 均衡した場合（a = b）は、1 点あたり 3·2^{1/3}·(a·a·4a)^{1/3} ≈ 6.0a になります。
- 必要なのは、12 個の一致点の合計で M ≤ (1 − c)(a + b)、つまり 1 点あたり平均で約 a/6 です。
- **約 36 倍足りません。** 定数を最良の (4/3)^{1/3} に替えても、約 1.75a で、10 倍ほど足りません。
- E16 §4 の「χ が a の 1 次なので、評価も 1 次」と一致します。

## 2. Yamanoi（と McQuillan）の強い abc（移動標的つきの第二主定理）

**出典。**
- K. Yamanoi, *The second main theorem for small functions and related problems*, Acta Math. 192 (2004) 225–294。Springer の本文はログインが要るので、読めていません。
- 主定理の形は、C. Gasbarri のブルバキ報告（Exp. 989、arXiv 0811.3153）の定理 2.1 で確認しました。McQuillan と Yamanoi が独立に証明したものです。

**主張（Gasbarri 定理 2.1）。**
- p : X → B は滑らかな射影曲面から曲線への射で、D は正規交差の因子、ε > 0 です。
- 曲線 Y と f : Y → X（像が D に含まれない）について、
  **(K_X(D)·Y) ≤ (1 + ε)(N_D^{(1)}(Y) + χ(Y)) + O_ε([Y : B])**
  です。
- N_D^{(1)} は、打ち切り（重複度を 1 に切った）の数え上げ関数です。定数は X、D、p、ε だけで決まります。
- 小さい関数（移動標的）の版では、標的が f に比べて「小さい」ことが仮定です。

**当てはめ。**
- X = P¹ × P¹、Y = V₀、D = 6 本の水平線と 4 本の Klein のグラフです（E16 §4 の設定）。
- **誤差の項 O_ε([Y : B])。** P¹ × P¹ の基点のない鉛筆のどれをファイバーに取っても、[Y : B] = W·F ≥ min(a, b) です。均衡した場合は、主要な項と同じ大きさです。
  - Gasbarri §5 も、この定理を使うときは lim [Y_n : B]/(高さ) = 0 を仮定しています。この問題では、その比は 0 に行きません。
- **誤差を 0 にしても足りません（E16 §4）。** 主要な項だけで 2j ≤ (6 + 2ε)a + s₂ です。矛盾には j > 3a が要りますが、均衡した場合は j ≈ 2a なので、1.5 倍足りません。
- (q − 2) の形の第二主定理は、それ自体が最良です（等号の例がある）。標的を増やすしか道はありませんが、ラベルを保つ標的の曲線は Klein のグラフのほかにありません（E16 §4）。
