## 1. §2 の偶奇の表

| 型 | h | |Ω| | δ（g） |
|---|---|---|---|
| (1,1) | 0 | 2 | 2（g = 0） |
| (1,1) | 1 | 3 | 4（g = 0） |

## 2. 命題 T

### 2-1. 鏡映の被覆

- s₁ : x ↦ −x、s₂ : x ↦ 1 − x（mod n）は対合で、積 s₁s₂s₂s₁ = 1、生成する群は推移的。互換の数: n が奇数なら各 (n−1)/2、偶数なら s₁ が (n−2)/2、s₂ が n/2。どちらも合計 2n − 2 なので種数 0、余り 0。
- 奇点の数: ラベル e の上には s₁ と s₂ が一つずつ乗るので、固定点の数の和 = 2（n の偶奇によらず）。b も同じ。a（±i）の上はモノドロミーが恒等で 2n 点。よって (2, 2, 2n)。正しい。`dihedral_check.py 60` を再実行して PASS。

### 2-2. 組の作り方

- 1（(1,1) 型）: φ が O₁ ∖ {u} を動かさず、O₁ の外の点 w を u に送る（u は O₁ の外へ）とする。p₂ = p₁ ∘ φ の奇点の集合は φ⁻¹(O₁) = (O₁ ∖ {u}) ∪ {w}。共通の点では p₂ = p₁ なのでラベルが一致し h = 0。w のラベルは p₁(u) のラベルと同じなので、§2 の表の (1,1)・h = 0 の条件も満たす。正しい。2（(2,2) 型）も同じ。
- 3（(1,3) 型）: 共通の点に要るのは「ラベルが同じ」だけで、B の同じ点である必要はない（E10 §2 の j の定義）。数え方 (2,2,2n) − (0,0,1) = (2,2,2n+2) − (0,0,3) は正しい。球面の同相写像群は有限個の点について何重にも推移的なので、ラベルを保つ対応（と、残りの 3 点を O₁ の外へ送ること）は同相写像に延びる。Ω の 4 点はすべてラベル a で、和 0、δ = 2、g = 1。正しい。

### 2-3. 「意味」の段落の範囲

- 主張そのもの（列挙した条件はすべての次数で満たせる）は証明されている。
- 「位相だけで決まる条件では閉じない」の「位相だけ」は、各脚の分岐の形・点の対応・ラベルのこと。曲線 W が正則であることを使う議論（たとえば E12 で使った、ラベルを保つ Möbius のグラフとの交点数 W·Γ = a + b が局所的に正であること）は、位相の組では符号つきの数にしかならないので、命題 T の外にある。E25 は交点の議論を §1 の表の別の行（E20 で済み）で扱っていて、命題 T がそれまで締め出すとは書いていない。ただ「意味」の一文は広く読めるので、「（交点の正値性のように正則性を使うものは除く）」と添えるとよい（任意、数値は変わらない）。

## 3. 命題 M

1. Lüroth: V₀ = P¹ なので C(p₁, p₂) = C(κ)。正しい。
2. 分岐の指数は掛け算 e_v(p_i) = e_v(κ)·e_{κ(v)}(c_i)。p_i が B の外で分岐せず指数 ≤ 2 なので、c_i も同じ。余り 0 は「B の外で分岐しない、B の上の指数が 1 か 2」と同値（RH から 2n − 2 = Σ(n − o_β)/2）なので c_i も余り 0。κ の分岐点 v では e_{κ(v)}(c_i) = 1 かつ c_i(κ(v)) ∈ B、つまり κ(v) ∈ O_{c₁} ∩ O_{c₂}。正しい。
3. O_{p_i} = {v : κ が v で分岐しない、κ(v) ∈ O_{c_i}}、ラベルは c_i(κ(v)) のもの。κ は O_{c₁} ∖ O_{c₂} の上で分岐しないので、その上の k 点はすべて O_{p₁} ∖ O_{p₂}。型は k 倍。正しい。
4. (1,1)、(2,2)、(1,3)、(3,1) のうち k ≥ 2 倍で書けるのは (2,2) = 2·(1,1) だけ。正しい。(a, a+1) は k | a、k | a+1 から k = 1。
5. κ の分岐点はどちらの O_{p_i} にも入らないので Ω にも入らない。分岐しない点では「Ω に入るか」が κ(v) で決まる。だから Ω_p は Ω_c の分岐しない逆像。|Ω_p| ≤ 4 なら Ω_c のうち u, w 以外はすべて κ の分岐値で |Ω_c| ≤ 4。(c₁, c₂) の型 (1,1) は k 倍で書けないので、1〜4 を (c₁, c₂) に当てはめて双有理。正しい。

- 数値の確かめ（`compose_types.py`）: c₁ = id、c₂ = U（|B ∩ U⁻¹B| = 3 または 4）、κ = A(z²)（分岐値は B ∩ U⁻¹B の 2 点）で作った 432 例すべてで、p の型 = 2 × c の型、ラベルの違う共通点の数 = 2 × （κ が分岐しない c の側の数）、|O_{p_i}| = 2·2 + 4。PASS。
- 「意味」の段落: E14 命題 C の塔は O₁ = O₂ の組（Ω = ∅）を合成で増やすもの。混合型の双有理でない組は、命題 M により「半分の次数の本物の解の 2 重化」に限り、2 重化をもう一度すると (4,4) 型で混合型ではない。だから混合型には塔がない、という読みは正しい。「原理的な壁がない」は「この壁がない」という意味で、道具が効くことの証明ではない（本文もそう書いている）。

## 4. §4（Hecke 型でない部分的な一致）

### 4-1. Möbius の補題

- 主張: |B ∩ U(B)| = 5 となる Möbius U はない。だから |B Δ U(B)| = 2(6 − |B ∩ U(B)|) は 0 か 4 以上。
- 本文の理由（5 点の中の正方形はただ一つ、正方形を正方形に送る Möbius は八面体群に入る）を確かめた: B の 4 点のうち複比が調和（−1 の類）になるのは、対蹠の 2 組からなる 3 つの正方形だけ（{0, ∞, 1, i} 型の 12 個は複比 i の類）。調和な 4 点を保つ Möbius は 8 個で、すべて八面体群の正方形の固定群に入る。
- `mobius_overlap.py`: B の順序つき 3 点から B の順序つき 3 点への Möbius 120 × 120 個を Q(i) の上で厳密に作り、|B ∩ U(B)| を数えた（`mobius_overlap.out`）。結果は {3: 4,608, 4: 6,912, 6: 2,880}（重複込み）で、**5 は一度も出ない**。6 の 2,880 = 24 × 120 は八面体群の 24 個にあたり、検算になっている。
- 素数次数 k での帰結（双有理でない組は p_i = c_i ∘ κ、|O₁ Δ O₂| = k|B Δ U(B)|、よって |Ω| ≤ |O| か |Ω| ≥ 4k）も導き直した。κ は B₁ ∩ B₂（B_i = c_i⁻¹(B)）の上だけで分岐し、B₁ ∖ B₂ の上の k 点はすべて O₁ ∖ O₂ に入る。正しい。
