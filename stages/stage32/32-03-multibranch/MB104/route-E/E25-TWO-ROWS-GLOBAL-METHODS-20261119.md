## 0. 2 列の中身（E13 §0、E14 A⁺ の整理）

型 (m₁, m₂) = (|O₁ ∖ O₂|, |O₂ ∖ O₁|)、b − a = (m₂ − m₁)/2。入れ子型は A⁺ で済み、(0, 0) は等号面（E03/E04）。残りは

| 列 | 残る型 | 共通の錐点 |O₁ ∩ O₂| |
|---|---|---|
| (a, a) | (1, 1)、(2, 2) | 2a + 3、2a + 2 |
| (a, a+1) | (1, 3)（と左右を入れ替えた (3, 1)） | 2a + 3 |

## 1. 試した方法と結果

| 方法 | 結果 | 理由 |
|---|---|---|
| 分岐の数え上げ（RH、ラベルごとの奇点の数 n_χ = 2n − 2t_χ） | 効かない | Kummer の偶奇（各 h_χ の奇点の数が偶数）と同じ情報。次数によらず満たせる（§2 の表、命題 T） |
| パリティ・不変量（G = (Z/2)³ への写像、δ） | 効かない | V₀ = P¹ では G への写像は局所のラベルで決まる。新しい情報はない（E20 §A と同じ結論を、別の側から確認） |
| モノドロミー・群論（E20 §E の候補 1） | **原理的に効かない** | 命題 T |
| 対称性（V × V、Aut(B)、脚の入れ替え、複素共役） | 効かない | 解を軌道にまとめるだけ。「数が 0」は出ない |
| 交点理論・Hodge 指数・種数の偶奇 | 効かない | E20 §A, §F で済み（δ = 8 の類は β^*O(a, b)、(a, a) で Hodge は等号で自明） |

| 「5 点以上一致すれば Hecke 型」という剛性 | **データで反証** | §4 |

## 2. 偶奇の表（型ごとに、ありうるラベルの並びと δ）

Ω の各点は、どの h_χ が奇数位数か、を表すベクトル（G の元）を持つ。O₁ ∖ O₂ や O₂ ∖ O₁ の点はラベル χ の単位ベクトル e_χ、
ラベルの違う共通点は e_χ + e_ψ。条件は「和が 0」、δ = 張る部分群の位数。RH は 2g − 2 = −2δ + (δ/2)|Ω|。

| 型 | h | |Ω| | ラベルの条件 | δ | g |
|---|---|---|---|---|---|
| (1, 1) | 0 | 2 | u と w が同じラベル | 2 | 0 |
| (1, 1) | 1 | 3 | {u, w} のラベル = 違う点の 2 ラベル（u ≠ w） | 4 | 0 |
| (1, 1) | 2 | 4 | 和が 0 | 4, 8（監査で訂正: 2 は起きない） | 1 |
| (2, 2)、(1, 3) | 0 | 4 | 4 点で各ラベルが偶数回 | 2 または 4（**8 は不可**） | 1 |

- 小さな副産物: **(2, 2) 型と (1, 3) 型では δ ≤ 4**。3 つ目の h_ψ は平方になる。d = δ(a + b) は最大の場合 8(a + b) にならない。ただし、次数の上限にはならない。

## 3. 命題 T — 位相だけの条件はすべての次数で満たせる [proved]

**主張.** すべての n ≥ 1 について、次の「位相的な組」がある。どれも §2 の表の条件、E10 §2、E12 Lemma 0 など、
**各脚の分岐の形と、点の対応とラベルだけで決まる条件**をすべて満たす。

1. (n, n)、型 (1, 1)、h = 0、|Ω| = 2。
2. (n, n)、型 (2, 2)、h = 0、|Ω| = 4。
3. (n, n + 1)、型 (1, 3)、h = 0、|Ω| = 4（Ω のラベルは 4 点とも a）。

**作り方.**
- slack 0 の被覆はすべての次数にある。例: 正 n 角形の 2 つの鏡映 s₁ : x ↦ −x、s₂ : x ↦ 1 − x（mod n）で、
  (0, ∞, 1, −1, i, −i) の上のモノドロミーを (s₁, s₂, s₂, s₁, 1, 1) とする。積は 1、推移的、互換の数の和は 2n − 2。
  ラベルごとの奇点の数は (e, b, a) = (2, 2, 2n)（`e25/dihedral_check.py`、n ≤ 40 で PASS）。
- 1 と 2: p₁ を上の被覆、φ を球面の同相写像で、O₁ の 1 点（2 点）を O₁ の外の点に動かし、残りの O₁ を動かさないものとする。
  p₂ := p₁ ∘ φ。共通の錐点では p₂ = p₁ なのでラベルは一致する。
- 3: 次数 n と n + 1 の上の被覆では、奇点の数が (2, 2, 2n) と (2, 2, 2n + 2)。O₁ からラベル a の点 u を 1 つ、
  O₂ からラベル a の点を 3 つ除くと、どちらも (2, 2, 2n − 1)。ラベルを保つ対応を同相写像に延ばせばよい
  （球面の有限個の点の並べ替えは、いつも同相写像に延びる）。

**意味.** 本物の解との違いは、ただ一つ、**p₁ と p₂ が同じ複素構造に対して正則であること**（φ が等角であること）だけ。
これは位相では見えない。だから、分岐の数え上げ・パリティ・モノドロミー・群論・対称性の議論は、2 列を全次数で閉じられない。
（交点の正値性のように、W が正則であることを使う議論はこの外にある。§1 の表の交点理論の行を見よ。）
効きうるのは、複素構造（距離・等角性）を見る道具（E13/E19 の系統。床は約 10^9.5）か、被覆の数論（知られた道具なし）だけ。

- 補足: 和が 2n − 2 で各成分 ≤ n/2 の 6 つ組の分岐の形は、n ≤ 5 では**すべて**実際に現れる（n = 4: 141/141、
  n = 5: 90/90）。n = 6 では 486/546 で、(3, 3, 3, 1, 0, 0) の並べ替え 60 個だけが現れない（Hurwitz の例外。
  `hurwitz_6.out` でもこの形の数は 0）。〔監査で訂正: 初版は「546/546」としていた。〕位相の側には制約がほとんどない。
  命題 T の証明はこの補足を使わない。

## 4. 部分的な一致は Hecke 型の構造なしに起きる（データ）[computed、既存の記録から]

- 発想: 「共通の錐点が 5〜6 個を超えて一致するなら、二つの被覆は Hecke 型に関係する」という剛性があれば、
  混合型（2a + 2 個以上の一致が要る）は全次数で消える。
- 反証: E21/E24 の照合の記録（`slack0/speedup-20261118/logs/search2_55.log`、`slack0/fast40-20261118/logs/`）。
  - 素数次数 k での双有理でない組: p_i = c_i ∘ κ（c_i は Möbius、deg κ = k）。O_{p_i} は c_i⁻¹(B) の κ による逆像なので、
    |O₁ Δ O₂| = k·|B Δ U(B)|（U = c₂c₁⁻¹）。B の 5 点を含む集合には正方形（調和な 4 点）が一つだけあり、それを正方形に写す
    Möbius は八面体群に入るので、|B Δ U(B)| は 0 か 4 以上。よって双有理でない組は |Ω| = h ≤ |O|（O₁ = O₂ のとき）か
    |Ω| ≥ 4k。**|O| < |Ω| < 4k の組は双有理**（Hecke 型ではない）。
  - (5, 5): |O| = 14、4k = 20。|Ω| = 16、18 の組が約 1,000 ずつある → 双有理。|Ω| = 28 − 2j − h = 16 から
    |O₁ ∩ O₂| = j + h = 12 − j ≥ 6（j ≤ 6）。
  - (7, 7): |O| = 18、4k = 28。|Ω| = 24（9 組）、26（42 組）→ 双有理。24 のとき |O₁ ∩ O₂| ≥ 6。
- 結論: 6 個以上の錐点が一致する、Hecke 型でない組は実際にある。**少数の点の一致からの剛性はない。**
  一致の大部分を使う議論（E13 定理 B の「深い集まり」、E19）しか残らない。
- 注意: 照合は「4 点組の表」で候補を作り、あいまいな候補を飛ばすので、この記録から「一致の最大個数」や
  その次数による伸び方は読めない（数え落としがある）。

## 5. 命題 M — 混合型の「双有理でない見かけの解」[proved]

**主張.** (p₁, p₂) を余り (0, 0)、混合型、|Ω| ≤ 4 の組とする。双有理でないなら、a = b は偶数、型は (2, 2) で、
p_i = c_i ∘ κ（deg κ = 2）。ここで (c₁, c₂) は双次数 (a/2, a/2)、余り (0, 0)、型 (1, 1)、|Ω| ≤ 4 の**双有理な**組
（つまり Problem W の本物の解）。特に

- (a, a + 1) の列の組はいつも双有理（κ の次数は a と a + 1 を割る）。
- 混合型に解がない次数の範囲では、双有理でない混合型の組もない。E21〜E24 で見つかった双有理でない組が
  すべて (0, 0) 型（Hecke 型の合成。例: (7, 7) の記録の「points matched 30/30」）だったことと合う。

**証明.**
1. Lüroth: 双有理でなければ C(p₁, p₂) = C(κ)、deg κ = k ≥ 2、p_i = c_i ∘ κ。
2. p_i は B の上だけで指数 ≤ 2 で分岐する。だから c_i も B の上だけで指数 ≤ 2 で分岐し、RH から c_i も余り 0。
   κ の分岐点 v（指数 2）では p_i の指数 = 2·e_{κ(v)}(c_i) ≤ 2 なので、κ(v) は O_{c₁} ∩ O_{c₂} の点。
   よって κ は O_{c₁} ∩ O_{c₂} の上だけで分岐する。
3. O_{p_i} = {v : κ が v で分岐しない、κ(v) ∈ O_{c_i}}、ラベルは κ(v) のもの。κ は O_{c₁} ∖ O_{c₂} の上で分岐しないので、
   **型は k 倍になる**: (m₁(p), m₂(p)) = k·(m₁(c), m₂(c))。
4. 混合型 (1, 1)、(2, 2)、(1, 3)、(3, 1) のうち、k ≥ 2 倍で書けるのは (2, 2) = 2·(1, 1) だけ。
5. Ω_p は Ω_c の、κ が分岐しない逆像。u, w（O_c の差）は分岐点にならないので |Ω_p| ≥ 4。|Ω_p| ≤ 4 なら、
   Ω_c のラベルの違う点はすべて κ の分岐点の像で、|Ω_c| ≤ 4。(c₁, c₂) の型 (1, 1) は k ≥ 2 倍で書けないので、
   (c₁, c₂) は双有理。□

**意味.** E14 命題 C は「O₁ = O₂ の組では、双有理性を見ない議論はどれも次数を抑えられない」（(L_n, −L_n) の塔）。
混合型にはこの塔がない。だから、距離や holonomy だけを見る議論（E13/E19 の系統）が混合型で効くこと自体には、
原理的な壁はない。E19 が混合型に有限の上限を出せたのは、このためと言える。

## 6. 正直な位置づけ

- 「全次数まとめて」の道具は見つからなかった。命題 T により、位相・数え上げ・偶奇・対称性の系統は**原理的に**効かない。
- 残る道は二つ。(i) 複素構造を見る解析の道具（E19 の系統。今の床は約 10^9.5、直接計算は次数 7）。
  (ii) 被覆の数論（定義体、還元、高さ）。(ii) で「同じ曲面に二つの算術的な錐構造が乗る」ことを禁じる定理は、知らない
  （E20 §C の「起こりにくい交わり」と同じ形）。
- 前回までの「組になれない理由」「ほぼ対称」（`pairing-obstruction-sieve`、E20 §F.4）は、**一組ごと**の条件を絞り込みに
  使う話だった。今回は**次数によらない大域の不変量**を探した。違う種類の道だが、命題 T がその種類全体を締め出す。
