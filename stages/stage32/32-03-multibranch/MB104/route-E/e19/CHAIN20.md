## 結果

| 量 | 値（C_X = 2） | C_X を 1〜10 に動かすと |
|---|---|---|
| C₀ | 4.05 | 3.36〜5.66 |
| R₀ | 12.31 | 12.31〜12.73 |
| N_v(R₀)（欠損一つのまわりの頂点の上限） | 約 7.8·10⁵ | 同程度 |
| **混合型 slack (0,0) の次数の上限 a_max** | **約 10^{58.7}** | 10^{58.4}〜10^{59.4} |
| **正の slack: b ≤ C′·S の C′** | **約 10^{58}** | — |
| 閉じる slack の密度 ρ = S/b | ρ ≲ 10^{−58} | — |
| 原理的な限界（深い所が残る条件、§17.3） | ρ ≲ e^{−R₀} ≈ 4.5·10⁻⁶ | — |

- 上限を決めているのは、どの場合も**運べない深い点（b^{0.90} の項）**です。欠損のまわりの M(R₀) ではありません。
- 正の slack の C′ は、S によらず一定でした（10、10³、…、10²⁴ で同じ）。「b ≤ C′·S」の線形の形と合います。
- 指数 0.90 から、上限は（定数）^{10} の形になります。10^{58} の大きさは、これで説明できます。

## どの入力が効くか（C_X = 2 で一つずつ変えた）

| 変えたもの | log₁₀ a_max |

| そのまま | 58.7 |
| R_seed 10.78 → 4.98（ANSWER-09 の半径） | 58.4（ほぼ動かない） |
