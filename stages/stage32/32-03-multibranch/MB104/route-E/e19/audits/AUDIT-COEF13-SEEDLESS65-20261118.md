## 1. §15.1：悪い点の係数 1/3

### 1.1 形（係数 1/3）は正しい [確認]

- 隣り合う良い点 x、x′（深さ t、t′、一番近いアンカー c、c′ までの距離 s、s′）。運ぶ道 c → c′ の長さは s + s′ + ℓ 以下（ℓ = ℓ_min = 1.5286）。
- その道は H に持ち上げた測地線で、距離関数の凸性から、点はすべて x から max(s, s′ + ℓ) 以内。だから道の深さは t − s − O(1) 以上。
- 定理 T（§9.2）の条件「長さ < 深さ − C₀」は、2s + O(1) < t − s − O(1) − C₀、つまり **s < (t − κ)/3**。係数 1/3 は正しい釣り合いです。
- 道を測地線に置き換えるときに欠損をまたがない（深さが正のまま）ことも確かめました。
- 指数 3/(3 + c) = 0.9016、単連結なら 3/4、も式どおりです。

### 1.2 定数 4.06 は足りない [指摘・定数]

本文は s′ ≤ s（対称）と、今の段の道の深さだけを使っています。実際には:
- s′ は s + ℓ まで大きくなれる（x′ は x の隣なので）。
- §9.2 の条件は **min(R_{k−1}, R_k)**、つまり一つ前の段の道の深さも要る。

これを入れて解くと（前の段も隣の頂点 x″ から来る場合）、
  3κ ≥ 3C₀ + 3 + 8ℓ、つまり **κ ≥ C₀ + 1 + 8ℓ/3 = C₀ + 5.08**（本文と chain20 は C₀ + 4.06）。

### 1.3 前の段の回転：書かれた形では穴がある（直せる、log の損）[指摘・穴]

- 一つのアンカー c を「一番近いアンカー」とする頂点は、c のまわり半径 s ほどの範囲に広がります。その中で深さは ±2s ほど違いえます。
- 鎖が c に浅い側から入り、深い側へ長い段で出ていくと、§9.2 の min(R_{k−1}, R_k) の R_{k−1}（浅い入り口の段）が足りず、条件「L_k < R_{k−1} − C₀」が定数のずれでは済みません。**1.2 の「隣の頂点どうしなら深さは O(1) しか違わない」は、同じアンカーを共有する頂点が多いと使えません。**
- 直し方: 補題 T2 の (3) を、一様な ε ではなく点ごとの ε(z(s)) で積分し直す（(1)・(2) は局所的なので、そのまま使えます）。c での回転角は
  θ ≲ C ∫ ε(z(s)) e^{−s} ds ≤ C (1 + L_{k−1}) e^{−深さ(c)}
  となり、**入り口の段の浅さではなく c の深さで決まります**。損は因子 (1 + L_{k−1}) だけで、κ に log(1 + 深さ) が足されます。
- 帰結: 悪い点の数は a^{0.90}·(log a)^{c/3} の程度。**次数より小さいことは変わらず、有限性は保たれます。** κ は定数でなくなるので、chain20 の「定数の鎖」はこの項を入れて書き直す必要があります。

## 2. §15.2：種のない成分と係数 65

### 2.1 組み立て直しの筋道は正しい [確認]

- 良い頂点（1 の意味）の連結成分ごとに分けると、隣り合う良い頂点は定義から同じ成分なので、**(c)「境目はすべて悪い頂点の隣」は自動的に成り立ちます**（監査で心配されていた N 型と種のない成分の接触は、定義上起きません）。
- (a) 種を持つ成分: g ∈ N(Γ₀) なので g·Fix(Γ₀) = Fix(Γ₀)、δ₁ = ℓ_min で一様。成分の中の鎖で全体を運べる（1.3 の直しのもとで）。二つの種が違う g を出すことはない（二つのアンカーで一致する向きを保つ等長写像は一つ）。
- (b) 種のない成分の数え上げを導き直しました:
  - 星の中の距離（k = 1〜4 で 1.5286、2.4485、2.9140、3.0571）を計算で確認。sinh² d のノルムは −4、−32、−36、−64 で、**奇素数が出るのは k = 3（素数 3）だけ**。表と一致します。
  - 錐点どうしは隣り合えない（距離 ℓ_min は種）。滑らかな頂点のまわりの錐点は 2 個以下（差が ±3 mod 8 の組だけ。{0, 3} が最大）。
  - 錐点と滑らかな頂点の辺を数えて 4|C_内| ≤ 2(|S_内| + |S_境|)。**「錐点は頂点の 1/3 以下」は正しい**です（境界の項を除いて）。

### 2.2 Gauss–Bonnet の段の不等式の向き [指摘・小]

- §14.4 の「= 6(2 − k) ≤ 6」は、ここで要る向きと逆です。要るのは内部の和の**下からの**評価で、そのためには境界の数 k を上から抑える必要があります。
- 正しくは: 境界の各円は頂点 3 個以上なので k ≤ |∂H|/3。これで
  |S_内| ≤ 6k − 12 + 3|∂H| ≤ 5|∂H|、|C_内| ≤ 3|∂H|、**内部 ≤ 8|∂H|**。§15.4 の「内部 ≲ 8·|∂H|」は、この補いのもとで正しい値です。

### 2.3 係数 65 は数え落とし、少なくとも 73 [指摘・定数]

- chain20 の 65 = 1 + 64 は「悪い頂点 1 ＋ 内部 8 × 境界 8」です。
- しかし種のない成分の**境界の頂点そのもの**（悪い頂点の隣の良い頂点、合わせて 8·M_bad 個以下）も、定理 C では「良くない頂点」に数えなければなりません。
- したがって **1 + 8 + 64 = 73** です。
- くびれ（境界の円が頂点を共有）や穴がある場合、§15.4 は「近くを太らせて扱う」とだけ書いています。安全側に、穴の数を「境界の頂点と悪い頂点の隣接の組」で数える一般の形で導くと、係数は約 169 になります（形は線形のまま）。

## 3. chain20 の小さな点 [指摘・定数]

- 運べない深い点を面積から頂点の数に直すところで、指数が −c((t − κ)/3 − 1) になっています。頂点のまわりの半径 ℓ/2 の円板は U_{r − ℓ/2} に入るので、正しくは −c((t − κ)/3 − 1 − ℓ/2)（因子 e^{0.25} の差）。
