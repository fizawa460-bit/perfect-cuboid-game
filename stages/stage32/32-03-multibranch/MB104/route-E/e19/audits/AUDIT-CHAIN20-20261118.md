## 結論

- **鎖の順序と使っている式は、おおむね E19 本文どおり**です。循環もありません（ε₀ → R_seed → K → C₀ → R₀ → M(R₀) → 運べない深い点 → 上限）。
- ただし、**数値に誤りが一つ、ゆるい計算が一つ**あり、上限 **10^{58.7} は約 2 桁大きすぎ**ます。E19 の式どおりに計算し直すと **約 10^{56.7}**（C_X = 1〜10 で 10^{56.4}〜10^{57.4}）。
- 「種のない成分」の係数 65 が境界の頂点を数え落としている疑いがあり、73 にすると **約 10^{57.3}** です。
- **CHAIN20.md の結論の形（上限を決めるのは運べない深い点、指数 0.90 で（定数）^{10}、効くのは c と係数 1/3 だけ、ρ ≲ 10^{−5x} が閉じる帯）は変わりません。** 変わるのは桁の数字だけです。
- 正の slack の C′ も同じ直しで 10^{58.06} → **10^{56.14}**。

## 式どおりと確かめたもの

- ℓ_min = arccosh(1 + √2) = 1.5286（角 π/4 の正三角形の辺）、ℓ₀ = 2ℓ_min = 3.0571、λ₀ = min(π sinh 1, ℓ₀) = ℓ₀、c = 1/(1 + 2π/λ₀) = 0.3273（§13.2）。
- ε(R) = −log tanh(R/2)（§7.2）。ε(10.78) = 4.162·10⁻⁵。
- K = 7.647: 式（単位円板の Poincaré 模型、r = tanh(1/2)、調和部分の勾配 (2/r)sup、Green 部分 r·sup|f|、双曲の勾配は ÷2）を手で追って同じ値。Green 部分の真の係数は 2r/3、調和部分は 4/(πr) なので、どちらも保守的（導出の妥当性そのものは範囲外）。K は ε(R_seed) で固定だが、深さによる変化は 10⁻⁴ 程度で無視できる。
- 運搬の誤差 E(L) = 3·C_X·K·ε·sinh L（§7.2(3) の積分 ∫cosh = sinh、§9.2 の係数 3）。
- 悪い点のしきい値 (t − C₀ − 4.06)/3（§15.1 は 4.1、本文の内訳 1.53 + 2.5 = 4.03。違いは保守側で無視できる）。
- N_v(R) = (cosh(R + ℓ/2) − 1)/(cosh(ℓ/2) − 1)（H の球の詰め込み、§15.4）。R = 4 で 188 ≥ 本文の実測 89。N_v(12.31) = 7.8·10⁵。
- 定理 C: a ≤ 11 + 216.3·M_bad（§12.2）、欠損 4 個、面積 2πa（三角形 8a 枚 × π/4）、補題 P の A(U_r) ≤ 2πa·e^{−c(r − 1)}（§13.3）、t₀ で分ける形（§17.2）。
- 指数 3/(3 + c) = 0.9016、1/(1 − 指数) = 10.17（「（定数）^{10}」と合う）。
- 原理的な限界 e^{−R₀} = 4.51·10⁻⁶、e^{−R_seed} = 2.08·10⁻⁵。
