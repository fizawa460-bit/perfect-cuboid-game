## 2. (1) の補足: δ ≤ 4 の混合型で E09 の盲点は変わるか [見立て＋簡単な計算]

- E10 §4 の盲点の計算は δ = 8（Q が自明）の場合。E25 §2 によれば (2, 2) 型と (1, 3) 型では δ ≤ 4 なので、Q に自明でない χ がある。
- E10 §3 の式で、分かれる場合の寄与は I_χ − 2ab = 2|φ_χ|²（|φ_χ|² は φ_χ の次数。Bolza の部分では tr(φφ†)/2）。
  導き方: Ȳ_χ の二つの射影の次数は a, b。Ȳ² = Ȳ′² と Ȳ² + Ȳ·Ȳ′ = 4ab、および E_χ×E_χ の上で Ȳ² = 2ab − 2|φ_χ|²。E04 の検算（楕円で I = 4 ⇒ |φ|² = 1、自己同型）と合う。
- E09 のおおよその判定 C̄² < d²/32（d = δ(a + b)）は、**Σ_{χ∈Q} |φ_χ|² > ab − (a + b)²/8** と同じ。a = b なら Σ|φ_χ|² > a²/2。
- 一方、Ȳ_χ の正規化（共通のラベル χ の奇点で分岐する超楕円曲線、種数 g_χ）から |φ_χ|² ≤ ab − g_χ + 1（随伴公式）。
- つまり E09 が効くのは、二つの脚の持ち上げ f₁, f₂ : Ỹ_χ → E_χ が「ほぼ平行」なときだけ。これを強いる仕組みはない（E20 §F.3「はみ出しに下限がない」と同じ）。Q の自明でない元が種数 0 の指標なら寄与は 0 で、δ = 8 と同じく盲点のまま。
- 結論: δ ≤ 4 にしても盲点は閉じない。

## 3. (3) の補足: 周期の条件はどこに入っているか [proved の照合＋見立て]

- 種数 1 の曲線 E（像の曲線の正規化）は、Ω の 4 点で分岐する V₀ = P¹ の (Z/2)^s 被覆。j(E) は Ω の複比で決まる。
- E から C8 の楕円商 E_χ への写像による周期の条件は出ない: 対応 Z ⊂ C8×C8 を E = Z/ΔG に押し出すと、H¹(C8) から H¹(E) への写像は G 不変な部分 H¹(C8)^G = 0 を通るので 0（q(B̂) = 0 と同じ）。
- 周期が効くのは分かれる場合の φ_χ ∈ End(E_χ) = Z[i]（F83）だけで、それは §2 の |φ_χ|² そのもの。整数性で値は離散的になるが、0 も許されるので下限にならない（E20 §F.4）。
- 結論: 周期の格子は、すでに使っている「ほぼ対称」の条件以上を言わない。

## 4. (4) 小さい素数での還元 [見立て]

- B = {0, ∞, ±1, ±i} は 2 以外のすべての素数で良い還元を持つ（x⁴ − 1 の判別式は −256）。Kummer の (Z/2) 被覆は p ≠ 2 で穏やか。
- p > max(a, b) では、余り 0 の被覆は良い還元を持ち、標数 0 の解と標数 p の解は 1 対 1（Grothendieck の穏やかな基本群、Beckmann）。これは E11・E12 の F_p 計算の土台で、**計算の道具であって次数の上限にはならない**。
- p = 3（3 ≤ a）では被覆は荒い（wild な）還元をしうる。安定還元すると V₀ は P¹ の木になり、脚は成分ごとに非分離（フロベニウス）を含みうる。
  - 還元は「解があれば標数 3 に何かがある」という**必要条件**しか出さない。
  - 標数 3 では非分離写像や荒い分岐が許されるので、条件を満たす配置は**増える**向き。「標数 3 に解がない」を示す道具（Raynaud、Wewers、Obus の安定還元の理論）は、構造を記述するだけで非存在は言わない。
- p = 2 では B 自体が悪い還元（±1, ±i が 1 に集まる）で、しかも偶奇（Z/2）の条件が荒い分岐になる。偶奇の情報が壊れる。
- 結論: 小さい素数での還元は、2 列を閉じる道具にも、下界を上げる道具にもならない。

## 5. ほかに挙げうる性質（簡単な見立てだけ）

- **高さ（係数の大きさ）**: Bilu–Strambi の型の「被覆の高さの上限」はあるが、組になると高さが小さくなる・大きくなるという下限側の道具は知らない。上限だけでは矛盾にならない。
- **Galois 軌道**: 解の集合は有限な Galois 集合だが、余り 0 の被覆はどれも算術的にきれいなので区別できない（E26 の結論と同じ）。
