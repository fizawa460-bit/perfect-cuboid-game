# F-03 — 楕円型 (E) の slack 0 の組で、一致の数 c を高い次数まで正確に測る（2026-11-14）

状態: **測定です。定理ではありません。** credit 0。

- スクリプト: `f03_isogeny_pairs.py`（mpmath、既定 60 桁。環境変数 `F03_DPS` で桁数を変更可）、`f03_nearmiss.py`（記録した T の作り直しと、近い組の確認）。
- 模型: THEORY-02 の 2 同種写像の鎖を mpmath で書き直したもの。E′: y² = x(x+1)(x+i)、B′ = {0, ∞, −1, −i}、k2(x) = −(x+i)/(x+1)。組は (p_c, k2∘p_c′)（c, c′ は鎖のつなぎ方）。
- 探し方: 4 点の組の複比をすべて照合する厳密な探索です。倍精度のふるいは使っていません。一致は弦距離 10⁻⁴⁰ 未満としました。
- 途中結果の `*.jsonl` は大きい（次数 16 で 47 MB）ので、git には入れていません。`*_summary.json` と `*.log` が結果です。

## 次数 16 の精度の確認

- 60 桁では、一致しない組の最小距離が 1.004×10⁻⁴⁰ で、境目のすぐ外でした。精度が足りていなかったということです。
- 90 桁でやり直すと、T の数も内訳も 60 桁と同じでした。数えもらした一致はありません。
- `f03_nearmiss.py` で、記録した 143,364 個の T を 90 桁で作り直しました。
  - 記録した一致は、すべて再現しました（誤差は最大 2.1×10⁻⁶⁴）。
  - 60,732 個の T には、一致しないけれど距離が 10⁻¹⁵ より小さい組があります。いちばん近いものは 3.5×10⁻²³ です。
  - この値は、60 桁でも 90 桁でも、表示されたすべての桁で同じでした（3.5062582833092147×10⁻²³）。計算の誤差（約 10⁻⁶⁴）よりはるかに大きいので、**本当に近いけれど一致しない組**と判断しました。
- 出力: `f03_nearmiss_n16_dps60.out`、`f03_nearmiss_n16_dps90.out`。60 桁の確認では、一致の再現に失敗するもの（誤差 7×10⁻³⁴）があります。これも、60 桁では足りないことを示しています。

## 意味

- 測った範囲（(E) 型の (H) の組、次数 4・8・16）では、**c は次数とともに増えません**（5 → 4 → 4）。route F の予想と合っています。
- ただし、これは (E) 型だけの測定です。一般の slack 0 の写像の組で c に上限があるか（c₀）は、何も動いていません。
