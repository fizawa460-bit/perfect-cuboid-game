## F2. 道具の仕様

数字は、均衡した slack 0 の場合（a = b、λ = 1、j ≈ 2a）で比べます。出典は E16 §2〜§4、E15 §1、E09 §2 です。

### T0（Klein 型の上界）— 主軸

| 項目 | 内容 |
|---|---|
| 不等式 | |Ω| ≤ 4 の双有理な組で **M ≤ c₀·(a+b) + C** |
| 現在の最良 | c₀ = 2（E15 Lemma K）[proved]。ほかに M ≤ 6·min(a,b)（ファイバーの上界） |
| 必要な値 | c₀ < 1。M ≥ j ≥ 2·max(a+s₁, b+s₂) ≥ a+b（E12 Lemma 0）と合わせて a+b ≤ C/(1−c₀) |
| 差 | 定数で 2 倍以上（2 → 1 未満） |
| 途中の価値 | c₀ = 2−η で G3（slack の範囲）が出る。**数字が少し動くだけで記録できる結果になる** [proved: 下の計算] |
