## 2. 一致を生む仕組み（証明できた部分）

c := j + h（一致する点の数）。M = 2j + h なので c ≤ M ≤ 2c です。

**補題 1（複比）[proved]。** c ≥ 4 となる T があるのは、O₁ の 4 点と O(q) の 4 点で複比が等しい組があるとき、そのときに限ります。T は 3 点で決まるので、c ≥ 4 は 1 つ以上の「偶然の等式」です。
- 3 個までは、どんな組でも T を選べば一致させられます。**一致の「ただの値」は c = 3 です。**

**補題 2（同じ β）[proved]。** β_q ≅ β_{p₁}（q = g∘p₁∘S）なら、O₁ のどの 4 点 A に対しても、A を保つ対合が 3 個あり、T = S⁻¹∘(その対合) で c ≥ 4 です。
- 理由: 2 組の点の対を入れ替える対合は必ず 1 つあります。O(q) = S⁻¹(O₁) なので、A の 4 点が一致します。
- つまり分類 2・3 では、**c = 4 は必ず大量に起きます**（(3,3) で c = 4 の配置は約 90 万個あり、そのうち違う類のあいだのものは約 1.3 万個だけです [computed]）。c = 6 は「3 組の対が同じ対合で入れ替わる」ときです。

**補題 3（対称性の移し替え）[proved]。** σ₁ ∈ G(p₁)、σ₂ ∈ G(q) が同じ位数 m の元で、T が σ₁ を σ₂ に移す（Tσ₁T⁻¹ = σ₂）とします。
- そのような T は 1 つのパラメータを持ちます（固定点 2 個を固定点に移す。残りは回転の 1 自由度）。
- 一致の集合は σ₁ の軌道の和集合です。自由度 1 を使うと、軌道 1 つ（m 点）を軌道 1 つに重ねられます。
- **固定点が O に入る条件**: p∘σ = g∘p で、g が B の点を固定する回転のとき、固定点での p の局所次数 e は奇数です（σ の固定点での回転と g の回転を比べる）。slack 0 では e = 1 なので、固定点は O の点です。g の固定点が B の外（辺の中点や面の中心）のときは、固定点は O に入りません。
- したがって、ただで得られる一致は次のとおりです。

| 移す対称性 | 固定点の分 | 軌道の分 | 合計 c |
|---|---|---|---|
| 位数 2（g は頂点の回転） | 2 | 2 | **4** |
| 位数 4（g も位数 4） | 2 | 4 | **6** |
| 位数 4（g は位数 2。例: t² と t ↦ it） | 0（固定点は臨界点） | 4 | 4 |
| 位数 2（g は辺の回転）、位数 3 | 0 | 2、3 | 2、3（得にならない） |
| 巡回でない群（T は有限個） | 固定点のうち O に入るもの。**最大 6** | 0 | ≤ 6 |

- 最後の行: 固定点が O に入るのは頂点の回転だけで、その固定点は全部で高々 6 点です（B の 6 点に対応）。
- **データとの照合**: 測定された c の最大は、すべての bidegree で 6 です（(4,2) と (6,0)）。上の表の最大値と一致します。

**補題 4（Galois 共役）[proved]。** q = p₁^τ（係数に体の自己同型 τ を施したもの）とします。O₁ の部分集合 Q で、Q の中の複比がすべて τ で動かないものがあれば、c ≥ |Q| となる T があります。
- 理由: Q^τ ⊂ O(q) で、Q と Q^τ は複比がすべて等しいので Möbius 変換で移り合います。
- τ が i を動かさなければ、p₁^τ(v^τ) = p₁(v)^τ = p₁(v) なので、**ラベルはすべて合います（h = 0）**。τ が複素共役のときも、ラベルは組として保たれます。
- 複素共役の場合、「複比がすべて実数」は「同じ円の上にある」ことです。

## 4. Q1 への答え：二分法の形

### 4.1 構造の定義（足すもの）

分類 1〜3 に、次を足す必要があります。

- **G（Galois 共役）**: β_q が β_{p₁} の Galois 共役と同型。複素共役（鏡像）を含みます。
  - 必要条件は安く調べられます: Galois 共役な写像は、B の各点の上の分岐の型が同じです（i を動かす τ では、±i の入れ替えを許す）。
- **T（移し替え）**: G(p₁) と G(q) の自明でない元が T で移り合う。**これは「組の構造」ではなく、p₁ と q それぞれの性質です。** 次数が違っても起きます。
- 分類 1（左側の因子）は残します。ただし §5.1 のとおり、これは一致の「原因」ではなく、問題を別の軌道体の上に移すだけです。
- 分類 2・3 は「β が同型」の 1 つにまとめます。g に複素共役を許すなら、S も向きを変える変換にする必要があります（そうしないと q が有理写像になりません）。F02-SHAPE の判定がどちらだったかは、コードを読んでいないので分かりません。

### 4.2 主張

**主張 D [heuristic。(1,3) と (3,3) では computed]。** 双有理な slack 0 の組 (p₁, q∘T) で c ≥ 4 なら、次のどれかです。
- (S) β_q ≅ β_{p₁}（分類 2・3）。
- (G) β_q が β_{p₁} の Galois 共役と同型。
- (T) T が G(p₁) の自明でない元を G(q) の元に移す。
- (L) p₁ と g∘q が 2 次以上の左側の因子を共有し、右側の組 (u₁, u₂) が、その因子の軌道体の上で (S)(G)(T) のどれか。

**どれでもない組では c ≤ 3、したがって M ≤ 6。**

**表 2 との照合**
- (3,3) (4,2) 192 個（分類 3）: (S) で、補題 2 の c = 6。合います。
- (3,3) (5,0) 192 個（「構造なし」）: (G)。**主張 D とは合い、「構造なしで M = 10」という読みとは合いません。** 構造なしではなかった、ということです。
- (4,4) (6,0) 11,136 個: 全部が分類 1〜3。合います。
- (4,4) ω = 14 の「構造なし」3,072 + 9,216 個: **未確認です。** 主張 D が正しければ、全部が (G) か (T) です（予測 P1）。そうでなければ主張 D は外れです。
- 対角線の外の M = 8: (S)(G) は次数が違うので起きません。主張 D が正しければ、全部が (T) の位数 2 です（予測 P2）。(1,3) では確認済みです。

**「構造なしなら M ≤ 10」について。** この形は勧めません。(G) を構造に入れないと、Galois 共役の組で c が次数とともに増える可能性を排除できないからです。(3,3) では c = 5 = n + 2 でした。c ≈ (a+b)/2 + 2 で増えるかもしれません [heuristic。根拠は 1 点だけ]。

### 4.3 一致を数える仕組みの候補

- **曲線の特異点・Plücker 型**: E16 で試して、強制される分は予算の 1/6 でした。ここでは使いません（言い換えになります）。
- **Klein グラフとの交点**: ラベルの合う一致は、像の曲線 W と 4 本の Klein グラフ y = g(x) の交点です。(1,3) の (4,0) では、W と 1 本のグラフの交点 4 個（= a + b）が**全部**一致点でした [computed]。これは E15 補題 K の等号の場合で、新しい不等式にはなりません。
- **新しい候補は「体」です。** c ≥ 4 は複比の等式で、複比は β_p の定義体に関係する代数的数です。数える対象を「点」から「複比の体」に変えるのが、補題 1〜4 の中身です。計画書 F4 の 6 分類（I, S, B, R, M, H）のどれにも入りません。

## 5. Q2 への答え：構造のある組

### 5.1 分類 1（p₁ = r∘u₁、p₂ = r∘u₂）

- **戻せます [proved]。** O(p_i) は、u_i による O(r) の逆像のうち不分岐な点です。Y_r := (P¹; O(r)) と置くと、u_i は Y_r の軌道体被覆（次数 n/2）で、**O₁ と O₂ は (u₁, u₂) の問題としてもまったく同じ集合**です。変わるのはラベルの意味だけです。
- **帰納法は、次の形でなら閉じます [outline]**: 「Γ₀ の指数有限・種数 0 の部分群 Λ すべてについて、H/Λ の被覆の組を考える。ラベルは使わず c だけを数える」。こうすると、分類 1 は「Λ₁, Λ₂ ⊂ Λ_r」というだけのことになります。
- **ただし、問題はやさしくなりません。** 面積で測れば、(u₁, u₂) の問題は元とまったく同じ大きさです（Y_r の面積は 2 倍、次数は半分）。分類 1 は一致の原因ではなく、(u₁, u₂) の側に別の原因（Y_r の上での (S)(G)(T)）があります。
  - Y_r は B より多くの対称性を持つことがあります（例: r = t² なら O(r) は 1 の 8 乗根）。(4,4) で分類 1 が 8,832 個あるのは、これだと思います [heuristic]。
- 注意: 設定が B から O(r) に変わるので、E11・E12 のラベルを使った結果は、そのままでは使えません。

### 5.2 分類 2・3（p₂ = g∘p₁∘σ、σ = S∘T）

- 一致点の数は c = |O₁ ∩ σ⁻¹(O₁)| です。**1 つの点集合 O₁ を Möbius 変換 σ で動かしたとき、何点が O₁ に戻るか**、という問題です。
- **別の理由では除けません（私の知る範囲で）[heuristic]。** 曲線が対称性で保たれることと、対称性で点ごとに固定されることは違います。保たれるだけの曲線は、固定される場所には入りません。ここが罠 A に当たる場所だと思います。
  - 除けるのは σ ∈ G(p₁) のときだけです。このとき像は 24 本の対称性のグラフの 1 つで、双有理ではありません（E06）。
- 問題 W の条件 |Ω| ≤ 4 のもとでは、|O₁ Δ σ⁻¹O₁| ≤ 4 です。X₁ = (P¹; O₁) とそれを σ で動かしたものの組で、**Λ₂ = Λ₁ の場合の問題 W そのもの**です。
  - 入れ子の型は起きません（E14 定理 A⁺）。型 (0,0) は等式の面（E03、E04）。残るのは混合型 (1,1)、(2,2) で、E13 §6.1 の未解決の場合と同じです。**新しい手がかりにはなりません。**

## 7. Q4 への答え：手元で確かめられる予測

**P1. (4,4) の「構造なし」は、全部 (G) か (T)。**

**P2. 対角線の外の極値（M = 8、(4,0)）は、全部が位数 2 の移し替え。**
- 測り方: (2,3)、(2,4)、(3,4) の極値の T について、Tσ₁T⁻¹ ∈ G(q) となる対合 σ₁ ∈ G(p₁) があるかを調べる。固定点 2 個が一致点に入っているかも見る。
- 数の予測: c ≥ 4 の T の総数は、頂点型の対合の対 (σ₁, σ₂) についての和 Σ 4·((|O₁|−2)/2)·((|O₂|−2)/2) です（c > 4 の重なりを除く）。(1,3) では 3·12·32 = 1,152 で合いました。
- **外れの条件**: 対称性を移さない T で c ≥ 4 のものがある。または、G(p) が頂点型の対合を持たない写像が、極値に現れる。

**P3. (5,5)。**
- 5 は素数なので (L) は起きません。予測: 違う類で、Galois 共役でもなく、対称性も移さない組は c ≤ 3。
- 位数 4 の対称性を持つ次数 5 の写像（E15 補題 M の f は候補です）どうしでは c = 6、M ≤ 12 が出るはずです。
- **外れの条件**: (S)(G)(T) のどれでもない組で c ≥ 4。または c ≥ 7 の双有理な組（補題 3 の上限 6 を超えるので、「偶然の一致」が実在することになります）。

**P4. (3,3) の (5,0) の 5 点は、複比がすべて √3 を含まない体に入る。**
- 測り方: mpmath で 5 点の複比（2 個で足ります）を求め、Q(i) の上の最小多項式を探す（PSLQ）。
- **外れの条件**: 複比に √3 が現れる。そのときは補題 4 では説明できず、別の仕組みがあります。
