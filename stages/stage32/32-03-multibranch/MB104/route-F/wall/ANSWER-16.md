## 4. B への答え：写像のデータから、局所条件を読み取れるか

### 4.1 どこまで決められるか

**悪い還元の素数 [outline]。** C̃ の悪い素数は、次の 3 種類に入ります。

1. **2 と ∞。** B の 6 点は 2 の上でつぶれます（0, ∞, ±1, ±i が 3 点になる）。いつでも悪い素数です。
2. **脚の悪い素数。** 被覆は、分岐点がつぶれず、モノドロミー群の位数を割らない素数で良い還元を持ちます（Beckmann の定理。**記憶による引用で、本文は確かめていません**）。
   - 楕円型で次数 n の写像では、モノドロミー群の位数を割る素数は 2n の素因数だけなので、悪いのは 2n を割る素数だけです。
   - 一般の slack-0 写像では、群が対称群に近いので、n 以下の素数はすべて悪い可能性があります。
3. **T の悪い素数。** 2 つの脚が良い還元を持っていても、O(p) と O(q′) の別々の点が mod p で重なることがあります。これは写像それぞれからは読めず、組ごとに終結式で計算する量です。大きさに上限はありません。
   - 例外: 両方の脚が同じ楕円曲線 E′ から来る場合（定理 14-A の (B)）は、O の点がすべて E′ のねじれ点なので、重なるのは次数を割る素数だけです [outline]。

**確かめた例 [computed、厳密]。** f = x((2 + i)P)（次数 5、y² = x³ − x）を、5 の上の 2 つの素数で還元しました（`checks16/red16.py`）。
- (2 + i) では f ≡ −x⁵ です。純非分離で、slack 0 の構造は消えます。
- (2 − i) では、次数 5 の分離的な写像のままで、0, ∞, ±1 の上は「二重点 2 個と単純な点 1 個」、±i の上は不分岐です。slack 0 の型が保たれます。
- 「次数を割る素数で還元が壊れる」ことの、いちばん小さい実例です。

**p 進点の有無 [proved]。**
- **良い還元の素数では、必ず局所点があります。** 種数 0 の conic は有限体の上で必ず点を持ち、種数 1 の曲線も必ず点を持ちます（Hasse–Weil の評価、または Lang の定理）。Hensel の補題で Q_p の点に持ち上がります。
- **悪い素数と ∞ では、有限の計算で決まります。** 入力は c_χ と s_χ だけです。種数 0 なら Hilbert 記号です。
- **実数の場所の条件は、写像からすぐ読めます。** C̃(R) ≠ ∅ ⟺ 実数 t で、p·q′ > 0 かつ (1 − p²)(1 − q′²) > 0 となるものがある（h_a は実数ではいつも正）。
  - 対照: Klein のグラフ y = −x、y = 1/x、y = −1/x は、それぞれ h_e = −x²、h_b = −(1 − x²)²/x²、h_e = −1 で、実数の点を持ちません。y = x だけが通ります。

### 4.2 次数が上がると、系統的な障害が出るか

**出る仕組みは見つかりません。理由は 4 つです。**

1. **良い素数では障害がない**（§4.1）[proved]。障害は、2、∞、有限個の悪い素数でしか起きません。
2. **悪い素数での可否は、次数と結び付かない [heuristic]。** 窓の曲線は種数 1 以下で、分岐点は 4 個以下です。局所的な可否を決めるのは、c_χ の平方類と Ω の位置という有限個のデータで、次数 a、b はそこに現れません。
3. **種数 0 では、障害のある場所の数は偶数 [proved、Hilbert の相互法則]。** 「ある 1 つの素数で必ず失う」という形は、単独では起きません。
4. **§3.3 の表の「必ずある」の行では、障害はそもそも起きない** [proved]。

- **起きうる唯一の系統的なこと**は、次数を割る素数での還元の崩れです（§4.1 の例）。ただしこれは、局所点を**失う**方向ではなく、O の点が mod p でつぶれて C の還元が悪くなる、というだけです。局所点の有無は、やはり平方類で決まります。
- 証人の族 (p, −p) は、どの次数でも h_e = −p² で、実数の場所で止まります。これは系統的ですが、像が y = −x であることの言い換えで、次数とは関係がありません。

## 6. D への答え：手元で測れる予想

どれも、局所的な道具が「効かない」ことを数字で確かめる予想です。外れたら、§4.2 の結論が誤りということになります。

**D1（還元の型）。** 楕円型で次数 n の写像は、2n を割らない素数 p では、座標を取り直せば slack 0 のまま還元されます（B の上の型が変わらない）。n を割る素数では、純非分離になることがあります。
- 測り方: 次数 4 の Q の上の 16 個と、次数 5 の 6 個（Q(i) の上）を、p < 100 で還元して、B の上のファイバーの型を調べます。`checks16/red16.py` が次数 5 の 1 個についての見本です。
- **外れの条件**: 2n を割らない奇素数で、どの座標でも型が変わる写像がある。

**D2（実数の場所）。** Q の上の組（窓でなくてよい）について、「p·q′ > 0 かつ (1 − p²)(1 − q′²) > 0 となる実数 t があるか」を調べます。
- 予想: 通る組の割合は、次数によらず 0 でも 1 でもない一定の範囲に収まります。対照として、Klein のグラフは 4 本のうち y = x だけが通ります。
- **外れの条件**: ある次数で、Q の上の組がすべて通らない。または、次数とともに通る割合が 0 に近づく。その場合は、実数の場所に系統的な障害があることになり、§4.2 を書き直します。

**D3（F_p 点）。** Q の上の組 (p, q′) と良い素数 p について、N_p := #{t ∈ F_p : h_a, h_b, h_e がすべて 0 でない平方数} を数えます。
- 予想: 3 つの h_χ のうち、定数倍を除いて平方になる組み合わせの定数 c が mod p で平方なら、N_p = p/δ + O(g·√p) です（g は C̃ の種数。Weil の評価）。N_p = 0 になるのは、小さい p か、その定数が mod p で平方でないときだけです。
- 窓の曲線（g ≤ 1）がもし見つかれば、良い素数 p ≥ 5 ではいつも N_p > 0 のはずです [proved。上の評価から。小さい p の境目は確かめていません]。
- **外れの条件**: 良い素数で N_p = 0 が、c_χ では説明できない形で、同じ次数の候補すべてに共通して現れる。

**D4（次数 6 の候補）。** 次数 6 の Q の上の写像が出たら、D1〜D3 を同じ形でかけます。
- 予想: 悪い素数は 2、3 と、組ごとの「T の悪い素数」だけです。局所点を欠く組は、c_χ の符号か 2 進の条件で説明がつきます。
- **外れの条件**: D1〜D3 と同じです。

**核（E12 §5）に届く見込みは変わりません [estimate]。** ANSWER-14 の見積もり（Q の上の (F∞_Q) で 1〜2 %、E12 §5 で 1 % 以下）から動かす理由がありません。

**効かなくなる段は 3 つです。**

1. **目標を弱める段（§3.2）。** 種数 0 では、弱めた目標は (F∞_pt) と同じ主張です。種数 1 でも、有理点が強制される型（§3.3 の表）では同じです。「軽くなる」範囲は、型 (2,2) と δ ≥ 4 の一部だけです。
2. **一様な上限を示す段（§4.2）。** 局所的な可否は有限個の平方類で決まり、次数と結び付きません。次数が大きいことから局所的な障害を引き出す道がありません。局所条件は、候補を定数倍減らすふるいにはなりますが、次数の上限は出しません。
3. **曲線ごとの計算に渡す段（§5）。** 溝の一覧があっても、溝の外の有理点は扱えません。足りないのは Bombieri–Lang 型の入力で、Stage32-03 からは出ません。

**組み合わせて実際に得られるもの。**
- census の候補に対する、安い必要条件（c_χ が平方数か、実数の場所を通るか）。次数 6 の候補にそのまま使えます。
- 溝の一覧ができたあとの、曲線ごとの手順（§5 の段 1〜4）。
- 「局所条件は罠 A を避けない」ことの、曲線の上でのはっきりした形（補題 1、補題 2）。

**罠との関係。**
- 罠 A: 補題 1 と補題 2 が、その曲線版です。この答えは、局所条件で何かを除外する主張を 1 つもしていません。
- 罠 B: この答えは、数字を動かしていません。新しい不等式も出していません。

| スクリプト | 内容 | 出力 |

**確かめていないこと**
- 仮定 (M1)、(M2) を、Stage の定義にさかのぼって確かめていません。とくに、Δ が (x, y) の座標でどこにあるか（12 本の線か、対称性のグラフか）は調べていません。この答えで使ったのは、「Δ は真の閉部分集合で、窓の曲線を含まない」ことだけです。
- Beckmann の定理は記憶による引用です。仮定（定義体、自己同型のある被覆の扱い）を確かめていません。§4.1 の「脚の悪い素数」は [outline] です。

- 種数 1 の段（§5 の段 3、4）で、実際に階数が求まるかどうかは、曲線の導手の大きさによります。見積もっていません。
