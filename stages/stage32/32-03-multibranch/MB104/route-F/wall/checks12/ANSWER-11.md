## 1. 補題 M：二つの計量のずれ

### 1.1 設定

- ρ_p = p*ρ_B は、軌道体 (P¹; O(p)) の双曲計量です（錐点はすべて位数 2）。一意化から、ρ_p は集合 O(p) だけで決まります。ρ_{q′} も同じです。
- Ω_p := O(p) ∖ O(q′)、Ω_q := O(q′) ∖ O(p)、ρ_∪ := 軌道体 (P¹; O(p) ∪ O(q′)) の双曲計量、と置きます。
- 恒等写像は、(P¹; O(p) ∪ O(q′)) から (P¹; O(p)) への正則な軌道体の写像です。Schwarz–Pick から ρ_p ≤ ρ_∪、ρ_{q′} ≤ ρ_∪ です [proved]。
- u_y := log(ρ_∪/ρ_p) ≥ 0、u_x := log(ρ_∪/ρ_{q′}) ≥ 0 と置くと、

  log(ρ_p/ρ_{q′}) = u_x − u_y、　|log(ρ_p/ρ_{q′})| ≤ max(u_x, u_y)。

### 1.2 補題 M [proved]

**主張。** X を閉じた双曲軌道体、ρ₁ をその計量、F を有限個の点の集合とします。F の各点の位数を 2 倍にした軌道体（位数 1 なら 2）の計量を ρ₂、u := log(ρ₂/ρ₁) とします。X の普遍被覆 H（計量は ρ₁）の中で、F の持ち上げを f̃₁, f̃₂, … とすると、

  u_model(d₁) ≤ u(x) ≤ (1/2)·Σ_i Q₁(cosh d(x̃, f̃_i))

- d₁ は、いちばん近い持ち上げまでの距離です。
- u_model(d) := log((1 + r)/(2√r))、r = tanh(d/2)。d が大きいとき (1/2)e^{−2d} です。
- Q₁(c) := (c/2)·log((c+1)/(c−1)) − 1（第二種 Legendre 関数）。d が大きいとき Q₁(cosh d) は (4/3)e^{−2d} です。

**証明。**
- 曲率の式から、F の外で Δ₁u = e^{2u} − 1 です（Δ₁ は ρ₁ のラプラシアン）。F の点では u = (1/2)·log(1/距離) + O(1) です。
- H に持ち上げると、ρ₂ は、各 f̃_i に位数 2 の錐点を持つ計量になります。X の錐点の持ち上げでは、どちらの計量も滑らかです。
- *上の評価。* v := (1/2)ΣQ₁(cosh d(·, f̃_i)) と置きます。
  - Q₁(cosh d) は (Δ − 2)Q = 0 の、遠くで減る解です。持ち上げの数は e^{r} 程度までしか増えないので、和は収束します。
  - f̃_i の近くで v = (1/2)·log(1/d) + O(1) なので、w := u − v は有界です。
  - e^{2u} − 1 ≥ 2u から、f̃_i の外で Δw ≥ 2w です。有界なので、f̃_i を越えて劣解として延びます。
  - w は群の作用で不変なので、コンパクトな X の上で最大値をとります。そこで w > 0 なら Δw ≥ 2w > 0 となり、最大値の原理に反します。したがって u ≤ v です。
- *下の評価。* 恒等写像 (H; すべての f̃_i) → (H; f̃₁ だけ) は正則な軌道体の写像です。Schwarz–Pick から、ρ₂ は「H に錐点を一つだけ置いた計量」以上です。
  - 後者は、円板で z ↦ √z を引き戻したもので、ρ₁ との比の対数が u_model(d) です。□

**使い方。** u_y には F = Ω_q、X = (P¹; O(p))（距離は ρ_p）で使います。u_x には F = Ω_p、X = (P¹; O(q′)) で使います。

### 1.3 平均 [proved]

- 面積の差（Gauss–Bonnet）から、∫_X (e^{2u} − 1) dA₁ = π|F| です。X = (P¹; O(p)) の面積は 2πn なので、e^{2u_y} − 1 の平均は**正確に |Ω_q|/(2n)** です。
- 一方 ∫₁^∞ Q₁ = 1/2 から、上の評価 v の平均は |F|/(4n) です。つまり、u が小さいところでは、上の評価は平均の意味で鋭いです。
- 意味：一つの側のずれ u_x、u_y は、平均で 1/n の大きさより小さくはなりません。
- **注意**：log(ρ_p/ρ_{q′}) = u_x − u_y は差なので、打ち消し合うことがあります。差そのものの下からの評価は、持っていません。

### 1.4 確かめ [computed]

- **モデル**（`metric12.py` Part B、50 桁）：0 < u_model < (1/2)Q₁ を d = 0.1〜8 で確認。u_model·e^{2d} → 0.5000、(1/2)Q₁·e^{2d} → 0.6667。Schwarz–Pick の評価 log coth(d/2) は、d = 8 で 6.7×10⁻⁴（u_model は 5.6×10⁻⁸）。
- **コンパクトな軌道体**（`lemma12.py`、50 桁）：X = P¹(3,2,8) で、3 つの錐点のうち一つの位数を 2 倍にしました（計量は P¹(3,2,16)、P¹(3,4,8)、P¹(6,2,8) のもので、どれも三角形関数から計算できます）。
  - 持ち上げは、(3,2,8) 分割の頂点を半径 8.5 まで数えました（7,353 個、29,511 個、19,666 個。面積からの数と 0.3% 以内で一致）。
  - 46 点 × 3 通りのすべてで、u_model(d₁) < u < (1/2)ΣQ₁ でした。u/上の評価は 0.27〜0.60 です。
  - **u·e^{2d₁} は一定ではありません**（0.96 から 1.88 まで増えます）。小さい軌道体では持ち上げが多く、いちばん近いものだけでは決まらないからです。これが、P2 がデータで成り立たない理由です。
- **ρ_B そのもの**（`metric12.py` Part A、50 桁）：辺の長さ ∫₀¹ρ_B = arccosh(1 + √2)（差 3×10⁻²⁸）、曲率 −1（誤差 4×10⁻²¹）。
- **型 (0,0) の組**（O(p) = O(q′)）では、格子の上で |u| ≤ 2×10⁻¹² でした（定理 U と整合）。

## 2. 問い 2：計量が近いことから q′ = h∘p を出せるか

**答え：出せません [proved]。**

- ある開集合で ρ_p = ρ_{q′} が**正確に**成り立てば、実解析性から全体で等しく、O(p) = O(q′)、つまり型 (0,0) です。問題の組（混合型）では、どの開集合でも正確には一致しません。補題 M の下の評価から、u_x ≥ (1/2)e^{−2d₁} > 0 です。
- 近似的に一致するとき、言えるのは「F = dev₂∘dev₁⁻¹ が、その領域で、ある等長写像 g に近い」ことだけです。
  - g が離散的な集合に入ると言えるのは、錨点があるときだけです（錨点の像が分割の頂点だから。E13 定理 B、補題 I′）。
  - 錐点のない円板には錨点がないので、g には何の制約もかかりません。**帯の中だけでは、格上げする相手がありません。**
- 帯について出せるのは、「帯の両側のクラスタの共役元 g₁、g₂ が等しい」という運びの主張です。g₁、g₂ ∈ N(Γ₀)（離散群）が補題 I′ から分かっていれば、g₁⁻¹g₂ が恒等写像に十分近いことから g₁ = g₂ が出ます。この「十分近い」を計量のずれから出すのが、§3 です。

## 3. 運びの評価と、E13 との関係（問い 1・3・4）

### 3.1 運びの式 [outline]

- σ を、dev₁ の像の中の測地線分とします（Ω の持ち上げを通らない）。u := log(ρ_p/ρ_{q′}) の持ち上げを同じ記号で書きます。
- F は σ を、速さ e^{−u} の曲線に写します。向きの変化の差は ∂_n u（σ に垂直な方向の微分）です。
- 点 z で F に一次まで合う等長写像を g_z とすると、σ の両端での g の食い違い γ := g_{z₁}⁻¹g_{z₂} は、σ の上の基点 σ(s₀) から見て、

  （基点の動き）≤ ∫_σ |e^{−u} − 1| ds + ∫_σ |∂_n u|·sinh|s − s₀| ds、　（回転）≤ ∫_σ |∂_n u| ds

  です。
- ここで要る「|∇u| ≤ C·(近くでの u の上限)」（楕円型の内部評価）は、書き下していません。そのため [outline] です。

### 3.2 持ち上げ一つの寄与 [computed（モデル）+ outline]

- 持ち上げ f̃ が、σ から距離 δ、足が基点から距離 a のところにあるとします。u ≈ (1/2)e^{−2d} を入れると、寄与は **C·e^{a − 2δ}** です。
- **モデルでの確認**（`transport12.py`、50 桁。円板に錐点を一つ置き、F = √z）：
  - 基点を足に取ると（a = 0）、基点の動きは 1.00·e^{−2δ}、回転は 2.96·e^{−2δ} に収束し、**線分の長さ w によりません**（δ = 1〜4、w = 1〜12）。
  - 基点を端に取ると（a = w/2）、動きは e^{w/2 − 2δ} の 0.4〜1.0 倍でした。

### 3.3 E13 と同じところ、違うところ

| | E13 補題 B1・B2 | 補題 M と §3.1 |
|---|---|---|
| 使う事実 | Ω から遠いと、F は等長写像に近い | 同じ |
| 道具 | 深さ R の円板での、両側の Schwarz–Pick | 曲率の式と最大値の原理、同じ Schwarz–Pick（下の評価） |
| ずれの形 | 中心から L の点で e^{L − R} 程度（確定した定数つき） | 持ち上げごとに e^{a − 2δ}、その和（定数なし） |
| 運ぶ範囲 | 一つの円板 B(c, L) | 測地線分 |
| 遠くへ運ぶと | 増える（L について） | 増える（a について） |
| Ω から遠いと | 減る（R について、速さ 1） | 減る（δ について、速さ 2） |

- **同じところ**：核になる事実と、「運ぶ距離で増え、深さで減る」という構造は同じです。候補 1 は、E13 B1・B2 の評価を鋭くしたもので、別の仕組みではありません。
- **違うところ**：
  1. 持ち上げ一つあたりの速さが 2 になる。
  2. 持ち上げごとに足し算できるので、「深いか深くないか」の二択でなく、段階的に使える。
  3. 下からの評価と平均の式がある（§1.2、§1.3）。これは壁の側の主張に使います。
- **持ち上げの数が最大の場合**（半径 r の中に e^{r} に比例して増える場合）は、和が e^{−（深さ）} になり、**指数まで E13 と同じ**です [estimate]。速さ 2 が効くのは、近くの持ち上げが少ないときだけです。

### 3.4 どの次数から排除できるか（問い 3）

- **新しく排除できる次数はありません。** 確定した閾値（504、16,535、168,290）は動いていません。
- 幅 w の帯を越える条件の見積もり [estimate]：
  - E13：帯の中点が深さ R_B(w/2 + 1.6) を持つこと。確定した定数では R_B(L) ≈ 3.4L なので、閾値は e^{1.7w} に比例します。
  - §3.1：Σ e^{a_i − 2δ_i} が、N(Γ₀) の離散性の定数より小さいこと。a ≤ w/2 なので、持ち上げが少なければ e^{w/2} に比例する見込みです。
- この見積もりを定理にするには、(i) |∇u| の評価、(ii) §3.1 の式の証明、(iii) N(Γ₀) の離散性の定数、(iv) 持ち上げの数え上げ、の 4 つが要ります。どれもしていません。

## 4. 壁の補題（(b)）

「計量の比較」とは、u についての評価（補題 M）と、それを F の運びに直す式（§3.1）だけを使う論法のことです。

**(W1) Ω の近くを通る帯は越えられない [proved（モデル）]。**
- u_x ≥ u_model(d₁) > (1/2)e^{−2d₁} なので、計量の一致は、深さの 2 倍の指数より良くはなりません。
- モデル（§3.2）では、運びのずれは実際に e^{a − 2δ} の大きさで、これより小さくなりません。
- したがって、a − 2δ > −c₀ となる持ち上げが一つでもあれば、この論法では共役元を比べられません。a ≤ w/2 なので、幅 w の帯は、**Ω の持ち上げから w/4 + c₀/2 以内を通るなら越えられません。** c₀ は N(Γ₀) の離散性で決まる定数で、値は出していません。

**(W2) 面積の一定の割合を占める帯は越えられない [estimate]。**
- 持ち上げの密度は、平均で |Ω|/(2πn)（面積あたり）です。和 Σe^{a_i − 2δ_i} は、遠くの持ち上げだけで C′·|Ω|·e^{w/2}/n 程度になります（§1.3 の平均から）。
- したがって、越えられるのは e^{w/2} ≤ n/C の帯だけです。
- 一方、幅 w の帯の中点のまわりには、半径 w/2 − O(1) の錐点のない円板があります（成分の間のいちばん狭い渡りについて）[outline]。面積から cosh(w/2 − O(1)) ≤ n + 1 です（LIT-11）。
- 二つを比べると、**越えられる幅と、面積が許す幅は、どちらも w ≈ 2·log n で、差は定数です。** 残るのは、錐点のない円板が全体の面積の 1/C 以上を占める帯です。C の値は出していません。
- E13 の確定した定数で言えば、越えられるのは w ≤ (log n)/1.7 − 定数 までです。

**(W3) x・y の近くの錨点 [proved]。**
- 深さ d₁ の点では u_x ≥ u_model(d₁) です。u_model(0.5) = 0.229、u_model(1.0) = 0.073、u_model(1.5) = 0.026。
- 定数程度の深さでは、計量は数 % 以上ずれていて、F は等長写像に近くありません。
- 定理 S5 の仮定「円板 D の外の錨点が 2n + 1 個以上」（D の中の錨点は 2 個以下）は、帯とは別の条件で、この論法では緩みません。

**まとめ。** 計量の比較は、帯の**中**では働きます（帯の中には錐点がないので、持ち上げが少なく、ずれは小さい）。難所は帯の中ではなく、(W1) Ω の近く、(W2) 大きすぎる帯、(W3) Ω の近くの錨点、の 3 つです。

## 5. 候補 2：二つの分割に同時にできる帯

**障害は見つかりませんでした [heuristic]。**

- τ_p と τ_{q′} が共有するのは錐点（4 個以下を除く）だけです。滑らかな頂点（p⁻¹(B) と q′⁻¹(B) の臨界点）は、別々の点です。
- 補題 F（T₂ + 2T₃ = T₀ + 16）は、それぞれの分割で別々に成り立ちます。型 (1,1) では次数も錐点の数も同じなので、二つの式は同じ形で、互いを縛りません。
- 面積の制約（cosh r ≤ n + 1）も、二つの計量で同じです。
- ラベルは、錐点にしか付いていません。錐点のない領域には、ラベルの制約がありません。
- 錐点のない領域では、p も q′ も、局所的には種数 2 の曲面（P¹(2⁶) の二重被覆）への写像に持ち上がります。局所的な条件は、これ以上ありません。
- 「障害がない」ことを証明したわけではありません。探した範囲（面積、Euler 数、ラベル、補題 F）で見つからなかった、という意味です。

## 6. 候補 3：帯の実例 [computed、`bands12.py`]

- 三角形の隣接は、面の中心の逆像を、辺の中点を通って隣の面まで追跡して決めました。
- 「成分」は、錐点を持つ三角形を辺でつないだ連結成分です。「越える幅」は、いちばん大きい成分から別の成分へ渡るのに通る、錐点のない三角形（T₀）の最小の数（成分についての最大）です。

| 次数 3（全部） | 60 | 12 | 2 | 8% | 1 個：12 |
