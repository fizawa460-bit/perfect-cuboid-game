## 1. 記号

- p は次数 a、q は次数 b の slack 0 の写像、T は Möbius 変換、q′ := q∘T です。O₁ := O(p)、O₂ := O(q′) と書きます。
- **錨点**は O₁ ∩ O₂ の点です。j はラベルの合う錨点の数、h はラベルの食い違う錨点の数です。
  - m₁ := |O₁| − j − h、m₂ := |O₂| − j − h とし、型は (m₁, m₂)、|Ω| = m₁ + m₂ + h です。
  - 問題の組は、混合型で |Ω| ≤ 4 のもので、(1,1)（h ≤ 2）、(2,2)（h = 0）、(1,3)（h = 0、b = a + 1）のどれかです。
- **回転**: Oct は B を保つ Möbius 変換（八面体の回転）24 個です。V₄ := {z, −z, 1/z, −1/z} は、三つのラベル対をそれぞれ保つ回転で、E15 の K と同じです。
- **隣接**: H/Γ₀ = P¹(2⁶) の八面体分割では、三角形の辺の長さが ℓ_min = arccosh(1 + √2) = 1.5286 です。二つの錐点（の H での持ち上げ）が距離 ℓ_min にあるとき、「隣接する」と言います。
- **対合**: 錐点 c の持ち上げの安定化群の生成元 e_c を、ρ で Γ₀ の楕円対合に送ります。Q¹ での持ち上げは x² = −1 を満たします。
- **トレース**: 二つの対合 x、y の固定点の距離が d なら、|tr(xy)| = 2cosh d です。t := tr(xy) = ±(2 + 2m)（m ∈ Z[√2]）と書き、t² − 4 = 4m(m + 2) です。

## 2. 補題 I と、共役元が八面体の回転になること

### 2.1 補題 I（Iwahori の補題）[proved・新]

**主張。**
- 𝔭 を Z[√2] の奇素数、x、y ∈ Q¹ を楕円対合の持ち上げ（x² = y² = −1）、t = tr(xy) とします。
- x と y が 𝔭 で同じ Iwahori 部分群に入るなら（Bruhat–Tits 木の標準頂点 v₀ から出る同じ辺を、両方が固定するなら）、t ≡ ±2 mod 𝔭 です。つまり 𝔭 | t² − 4 です。

**証明。**
- Iwahori 部分群を mod 𝔭 で落とすと、上三角行列になります。
- x̄ が上三角で x̄² = −1、行列式 1 なら、対角成分は (α, −α) で α² = −1 です。ȳ も同じく (β, −β)、β = ±α です。
- x̄ȳ の対角成分は (αβ, αβ) なので、トレースは 2αβ = ∓2 です。□

### 2.2 距離ごとの奇素数 [computed、`borel9.py` Part A]

二つの錐点の距離 d として許される値（2cosh d = 2 + 2m、m の共役が [−2, 0]）を、cosh d ≤ 400 まで 282 個並べ、t² − 4 の奇素因子を求めました。

| d | m | t² − 4 の奇素数 |
|---|---|---|
| **1.5286（ℓ_min）** | √2 | **なし** |
| 1.8989 | 1 + √2 | 7 |
| 2.2568 | 1 + 2√2 | 7 |
| **2.4485（= 2h）** | 2 + 2√2 | **なし** |
| 2.7988 | 3 + 3√2 | 3, 7 |
| 2.9140 | 4 + 3√2 | 3 |
| **3.0571** | 4 + 4√2 | **なし** |

- 奇素数を持たない距離は、この範囲で ℓ_min、2.4485、3.0571、4.8969 の四つだけです。
- 1.6 以下の距離は ℓ_min だけです（E13 §4.0 の表の「sides ≤ L: 1」と一致）。
- ここでの「許される」は、トレースの条件から来る上からの候補です。どれが実際に現れるかは主張していません。

### 2.3 補題 I′（共役元の整数性）[proved・新]

**主張。**
- g ∈ Comm(Γ₀) とし、部分群 H ⊂ Γ₀ ∩ g⁻¹Γ₀g が、固定点の距離が「奇素数なし」（たとえば ℓ_min）の対合を二つ含むとします。
- このとき g は Γ₀ を正規化し、P¹(2⁶) の八面体の回転 σ_g を引き起こします。

**証明。**
1. 奇素数 𝔭 では D_B は分裂し、Q_B は極大整環なので、Γ₀ は頂点 v₀ を固定します。gHg⁻¹ ⊂ Γ₀ から、H は g⁻¹v₀ も固定します。
2. g⁻¹v₀ ≠ v₀ なら、H は v₀ と g⁻¹v₀ を結ぶ道を固定します。とくに v₀ から出る辺を一本固定するので、H は Iwahori 部分群に入ります。補題 I から 𝔭 | t² − 4 となり、仮定に反します。
3. したがって、すべての奇素数で g は v₀ を固定し、Q_B ⊗ O_𝔭 を正規化します。
4. √2 では、D^×_{√2} の元はすべて、一意な極大整環と 𝔓 を保ちます（E13 補題 1、定理 U の段 4b）。
5. 整環は局所で決まるので g Q_B g⁻¹ = Q_B です。g は 𝔓、Q¹(𝔓²) を保ち、Γ₀ を正規化します。
6. g は PGL₂(R)⁺ の元（E13 補題 B6）なので、H/Γ₀ の向きを保つ自己同型、つまり八面体の回転を引き起こします。□

### 2.4 隣接する錐点はラベルが違う [proved・新]

**主張。** 同じラベルの対合 x、y では m ∈ 2Z[√2] です。したがって隣接する（m = √2）錐点は、必ず異なるラベルを持ちます。

**証明。**
- ラベルは Q_B/2Q_B での類です（E13 定理 B(4) の証明）。同じラベルなら x ≡ y mod 2Q_B で、u := xy⁻¹ = 1 + 2w（w ∈ Q_B）と書けます。
- nrd(u) = 1 から 1 + 2tr(w) + 4nrd(w) = 1 で、tr(w) = −2nrd(w) ∈ 2Z[√2] です。よって tr(u) ∈ 2 + 4Z[√2] です。
- y⁻¹ = −y なので xy = −u、t ∈ −2 − 4Z[√2]、つまり m ∈ 2Z[√2] です。□

確認（`borel9.py` Part C(iv)、語の長さ 11）: 隣接する組 61 個はすべて異なるラベル、同じラベルの組 135 個はすべて m ∈ 2Z[√2] でした。2h（m = 2 + 2√2）では同じラベルが許され、八面体の対蹠点の距離と合います。

### 2.5 定理 U の段 4 の別証明 [proved・新]

- 定理 U の設定で、Λ_p ⊂ Γ′ = Γ₀ ∩ k⁻¹Γ₀k です。
- p で引き戻した八面体分割には、三角形が 8n 個あります。錐点（2n + 4 個）はそれぞれ 4 個の三角形に、B の上の滑らかな点（2n − 2 個）は 8 個の三角形に入ります。
- 三角形ごとの錐点の数の合計は 4(2n + 4) = 8n + 16 > 8n なので、錐点を二つ持つ三角形があります。その二点は隣接していて、対合はどちらも Λ_p に入ります。
- 補題 I′ から、k は Γ₀ を正規化します。強近似と球面の数え上げは要りません。□
- 確認: 定理 U の結論そのもの（型 (0,0) の T がすべて八面体の回転）は、`census9.py` で全次数について成り立っています（§7）。

### 2.6 定理 B⁺（クラスタの共役元は八面体の回転）[proved・新。E13 定理 B（監査 PASS）を使う]

**主張。** E13 定理 B の設定（slack (0,0)、O₁ ≠ O₂、ℓ₀ = 1.6、L = 3.2、R = 10.78）で、dev₁ が一直線に並ばないクラスタ 𝒞 の共役元 g_𝒞 は、Γ₀ を正規化します。σ_𝒞 をその回転とすると、次が成り立ちます。
1. 𝒞 の射影の上の錨点 c では、q′(c) = σ_𝒞(p(c)) です。
2. Π_𝒞 の上で ρ₂ = gρ₁g⁻¹、g ∈ N(Γ₀) です。
3. 𝒞 の錨点がすべてラベルの合う錨点なら、σ_𝒞 ∈ V₄ です。

**証明。**

## 3. 系 R と、型 (1,1) の範囲を限った定理

### 3.1 系 R（同じ回転のクラスタの錨点の数）[proved・新]

**主張。** 混合型（slack (0,0)、次数 (a, b)）で、回転 σ ごとに A_σ := {σ_𝒞 = σ となる、一直線でないクラスタの射影の上の錨点} と置くと、|A_σ| ≤ a + b です。

**証明。**
- 定理 B⁺(1) から、q′ − σ∘p は A_σ の上で 0 です。
- q′ = σ∘p なら O₂ = O(σ∘p) = O₁ となり、混合型に反します。したがって q′ − σ∘p は恒等的に 0 ではありません。
- その分子は次数 a + b 以下なので、零点は a + b 個以下です。□

**既存の結果との関係。**
- E15 補題 K は、四つの Klein のグラフ（V₄ の元のグラフ）について、重複度付きで合計 2(a + b) 以下を示しています。
- 系 R はグラフ一本ずつの形です。定理 B⁺ が、クラスタ全体を一本のグラフに載せるので、クラスタの大きさに直接効きます。

### 3.2 型 (1,1)・h = 0 の範囲を限った定理

ここでは錨点は 2n + 3 個で、すべてラベルが合います。x ∈ O₁ ∖ O₂ と y ∈ O₂ ∖ O₁ は同じラベルです。

- **定理 S1（x と y が離れている場合）[proved。E13 定理 B(3) そのもの、新しくない]**: どのクラスタの近傍 W_𝒞 の中にも、x と y を分ける単純閉曲線はありません。
- **定理 S2（x と y が近い場合）[proved・新]**:
  - 一つのクラスタ（あるいは σ_𝒞 が同じクラスタの和）に乗る錨点は 2n 個以下です。2n + 3 個のうち、少なくとも 3 個は外にあります。
  - とくに、「x と y を含み、錨点を 2 個以下しか含まない円板 D があって、D の外の錨点がすべて一つのクラスタに乗る」配置は起こりません。
  - 証明: 系 R（a + b = 2n）と、2n + 3 − 2 = 2n + 1 > 2n。□
- **h = 1、2 の場合**: 定理 B⁺ と系 R はそのまま使えます。
  - クラスタが、両端ともラベルの合う錨点の辺を一本でも持てば、σ_𝒞 ∈ V₄ で、そのクラスタの錨点はすべてラベルが合います（§2.4 と定理 B⁺(1)。E13 定理 B(4) と同じ内容）。
  - そうでないクラスタでは、どの辺も、ラベルの食い違う錨点（2 個以下）のどれかを端に持ちます。このようなクラスタについては、σ_𝒞 ∈ Oct までしか言えません。

### 3.3 S2 に中身があるのはいつか [estimate]

- クラスタには、x と y から（両方の計量で）10.78 以上離れた錨点が要ります。
- E14 §7 の数え上げでは、そのような錨点が保証されるのは 2·max(a, b) > 336,582·2 のとき、つまり n > 3.4·10⁵ 程度からです。
- それより小さい次数では、S2 は空かもしれません。S2 は大きな次数についての主張です。
- [heuristic] E15 定理 E は、距離の一致をもっと小さな半径（ℓ_min で 2.23、3.2 で 4.41）で与えます。その半径で E13 補題 B2〜B4（星の上の等長写像、鏡像の除外）が作れれば、S2 の効く範囲は大きく広がります。今回はやっていません。

### 3.4 禁止の形との関係

- 系 R は、禁止リストの「j ≤ c·max(a, b) + C」の形ではありません。
  - 抑えているのは、同じ回転のクラスタに乗る錨点だけです。j 自体（= 2n + 3 > a + b）は抑えていません。
  - 目標として掲げたものでもなく、証明の付いた主張です。

## 4. 合成の補題：双有理でない組は型を d 倍にする

### 4.1 補題 C [proved・新]

**主張。** p、q′ を slack 0 の写像とし、(p, q′) が像の上で次数 d だとします。このとき次が成り立ちます。
1. 次数 d の κ と、slack 0 の写像 p₀、q₀ があって、p = p₀∘κ、q′ = q₀∘κ、(p₀, q₀) は双有理です。
2. κ の臨界値は O(p₀) ∩ O(q₀) に入ります。
3. m₁(p, q′) = d·m₁(p₀, q₀)、m₂(p, q′) = d·m₂(p₀, q₀) です。
4. h(p, q′) = Σ_{w ∈ H₀} #{w の上の κ の不分岐な点} ≤ d·h₀ です（H₀ は (p₀, q₀) のラベルの食い違う錨点）。

**証明。**
- (1) Lüroth の定理から、C(p, q′) = C(κ)、[C(t) : C(κ)] = d となる κ があります。
- (2) κ の臨界点 c で、e_c(p) = e_c(κ)·e_{κ(c)}(p₀) ≤ 2 かつ p(c) ∈ B です。したがって e_c(κ) = 2、e_{κ(c)}(p₀) = 1、p₀(κ(c)) ∈ B で、κ(c) ∈ O(p₀) です。q₀ でも同じです。
- p₀ が slack 0 であること: p₀ に欠陥（B の外の臨界値、または局所次数 3 以上）があれば、その κ での逆像で p も同じ欠陥を持ちます。q₀ も同じです。
- (3) κ は O(p₀) Δ O(q₀) の上で不分岐です。したがって O(p) Δ O(q′) は κ⁻¹(O(p₀) Δ O(q₀)) で、各点の上にちょうど d 点あります。
- (4) 同じ理由で、分岐する点は O に入りません。□

### 4.2 系 C [proved・新]

1. gcd(m₁, m₂) = 1 の型、とくに **(1,1) と (1,3) の組は必ず双有理です。**
2. **双有理でない混合型の問題の組は、(2,2)・h = 0、d = 2 だけです。** それは、次数 n/2 の双有理な型 (1,1) の組 (p₀, q₀)（h₀ ≤ 2）に、O(p₀) ∩ O(q₀) の二点で分岐する二重被覆 κ を合成したものです。二つの分岐値は、ラベルの食い違う錨点をすべて含みます。
   - 理由: d·(m₁, m₂) = (2,2) から d = 2、型 (1,1)。|Ω| = h + 4 ≤ 4 から h = 0 で、ラベルの食い違う錨点はすべて κ の分岐値です。
3. 逆に、そのような (p₀, q₀, κ) は (2,2)・h = 0 の問題の組を与えます。

### 4.3 混合型の例が作れない理由（依頼 3）[proved + computed + heuristic]

- **[proved] 知られている作り方は、どれも混合型を生みません。**
  - 左から回転を合成する（W2 の (f, −f)）: O 集合が同じなので、型 (0,0) です。
  - 右から合成する（E14 命題 C(i)、W3 の L_n(t² + c)）: 補題 C から型は d 倍です。型 (0,0) からは型 (0,0) しか出ません。
  - O 集合が完全に重なる組: 定理 U から、回転の合成だけです。

## 5. 定理 F：二つの算術的な点が同じファイバーに乗る（依頼 1）[proved]

**主張。** n ≥ 1、|A| = 2n + 3 の A ⊂ P¹ と z ∉ A について、V_z := (P¹; A ∪ {z})（錐点はすべて位数 2）と置きます。Z(A) := {z : V_z から P¹(2⁶) への次数 n の軌道体の被覆がある} とします。
1. Z(A) は有限集合です。z ∈ Z(A) の上の被覆 p_z は、σ∘p_z（σ ∈ Oct）を除いて一意です。
2. 次数 n の型 (1,1)・h = 0 の組は、(A, x, y)（x ≠ y ∈ Z(A)、A の上で p_x と p_y のラベルが一致）と一対一に対応します（源の Möbius 変換と σ を除いて）。こうして得られる組は必ず双有理です（系 C）。
3. h = 1、2 は、A の上のラベルが 1 点、2 点で食い違う場合です。

**証明。**
- (1) Γ₀ の指数 n の部分群は有限個なので、次数 n の被覆は Möbius 変換を除いて有限個です。一意性は定理 U です。
- (2) は定義の言い換えです。x の上では q′ が、y の上では p が錐点を持たないことが、型 (1,1) の定義です。□

**新しさ。**
- THEORY-07 §4 の言い直しを、一意性と有限性の付いた主張にしたものです。新しいのは、一意性（定理 U から）と、双有理性が自動で付くこと（系 C）の二点だけです。

## 6. 二重被覆の帰着と命題 C の障害（依頼 5）[proved]

**設定。** π : V₁ → V₀ を x、y で分岐する二重被覆、ι をその被覆変換とし、P := p∘π、Q := q′∘π と置きます。

1. **（E14 §6 の注意）** P と Q の O 集合はどちらも π⁻¹(A) で、ラベルも合い、slack は (1,1) です（s′ = 2s + m）。型 (0,0)・slack (1,1) です。
2. **欠陥の位置。**
   - P の欠陥は ỹ（y の上の点）一点だけ、Q の欠陥は x̃ 一点だけで、x̃ ≠ ỹ です。
   - x̃ は P の B の上の臨界点（局所次数 2）、ỹ は Q の B の上の臨界点です。
   - 理由は局所次数の掛け算だけです。
3. **双有理性。** (P, Q) は π を通るので、決して双有理ではありません。帰着は、双有理性を使って命題 C を避けているわけでは**ありません**。E15 §4（補題 Q、二乗による帰着）と同じく、被覆を合成する帰着は双有理性を壊します。
4. **逆向き。** ι で不変な型 (0,0)・slack (1,1) の組で、欠陥が ι の二つの固定点に一つずつあるものは、型 (1,1) の slack 0 の組に降ります。情報は失われず、ι の不変性に移っています。
5. **命題 C の族との違い。**
   - (P, σ∘P)（σ ∈ Oct）の形の組では、σ が B を保つので、欠陥の集合は必ず等しくなります。
   - 命題 C の族 (L_n(t² + c), −L_n(t² + c)) はこの形（σ = −z）で、欠陥は t = 0 の一点を共有します。下に降ろすと型 (0,0) の組 (L_n, −L_n) で、定理 U の場合です。
   - したがって、命題 C の証人は帰着の像の外にあります。両者を分ける量は「欠陥が別の点にあること」（同じことですが、Q ≠ σ∘P がすべての σ で成り立つこと）です。
6. **使い方への帰結。**
   - 上（帰着した側）で議論するなら、欠陥が別の点にあることを使わない限り、その議論は命題 C の族にも当てはまり、次数の上限は出ません（命題 C(iii)）。
   - 下（元の側）で議論すれば、命題 C の証人は型 (0,0) で、定理 U で片づいています。そのため、定理 B⁺、系 R、補題 C は下で述べています。これらは命題 C に妨げられません。

**確認（`dcover9.py`）。**
- Part 1: 命題 C の族（n = 1、2、c = 2、1/3 + i/2）で、P と −P の欠陥はどちらも {t = 0} で一致しました（slack 1）。
- Part 2: 次数 2 の (2,2)・h = 2 の記録で、x ∈ O₁ ∖ O₂、y ∈ O₂ ∖ O₁ の 96 通りすべてで、slack (1,1)、P の欠陥は s = ∞（y の上）、Q の欠陥は s = 0（x の上）で別の点、s = 0 は P の B の上の臨界点、s = ∞ は Q の B の上の臨界点、像の上の次数は 2 でした。
  - 型 (1,1) の例は知られていないので、仕組み（ラベルを使わない局所的な主張）を、この記録で確かめています。
