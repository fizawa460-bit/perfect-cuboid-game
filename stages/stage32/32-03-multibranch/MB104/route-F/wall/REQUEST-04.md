## 2. 訂正してほしいこと

1. **「双有理なら gcd(e₁, e₂) = 1」は誤りです**（§2）。
   - 反例：Φ(t) = (t², t² + t³) は像の上へ双有理ですが、t = 0 で e₁ = e₂ = 2 です。
   - (t², t⁴ + t⁵) では e = (2, 4) です。
   - したがって、「exc_v > 0 となるのは、e₁ = e₂ = 1 の点での接線の一致だけ」も成り立ちません。e₁ = e₂ ≥ 2 の点でも exc > 0 になりえます。
   - 不等式 M ≤ 2(a+b) − 1 − g(C) が、この誤りに頼っていないかを確かめてください。こちらの読みでは、exc ≥ 0 しか使っていないので無事のはずです。
2. **「2−η は g(C) の線形の増加と正確に同値」は言い過ぎです**（§5）。
   - 言えるのは、「g(C) ≥ η(a+b) − C′ ならば c₀ = 2−η」という片方の向きだけです。
   - g(C) ≤ （欠損）/2 − 1 なので、欠損が大きくても g(C) が小さいことはありえます。
3. **§3 の次元の数え上げは、数え方が誤っています。**
   - p₂ は、次数 b の写像全体（2b+1 次元）を自由に動くわけではありません。slack s₂ の写像は、B の上での分岐の条件で縛られています。slack 0 なら、Möbius 変換を除いて有限個しかありません。
   - 自由に動くのは、p₂ = q∘T の T（3 次元）だけです。
   - そのため、「a = b かつ s₁ + s₂ ≤ 1」という予測は根拠を失います。直すか、取り下げてください。
