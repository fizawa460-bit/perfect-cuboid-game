## 2. 孤立した錐点と 2h の連結

**2h の連結。** 二つの錐点 c、c′ が共通の隣の頂点 v を持ち、p(c) と p(c′) が B の対蹠点であるとき、「2h で連結している」と言います。
- v のまわりで c と c′ は 2 つ離れた位置にあり、v での角は π/2 です。距離はちょうど 2h です [proved: ANSWER-09 §3.1 の「滑らかな頂点を直角に挟む」と同じ。v が錐点でも同じ]。
- 2h は、ANSWER-08 §2.2 の表で「奇素数なし」の距離です。補題 I′ が使えます。

**補題 H（2h でも孤立する条件）[proved]。** c を孤立した錐点（隣の 4 頂点 v₁,…,v₄ がすべて滑らか）とします。c の星の境界の辺 v_iv_{i+1} の向こう側の三角形を (v_i, v_{i+1}, w_i) とします。
1. c と 2h で連結する錐点は、w₁,…,w₄ のうち錐点であるもの、ちょうどそれだけです。
2. したがって、c が 2h でも孤立 ⟺ 向こう側の 4 つの三角形がすべて錐点のない三角形。
3. I₂ を 2h でも孤立した錐点の集合、N_c を孤立していない錐点の数とすると、

   **4·|I₂| ≤ 3·T₀、|I₂| ≤ 2N_c − 12。**

*証明。*
- (1) v_i のまわりの隣の頂点を順に並べると、c、v_{i+1}、w_i、… です。c から 2 つ離れた位置は w_i と w_{i−1} です。c は孤立しているので、c の隣はすべて滑らかで、2h の連結は滑らかな v_i を通るものだけです。
- (2) 向こう側の三角形の頂点は v_i、v_{i+1}（滑らか）と w_i です。
- (3) 錐点のない三角形の 1 本の辺の向こう側には、三角形が 1 つしかなく、その反対の頂点も 1 つです。したがって、1 つの T₀ の三角形が「向こう側の三角形」になれるのは 3 回までで、4|I₂| ≤ 3T₀ です。
  T₂、T₃ の三角形の錐点はどれも孤立していないので、2T₂ + 3T₃ ≤ 4N_c です。これから T₂ + 2T₃ ≤ 8N_c/3 で、補題 F より T₀ ≤ 8N_c/3 − 16、|I₂| ≤ 2N_c − 12 です。□

## 3. 連結成分は「錐点を持つ三角形」の連結成分と同じ

G を、錐点を頂点とし、「隣接」と「2h の連結」を辺とするグラフとします。

**補題 G [proved]。** 錐点を持つ三角形（T₁、T₂、T₃）を、辺を共有するものどうしでつなぎます。このときの連結成分と、G の連結成分は、一対一に対応します（成分 K の錐点 = K の三角形の錐点である頂点）。

*証明。*
- 同じ三角形の錐点どうしは隣接しています。
- 辺 (u, w) を共有する二つの錐点を持つ三角形 t = (u, w, c)、t′ = (u, w, c′) を考えます。
  - u か w が錐点なら、t と t′ は錐点を共有します。
  - u も w も滑らかなら、c と c′ は錐点で、u のまわりで w を挟んで 2 つ離れています。c と c′ は 2h で連結しています。
- 逆に、隣接する錐点は辺を共有し、その辺の両側の三角形は錐点を持ち、辺でつながっています。2h で連結する c、c′（共通の隣 v、間の頂点 w）では、三角形 (v, c, w) と (v, w, c′) が辺 (v, w) を共有します。□

- 意味: **G が分かれるのは、錐点のない三角形（3 頂点とも p の臨界点である三角形）が、辺か頂点でつながった輪になって、球面を仕切るときだけです。** これを「錐点のない帯」と呼びます。
- 補題 H(2) は、その最小の場合です（1 個の錐点を、4 個の T₀ の三角形の輪が囲む）。
- 帯を作るには T₀ の三角形が要り、それは補題 F で、錐点どうしの辺を持つ三角形と同じ数だけ釣り合います。

## 4. 孤立が多い分割の形（依頼 (a) の 3 と 4）

**補題 P（T₁ の型）[proved]。** 滑らかな頂点 v のまわりの 8 個の三角形が、すべて T₁（錐点がちょうど 1 個）だとします。p(v) = β₀ とし、β₀ に隣り合う B の 4 点を、順に β₁、β₂、β₃、β₄ とします（β₁ と β₃、β₂ と β₄ が対蹠点）。
1. v の 8 個の隣の頂点は、錐点と滑らかな頂点が交互に並びます。
2. 錐点は一方の対蹠点の組（たとえば {β₁, β₃}）の上に、滑らかな頂点はもう一方（{β₂, β₄}）の上にあります。
3. T₁ の三角形だけでできた、ひとつながりの領域では、錐点はすべて同じ対蹠点の組の上にあり、残りの 4 点（正方形）の上の頂点はすべて滑らかです。

*証明。* 三角形 (v, w_k, w_{k+1}) の錐点はちょうど 1 個で、v は滑らかなので、w_k と w_{k+1} の一方だけが錐点です。隣の頂点の像は β₁、β₂、β₃、β₄ を 2 周します。(3) は、隣の滑らかな頂点に (1)(2) を順に当てはめます。□

- 意味: **孤立した錐点が多い（T₀ が小さい）分割は、局所的に「正方形の 4 点だけで分岐する被覆」の形です。** THEORY-02 補題 5 の、j = 1728 の楕円曲線の同種写像から来る写像（正方形型の Lattès 型）と同じ形です。
- L_n [computed]: T₀ = 0、T₂ = 16、T₃ = 0、T₁ = 8n − 16。孤立した錐点は、すべて対蹠点の組 {i, −i} の上にありました。L_n は臨界値が {±1, 0, ∞} に入る写像で、補題 P の形そのものです。
- **依頼 (a) の 4 への答え**: 孤立の多さは、型 (0,0) や合成と結びついているのではなく、**正方形型の構造**と結びついています。そして、その構造の中では、錐点は 2h の連結で全部つながります（補題 G。T₁ の三角形はすべて錐点を持つので、領域がつながっていれば G もつながる）。「双有理な混合型では孤立が少ない」という主張は、要りません。
- **依頼 (a) の 3 への答え**: 孤立が多いと「滑らかな頂点ばかりの広い領域」ができる、という見方は逆でした。孤立が多いほど T₀ は小さく（補題 H(3) の逆向き：T₀ = T₂ + 2T₃ − 16 ≤ 8N_c/3 − 16）、錐点のない領域は**狭く**なります。

**依頼 (a) の 2（二つの分割の両方を見る）への答え [proved、ANSWER-09 §1.3 を使う]。**
- 深さ 4.77 以上の錨点どうしでは、二つの計量での距離が等しくなります（現れる距離のすき間）。したがって、深い錨点については、「τ_p で隣接」と「τ_{q′} で隣接」は同じです。2h の連結も、深さ 8.46 では同じです。
- つまり、深い錨点が τ_p で孤立なら、τ_{q′} でも孤立です。両方を見ても、新しい制約は出ません。

## 5. 何が閉じ、どこで止まるか

### 5.1 範囲を限った定理 S5

**定理 S5 [proved。ANSWER-09 §3.1（L = 2.5、R = 8.46）と ANSWER-08 補題 I′・系 R を使う]。** 型 (1,1)・h = 0 とします。次の配置は起こりません。
- x と y を含み、錨点を 2 個以下しか含まない円板 D がある。
- D の外の錨点は、すべて 8.46 だけ深い。
- D の外の錨点は、「隣接」と「2h の連結」で（同じシートで）ひとつながり。補題 G により、これは「D の外で、錐点を持つ三角形が辺でひとつながり」と同じです。

(2,2)・(1,3)（h = 0）では、D の錨点を 1 個以下として、同じことが言えます。

*証明。*
- ANSWER-09 §3.1 から、距離 2.5 以内の深い錨点の共役元は等しいので、D の外の錨点の共役元は 1 つの g です。
- 2h か ℓ_min の距離の組が 1 つあれば、補題 I′ から g は Γ₀ を正規化し、回転 σ を与えます（どちらの距離も奇素数なし）。

- ANSWER-09 の定理 S2′ との違い: S2′ は「錐点どうしの辺でひとつながり」を仮定するので、孤立した錐点が 1 個でも D の外にあると使えませんでした。S5 は、孤立した錐点がいくつあっても使えます。代わりに、深さが 4.98 から 8.46 に、閾値が 504 から 16,535 に上がります。

### 5.2 壁の補題（依頼 (b)）

**補題 W [proved]。** 星の半径 L、深さ R_B(L) のクラスタの方法が与えるのは、次の 3 つです。
- (i) 深い錨点を距離 L 以内でつないだグラフ G_L の各成分 K の上で、共役元は 1 つの g_K（ANSWER-09 §3.1）。
- (ii) K に奇素数のない距離の組があれば、g_K は回転 σ_K（補題 I′）。
- (iii) 同じ σ の成分の錨点は、合わせて a + b 個以下（系 R）。Lemma Z を使うなら、隣の滑らかな頂点も合わせて a + b 個以下。

したがって、この方法が矛盾を出すのは、「ある σ について、σ_K = σ となる成分の錨点が a + b 個を超える」ときだけです。**G_L の成分が 2 つ以上あり、それぞれの錨点が a + b 個以下なら、この方法は何も排除しません。** 成分ごとの σ が等しいことを言う仕組みが、方法の中にないからです。

*証明。* (i)〜(iii) のどれも、別の成分のあいだの関係を含みません。成分ごとに違う σ を割り当てた数え上げは、(iii) を満たします。□

**L = 2.5 のときの形 [proved]。** 補題 G により、G_{2.5} の成分は「錐点のない帯」で仕切られた領域です。したがって壁は、次のように言えます。

> 星の半径 2.5 のクラスタの方法では、**錐点のない三角形の帯が、深い領域を、錨点 2n 個以下の部分に仕切っている配置**は排除できない。孤立した錐点の数は関係しない。

**数字。**
- 帯を越えるのに要る距離: 三角形 1 個の幅の帯を越える錐点の組は、距離 2.914（奇素数 3 を持つ）か 2ℓ_min = 3.057（奇素数なし）です [proved: 滑らかな頂点のまわりで 3 つ、4 つ離れた位置]。L = 3.2 が要り、深さは 10.78、閾値は n ≥ 168,290 です（ANSWER-09 §3.1 の表）。
- 幅 w の帯を越えるには、L は w に比例して増え、深さ R_B(L) は L に比例して増えます（表の 3 点では、L が 1 増えると R は約 3.7 増える）[estimate]。閾値は e^R に比例します。
- 一方、錐点のない円板の半径 ρ は、面積から cosh ρ ≤ n + 1 までしか抑えられません [proved: 面積 2π(cosh ρ − 1) ≤ 2πn]。深さの目安は log n なので、L を深さに合わせて広げても、ρ がそれを上回る配置を、面積だけでは除けません [outline]。
- データでは、次数 4 以下と L_n、p₀∘κ のすべてで、どの錐点も距離 2ℓ_min 以内に別の錐点を持ち、距離 2ℓ_min まで広げたグラフは 778 個中 770 個でひとつながりでした [computed]。幅の広い帯は、この範囲には現れていません。

### 5.3 止まった場所

- **閉じたこと**: 孤立した錐点そのものは、障害ではなくなりました（補題 H・G・P、定理 S5）。
- **残ったこと**:
  1. 錐点のない帯で仕切られた配置（補題 W）。帯の幅に上限を付ける道具は、見つけていません。
  2. 閾値より小さい次数。S5 が使えるのは n ≥ 16,535 で、計算で届くのは n ≤ 5 です。このすき間は、今回も埋まっていません。
- 形は「小さい側と、条件付きの大きい側は片づいた。残りは OPEN」です。ここで止めます。

## 6. 試して捨てた案

- **滑らかな頂点を「つなぎ」に使う（依頼 (a) の 1）。** Lemma Z の零点は、滑らかな頂点の「近く」にあるだけで、頂点そのものではありません。共役元を運ぶには、F と g のずれが ℓ_min/2 より小さいことを、帯の向こう側まで保つ必要があります。ずれは距離とともに指数的に増えるので、要る深さは ANSWER-09 の merge10 の見積もり（2h で約 10）と同じ程度になり、表の値（8.46）より良くなりません [estimate]。新しい仕組みにはなりませんでした。
- **「深い領域全体で、F は 1 つの等長写像に近い」。** 局所的には正しいですが、離れた 2 点で比べると、ずれが e^{距離} 倍に増えます。帯を越える距離 D には、深さが D に比例して要ります。補題 W の数字と同じ結論です [outline]。
- **錐点の割合からの面積の議論。** 距離 L 以内に別の錐点がない錐点の割合は、おおよそ 1/(cosh(L/2) − 1) 以下です（半径 L/2 の円板が重ならないため）[outline: 円板が埋め込まれていることを確かめていません]。L = 3.2 で 0.63、L = 5 で 0.19 です。孤立の「数」は抑えられますが、「ひとつながり」は出ません。
