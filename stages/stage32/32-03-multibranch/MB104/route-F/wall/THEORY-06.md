## 2. 出口 (i)：Φ に合わせて動く曲線

### 2.1 補題 T（W の移動）

**補題 T [proved]。** g ∈ G で gW ≠ W なら、

  **Σ_{P∈Z} m_P · m_{g⁻¹P} ≤ W·gW = 2ab。**

*証明。* g は 2 つの ruling を保つので、gW の bidegree は W と同じで、W·gW = 2ab です。P ∈ Z での局所交点数は m_P(W)·m_P(gW) 以上で、m_P(gW) = m_{g⁻¹P}(W) です。Z の外の交点は 0 以上です。□

**系 [proved]。** どの g ≠ e も W を保たないとき、15 個を足すと、Σ_g m_P m_{g⁻¹P} = 4·M_χ（P の格子の和）なので

  4·Σ_χ M_χ² − Σ_P m_P² ≤ 30ab。

E16 Lemma S（Σ_P m_P(m_P − 1) ≤ 2(a−1)(b−1)）と合わせると、Σ_χ M_χ² ≤ 8ab + M/4、したがって **M ≤ √(24ab) + O(1)** です。
- これは、商 X/G の上の曲線 π(W)（bidegree (4b, 4a)、3 点 Q_χ で重複度 2M_χ）の種数の式と同じ内容です [outline]。π(W) の Q_χ 以外の特異点が、W と gW の Z の外の交点です。
- 均衡した範囲では √(24ab) ≈ 4.9√(ab) > 4√(ab)、かつ 2S ≥ 4√(ab) なので、**M については Lemma K より弱い**です。E15 の注記の数字（(a+s₁)² ≤ 6ab）と同じ定数です。

### 2.2 ふさがっていること（補題 B1）

**補題 B1 [proved]。** max(a,b) ≤ 2·min(a,b) とします。m_P = S/6（12 点に均等、M = 2S）という分布は、次のすべてを満たします。

| 不等式 | 均等な分布での値 | 成り立つ条件 |
|---|---|---|
| Lemma K（グラフごと）: x_g ≤ S | S（等号） | いつでも |
| ファイバー: 列の和 ≤ a、行の和 ≤ b | S/3 | max ≤ 2·min |
| 補題 T（各 g）: Σ m_P m_{g⁻¹P} ≤ 2ab | S²/3 | S² ≤ 6ab、つまり max/min ≤ 2+√3 |
| Lemma S: Σ m_P(m_P−1) ≤ 2(a−1)(b−1) | S²/3 − 2S | 同上（主項） |

- したがって、**これらの不等式をどう組み合わせても、M = 2S は排除できません。** 壁の補題の「固定した因子」を「W の移動」に広げても、M の天井は 2 のままです。
- 補題 T で矛盾を出すには、W と gW の交点のうち、Z の外にあるものか、Z での接し方の余りが、**2ab − M²/12 以上**（均等な分布のとき。a = b、M = 2S なら (2/3)a² 以上）強制される必要があります [proved: 式の差]。
- 強制されると分かっている分は、a, b について 1 次です [outline]。g = (g₁, id) のとき、g₁ の固定点 2 個の上のファイバーは gW と W で共通なので、そこで 2a 以上交わります。それ以外に強制される交点は、見つけていません。

## 3. 出口 (ii)：12 点での重複度の分布と、B の上の分岐

### 3.1 slack 0 での分解（補題 D）

一致点 v ∈ J を、(e₁, e₂) の型で数えます。n₁₁、n₁₂、n₂₁、n₂₂ をその個数とします。

**補題 D [proved]。** slack (0,0) の組で、
1. M = n₁₁ + n₁₂ + n₂₁ + 2·n₂₂。
2. 型 (1,2)、(2,1) の点は、O₁ と O₂ の片方にしか入らないので、Ω に入ります。**n₁₂ + n₂₁ ≤ |Ω|。**
3. E12 Lemma 0 より n₁₁ ≥ |O_i| − |Ω| = 2·deg p_i + 4 − |Ω|。また n₁₁ ≤ min|O_i| = 2·min(a,b) + 4。
4. 問題の組（|Ω| ≤ 4）では、**2·max(a,b) ≤ n₁₁ ≤ 2·min(a,b) + 4**、したがって |a − b| ≤ 2 で、

   **M = n₁₁ + 2·n₂₂ + ε、0 ≤ ε ≤ 4、S − 2 ≤ n₁₁ ≤ S + 4。**

5. Lemma K は、n₂₂ ≤ (2S − n₁₁ − ε)/2 ≤ S/2 + 1 と同じです。

- n₂₂ は、「p₁ と p₂ の臨界点が同じ点にあり、臨界値のラベルが合う」点の数です。

### 3.2 M の上界を下げる論法の床（補題 B2）

**補題 B2 [proved]。** slack 0 の問題の組について、
- M ≤ (2 − η)S + C は、**n₂₂ ≤ (1 − η)·S/2 + C′** と同じ内容です（C′ = C/2 + 1 程度）。
- n₂₂ をどれだけ小さく抑えても、M ≥ n₁₁ ≥ S − 2 なので、**c₀ は 1 より下がりません。**
- c₀ < 1 は、「n₁₁ ≥ 2·max(a,b) となる組は、次数が大きいと存在しない」という主張そのものです。
- Klein のグラフの予算は Σ_g deg Φ*Γ_g = 4S です。型 (1,1) の点は、1 個につきちょうど 2（接し方の余りがなければ）を使います。問題の組では 2n₁₁ ≈ 2S で、予算の半分です。**予算の式は、n₁₁ が大きいことと矛盾しません。**

意味:
- **途中の目標 2 − η は、共通の臨界点 n₂₂ についての主張で、核（次数の上限）とは別の問いです。**
- 核に効くのは n₁₁ の側で、そこには交点数の予算（分類 I）も、移動（補題 T）も届きません。均等な分布で n₁₁ = S、n₂₂ = 0（M = S）とすると、補題 T の左辺は S²/12 で、2ab の 1/6 しか使いません。
- これは δ ≥ ηS の言い換えではありません。δ を、型ごとの数（n₁₁、n₂₂）に分け、問題の条件がどちらを縛るかを分けたものです。ただし、c₀ の数字は動いていません。

### 3.3 天井が下がる分布の条件（数字）

均衡した範囲で、次の情報があれば、c₀ は右の値になります [proved: 各行は補題 D、Lemma K（グラフごと）、補題 T の代入]。

| 分布についての情報 | 出る上界 | c₀ |
|---|---|---|
| n₂₂ ≤ γ·S/2（slack 0、問題の組） | M ≤ (1+γ)S + 8 | 1 + γ |
| あるグラフ Γ_g で x_g ≤ θS | M ≤ (3+θ)S/2 | (3+θ)/2 |
| 2 本のグラフで x_g ≤ θS | M ≤ (1+θ)S | 1 + θ |
| 重複度が 1 つのラベルの 4 点だけにある | M ≤ 2·min(a,b)（ファイバー） | 1（a = b のとき） |
| 重複度が、1 本のグラフの上の 6 点だけにある | M ≤ S | 1 |
| ある g で Σ_P m_P m_{g⁻¹P} ≥ κ·M²（集中の度合い κ。均等なら 1/12） | M ≤ √(2ab/κ) | a = b なら 1/√(2κ)。κ = 1/8 で 2、κ = 1/4 で 1.41 |

- 逆に、**12 点に均等で、4 本のグラフに均等な分布のままなら、天井は 2 です**（補題 B1）。
- |Ω| ≤ 4 という条件が、上の表の左の列のどれかを強制するかどうか。私は、強制する理由を見つけていません。
  - ラベルへの配分: n₁₁ のラベルごとの数は、O_i のラベルごとの数（B_χ の上の不分岐な点の数）で決まります。これは写像ごとに違い、一般には偏りません。
  - グラフへの配分: p₂ を g∘p₂（g ∈ V₄）に替えると、4 本のグラフが入れ替わります。問題の条件はこの入れ替えで変わらないので、特定のグラフが空くことは強制されません [proved: 対称性]。
  - n₂₂: 臨界点の重なりを縛る条件は、問題の条件の中にありません。Hecke 型でない限り、多いとも少ないとも言えません [heuristic]。

## 4. こちらで測れる予測

**P-6a. W と gW は、Z の点で接しない。**
- 測り方: O3 の 38,976 個（または次数 4 の全体）で、各 g ∈ G∖{e} と各 P ∈ Z について、W の P での枝の接線の向きと、gW の P での枝の接線の向きが一致するものがあるか。型 (1,1) の枝の向きは p₂′/p₁′ の値で、g による像の向きは g の微分で決まります。高精度で比べてください。
- 予測: 一致はない（局所交点数は m_P·m_{g⁻¹P} ちょうど）。
- **外れの条件**: 接線の一致が、組によらず系統的に出る。その場合、補題 T に強制される余りがあり、出口 (i) はふさがっていないことになります。

**P-6b. 補題 T の左辺の大きさ。**
- 測り方: 同じデータで、max_g Σ_P m_P m_{g⁻¹P} を求める。
- 予測: すべて 2ab = 32 以下（補題 T。破れたら、数え方か補題のどちらかが間違い）。M ≤ 6 なので、均等に近ければ M²/12 = 3 前後の小さい値のはずです。最大値と、それを取る組の分布（何点に集まっているか）を記録してください。
- **外れの条件**: 32 を超える組がある。

**P-6c. 共通の臨界点 n₂₂ の分布。**
- 測り方: 次数 (3,3)、(4,4) の双有理な slack 0 の組の全体で、(n₁₁, n₁₂ + n₂₁, n₂₂) の組み合わせごとの個数を数える。一致の多い組だけでなく、T を「臨界点 3 個を臨界点 3 個に移す」形でも列挙する必要があります。
- 予測:
  - n₂₂ = 3 の組は大量にある（T の自由度 3 を、臨界点の一致に使うだけなので）。そのとき Lemma K の M は 6 以上です。
  - n₂₂ ≥ 4 の双有理な組は、構造のある組（(S)、(L)、(E) など）に限られる。
  - O3 の 38,976 個では n₂₂ = 0（O3 の表の M と j から、すでに読み取れます）。
- **外れの条件**: 構造のない組で n₂₂ ≥ 4。または、n₁₁ と n₂₂ が同時に大きい組（n₁₁ + 2n₂₂ ≥ S = 8）が、次数 4 にある。後者は問題の組に近い組で、G2 の測定（次数 4 に問題の組はない）と食い違います。
- この測定は、G1（不一致 ω の表）では見ていない量（Lemma K の M への臨界点の寄与）を測ります。

## 6. 分かっていないこと・確かめていないこと

- 補題 D は slack (0,0) だけです。slack が正のときは、B の上の局所次数が 3 以上になりえて、型の表が増えます。
- §2.3 の最大値は、乱数の初期値からの局所最適化（SLSQP、各 300 回）です。真の最大値はこれ以上かもしれません（その場合、「従わない」という結論は強まるだけです）。
- リポジトリのデータでは、何も測っていません。
