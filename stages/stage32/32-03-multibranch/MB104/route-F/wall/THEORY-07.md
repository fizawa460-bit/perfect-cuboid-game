## 1. A-1 定理 U：O 集合が完全に重なると、写像も重なる [proved]

**主張。** p、q を slack 0 の写像（次数 n）、T を Möbius 変換とし、O(p) = O(q∘T) が点集合として一致するとします（ラベルは問いません）。このとき、八面体の回転 h があって q∘T = h∘p です。特に、(p, q∘T) が双有理なら n = 1 です。

**証明の流れ。** q′ := q∘T と書きます。
1. slack 0 なので p は軌道体の被覆です。したがって p が引き戻す計量は、X_p = (V₀; O(p)) の完備な双曲軌道体計量そのものです。
2. O(p) = O(q′) なら X_p = X_{q′} です（同じ Riemann 面、同じ錐点）。一意化の一意性から計量が等しく、dev_{q′} = k∘dev_p、Λ_{q′} = kΛ_p k⁻¹ となる k ∈ PSL₂(R) があります。
3. Λ_p と kΛ_p k⁻¹ はどちらも Γ₀ の有限指数の部分群なので、k ∈ Comm(Γ₀) です。さらに Λ_p ⊂ Γ′ := Γ₀ ∩ k⁻¹Γ₀k で、V₀ → H/Γ′ があるので、H/Γ′ の種数は 0 です。
4. **（算術）種数 0 なら d := [Γ₀ : Γ′] = 1 です。**
   - 種数 0 なら、H/Γ′ の錐点はちょうど 2d + 4 個あります（χ = −d）。
   - 錐点の数は、Γ₀ の 6 個の楕円対合が Γ₀/Γ′ の上に持つ固定点の合計です。
   - k は √2 では局所極大整環とその filtration を保つので、Γ₀ を正規化します。そのため Γ₀/Γ′ は、奇素数 𝔭 での Bruhat–Tits 木の球面の積になります（強近似）。
   - 楕円対合は ±1 mod 𝔭 にならない（トレースが 0）ので、各球面に固定点は高々 2 個です。したがって錐点は 6·2^ω 個以下です。
   - 一方 d ≥ 8^ω です（Z[√2] の奇素数の最小ノルムは 7）。ω ≥ 1 なら 2·8^ω + 4 > 6·2^ω となり矛盾するので、ω = 0、d = 1 です。
5. d = 1 なら k は Γ₀ を正規化し、軌道体 P¹(2⁶) の自己同型、つまり B を保つ Möbius 変換 h を引き起こします。これは八面体の回転で、q′ = h∘p です。□

使っている標準的な入力は、一様化の一意性、D_B¹ の強近似、木の上での対合の固定点集合の三つです。監査が必要です。

**確かめた例。** 次数 2 と 3 の写像をすべて 60 桁で作り、O 集合が完全に一致する T をすべて調べました。

| (2,2) | 720 | 0, 4, 6, 8 | 720 / 720 |

h > 0 の例（ラベルを入れ替える回転、たとえば z ↦ iz）も、すべて定理 U どおりでした。
