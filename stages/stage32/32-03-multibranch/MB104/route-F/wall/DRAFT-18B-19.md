## 1. 定理 18-B：両方の脚が B 形のとき [proved。一様 Mordell–Lang、補題 C、定理 14-A を入力に使う]

**主張。** (p, q′) を混合型の窓の組とし、p = f∘g₁、q′ = f′∘g₂ がどちらも B 形（deg g_i = ℓ_i ≤ d₀）だとします。このとき、次のどれかが成り立ちます。

- (i) max(a, b) ≤ (d₀·N(d₀) − 1)/2。ここで N(d₀) := 4·c(2, 4d₀)⁵ です。**f、f′ の次数によりません。**
- (ii) p と q′ はどちらも楕円型です。したがって定理 14-A から、max(a, b) ≤ (c(2, 4)⁵ − 1)/2 です（D_p = D_q なら窓の組はありません）。
- (iii) 型は (2,2) で、p と q′ は次数 2 の共通の右因子 h を持ちます。系 C で、次数半分の型 (1,1) の窓の組 (p̄, q̄′) に戻ります。p̄ = f∘ḡ₁、q̄′ = f′∘ḡ₂（g_i = ḡ_i∘h）で、これも B 形です（deg ḡ_i ≤ d₀/2）。

**系。** d₀ についての帰納法で、両方の脚が B 形の窓の組は、max(a, b) ≤ C(d₀) を満たします。C(d₀) は d₀ だけで決まる定数です（具体的ではありません）。

### 証明

ν := (g₁, g₂) : P¹ → V × V′ と置き、像を Y、ν の像の上の次数を k とします。

**手順 0（k ≥ 2）。**
- (p, q′) = (f × f′)∘ν なので、(p, q′) の像の上の次数 d は k の倍数です。
- 補題 C から、d は m₁ と m₂ を割り切ります。窓の混合型では d ≤ 2 で、d = 2 は型 (2,2) だけです。したがって k = 2 で、型は (2,2) です。
- ν は Y の正規化 Y^ν を通ります。Y^ν は P¹ に支配されるので、Lüroth の定理から P¹ です。ソースから Y^ν への次数 2 の写像を h とすると、g_i = ḡ_i∘h です。
- 系 C から、(p̄, q̄′) = (f∘ḡ₁, f′∘ḡ₂) は次数半分の型 (1,1) の窓の組です。これが (iii) です。

**手順 1（k = 1）。**
- A := E′ × E″ と置き（E″、π″、φ′、Γ″ は f′ の側の記号）、Z := (π′ × π″)⁻¹(Y) ⊂ A と置きます。
- π′ × π″ は有限平坦なので、Z のどの既約成分も Y の上に全射です。
- **Z の次数。** L = pr₁*[O] + pr₂*[O] について、Z·pr₁*[O] は「π′(O) を第 1 成分に持つ Y の点の上の、E″ の点の数」です。k = 1 なので、それは 2·deg(Y → V) = 2ℓ₁ です。同様に Z·pr₂*[O] = 2ℓ₂ です。したがって deg_L Z = 2(ℓ₁ + ℓ₂) ≤ 4d₀ です。成分は 4 個以下です（Z → Y の次数が 4 なので）。
- **点の対応。** x ∈ O(p) ∩ O(q′) を取ります。補題 T0 (ii) から、g₁(x) ∈ O(f)、g₂(x) ∈ O(f′) です。その持ち上げ P ∈ Γ、P″ ∈ Γ″ を選ぶと、(P, P″) ∈ Z ∩ (Γ × Γ″) です。同じ (P, P″) を与える x は、g₁(x) = π′(P) を満たすので、ℓ₁ 個以下です。

**場合 1a：Z のどの成分も種数 2 以上。**
- 正の次元の剰余類を含まないので、一様 Mordell–Lang から、各成分の Γ × Γ″ の点は c(2, 4d₀)^{1+4} 個以下です（Γ × Γ″ の階数は 4 以下）。
- 成分は 4 個以下なので、|Z ∩ (Γ × Γ″)| ≤ N(d₀) です。
- 点の対応から、|O(p) ∩ O(q′)| ≤ ℓ₁·N(d₀) ≤ d₀·N(d₀) です。
- 窓の不等式と合わせて (i) が出ます。

**場合 1b：Z のある成分 W が種数 1。**
- W は剰余類です。pr₁|_W : W → E′ は、準同型と平行移動の合成です。定数ではありません（定数なら Y ⊂ {π′(P)} × V′ となり、g₁ が定数になってしまうからです）。したがって pr₁|_W は不分岐です。pr₂|_W も同じです。
- k = 1 なので Y^ν はソースの P¹ で、W → Y はソースへの写像 r : W → P¹ を与えます（W は滑らかなので、正規化を通ります）。作り方から、**g₁∘r = π′∘pr₁|_W** です。
- **g₁ の臨界値は D_f に入ります。** x を g₁ の臨界点（e_x(g₁) = 2、補題 T0）とし、w ∈ r⁻¹(x) を取ります（W → Y は全射）。
  - 左辺の局所次数は e_w(g₁∘r) = 2·e_w(r) ≥ 2 です。
  - 右辺は e_w(π′∘pr₁) = e_{pr₁(w)}(π′) ≤ 2 です（pr₁|_W は不分岐）。
  - したがって e_w(r) = 1 で、π′ は pr₁(w) で分岐します。つまり g₁(x) = π′(pr₁(w)) ∈ D_f です。
- **g₁ は D_f について楕円型で、p は楕円型です。**
  - g₁ の臨界点はすべて単純で、臨界値は 4 点 D_f に入ります。補題 1 の証明（引き戻しの正規化）がそのまま通ります。D_f の上の単純な点は 4ℓ₁ − 2(2ℓ₁ − 2) = 4 個です。だから g₁∘π‴ = π′∘φ₁ となる同種写像 φ₁ : E‴ → E′（次数 ℓ₁）があります。
  - すると p∘π‴ = f∘π′∘φ₁ = π_{S_f}∘(φ∘φ₁) です。φ∘φ₁ は −1 と交換する同種写像なので、補題 1 の逆向きから、p は S_f について楕円型です。
- q′ も、pr₂ について同じ議論で、S_{f′} について楕円型です。これが (ii) です。□

**注意。**
- 場合 1b では、一つの成分が種数 1 であれば十分です。成分の間の推移性は使いません。
- (ii) の上限は定理 14-A (A) のもので、(i) の上限より小さいです。

## 2. 定理 19-M：T 形の脚と B 形の脚の組 [proved。同じ入力を使う]

**主張。** (p, q′) を混合型の窓の組とし、p = f₁∘g₁ が T 形（deg f₁ = d₁ ≤ d₀、g₁ は S_{g₁} ⊂ O(f₁) について楕円型）、q′ = f′∘g₂ が B 形（f′ は楕円型、deg g₂ = ℓ₂ ≤ d₀）だとします。このとき、次のどちらかが成り立ちます。

- (i) max(a, b) ≤ (4·c(2, 2 + 2d₀)^{3+2d₀} − 1)/2。**f′ と g₁ の次数によりません。**
- (ii) q′ は楕円型です。したがって、組は両方とも T 形（楕円型の脚は d = 1 の T 形）で、定理 T が使えます。

### 証明

- A := E′_{g₁} × E″ と置き、Z := {(P, P″) : g₂(π′_{g₁}(P)) = π″(P″)} ⊂ A と置きます。
  - Z → E′_{g₁} は次数 2 で、Z·pr₁*[O] = 2 です。Z·pr₂*[O] は、g₂∘π′_{g₁} が y₀ を取る点の数で、2ℓ₂ です。したがって deg_L Z ≤ 2 + 2d₀ で、成分は 2 個以下です。
- **点の対応。** x ∈ O(p) ∩ O(q′) を取ります。
  - x ∈ O(p) なので、x の E′_{g₁} への持ち上げ P は Γ_{g₁}（階数 2d₁ 以下）に入ります。
  - x ∈ O(q′) なので、補題 T0 (ii) から g₂(x) ∈ O(f′) で、その持ち上げ P″ は Γ″（階数 2 以下）に入ります。
  - (P, P″) ∈ Z ∩ (Γ_{g₁} × Γ″) で、P から x = π′_{g₁}(P) が決まるので、この対応は単射です。
- **場合 a：どの成分も種数 2 以上。** 一様 Mordell–Lang から、|O(p) ∩ O(q′)| ≤ 2·c(2, 2 + 2d₀)^{1+2d₁+2} です。窓の不等式と合わせて (i) が出ます（係数は余裕を見て 4 にしています）。
- **場合 b：ある成分 W が種数 1。** pr₁|_W、pr₂|_W は、定数でない不分岐な写像です。W の上で、**g₂∘π′_{g₁}∘pr₁ = π″∘pr₂** です。
  - x を g₂ の臨界点とし、P ∈ (π′_{g₁})⁻¹(x)、w ∈ pr₁⁻¹(P) ∩ W を取ります（pr₁|_W は全射）。
  - 左辺の局所次数は 2·e_P(π′_{g₁}) で、右辺は e_{pr₂(w)}(π″) ≤ 2 です。
  - したがって e_P(π′_{g₁}) = 1（x ∉ D_{g₁}）で、π″ は pr₂(w) で分岐します。つまり g₂(x) ∈ D_{f′} です。
  - §1 の場合 1b と同じく、g₂ は D_{f′} について楕円型で、q′ = f′∘g₂ は楕円型です。これが (ii) です。□

## 4. 残る穴：補題 M の塔

- 補題 M の族 x_{S₁}([m₁]·)∘x_{S₂}([m₂]·) は、上も下も楕円型で、どちらの次数にも上限がありません。T 形にも B 形にもなりません。
- 二つの持ち上げ方のどちらでも、片方が次数とともに増えます。
  - ソース側（E′_g）に持ち上げると、O(f) ∖ S_g の 2·deg f 点が E_{S_g} の上で一般にはねじれ点でないので、群の階数が deg f とともに増えます（ANSWER-18 §4.1）。
  - 真ん中の直線の側（E′_f）に持ち上げると、群の階数は 2 以下ですが、曲線 Z の次数が deg g とともに増えます。
- 一様 Mordell–Lang の形（c(g, d)^{1+ρ}）では、d と ρ のどちらかが伸びると上限が使えません。**この穴を閉じるには、別の道具が要ります。** L1（`checks19/l1.py`）は、この族の組が実際に窓に近づくかを測っています。
