2. **2.1 の読みは一か所直す必要がある [proved]。** 錨点だけを数えるなら、「定数個を除いて」の定数は **2 以下**でなければなりません（2n + 3 − C > 2n）。
   - ところが、x、y の近くの深くない錨点は最大 2N₀(R)（R = 4.98 で約 1,010 個）あり、2 以下にはなりません。
   - そこで **Lemma Z** を加えました。クラスタの近くでは、τ_p の滑らかな頂点（B の上の臨界点）ごとに、q′ − σ∘p の零点が一つずつ現れます [proved、仮定 (Z) の下]。

3. **段 1（被覆）は、半径をいくら下げても一般には成り立たない [computed]。**

5. **範囲を限った定理**（§5）。

## 1. 半径を小さくする（依頼 2.2 の 1）

### 1.1 八面体分割の頂点の距離 [proved + computed、`radius10.py` Part A]

**補題 T（距離 2h 未満なら隣接）[proved]。** 八面体分割（{3,8} 分割）の二つの頂点の距離が 2h 未満なら、二つは隣接していて、距離は ℓ_min です（h は三角形の高さ、cosh 2h = 3 + 2√2、2h = 2.4485）。

*証明。*
- u から隣接しない頂点 w への測地線は、u の星（u のまわりの 8 個の三角形）から、ある辺 e の点 P で出ます。
- d(u, P) は三角形の高さ h 以上です。
- w は e の端点ではないので、e は w の星の外にあるか、w の星の境界にあります。どちらでも d(P, w) ≥ h です。
- したがって d(u, w) ≥ 2h です。□

**計算（半径 4.0 の中の頂点 88 個）。**
- 現れる距離は 1.5286（8 個）、2.4485（8 個）、2.9140（16 個）、3.0571（8 個）、3.6316（16 個）、3.9403（32 個）です。どれも E13 のトレースの候補（cosh d = 1 + m + n√2）と一致しました。
- 候補のうち **1.8989、2.2568、2.7988、3.1472 などは、頂点の間には現れません。**
- 2h 未満の距離は ℓ_min だけでした（補題 T と一致）。

### 1.2 辺は交わらない。だから L = 2ℓ₀ は要らない [proved]

- E13 の辺（長さ ℓ₀ ≤ 1.6 の、深い錨点の持ち上げを結ぶ線分）は、dev₁ で八面体分割の辺に写ります（補題 T）。
- 分割の辺は内部で交わらず、dev₁ は局所同相なので、Ũ の中でも辺は交わりません。
- E13 補題 B4 で L = 2ℓ₀ が要ったのは、交わる辺の場合（§4.4 の証明の後半）だけです。ほかの部分（B1〜B3、B5、B6、定理 B(3)(4)）は、星の半径 L にしか依存しません。
- したがって **L = ℓ₀ = 1.6** で定理 B が成り立ちます。E13 の定数の表（L = 1.6 の行）では R_B(1.6) = 5.49 です。
  - 幅の下界 0.25 は、`thmb_constants.py 1.6 0.25` で 6 個の形すべてについて確かめました（`thmb_L1.6.out`）。

### 1.3 補題 B1 を、実際に現れる距離のすき間で置き換える [proved + computed]

- B1 の証明が使うのは、d₂ ≤ λ₁d₁ と d₁ ≤ λ₂d₂ の二つの不等式です。
- d₁ と d₂ は、どちらも頂点の間の距離です。錨点の dev_i の像は分割の頂点だからです。
- 現れる距離の、隣り合う値の比が max(λ₁, λ₂) より大きければ、d₁ = d₂ です。
- 比がいちばん小さいのは 3.0571/2.9140 = 1.049 です。λ(R, 1.6) < 1.049 となるのは R ≥ **4.766** です。
- ここで使う距離の一覧は 1.1 の数値計算です（候補と 10⁻⁷ で一致を確認）。そのため、この段は [computed] を含みます。

### 1.4 下限：鏡像の除外 [proved（不等式の評価）、限界の指摘]

- B3 は、星の三角形が鏡像に写る可能性を、B2（F が向きを保つ等長写像の ε 以内にある）で除きます。条件は ε(R, L) < 2·幅 です。
- 幅 0.25（L = 1.6）では、**R ≥ 4.978** が要ります。1.3 の 4.766 より大きいので、**R = 4.98 がこの方法の下限**です。
- E15 定理 E（半径 2.23）は、二点の距離の一致だけを与えます。三点の配置が鏡像かどうかは、距離では区別できません。
  - 鏡像の場合、共役元は向きを逆にする元になります。補題 I′ と同じ議論で、八面体群の反正則な元 τ が出ます。
  - そのとき錨点では q′(c) = τ(p(c)) となります。q′ − τ∘p は正則でないので、Bezout の数え上げ（系 R）が使えません。（このような調和関数の零点の数は、一般には次数の二乗まで達しえます。Wilmshurst の例。引用で、ここでは確かめていません。）
  - したがって、半径 2.23 から先へ進むには、鏡像を除く新しい道具が要ります。ラベルの向きや、源の三角形の向きを使う案を試しましたが、二つの三角分割の辺の位置を比べる量的な道具（B2 と同じもの）に戻りました。**ここで止まりました。**

### 1.5 閾値の表 [proved（数え上げ）、`radius10.py` Part C]

E14 命題 L(c) から、深くない錨点は 2(σ₁ + σ₂)·N₀(R) 個以下です。型 (1,1) では σ₁ + σ₂ = 1、(2,2)・(1,3) では 2 です。

| R | 出どころ | N₀(R) | (1,1) で深い錨点が出る最小の n | (2,2)・(1,3) |

- ただし使える R の下限は 2.23 ではなく 4.98 なので、閾値は数十ではなく **504** です。

## 2. 2.1 の読みを直す：錨点だけでは数えきれない

### 2.1 錨点だけの数え上げ [proved]

- 系 R は、一つの σ のクラスタの錨点を a + b = 2n 個以下に抑えます。
- 錨点は 2n + 3 個なので、矛盾には「σ のクラスタの外の錨点が 2 個以下」が要ります。(2,2)・(1,3) では 1 個以下です。
- 一方、x、y の近くの深くない錨点は 2N₀(R) 個まで許され、R = 4.98 で約 1,010 個です。下からの評価もないので、「定数」が 2 以下になる保証はありません。

### 2.2 Lemma Z：滑らかな頂点ごとに零点が一つ [proved、仮定 (Z) の下・新]

**主張。**
- v を τ_p の滑らかな頂点（p(v) ∈ B、局所次数 2）、V = dev₁(ṽ)、g ∈ N(Γ₀) を σ の持ち上げとします。
- 仮定 (Z): ある r < ℓ_min/2 について、円周 d(ζ, V) = r の上で d(Fζ, gζ) < 2r が成り立つ（F = dev₂∘s₁）。
- このとき、v の近く（B(V, r) に対応する円板）に、q′ − σ∘p の零点が少なくとも一つあります。

**証明。**
- 点 ζ が零点を与えるのは、π(Fζ) = π(gζ) のときです。V の近くでは、それは Fζ = gζ か Fζ = e_{gV}·gζ のどちらかです（e_{gV} は gV のまわりの半回転）。
- 後者は、K := e_V ∘ g⁻¹F の固定点と同じです。
- 円周の上では d(Kζ, e_Vζ) = d(Fζ, gζ) < 2r = d(e_Vζ, ζ) です。そのため、K と e_V を結ぶホモトピーの途中で、円周に固定点は現れません。
- K の固定点の指数の和は、e_V のもの（V だけ、指数 1）と同じです。K は正則なので、固定点はちょうど一つです。
- r < ℓ_min/2 なので、この円板にはほかの頂点が入らず、異なる頂点の円板は交わりません。□

**仮定 (Z) が深さから出る条件 [estimate、`zeros10.py` Part A]。**
- v が、クラスタの深い錨点 y に隣接していて、y が同じクラスタの隣 z を持つとします。
- B2 を y で半径 ℓ_min + r に使い、g と g̃ のずれを、y と z での一致から見積もります（等長写像を標本で調べる）。
- 結果は R ≥ **7.1**（r = 0.4）、N₀ = 4,242、型 (1,1) では n ≥ 4,241 です。

**仕組みの確認 [computed、50 桁、`zeros10.py` Part B]。**
- 次数 3・4 の写像 40 個 p と、恒等写像に近い Möbius 変換 μ で q′ = p∘μ と置きました（σ = id、F はどこでも g に近い）。
- q′ − p の 2n 個の零点は、p の 2n − 2 個の臨界点のそれぞれの近くに一つずつ、μ の固定点の近くに二つありました。
- この例には共通の錐点がないので、確かめたのは局所的な数え方だけです。

### 2.3 数え上げの結論 [proved、仮定 (Z) の下]

- σ ごとに、σ のクラスタの錨点と、仮定 (Z) が成り立つ隣の滑らかな頂点は、合わせて a + b = 2n 個以下です（Bezout。重複は一度だけ数える）。
- τ_p の頂点は、錐点 2n + 4 個と滑らかな点 2n − 2 個の、合わせて 4n + 2 個です。
- したがって矛盾に要るのは「一つの σ の領域が、2n 個を超える頂点を含む」ことで、**半分強**で足ります。2.1 の「定数 2 以下」よりずっと緩い条件です。

## 3. 段 2（連結）（依頼 2.2 の 2）

### 3.1 近いクラスタの共役元は等しい [proved]

**主張。** 星の半径 L で定理 B が成り立つ深さ R ≥ R_B(L) のとき、同じシートで距離 L 以内にある二つの深い錨点の共役元は等しくなります。したがって共役元は、「距離 L 以内」でつないだ深い錨点のグラフ G_L の連結成分ごとに一定です。

**証明。**
- x̃ の星には z̃ が、z̃ の星には x̃ が入ります。
- g_x̃ と g_z̃ はどちらも二点 dev₁x̃、dev₁z̃ を正しく写す、向きを保つ等長写像なので、等しくなります（E13 B4 の前半と同じ）。□

**L ごとの必要な深さ。**

| L | つながる距離 | R_B(L) | 閾値（(1,1)） | 出典 |
|---|---|---|---|---|
| 1.6 | 隣接（ℓ_min）だけ | 4.98 | 504 | §1 |
| 2.5 | 2h = 2.4485 まで（滑らかな頂点を直角に挟む二つの錨点） | 8.46 | 16,535 | `thmb_L2.5.out`（幅 0.04 を 225 形で確認） |
| 3.2 | 2ℓ_min = 3.057 まで（一つの頂点をまっすぐ挟む） | 10.78 | 168,290 | E13 |

- `merge10.py` で、別の見積もり（補題 M：二つのクラスタの共役元のずれが ℓ_min 未満なら等しい）からも、ほぼ同じ深さ（2h で 10.0、2ℓ_min で 11.25）が出ました [estimate]。表の値のほうが小さいので、表の値を使います。
- 補題 M そのもの（N(Γ₀) の自明でない元は、隣接する二頂点のどちらかを ℓ_min 以上動かす）は [proved] です。N(Γ₀) は分割を保ちます。

### 3.2 共役元が違う二つのクラスタの間にあるもの [proved]

二つのクラスタの共役元が違えば、Ũ の中でそれらを結ぶどの道も、次のどちらかを通ります。
1. **深い錨点が L 以内に一つもない区間**（錨点のない帯）。V_p では、そこにある B の点はすべて滑らかな頂点か、深くない点です。
2. **x か y の近く**（深くない領域）。

- E13 定理 B(3) から、クラスタの近傍の閉曲線は x と y を分けません。そのため 2 の場合は、x と y の両方を含む側を通ります。
- x、y の近く（半径 R の中）にある錨点の数の上限は 2N₀(R) です（R = 4.98 で 1,010、R = 7.1 で 8,484）。**定数ですが 2 以下ではありません**（§2.1）。Lemma Z の形（半分強）なら足ります。

### 3.3 データでの見え方 [computed、`tau10.py` Part 2]

- 混合型の記録で、「τ_p と τ_q′ の両方で隣接する錨点の組」（クラスタの辺になるための必要条件）を調べました。各組からは、辺の向きを合わせる回転 σ が一つ決まります。
- これらの次数では深い錨点がないので（全体の直径が R より小さい）、E13 のクラスタではありません。組合せだけで何が起こるかを見ています。

| 次数 | 調べた記録 | 錨点 | 両方で隣接する組 | 成分の中で σ が一定 | 回転の種類 | 一つの σ に乗る錨点の最大 |
|---|---|---|---|---|---|---|
| (1,1) | 32 | 96 | 96 | **いいえ**（三角形一つに 3 種類） | 3 | 2 = a + b |
| (1,2) | 61 | 184 | 78 | いいえ（3 件） | 0〜3 | 3 = a + b |
| (2,2) | 62 | 332 | 84 | はい | 1〜2 | 2 < a + b |

- 浅いところでは、隣接する錨点でも σ が一定になりません（(1,1) の三角形）。3.1 の深さの仮定が本当に要ることを示しています。
- 一つの σ に乗る錨点の数は、どの記録でも a + b 以下でした（系 R と一致）。

## 4. 段 1（被覆）はなぜ足りないか [computed + proved]

- **[proved]** 星の半径 L = 1.6 では、クラスタの辺は τ_p の錐点どうしの辺です。隣に錐点を持たない錐点は、どれだけ深くてもクラスタに乗りません。L を大きくすると、§3.1 の表のとおり R が急に大きくなります。
- **[proved]** 引き戻した分割では、三角形ごとの錐点の数の合計が 8n + 16 です。保証される錐点どうしの辺は 8 本だけで、孤立した錐点が大多数でも矛盾しません。
- **[computed、`tau10.py` Part 1]** 孤立した錐点の割合（辺の本数と、各頂点に出入りする弧の数はすべて確認済み）:

| 写像 | 個数 | 錐点 | 孤立 | 一つの写像での最大 |
|---|---|---|---|---|
| 次数 1、2 | 16 | 126 | 0% | 0% |
| 次数 3 | 60 | 600 | 2.0% | 20% |
| 次数 4 | 680 | 8,160 | 4.3% | 33% |
| p₀∘κ（次数 8） | 17 | 340 | 8.2% | 30% |
| **L_n（次数 2〜32、W3 の材料）** | 5 | 144 | **61.1%** | **82%** |

- L_n のように次数が上がると孤立が増える族があります。そのため、「深くさえあれば錨点はクラスタに乗る」は成り立ちません。段 1 は、新しい仕組み（たとえば、錐点の少ない広い領域が混合型の組では起こらない理由）がない限り、仮定です。

## 5. 範囲を限った定理（依頼 2.2 の 3）

1. **定理 B♭ [proved、§1.2〜1.4。距離の一覧は computed]。** E13 定理 B (1)〜(4) と定理 B⁺ は、ℓ₀ = L = 1.6、R = 4.98 で成り立ちます。
2. **定理 S2′ [proved]。** 型 (1,1)・h = 0、n ≥ 504 とします。次の配置は起こりません。
   - x と y を含み、錨点を 2 個以下しか含まない円板 D がある。
   - D の外の錨点はすべて 4.98 だけ深い。
   - それらは τ_p の錐点どうしの辺で（同じシートで）一つにつながっている。

   (2,2)・(1,3)（h = 0）では、D の錨点を 1 個以下として、n ≥ 1,010 で同じことが言えます。
3. **定理 S4 [proved、仮定 (Z) の下。(Z) は深さ 7.1 から [estimate]]。** 型 (1,1) で、各回転 σ について、σ のクラスタの錨点と、(Z) が成り立つ隣の滑らかな頂点は、合わせて 2n 個以下です。
   - とくに、深いクラスタとその隣の滑らかな頂点が τ_p の頂点を 2n 個より多く覆えば、回転は 2 種類以上現れます。
   - さらに、その全体が 3.1 の意味で一つにつながっていれば、矛盾です。
4. **証明できなかったこと。** 「n ≥ N₀ なら回転が 2 種類以上現れる」（被覆なし）と、「x と y の距離が d 以上なら起こらない」。どちらも段 1 を要します。
