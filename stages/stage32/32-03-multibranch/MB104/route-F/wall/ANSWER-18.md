*証明。*

- **S が正方形のとき。** E_S は Z[i] による虚数乗法を持ちます。
  1. ℓ ≡ 3 (mod 4) の素数を取ります。E_S[ℓ] ≅ F_{ℓ²} で、Gal(Q̄/Q(i)) の像 H は F_{ℓ²}^× の部分群です。

### 2.3 壁はどこか

**壁は、合成に分解できない写像です。**

- slack 0 の写像は、種数 2 の Bolza 曲線 y² = x⁵ − x の不分岐被覆と同じものです（B で分岐する二重被覆を p で引き戻す）[証明済み]。
  - 楕円型は、この被覆がアーベルな場合です。だから Jacobi 多様体と虚数乗法が効き、ノルムの条件が出ます。
  - 楕円型でない写像では、被覆がアーベルではありません。核のイデアルにあたるものがないので、「ノルム n の元」に代わる判別式は出てきません。
- 分解できない写像のモノドロミー群は、有限個の例外を除けば A_n か S_n、または楕円型のアフィン群です（Guralnick–Thompson 予想の解決と、種数 0 の原始群の分類。記憶。例外の正確な一覧は確かめていません）。
- つまり主張は、「B で分岐し、局所モノドロミーがすべて対合の A_n・S_n 被覆は、Q(i) の上にない」になります。これは、Hurwitz 空間の、特定の 1 点 B の上のファイバーに有理点がない、という主張です。動かせる分岐点がないので、組みひもの議論も剛性の議論も使えません。**この形の一般的な定理を、私は知りません。**

**依頼文の候補の道具について。**

| 道具 | 言えること | 言えないこと |
|---|---|---|
| Beckmann の定理 | 下のとおり。モジュライ体は、n 以下の素数でしか分岐しない | 体の次数の下限。「Q(i) にない」は出ない |
| 組みひも軌道 | 分岐点を動かせるときの成分 | 分岐点が B に固定されているので、使えない |
| F_p で 0 になる理由 | 軌道が大きいこと（下） | 構造的な理由は見つからない |
| 判別式 | 楕円型ではノルム | 楕円型でない写像では、対応するものがない |

- **Beckmann の定理（記憶。検索の要約で形だけ確かめました）。** G-Galois 被覆 X → P¹ の分岐点の集合が数体 K の上で定義されているとします。素数 p が |G| を割らず、分岐点が p を法として互いに異なるままなら、p の上の素点はモジュライ体で不分岐で、被覆は良い還元を持ちます。
  - 前提: Galois 被覆としての主張です。Galois でない被覆には、Galois 閉包を通して使います（もとの被覆のモジュライ体は、閉包のモジュライ体に含まれます）。
  - ここでは B は 2 の上でだけつぶれ、G ⊂ S_n です。だからモジュライ体は、Q(i) の上で n 以下の素数でしか分岐しません。
  - 検算 [計算]: 次数 6 の 4 データの体は Q(i, √2)、Q(i, √6)、Q(i, ⁴√3)（素数 2、3）。次数 7 の V 対称の体の判別式は −2⁶·7 と 2²²·3⁹·5³·7³（7 以下）。どれも合っています。
- **F_p で 0 になる理由。** N_p は、Frobenius が固定する類の数です。p について平均すると、Galois 軌道の数になります。
  - 次数 6 のデータでは、N_p の合計は 181 データで 116（p = 13）、72（p = 17）です。1 データあたり 1 個前後です。
  - つまり、1 データあたり平均 150 個ほどある類が、ほぼ 1 つか 2 つの大きな軌道にまとまっています。大きな軌道では、固定点のない Frobenius が正の割合であります（Jordan の補題）。
  - これは「一般の位置の Hurwitz ファイバーは既約」という期待と同じ形です。B が特別な点（八面体）でも、それが崩れていない、という観察です。証明ではありません。

### 2.4 対称な写像での探索（新しい計算）

有理的な類が出やすいのは、対称性で候補が少なくなる所です。そこを厳密に調べました。

**補題 V [証明済み]。** slack 0 の写像 p が、Klein の四元群 V（B の 3 本の軸のまわりの半回転）のすべての h に対して h∘p = p∘m_h を満たすとします。このとき次が成り立ちます。
- 次数 n は奇数です。
- p は、次数 n の Belyi 写像 p̄ : P¹/V′ → P¹/V に落ちます。分岐するのは、組 {0, ∞}、{1, −1}、{i, −i} の像の 3 点だけです。
- k 番目の点の上の分岐は 1·2^{a_k}·4^{b_k} で、Σa_k = Σb_k = (n − 1)/2 です。p のデータは、k 番目の組の 2 点でどちらも 2b_k です。
- p の類が Q(i) で固定されれば、p̄ の類も固定されます（p̄ は p から一意に決まるので）。

*証明の要点。* 商の軌道体は S²(4, 4, 4) です。p のソースは、p̄ による V 被覆の引き戻しと一致します。分岐を比べると、V′ の固定点 6 個はすべて O(p) に入り、分岐指数が 1 の点が各ファイバーに 1 個ずつです。Euler 標数を数えると、上の条件になります。

## 3. 問 2：F_p で数える方法の裏付け

### 3.1 不等式の正しい形 [証明済み。良い還元は文献による]

**主張。** p を奇素数、p > n、p ≡ 1 (mod 4) とします。データ（B の各点の上の分岐の型）を決めます。このとき、

  #{類のうち、Gal(Q̄/Q(i)) で固定されるもの} ≤ N_p := #{F_p の上の写像} / |PGL₂(F_p)|

ここで「類」は、**ソースの Möbius 変換だけ**で割ったものです（値の側は B を点ごとに固定します）。

*根拠。*
1. **良い還元。** 次数 n、分岐の型を決めた被覆の Hurwitz 空間は、分岐点の配置の空間の上で、Z[1/n!] の上の有限エタール被覆です。
   - 文献: Grothendieck, SGA 1 XIII 章（馴基本群の特殊化）、Fulton 1969（単純分岐、p > n）、Wewers「Construction of Hurwitz spaces」（Z[1/|G|] の上の構成）、Bertin–Romagny「Champs de Hurwitz」。すべて記憶です。Wewers の構成と「p が |G| を割らなければ良い還元」は、検索の要約で形を確かめました。本文は読んでいません。
   - 必要な条件は二つです。p > n（G ⊂ S_n なので p は |G| を割らず、野生分岐もない）。B の 6 点が p を法として異なる（p が奇数ならよい）。
   - 結論: B の上のファイバーは、Z[i][1/n!] の上の有限エタールな概形です。標数 0 の類と標数 p の類は、分解群の作用ごと 1 対 1 に対応します。Q(i) で固定される類は、Frobenius でも固定されます。
2. **有限体の上では、モジュライ体 = 定義体。** 有限体は cd ≤ 1 なので、降下の障害が消えます（Dèbes–Douai、記憶）。種数 0 の曲線は F_p の上で P¹ です。
3. **質量公式 [証明済み、初等的]。** Frobenius で固定される類 1 個に対して、F_p の上の形（ひねり）は Aut の Frobenius 共役類と対応し、Σ 1/|Aut_{F_p}| = 1 です。一方、#{(P₀, Q₀, c)}/|PGL₂(F_p)| = Σ_{軌道} 1/|固定群| です。だから N_p は、Frobenius で固定される類の数にちょうど等しくなります。

依頼文の三つの点（馴分岐、モジュライ体 = 定義体、質量公式）は、どれも正しいです。

### 3.2 足りない条件：類の定義

- 依頼文の「モジュライ体」は、値の側を八面体群でも割っています。**この定義では、不等式は一般には成り立ちません。**
  - p^σ = h_σ∘p∘m（h_σ は B の回転で、恒等でない）となる類は、八面体で割れば固定されますが、N_p には数えられません。
  - 八面体での固定群が自明なデータでは、問題は起きません。対称なデータ（022222 など）では、起き得ます。
- **32-03 のためには、ソースだけで割る定義のほうが正しいです。** ANSWER-14 §2.2 で、Q の上の曲線の脚は、B の座標を固定したまま Q の上にあるからです。
- 依頼者の表の数（次数 4 で 32、次数 5 で 6）は、ソースだけで割った数になっています。表と数え上げは整合しています。直すのは、定義の文だけです。

### 3.3 4 つのデータの正体 [証明済み + 計算（厳密）]

- この 4 データでは、f = x² がただ一つの左因子で、g は S_g を分岐集合とする 3 同種です。8 個の類は、「S_g の 2 通り」×「位数 3 の部分群 4 個」とちょうど対応します。
- S_g の 2 通りの曲線は、**j = 8000（Z[√−2] の虚数乗法）と j = 1728** です（`tower18.out` (b)）。

| 曲線 | 3 等分多項式の因子（Q(i) の上） | 軌道 | 体 |

| j = 8000 | 2 次 + 2 次 | 2 個と 2 個 | Q(i, √2) と Q(i, √6) |

  - p ≡ 2 (mod 3) では、√2 と √6 のちょうど一方が F_p に入ります。N_p = 2 です。
  - p ≡ 1 (mod 3) では、√3 が F_p に入ります。√2 と √6 は両方入るか、両方入らないかです。4 個組は、3 が 4 乗剰余のときだけ数えられます。
  - **p ≡ 5 (mod 8)、p ≡ 1 (mod 3) で、3 が 4 乗剰余でないとき、N_p = 0 です。** 最初の素数は 37 で、次は 61、157 です。

### 3.4 「次数 6 は 0 個」は、どこまで言えるか

- **F_p の数え上げだけで、181 データすべてが 0 になりました**（177 個は p = 13、17、29。残りの 4 個は p = 37）。
- 定理として言うための前提は、次の三つです。
