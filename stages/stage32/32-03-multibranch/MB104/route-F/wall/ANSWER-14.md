## 2. §3.1 の答え：絞り方は正しいか

### 2.1 (F∞_Q) で足りるか [proved]

- **足ります。ただし「有理点」という目的に限ります。**
- 理由: 曲面 B の有理点の Zariski 閉包のうち、1 次元の成分 C を取ります。
  - 閉包は Q の上で定義されているので、Galois 群は成分を入れ替えます。C が別の成分 C^σ に移るなら、C の有理点は C ∩ C^σ（有限個）に入ります。したがって、有理点を無限個持つ成分は Q の上で定義され、幾何的に既約です。
  - Faltings の定理から、その種数は 1 以下です。正規化は P¹_Q か、階数が正の楕円曲線です。
- **足りない点**
  1. E12 §5 は Q̄ の上の主張です。(F∞_Q) からは、「B の上の種数 1 以下の曲線は有限個」という幾何の主張は出ません。Q 以外の数体の上の有理点も扱えません。
  2. (F∞_Q) は次数の上限だけです。上限の下の有限個の確認（E12 §1〜§3 の型の計算）は、別に要ります。
  3. 罠 A の曲線（退化した点から来る既知の曲線）は Q の上にあり、有理点を無限個持ちます。(F∞_Q) は、それらを含めた形（「既知の一覧のほかにはない」）でしか成り立ちません。

### 2.2 曲線が Q の上にあれば、脚も Q の上にあるか [proved。ただし下の仮定つき]

**仮定。** E10 §1 の模型、つまり B の関数体が Q(x, y)(√h_a, √h_b, √h_e) で、β = (x, y) : B → P¹×P¹ が Q の上で定義されている、とします。E10・E06 の式からそう読みましたが、Stage の定義にさかのぼっては確かめていません。

**主張。** k = 8 で、C ⊂ B が Q の上で定義されているとします。

1. 像 W = β(C) と、その正規化 V₀、射影 p₁、p₂ : V₀ → P¹ は、すべて Q の上で定義されます。
2. V₀ は Q の上の conic です。C が特異でない有理点を持てば（有理点が無限個ならそうです）、V₀ ≅ P¹_Q で、**p₁、p₂ ∈ Q(t)** です。
3. したがって、どちらの脚も moduli の体は **Q そのもの**です。ここでの moduli の体は、B の回転 h を許さない、厳密な意味（P¹ ⊃ B を固定した被覆として）です。しかも、二つの脚は**同じ座標 t で同時に** Q の上にあります。
4. Galois 群はラベル a、b、e を保ちます。動くのはラベル a の中の i ↔ −i だけです。安定化群は k = 8 では S = G なので、体を大きくしません。

証明は、β が Q の上にあることと、像・正規化・射影が体の拡大と両立することだけです。

**すぐ出る帰結 [proved]。** p を、Q の上の slack-0 写像とします。

- **(a) 型の条件。** 複素共役は i の上のファイバーを −i の上のファイバーに写します。したがって、i の上と −i の上の臨界点の数は等しくなります（CHECK-13 の「00・11・22 で始まる型」と同じ条件。branch cycle lemma からもこれ以上は出ません。臨界点のまわりのモノドロミーは対合で、どの円分指標でも共役類が変わらないからです）。
- **(b) 鏡映の対称性。** p を引き戻した八面体分割は、実軸に関する鏡映で自分に重なります。Q の上の写像は、いつでも向きを逆にする対称性を持ちます。予想 Q-Sym が求めているのは、向きを保つ対称性です。
- **(c) 型 (1,1) の x と y。** O₁ ∖ O₂ = {x} と O₂ ∖ O₁ = {y} は Galois 群で保たれるので、x、y ∈ V₀(Q) です。p(x)、q′(y) は B の有理点 {0, ∞, ±1} に入るので、ラベルは e か b です。
- (c) は条件を一つ減らすだけで、窓を閉じる力はありません。

**k = 4 について。** R の Q の上の座標は r = √2·ρ（E06 §1）なので、分岐点への Galois 群の作用が変わります。脚が Q の上にあることは同じですが、以下の話は k = 8 だけです。

## 3. §3.2 の答え：予想 Q-Sym

### 3.1 楕円型の写像 [proved]

**定義。** slack-0 写像 p の臨界値が、B の 4 点の集合 S に入るとき、p を（S についての）**楕円型**と呼びます。

- S の取り方は 15 通りです。八面体の赤道にあたる 3 通り（{0, ∞, ±1}、{0, ∞, ±i}、{±1, ±i}）を**正方形**と呼びます。残り 12 通りは正方形でありません。
- E_S を、S で分岐する P¹ の二重被覆（楕円曲線）とします。正方形なら j = 1728（y² = x³ − x、虚数乗法 Z[i]）、正方形でなければ j = 128 です。

**補題 1（構造）。** p が S についての楕円型（次数 n）であることは、次と同値です。
楕円曲線 E′ と次数 n の同種写像 φ : E′ → E_S があって、p は φ を ±1 で割ったものである（p∘π′ = π_S∘φ）。
このとき π′ : E′ → V₀ は、S の上の単純な点 4 個の集合 **D_p** でちょうど分岐する二重被覆です。

- 証明: V₀ ×_{P¹} E_S の正規化を E′ とします。S の上では、局所次数 2 の点は E_S の分岐と打ち消し合い、局所次数 1 の点だけが E′ → V₀ の分岐点になります。その数は 4n − 2(2n − 2) = 4 個です。E′ → E_S は不分岐で次数 n です。逆は、同種写像が −1 と交換することから出ます。□
- 個数: n が奇数なら、S ごとに σ₁(n) 個（指数 n の部分格子の数）で、合計 15σ₁(n) 個です。n = 3 で 60 個（次数 3 の写像の全部）、n = 5 で 90 個（6,090 個のうち）で、データと合います。n = 4 は 200 個（680 個のうち）で、これも合います。

**補題 2（対称性）。** 楕円型の写像は、いつでも自明でない対称性 h∘p = p∘m を持ちます。

- 証明: a′ ∈ E′[2] による平行移動は −1 と交換するので、V₀ の Möbius 変換 m に降ります。φ(a′) による平行移動は、S の点を 2 個ずつ入れ替える Möbius 変換 h に降ります。
  - φ(a′) = O のとき（n が偶数で a′ が核に入るとき）は h = id で、m は p の自己同型です。
  - S の 4 点を 2 個ずつ入れ替える 3 つの変換のうち、B の回転になるのは、正方形なら 3 つとも、正方形でなければ 1 つです（手計算で確認）。n が奇数なら φ は E′[2] の上で全単射なので、その 1 つを選べます。□
- 正方形で n が奇数なら |Sym| ≥ 4 です。φ が虚数乗法そのものなら、x ↦ −x も加わって |Sym| ≥ 8 です。CHECK-13 の「|Sym| = 8 が 2 個、4 が 4 個」と合います。

**補題 3（B の正体）。** E : y² = x³ − x では、B = x(E[2 + 2i]) です。0、∞、±1 は 2 等分点、±i は 2P = (0, 0) となる点の x 座標です。したがって、正方形の S についての楕円型の写像では、O(p) はすべて E′ のねじれ点の像です。

### 3.3 予想 Q-Sym の判定

**証明できたこと [proved]。**

- 楕円型の写像では、Q-Sym は正しいです（補題 2。体の条件は要りません）。
- 次数 5 以下では、moduli の体が Q(i) に入る写像はすべて楕円型です [computed]。したがって、次数 5 以下の Q-Sym は補題 2 で説明がつきます。

**証明できないこと。** すべての次数での Q-Sym は、証明の道具が見つかりません。

- branch cycle lemma が与えるのは、§2.2 (a) の条件だけです。
- 剛性は使えません。同じ型の写像は次数とともに約 10 倍ずつ増え、Galois 群がその中の 1 個を固定することを禁じる定理はありません（dessin でも、同じ型の中で軌道がどう割れるかは一般には決まりません。これは記憶による一般的な事情で、文献は当たっていません）。
- 「n が素数なら」「Q(i) なら」に限っても、同じ理由で証明は出ません。

**「Q(i) なら楕円型」は、次数 10 で破れます [computed、厳密]。**

- f = x((2 + i)P) では、±i の上に Q(i) の有理点が 1 個ずつあります（x = ∓i）。この 2 点で分岐する 2 次写像 g を合成した f∘g は、次数 10 の slack-0 写像で、Q(i) の上にあり、臨界点の数は (i, −i, 1, −1, 0, ∞) の上で (1, 1, 4, 4, 4, 4) です。6 点すべてを使うので、楕円型ではありません。
- ただし g の被覆変換が自己同型になるので、Q-Sym には反しません。
- したがって、Q の上の写像を分類するなら、単位は「楕円型」ではなく「楕円型の写像を積み重ねた塔」です。

**反例の仕組み（具体的な形）。** 対称性のない Q の上の写像が出るとすれば、次の形です。

- p = f∘g。f は Q の上の slack-0 写像、g は 4 点の集合 S_g ⊂ O(f) についての奇数次 ℓ の楕円型の写像。
- 必要な条件は二つです。S_g が Galois 群で保たれること。E_{S_g} が Q の上の ℓ 同種（より一般には、Galois 群で保たれる指数 ℓ の部分格子）を持つこと。
- S_g が f の対称性で保たれるなら、p は対称性を持ちます（例: f が 2 次で、S_g が f のファイバー 2 本の和なら、p はまた楕円型です）。反例には、f の対称性で保たれない S_g が要ります。
- 2 次の部品を上に載せると、必ず自己同型ができます。したがって、**2 次だけの塔は Q-Sym の反例になりません** [proved]。

**探索 [computed、`tower14.gp`]。** Q の上の 2 次の塔（f = id から、Galois 群で保たれる 2 点で分岐する 2 次写像を、ひねり d ∈ {±1, ±2, ±3, ±6} つきで 3 段まで）を作り、各 f で、Galois 群で保たれる 4 点集合 S ⊂ O(f) をすべて取って、y² = s(x) の Jacobi 多様体の同種類を調べました。

| 段 | f の次数 | f の数（Q の上の形ごと） | 調べた 4 点集合（累計） | 奇数次の同種を持つもの |
|---|---|---|---|---|
| 0 | 1 | 1 | 7 | 0 |
| 1 | 2 | 50 | 147 | 0 |
| 2 | 4 | 480 | 1,119 | 0 |
| 3 | 8 | 1,619 | 3,362 | 0 |

- 次数 8 以下の 2 次の塔の上には、奇数次の同種の部品は 1 つも載りません（Q の上、ひねりの範囲の中で）。この形の反例は、あるとしても次数 48 以上です。
- [heuristic] 条件は「有理数の j が X₀(ℓ) の像に入る」ことで、1 回ごとに偶然でしか起こりません。反例があるとしても、まれです。
- 探していないもの: 臨界値が 5 個以上ある既約な部品（次数 5 のデータでは、Q(i) の上に 1 個もありません）、ひねり d のほかの値、Q(i) の上の塔。

**判定。** Q-Sym は「正しそうだが証明できず、しかも §4 で見るように、正しくても窓は閉じない」予想です。追う価値があるのは Q-Sym ではなく、下の定理 14-A の型の主張です。

## 4. §3.3 の答え：窓はどこまで閉じるか

### 4.1 対称性だけでは、窓は閉じません

- 対称な写像は、商の軌道体への被覆に落ちます。しかし商の軌道体（たとえば x ↦ −x の商は P¹(4, 4, 2, 2)）は双曲的なままで、その被覆も次数とともに指数的に増えます。剛性は増えません。
- 組 (p, q′) では、p の対称性 m_p と q′ の対称性 m_q は、ふつう別の変換です。商を取る相手が違うので、定理 U の議論（同じ O 集合なら同じ一意化）は商の側で始まりません。
- m_p = m_q = m の場合だけは、組ごと商に落ちます。型 (1,1) なら m は x と y を固定します。しかし落ちた先は、錐点の位数がそろわない別の問題で、定理 U の仮定（O 集合の一致）は満たしません。
- **したがって、「両方の脚が対称なら窓は空」は、いまの道具では出ません。**

### 4.2 定理 14-A：両方の脚が楕円型なら、窓は大きい次数で空 [proved、下の入力を使う]

**主張。** (p, q′) を、次数 (a, b) の slack-0 写像の組とし、p は S_p について、q′ は S_q について楕円型だとします（S_p、S_q は B のどの 4 点でもよい。体の条件も要りません）。

- **(A) D_p ≠ D_q のとき。** |O(p) ∩ O(q′)| ≤ M₀ です。M₀ := c(2, 4)⁵ は、次数によらない定数です。
  - 窓の組（m₁、m₂ ≤ 3）では |O(p) ∩ O(q′)| ≥ 2·max(a, b) + 1 なので、**max(a, b) ≤ (M₀ − 1)/2** です。
- **(B) D_p = D_q のとき。** 混合型の窓の組は、**どの次数にもありません**（具体的）。
- 系: 両方の脚が楕円型の問題の組は、次数が一様に有界で、有限個です。

**証明 (A)。**

1. E′_p、E′_q を補題 1 の楕円曲線とし、Ĉ := {(P, Q) ∈ E′_p × E′_q : π_p(P) = π_q(Q)} と置きます。D_p ≠ D_q なので、二つの二重被覆は別物で、Ĉ は既約です。正規化の種数は |D_p ∪ D_q| − 3 ≥ 2 です（Riemann–Hurwitz）。したがって Ĉ は楕円曲線の平行移動ではありません。
2. A := E′_p × E′_q に、L = pr₁*[O] + pr₂*[O] を入れます。deg_L Ĉ = 2 + 2 = 4 です。
3. B ∖ S_p の 2 点の E_{S_p} への持ち上げを ±U、±V とします。O(p) = D_p ∪ p⁻¹(B ∖ S_p) なので、O(p) の点の E′_p への持ち上げは、Γ_p := φ_p⁻¹(⟨U, V⟩ + E_{S_p}[2]) に入ります。Γ_p は階数 2 以下の群です（正方形なら補題 3 から階数 0）。q′ も同じです。
4. O(p) ∩ O(q′) の点は、Ĉ ∩ (Γ_p × Γ_q) の点を少なくとも 1 個与えます。Γ_p × Γ_q の階数は 4 以下です。
5. 一様 Mordell–Lang（Gao–Ge–Kühne、Theorem 1.1）から、その個数は c(2, 4)^{1+4} 以下です。□

**証明 (B)。** D_p = D_q なら E′_p = E′_q =: E′ です。原点を D の上の点に取ると、φ_p、φ_q は同じ E′ からの同種写像です。核を K_p、K_q（位数 a、b）、K := K_p ∩ K_q と置きます。

### 4.3 定理 14-A の位置（正直な評価）

- **形。** 「範囲を限った定理」で、すべての次数についての主張です。混合型の窓について、クラスタ（E13）を使わずに全次数を扱う主張は、route F ではこれが初めてです。ただし上限 M₀ は具体的でないので、(A) の「有限個の確認」は実行できません。
- **範囲の狭さ。** 楕円型は、次数 n の約 10ⁿ 個の写像のうち 15σ₁(n) 個ほどです。
- **Q との関係。** 次数 5 以下では「Q(i) の上の写像 = 楕円型」なので、Q の上の曲線に限れば、次数 5 以下の脚はすべて定理 14-A の範囲に入ります。次数 6 以上でこれが続く保証はありません（次数 10 で破れることは §3.3 のとおり。塔に広げても、2 次だけの塔が残ります）。
- **罠 A との関係。** 定理 14-A は点の集合を局所条件で除いていません。型 (0,0) の証人 (L_n, −L_n) は D_p = D_q の場合に入り、(B) の「混合型」の仮定で外れます。誤って除外していません。
- **罠 B との関係。** これは「小さい側は片づいた」型の記録ではありませんが、**核（E12 §5、G4）への進歩とは数えられません。** 楕円型でない脚については何も言っていないからです。

### 4.4 G4 の限界：slack が正の層 [proved + outline]

- Q の上の曲線に絞ること自体は、slack によらず同じに効きます（§2.2 の証明は slack を使いません）[proved]。
- しかし slack s ≥ 1 の脚は s 次元の族をなし、Q の上の脚が無限個あります（例: L_n(t² + c)、c ∈ Q）。「Q の上の脚は少ない」という絞り方は、slack が正の層では効きません。
- 定理 14-A の議論は、上の部品 g が楕円型で、下の f の次数と slack が有界なら、そのまま通る見込みです [outline]。族のパラメータが f の側にある場合だけです。
