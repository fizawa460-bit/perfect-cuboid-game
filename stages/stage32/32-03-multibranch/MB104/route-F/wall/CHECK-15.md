## 0. 結論

- **次数 6 に、moduli の体が Q(i) に入る slack-0 写像は 1 個もありません。** 根拠は二つで、互いに独立です。
  1. 数値で作った 7,133 個（全 7,148 個のうち）を、220 桁の PSLQ にかけました。Q(i) に入るものは 0 個です（§3）。
  2. F_p での数え上げで、181 個のデータすべてで上限 N_p = 0 になりました（§4）。これは、作れなかった 15 個も含みます。
- したがって、予想 P2 は次数 6 で成り立ちます。ただし、Q(i) の写像がそもそもない、という形でです。
- 合成（3∘2、2∘3）と楕円型の部分は、ANSWER-18 §2.2 が数値によらずに 0 個と示しています（監査 AUDIT-ANSWER-18 で PASS）。理論と計算が一致しています。
- 定理として言うための前提: F_p の不等式の良い還元（ANSWER-18 §3.1、文献は記憶）と、数え上げのプログラムの正しさです（回帰は §4）。

## 3. moduli の体の判定（`wall/checks15/moduli6.py`）

**判定のしかた**
1. 写像を 220 桁まで精密化します。
2. 不変量 J_e（e = 1, 2, 3）を計算します。J_e は、正規化の 3 点の組すべてについて、ラベルごとに重みを付けた複比のべき和を足したものです。
   - J_e は、Gal(Q̄/Q(i)) と同変です。
   - J が写像を区別できていること（単射性）は、J の衝突を数えて確かめます。
3. J_e の実部と虚部が有理数かどうかを、PSLQ で判定します。高さには 60 桁の余裕を求めます。

**回帰。** 次数 5（maps5b、372 個）で、Q(i) に入るのは 2 個（データ 002222）でした。CHECK-13、ANSWER-14 の結果（楕円型の 2 個）を再現しています。

- 合成にも 0 個なのは、部品の 3 次の写像に Q(i) のものがないからです（ANSWER-18 §2.2）。

## 4. F_p での数え上げ（`wall/checks15/fpcount.py`、`fpcount2.py`、GPU）

**方法**
- p ≡ 1 (mod 4)、p > n の素数で、N_p = #{F_p 上の写像} / |PGL₂(F_p)| を数えます。
- #{Q(i) で固定される類} ≤ N_p です（ANSWER-18 §3.1：馴分岐の良い還元、有限体で moduli の体 = 定義体、質量公式）。いくつかの p で最小値を取ると、上限になります。
- `fpcount.py` は cupy の RawKernel で、0 の上のファイバー P₀ と ∞ の上の Q₀、定数 c の組を総当たりします。`fpcount2.py` は P₀ を PGL₂(F_p) の軌道ごとに 1 個にして、軌道の大きさで重みを付けます（約 p³ 倍速い。204/204 で一致）。

**回帰**
- 次数 4: p = 13、17 の最小値が 32。既知の数と一致します。
- 次数 5: p = 13、17、29、37 の最小値が 6。既知の数と一致します。
- N_p は、すべて整数でした（整除の自己検査）。

**次数 6 の結果**（`fpcount2.jsonl`、`checks18/fp37.jsonl`）

- 最小値が 0 になる最初の素数: p = 13 で 97 データ、p = 17 で 80 データ、p = 37 で 4 データ。**181 データすべてで 0 です。**
- p = 17 の時点で 0 にならなかったのは、2∘3 の 4 データ（021133、201133、110233、112033）だけでした。
  - ANSWER-18 §3.3 が理由を説明しました。8 個の類は、Q(i, √2)、Q(i, √6) の上の 2 個組と、Q(i, ⁴√3) の上の 4 個組に分かれます。予測は p = 37、61 で 0、p = 73 で 4 です。
