## 2. 見てほしい所（優先順）

### A. §14（Hecke 型の領域）

1. **14.1 の「D_good の各連結成分で g は一定」。** 補題 C0（§12.3）は g ∈ N(Γ₀) の場合の余白の議論です。g ∉ N(Γ₀)（Comm(Γ₀) に入るかも不明）の場合にも、隣り合う頂点で g が一致すると言えるか。g が連続的に変わったり、成分の中でゆっくりずれたりしないか。
2. **14.2 の「欠損の外では、p と q′ の錐点は一致する」。** 窓の欠損の定義（E13・E15）と合っているか。深い所では |w| が小さいので、片方だけの錐点（w に対数の特異点が出る）はない、という理由でもよいか。
3. **14.2 の種の判定。** 二つのアンカーの距離が ℓ_min、2.4485、3.0571、4.8969 のどれかなら g ∈ N(Γ₀)（E15 定理 E ＋ 補題 I′）。これを、成分の中の任意の組に使ってよいか（どちらのアンカーも十分深い、などの条件は満たされているか）。
4. **14.3 の数え上げ。**
   - 滑らかな頂点のまわりの星で、u_i と u_{i+k} の距離を k = 1〜4 で 1.5286、2.4485、2.9140、3.0571 としました。星が凸で、この距離が τ_p の中の距離（＝ 運搬で使う距離）と一致するか。
   - 「滑らかな頂点のまわりの錐点は 2 個以下」「錐点は頂点の 1/3 以下」は正しいか。
5. **14.4 の組み合わせの Gauss–Bonnet。** 平面的な領域で |内部| ≤ 14·|境界| としました。境界の項の扱い（境界の頂点の価数、成分の数 k）に誤りはないか。
6. **境界はすべて悪い頂点の隣か。** Hecke 型の成分と N 型の成分が直接隣り合うことは本当にないか。

### B. §13（首）

1. **13.1 の Bishop–Gromov。** 錐点の角が π の双曲の錐曲面は、Alexandrov の意味で曲率 ≥ −1 なので、欠損から距離 t 以内の頂点は C·e^t 個以下、としました。この使い方は正しいか。
2. **補題 P（13.2）。** 球面の上で、錐点から距離 r 以上の領域 U について、A(U) ≤ (1 + 2π/λ₀)·L(∂U) です。
   - 平面性から A(U*) ≤ 2π(k − 2) を出すところ。
   - 曲線とその測地線の間の面積 ≤ 曲線の長さ、のところ。
   - 各境界の円の長さ ≥ λ₀ のところ。錐点 1 個のときは π sinh r₀、2 個以上のときは Γ_oct の最短の閉測地線 ℓ₀ です。
   - 曲線が自分自身や他の円と交わる場合を、雑に扱っていないか。
3. **ℓ₀ = 3.0571 の数値。** すべての slack-0 写像の軌道体の群は、Γ_oct（Δ(2,3,8) → S₄ の核）に入る、としました。この前提は正しいか。語の長さ 18 までの列挙で十分か（厳密な打ち切りの評価の付け方）。
4. **13.3 の指数。** 余面積の公式から A(U_r) ≤ 2πa·e^{−c(r − r₀)}（c = 0.327）。深さごとの min(C·e^t, C·a·e^{−c(t − C₀)/2}) の和から、a^{2/(2+c)} = a^{0.859}。この計算は正しいか。

### C. 全体

1. **定数の順序。** ε₀ → R₀ → C₀ → M(R₀) → 最後の上限、の順に決まり、循環がないか。とくに、C₀ と「悪い」の定義（§10.2 の係数 1/2）が、§14.1 の「隣り合う良い頂点で同じ g」に十分か。
2. **定理 C の前提とのずれ。** §11〜§12 の「良い頂点」（単位円板で ε₀ 以内）と、§14 の「D_good の N 型の成分の頂点」は同じものか。
3. **抜け道の確認。** この論法が正しいとすると、混合型の slack (0,0) の次数が有界になります。既知の例（補題 M の塔、L_n、μ の例）と矛盾しないか。たとえば、次数がいくらでも大きい混合型の slack-0 の組が知られていないか。
