## 2. 見てほしい所（優先順）

### A. 定理 C の数え上げ（§11.3）

自分で気になっている点を先に書きます。

1. **ほかの類の領域での零点（§11.3 の 2）。** q′ ≈ τ∘p の領域で、q′ = σ∘p の解は p(z) が σ⁻¹τ の固定点に近い所に出る、と書きました。
   - 固定点が八面体の辺の中点や頂点のとき、解は三角形の**境目の上**に来ます。領域の境目（類が変わる所、悪い三角形との境）で、Rouché の議論は本当に通るか。解の取りこぼしや二重の数えはないか。
   - 「良い三角形 T 枚に T/4 個」は、p の次数が T/8 で、固定点が 2 個だから、という数え方です。部分の領域（境目のある領域）でも、T/4 − O(境目の長さ) の形で正しいか。その誤差を T_bad で抑えてよいか。
2. **一つの点を二つの類で数えていないか。** S_τ の頂点 v で p(v) が σ⁻¹τ の固定点なら、q′(v) = σ(p(v)) になり、σ の数え上げの 2 に入ります。1（自分の類）とは重ならないはずですが、確認をお願いします。
3. **Bezout の「ちょうど a + b 個」。** 混合型で q′ ≢ σ∘p から、重複度込みで a + b 個、としました。∞ での解や、重複度の扱いに問題はないか。
4. **不等式の整理（§11.3 の 3、4）。** 4n₄ + 8n₈ = 3T、T_bad ≤ 8·M_bad、V₄ = 2a + 4、V₈ = 2a − 2、類は 24 個以下、から a ≤ 11 + 25·M_bad。係数の計算に誤りはないか。
5. **良い頂点の定義（§11.2）。** 「単位円板の上で G が σ の持ち上げに ε₀ 以内」という定義で、Lemma Z（ANSWER-09 §2.2）の仮定 (Z) と、2 の Rouché の両方が満たされるか。

### B. 悪い頂点は少ないか（§11.4、§10.3）

- **単連結な部分:** 線形の等周不等式から、悪い頂点は a^{2/3} の程度、という見積もり。指数 2/3 の出し方は妥当か。
- **首・襟（単連結でない部分）:** 一つの首で ℓ·e^{w/3} の程度、という見込み（証明なし）。首がたくさんある場合に、合計が o(a) に収まる理由はあるか。それとも、反例の配置（首だらけの三角形分割）が作れるか。
- **Hecke 型の領域:** アンカーのどの組も同じ奇素数 𝔭 を共有する領域。ここで q′ が p の Hecke 対応に近いなら、**Hecke 対応のグラフとの交点も Bezout で数えられ、同じ形の数え上げができないか**。それとも、この種類の領域は本当に大きくなれるか。
