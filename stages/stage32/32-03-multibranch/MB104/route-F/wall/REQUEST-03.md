## 1. 設定

- B = {0, ∞, ±1, ±i} ⊂ P¹。ラベルは a = {±i}、b = {±1}、e = {0, ∞} です。B×B の点 (β, β′) で、β と β′ のラベルが同じものを「合う点」と呼びます（12 個）。
- 組 (p₁, p₂) は、V₀ = P¹ から P¹ への 2 つの写像で、次数は (a, b) です。Φ = (p₁, p₂) : V₀ → P¹×P¹ が像の上へ双有理であるものを考えます。
- O_i は、p_i で B の上にあり、局所次数が奇数の点の集合です。slack s_i は、|O_i| = 2·deg p_i + 2s_i + 4 で決まる余裕の量です（slack 0 は臨界点がすべて単純で B の上にある場合）。
- 一致点 J は、Φ(v) が合う点になる v の集合です。j = |J|、M = Σ_{v∈J} min(e_v(p₁), e_v(p₂)) ≥ j。
- 不一致の集合 Ω は、O₁ と O₂ のうち、一致点にならないものです（E12 Lemma 0：O_i ∖ Ω ⊆ J）。
- **問題の組**は、|Ω| ≤ 4 を満たす双有理な組です。32-03 の目標は、**問題の組の次数 a+b に上限があること**です。

## 2. 証明ずみの 2 つの不等式と、壁

| 不等式 | 内容 | 出典 |
|---|---|---|
| 下から | 問題の組では、j ≥ |O_i| − |Ω| ≥ 2·deg p_i + 2s_i。とくに M ≥ j ≥ a+b | E12 Lemma 0 |
| 上から | 像が 4 本の Klein グラフ Γ_g（g ∈ {t, −t, 1/t, −1/t}）のどれでもなければ、M ≤ 2(a+b) | E15 Lemma K |

- Lemma K の証明：各 Γ_g は bidegree (1,1) なので Φ*Γ_g の次数は a+b です。合う点はどれも、ちょうど 2 本の Γ_g の上にあります。4 本を足すと 2M ≤ 4(a+b) になります。
- **必要なのは、問題の組について M ≤ c₀·(a+b) + C を c₀ < 1 で示すことです。** そうすれば、a+b ≤ C/(1−c₀) となります。
- **途中の目標は 2−η です。** M ≤ (2−η)(a+b) + C が言えれば、slack の範囲が s₁ ≤ (1−η/2)b − (η/2)a + C/2 まで狭まり、それだけで記録できる結果になります。**まだ、η > 0 すら出ていません。**

## 3. 分かっていること（壁の正体）

- **固定した曲線との交点数だけでは、2 から下がらない見込みです** [heuristic]。下げるには、合う 12 点で重複度 μ をもつ bidegree (u,u) の曲線が要ります。ところが、μ > u は次元の数え上げで不可能です（(u+1)² < 6u(u+1)）。
- そのため、**両方の写像が B の上でどう分岐しているかを使う**ことが必須、というのがこれまでの結論です（E16 §4）。
- 一般の組（問題の組ではない組）では、Lemma K はほぼ鋭いと期待されます（一般の有理曲線で M ≈ 2(a+b) − 1）。つまり、**問題の組だけが持つ条件（|Ω| ≤ 4、双有理性、slack の構造）を、証明のどこかで使わないと下がりません**。
- 測定（F-03、楕円型 (E) の組、次数 4・8・16）：M の最大値は 10・8・8 で、一定のままでした。ただし、これらの組は |Ω| が大きく、問題の組ではありません。
