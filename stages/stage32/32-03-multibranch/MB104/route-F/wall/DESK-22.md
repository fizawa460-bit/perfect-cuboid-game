## 0. 問いと結論

- **結論。効きません。** 命題 22-K（§1）で、Q の上の脚の「核」は route F の分類の対象になると分かりました。しかし、核が自明な脚には何も言えず、slack が正の一般の脚は核が自明です（§2）。

## 1. 命題 22-K（Q の上の脚の核）[proved。入力: E14 命題 F、ANSWER-14 §2.2]

**記号。** E14 命題 F により、脚 p : V₀ → P¹ は p = c∘κ と分解します。
- c は P¹(2⁶)（錐点 B）の軌道体被覆、つまり slack 0 の写像で、次数は m₀ = [Γ₀ : Λ] です。ここで Λ = ρ(π₁^orb(X)) です。
- κ は π₁^orb の上で全射です。slack s > 0 と deg κ ≥ 2 は同値です。
- この c を、p の**核**と呼びます。

**命題 22-K。** 曲線が Q の上にあり、脚 p が Q(t) に入るとします（ANSWER-14 §2.2）。このとき、p の核 c の moduli の体は Q です。B は点ごとに固定し、ソースの Möbius 変換だけで割ります。これは CHECK-15 §1 の意味の「類」です。

*証明。*
1. p = c′∘κ′（c′ は軌道体被覆）という分解は、Λ ⊂ Λ′ ⊂ Γ₀ となる部分群 Λ′ と対応します（共役を除いて）。次数が最大のものは Λ′ = Λ で、共役を除いて一つだけです。
2. B は Galois 群で集合として保たれる（動くのは i ↔ −i だけ）ので、軌道体 P¹(2⁶) は Q の上で定義されます。σ ∈ Gal(Q̄/Q) は、軌道体被覆を、同じ次数の軌道体被覆に写します。
3. σ(p) = p なので、σ(c)∘σ(κ) は p の分解で、σ(c) は次数 m₀ の軌道体被覆です。1 の一意性から、σ(c) = c∘μ（μ はソースの Möbius 変換）です。□

**帰結 [proved。入力: ANSWER-14、CHECK-15、CHECK-20、ANSWER-18 の定理 18-E]**
- Q の上の slack-0 写像は、次数 3、6、7 にありません（Q(i) の上にもない）。次数 5 は Q(i) の楕円型 6 個だけで、Q では共役（2 + i ↔ 2 − i）が入れ替わるので、Q の上にはありません。
- したがって、**Q の上の脚（slack は何でもよい）の核の次数 m₀ は、3、5、6、7 になりません。** 2 ≤ m₀ ≤ 5 なら、核は楕円型です（ANSWER-14）。
- P2∞（Q 版）が正しければ、どの Q の上の脚も「（楕円型か塔）∘ κ」の形です。

## 2. なぜ効かないか [proved + outline]

- **核が自明な脚（m₀ = 1、Λ = Γ₀）には、命題 22-K は何も言いません。** その場合 c は恒等写像で、p = κ です。
- slack が正の脚は、slack 次元の族をなします（E14 命題 F の後、ANSWER-14 §4.4）。一般の写像（slack 2n − 2）は ρ が全射で、核が自明です [outline：一般の写像のモノドロミーが Γ₀ 全体に行くこと]。Q の上の点も、族の中に無限個あります。
- E12 §5 の残り（双有理な組で、両方の slack が正）で、核が自明な脚を除く道具はありません。route F の数え上げ（F_p、P2∞）は、剛な（族にならない）写像の数を抑える道具なので、族には効きません。
- 障害は、E14 命題 C と同じく**双有理性**です。核が自明でない族 (L_n∘κ, −L_n∘κ) は双有理でないので外れますが、核が自明な組を外す議論は、双有理性を量的に使わないと出ません。
