## 1. 合成の基本補題

**補題 T0 [proved]。** f を次数 d の slack 0 の写像、g を次数 ℓ の写像とします。p = f∘g が slack 0 であることは、次の 2 つと同値です。
- (i) g の臨界点はすべて単純で、臨界値は O(f) に入る。
- (ii) そのとき、O(p) = {x : g(x) ∈ O(f) で、e_x(g) = 1}、つまり「g の、O(f) の上の単純な点」の集合になる。

*証明。*
1. e_x(p) = e_x(g)·e_{g(x)}(f) なので、局所次数が 2 以下であることは、「e_x(g) と e_{g(x)}(f) の少なくとも一方が 1 で、どちらも 2 以下」と同じです。
2. p の臨界値が B に入ることから、g の臨界点 x では f(g(x)) ∈ B かつ e_{g(x)}(f) = 1、つまり g(x) ∈ O(f) です。
3. 逆に (i) が成り立てば、p の臨界点は「g の臨界点」と「f の臨界点の上の g の点（g はそこで不分岐）」で、臨界値はすべて B に入ります。
4. 臨界点の数は自動的に (2d − 2)ℓ + (2ℓ − 2) = 2dℓ − 2 です。
5. (ii) は 1 から出ます。□

**楕円型の部品。** S_g ⊂ O(f) を 4 点の集合とし、g の臨界値がすべて S_g に入り、S_g の上で slack 0 だとします。これを「g は S_g について楕円型」と言います。
- ANSWER-14 の補題 1 がそのまま使えます。g∘π′ = π_{S_g}∘φ で、φ : E′_g → E_{S_g} は次数 ℓ の同種写像です。π′ は 4 点 D_g（S_g の上の単純な点）で分岐します。
- 補題 T0 から、O(p) = D_g ∪ g⁻¹(O(f) ∖ S_g) です。O(f) ∖ S_g は 2d 点で、g はその上で不分岐です。
- **例。**
  - d = 1（f が回転）なら、p は ANSWER-14 の意味の楕円型そのものです。
  - 次数 3 の slack 0 の写像（単純な分岐）は、分岐値の 4 点について必ず楕円型です（2ℓ − 2 = 4 なので）。
  - 次数 2 の写像は、分岐値 2 点に O(f) の 2 点を足した 4 点について楕円型です（ANSWER-14 §4.2）。

**上の次数。** p が「上が f、下が楕円型 g」と書けるとき、その f の次数の最小値を τ(p) と書きます。
- 楕円型の写像は τ = 1 です。
- 次数 6 の 2∘3 型は τ ≤ 2、3∘2 型は τ ≤ 3 です。

## 2. 定理 T：上の次数が有界なら、窓は大きい次数で空

**主張 [proved。ただし一様 Mordell–Lang と補題 C を入力に使う]。**
(p, q′) を窓の組とします。p = f₁∘g₁、q′ = f₂∘g₂ で、g_i は S_{g_i} ⊂ O(f_i) について楕円型、deg f_i = d_i だとします。

- **(A) D_{g₁} ≠ D_{g₂} のとき。**
  - |O(p) ∩ O(q′)| ≤ c(2, 4)^{1 + 2d₁ + 2d₂} です。
  - したがって、max(a, b) ≤ (c(2, 4)^{1 + 2d₁ + 2d₂} − 1)/2 です。
- **(B) D_{g₁} = D_{g₂} のとき。**
  - 型 (1,1)、(1,3)、(3,1)、および (2,2) で |K| = 1 の場合は、**a ≤ 4·d₁·d₂ + 1** です（具体的な上限）。b も同じです。
  - (2,2) で |K| = 2 の場合は、系 C で、次数半分の (1,1) の組に戻ります。
- **系。** d₁、d₂ ≤ τ₀ なら、窓の組の次数は τ₀ だけで決まる定数で抑えられます。

### 証明 (A)

ANSWER-14 の証明と同じ形です。違うのは群の階数だけです。

1. Ĉ := {(P, Q) ∈ E′₁ × E′₂ : π′₁(P) = π′₂(Q)} と置きます。
   - 二つの二重被覆の分岐集合 D_{g₁}、D_{g₂} が違うので、Ĉ は既約です。
   - Ĉ は (Z/2)² 被覆の合成で、その種数は 1 + 1 + (|D₁ △ D₂|/2 − 1) ≥ 2 です。
   - deg_L Ĉ = 2 + 2 = 4 です（L = pr₁*[O] + pr₂*[O]）。**これは d_i によりません。**
2. O(f_i) ∖ S_{g_i} の 2d_i 点を E_{S_i} に持ち上げたものを ±U_{i,1}, …, ±U_{i,2d_i} とします。
   - Γ_i := φ_i⁻¹(⟨U_{i,j}⟩ + E_{S_i}[2]) と置きます。⟨U_{i,j}⟩ は階数 2d_i 以下で、φ_i による逆像は階数を変えません。
3. x ∈ O(p) ∩ O(q′) を取ります。
   - x ∈ D_{g_i} なら、持ち上げ P は φ_i(P) ∈ E_{S_i}[2] を満たします。
   - そうでなければ、g_i(x) ∈ O(f_i) ∖ S_{g_i} なので、φ_i(P) = ±U_{i,j} です。
   - どちらでも P ∈ Γ_i です。したがって x は、Ĉ ∩ (Γ₁ × Γ₂) の点を少なくとも 1 個与えます。
4. Γ₁ × Γ₂ の階数は 2d₁ + 2d₂ 以下です。一様 Mordell–Lang から、点の数は c(2, 4)^{1 + 2d₁ + 2d₂} 以下です。
   - Ĉ は種数 2 以上なので、正の次元の剰余類を含みません。□

### 証明 (B)

D := D_{g₁} = D_{g₂} なので、E′₁ = E′₂ =: E′ です。原点を D の上に取ると、φ₁、φ₂ は E′ からの準同型になります（φ_i(O′) が 2 等分点 t になるときは、g_i を μ_t∘g_i に、f_i を f_i∘μ_t に取り替えます。μ_t は τ_t が P¹ に降りた Möbius 変換で、S_{g_i} を保ちます。p は変わりません）。それぞれの核を K₁、K₂、K := K₁ ∩ K₂ と置きます。

1. O(p) ∖ D の E′ への持ち上げを Σ₁ とします。
   - 補題 T0 から、Σ₁ = φ₁⁻¹({±U_{1,j}}) です。
   - これは K₁ の剰余類 4d₁ 個の和で、|Σ₁| = 4d₁ℓ₁ = 4a です。
   - Σ₂ も同じで、K₂ の剰余類 4d₂ 個の和です。
2. K₁ の剰余類と K₂ の剰余類の交わりは、空か K の剰余類です。したがって |Σ₁ ∩ Σ₂| ≤ 16·d₁·d₂·|K| です。
3. D の外では π′ は不分岐なので、|Σ₁ ∩ Σ₂| = 2(|O(p) ∩ O(q′)| − 4) = 2(2a − m₁) です。
4. 2 と 3 から、a ≤ 4·d₁·d₂·|K| + m₁/2 です。
5. |K| の扱い:
   - φ₁ と φ₂ は E′ → E′/K を通ります。これは ±1 で割ると、V₀ の次数 |K| の写像 h に降ります。そして g_i = ψ_i∘h と書けます。
   - したがって p と q′ は共通の右因子 h を持ち、像の上の次数 d は |K| の倍数です。
   - 補題 C から、d は m₁ と m₂ を割り切ります。窓では d ≤ 2 で、d = 2 は (2,2) だけです。
   - |K| = 1 なら、a ≤ 4d₁d₂ + 1 です（m₁ ≤ 3、整数なので）。
   - |K| = 2 なら、系 C で、次数 a/2 の (1,1) の組に戻ります。□

**検算。** d₁ = d₂ = 1 では a ≤ 4 で、ANSWER-14 の (B) と一致します。

## 4. 残る穴：上の次数が有界でない塔

**4.1 同じ右因子の場合は、補題 C で片づく [proved]。**
- g₁ = g₂ =: g（同じ右因子）なら、(p, q′) は g を通り、像の上の次数は deg g です。
- 補題 C・系 C から、窓では deg g ≤ 2 で、(2,2) から次数半分の (1,1) に戻ります。
- 次数を下げる帰納法になります。

**4.2 違う右因子の場合は、閉じていない [outline]。**
- 例: g₁、g₂ が違う次数 2 の写像で、f₁、f₂ の次数が大きい場合。
- O(p) ∩ O(q′) は、二つの 2 次写像の組 (g₁, g₂) による曲線（種数 1 以下）の上の点で、「g₁ で O(f₁) に、g₂ で O(f₂) に落ちる」ものです。
- この点の数を抑えることは、もとの問題と同じ形の問題を、次数半分で解くことにあたります。小さくなる量がないので、帰納法になりません。
- ANSWER-14 §4.2 の「2 次だけの長い塔は外」と同じ穴です。

**4.2′ 穴は、もっと大きい（ANSWER-18 §2.1 の補題 M、§4.1）[proved]。**
- 正方形 S の虚数乗法の x 座標 x_S(α·)（N(α) が奇数）は、B を B に 1 対 1 に写し、B ⊂ O(x_S(α·)) です。だから、違う正方形の部品を何段でも積めます。
- たとえば x_{S₁}([m₁]·)∘x_{S₂}([m₂]·) は Q の上にあり、m₁、m₂ をともに大きくできます。
  - 下の部品 x_{S₂}([m₂]·) は楕円型ですが、上の次数 τ = m₁² に上限がないので、定理 T は使えません。
  - 上の部品も楕円型ですが、下の次数 m₂² に上限がないので、下の 18-B（DRAFT-18B-19）も使えません。
- この族の組が実際に窓に近づくかは、L1（`checks19/l1.py`）で測っています。

**4.3 穴の大きさ [heuristic]。**
- 2 次の塔は、2 次の部品を載せるたびに自己同型が 1 つ増えます（ANSWER-14 §3.3）。自己同型があると、O(p) がその分だけ対称になります。
- 対称性で商を取ると、問題が 1 段小さくなるかもしれません。ただ、ANSWER-14 §4.1 のとおり、組の両方の脚が同じ変換で対称でないと、商に落ちません。
- これが穴を閉じる道になるかは、分かりません。
