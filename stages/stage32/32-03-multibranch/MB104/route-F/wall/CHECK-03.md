## 2. §B Pell 被覆：不等式は PASS。ただし新しい目標にはならない

**PASS した部分**
- 欠損の恒等式 δ := 4(a+b) − 2M = Σ_J exc_v + Σ_{J の外} ord_v Ξ です。ここで Ξ = Φ*D_K です。
- 奇数位の点の数について、o(f) ≤ δ です。f = φ∘p₁ − φ∘p₂ です。
- f が平方でないとき、M ≤ 2(a+b) − 1 − g(C) です。
- f が平方のときは、M ≤ 2(a+b) − δ/2 しか言えません。
- 等号の条件は、「J の外の交わりがすべて単純で、exc ∈ {0, 1}」です。
- gcd の誤りには頼っていません。exc ≥ 0 と偶奇しか使っていないからです。
- 例 (x², x³)：M = 6、δ = 8、g(C) = 3 で等号です（手計算で確かめました）。

**判定：言い換え（罠 B）**
- 外部 AI 自身が、g(C) ではなく δ を直接の目標にすべきだと勧めています（B.2）。
- ところが、δ ≥ η(a+b) − C は、M ≤ (2 − η/2)(a+b) + C/2 とまったく同じ文です。δ は 4(a+b) − 2M そのものだからです。
- さらに B.3 で、外部 AI 自身が、問題の組の条件は δ を上から押す（大きくしない）と書いています。
  - 細かい点：B.3 の「j ≥ 2·max(a,b) + 4」は、E12 Lemma 0 では j ≥ |O_i| − |Ω| ≥ 2·deg p_i + 2s_i です。結論の向きは変わりません。
- 新しい入力（6 分類の外）は、L1・L2 だけです。L1 は関数体の Pell 方程式、L2 は unlikely intersections を使う案で、どちらも経験則の段階です。
- L0（δ ≥ 2、つまり M ≤ 2(a+b) − 1）は、示せそうです。ただし、改善は定数 1 だけです。
