## 目標

Stage32-03（E12 §5）の有限化、つまり slack 0 の写像の対の混ざった窓（型 (1,1)、(2,2)、(1,3)）を、すべての次数で閉じることです。

## 記号（ANSWER-14、THEORY-07、DRAFT-TOWER-17 と同じ）

- B = {i, −i, 1, −1, 0, ∞}（八面体の 6 頂点）。
- 次数 n の写像 p : P¹ → P¹ で、臨界値がすべて B に入るものを考えます。
- O(p) は B の上の単純点の集合です。|O(p)| = 2n + 4 のとき、slack 0 と呼びます。
- 「楕円型」は、臨界値が B の 4 点に入る写像です。ANSWER-14 により、これは同種写像の x 座標です。
- 「塔」は、合成 f∘g（deg f ≥ 2、deg g ≥ 2）です。補題 T0（DRAFT-TOWER-17）により、f∘g が slack 0 になるのは、g の臨界点が単純で、臨界値が O(f) に入るときに限ります。
- 「モジュライ体」は、写像の同値類（両側の Möbius 変換。ただし値の側は B を保つもの）が Galois 作用で固定される体です。

## これまでに分かったこと（すべて PR #1876 にあります）

| 次数 | Hurwitz の総数 | モジュライ体が Q(i) に入るもの | 中身 |
|---|---|---|---|
| 3 | 60 | 0 | — |
| 4 | 680 | 32（Q 上は 16） | 全部が楕円型 |
| 5 | 6,090 | 6 | 全部が楕円型 |
| 6 | 71,508（代表 7,148） | **0** | — |

次数 6 の 0 は、次の二つの方法で確かめました（`wall/CHECK-15.md`、`wall/checks15/`）。
1. **数値で作った 7,133 個の写像**: J 不変量を 220 桁で計算して PSLQ にかけました。Q(i) に入るものは 0 個で、J の衝突もありません。この中には、合成 3∘2（168 個）、合成 2∘3、楕円型の候補（24 個）がすべて含まれます。
2. **F_p での数え上げ（GPU）**: p ≡ 1 mod 4 で p > n の素数 p = 13、17（一部は 29）について、N_p = #{F_p 上の写像} / |PGL₂(F_p)| を数えました。各データの上で p ごとの最小値を取ると、181 個のデータのうち 177 個で 0 になりました。数値で作れなかった 15 個の写像を含むデータは、すべて 0 です。この方法は、次数 4（32 個）と次数 5（6 個）で、既知の数をちょうど再現します。
   - 残りの 4 データ（021133、110233、112033、201133 と、その回転。どれも 2∘3 型で、写像は 8 個ずつ）は、N_13 = 4、N_17 = 2、N_29 = 2 で、0 まで下がりません。この 4 データは、8 個すべてを数値で作ってあり、方法 1 で Q(i) のものは 0 個です。
   - 私の推測: 8 個の Galois 軌道が、たとえば体 Q(i, √a)、Q(i, √b)、Q(i, √ab) の上の 2 個組に分かれていると、どの素数でもどれかの組が F_p 上に乗ります。そのため、最小値は 2 より下がりません（Jordan の補題は軌道ごとにしか効かない）。この推測が正しいかも、問 2 で見てください。

並びの観察: 数がある次数 4、5 は a² + b² の形に書ける数で、0 個の次数 3、6 は書けない数です。Z[i] による虚数乗法を持つ曲線 y² = x³ − x（または i を固定する曲線）の、次数 n の Q(i) 上の自己同種写像が、ノルム n の元に対応するという見方と合います。**ここまでのデータに、Q(i) の塔は 1 つも出てきません。**

## 問 1（本題）: Q(i) の写像は、すべての次数で楕円型だけか

**主張 Q:** slack 0 の写像で、モジュライ体が Q(i) に入るものは、すべての次数で楕円型である。

- 証明してください。証明できない場合は、次の三つを答えてください。
  - どこが壁か。
  - 塔を許した弱い形（元の予想 P2：「楕円型か塔だけ」）なら証明できるか。
  - 反例が最初に出そうな次数と、それを探すための計算方法。
- 使えそうな道具の候補です（私の推測なので、使わなくてかまいません）。
  - Galois 作用と組み紐軌道（Hurwitz 空間の Q(i) 有理点）。分岐の型が B の上で八面体群とどう両立するか。
  - 悪い還元の素数の制限（Beckmann の定理：単純化の前提も含めて正確に書いてください）。
  - F_p での数え上げが 0 になる理由の理論的な説明（たとえば、Frobenius の固定点がない理由）。
  - 楕円型の写像では、ノルム n の Z[i] の元が必要になる、という仕組みが、楕円型でない写像でも何かの「判別式」として現れないか。
- 主張 Q が全次数で無理なら、「次数 n がある条件（たとえば a² + b² の形でない）を満たすなら、Q(i) の写像はない」という部分的な結果でも役に立ちます。
