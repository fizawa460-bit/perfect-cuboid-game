# 罠の一覧（route F、2026-11-13）

依頼文や記録で「罠 A」などと書くときは、この一覧の意味で使います。

- 罠 A と罠 B は、以前の検討で使った名前です。定義は、その会話でユーザーが見つけた文をもとに書きました。
- 罠 C 以降は、2026-11-13 に route F の作業で足したものです。

新しい罠が見つかったら、ここに足してください。

## 罠 A：退化した点

- **内容**: 辺が 0 の (3,4,0) のような退化した直方体があると、集合が空でないように見えたり、無限に見えたりする。本物の解があるかどうかとは関係ない。
- **避ける条件**: 退化した直方体が満たさない性質を使う必要がある。
  - 例: 辺が 0 でないこと、辺が特定の素数だけでできていること。
  - 局所条件、Brauer 類、降下、被覆は使えない。退化した点もこれらを満たしてしまうから。Stage33〜36 は、これで止まった。

## 罠 B：言い換えの繰り返し

- **内容**: 手持ちの道具を新しい角度で当てただけで、数字が動かない（E13〜E16 の形）。
- **避ける条件**:
  - ゴールを最初から、有限の主張か、範囲を限った定理として書く。
  - 「小さい側は片づいた、残りは OPEN」の形になったら止める。
- route F での確かめ方: 計画書 F4 の基準 1〜3 と、F5 の「禁止」。

## 罠 C：浮動小数点の偽の一致

- **内容**: 倍精度だと、一致していない点が 10⁻⁸ ほどの近さで一致に見える。
- **確かめ方**: 小さい ω の T は、すべて mpmath（50 桁）で数え直す。一致は 10⁻³⁰ 未満、不一致は 10⁻¹² より大きいことを確かめる。
- 出どころ: F02-RESULT §2.1。(4,4) では、偽の双有理な組が 2,668 個出た。

## 罠 D：構造の取りこぼし

- **内容**: 「構造なし」と分類しても、別の構造が隠れていることがある。
- **確かめ方**: 分類を増やすたびに、残りを別の方法で調べ直す。
- 実例:
  - (3,3) の「構造なし」(5,0) の 192 個は、Galois 共役な 2 つの類の組だった（THEORY-01）。一致の仕組みはまだ分からない（CHECK-01 の P4）。
  - (4,4) の「構造なし」のうち 3,072 個は、q に B の対称性 g を合成すると、左側の因子を共有していた。F02-SHAPE の分類 1 は、g を合成せずに判定していた。
  - (4,4) の「構造なし」のうち 6,144 個は、q∘S = h∘p₁ の形だった。h は B の対称性ではない Möbius 変換（型 (H)、CHECK-01 §2.3）。
