# MB104 — Z34: incidence-24 conic orthogonality and improved Hodge bound

Status: **RESEARCH CHECKPOINT / PRE-AUDIT / NO CREDIT**

## Purpose

Z33 proves that for a potentially unbounded genus-one span-five carrier whose node support lies in a support hyperplane, the pulled-back hyperplane section on the normalization is exactly the reduced divisor of node-preimage branches:

```
div(nu^*h)=B_node,
M=R=O=d,
m_b=1 for every box-node branch.
```

For the two incidence-24 hyperplane orbits, the archived exact section classification gives eight smooth conics, each containing six of the 24 box nodes and each incidence-24 node lying on exactly two conics.

The old fixed-component argument only treated the uniform Picard ray. Z34 asks for a population-wide consequence that uses Z33 directly and does not assume equal exceptional coefficients.

## 1. Strict section conics are disjoint from the carrier

Let `Q_1,...,Q_8` be the strict transforms of the eight smooth conics in the minimal resolution `S`.

Z33 says every zero of `nu^*h` occurs at a box-node branch, with exact order one, and the residual strict-hyperplane factor is nonzero at the resolved landing point. Therefore the strict transform of the carrier has no intersection with the strict hyperplane section at those node branches.

There is also no intersection away from the box nodes because `div(nu^*h)` has no residual degree left.

Hence

```
D.Q_j=0,  j=1,...,8.                         (Z34-ORTH)
```

This is population-wide inside the active genus-one incidence-24 span-five sector; no uniform-ray hypothesis is used.

## 2. Geometry of the eight conics

Each `Q_j` is a smooth rational conic. Since `K_S=H` and `H.Q_j=2`, adjunction gives

```
Q_j^2=-4.
```

The eight strict conics are pairwise disjoint on the resolution: their intersections on the singular model occur only at the A1 nodes, and the distinct section branches separate on the exceptional curves. Equivalently, the archived section identity has

```
sum_j Q_j = H - sum_{s in Sigma_24} E_s,
```

whose square is

```
16 - 24*2 = -32 = 8*(-4).
```

Thus their span is negative definite with Gram matrix `-4 I_8`.

## 3. Orthogonal positive direction

Define

```
H_24 = H + (1/2) sum_{j=1}^8 Q_j.
```

Then for every `j`,

```
H_24.Q_j = 2 + (1/2)(-4) = 0.
```

Moreover

```
H_24^2
 = H^2 + sum_j H.Q_j + (1/4)sum_j Q_j^2
 = 16 + 16 - 8
 = 24.
```

Because `D.Q_j=0`, we also have

```
H_24.D = H.D = d.
```

The orthogonal complement of the negative-definite conic span has signature `(1,*)`. Applying Hodge index there to `D` and the positive vector `H_24` gives

```
D^2 <= d^2/24.                                (Z34-HODGE24)
```

This strictly improves the ambient population-wide bound `D^2<=d^2/16` on this incidence-24 sector.

## 4. Why this does not yet close the sector

For normalization genus one, MB102 only supplies the coarse lower bound

```
D^2 >= -d.
```

Combining with Z34-HODGE24 gives

```
-d <= D^2 <= d^2/24,
```

which allows arbitrarily large `d`.

Therefore the improved positive direction is a genuine structural gain but not a finite-degree theorem by itself.

It also does not justify combining the denominator `24` naively with the Z21 exceptional-root term `(1/2)sum M_i^2`: the conic classes are not orthogonal to the exceptional roots, so the two projections do not add independently.

## 5. Retained consequence and next gate

The incidence-24 span-five genus-one population now satisfies simultaneously

```
M=R=O=d,
m_b=1,
D.Q_j=0 for all eight strict conics,
D^2<=d^2/24.
```

The next useful question is therefore not another scalar Hodge replay. It is the coupled lattice problem generated by

```
{E_s}_{24 nodes} union {Q_j}_{8 conics},
```

using the exact conic-node incidence graph. A successful continuation must extract a quadratic penalty from nonuniform branch weights or prove that the equality-compatible weight cone is itself finite/rigid enough to feed the support-Hilbert route.

Z34 does not authorize reopening the old uniform-ray component-capacity argument as if it covered arbitrary coefficients.
