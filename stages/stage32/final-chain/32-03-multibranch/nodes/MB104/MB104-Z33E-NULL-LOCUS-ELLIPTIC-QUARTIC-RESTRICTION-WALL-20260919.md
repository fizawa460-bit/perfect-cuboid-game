## Target

Z33D leaves the possibility that zero-pairing elliptic quartics might impose a global, rather than merely pointwise, obstruction.

For a zero-pairing elliptic quartic `Q` and a hypothetical irreducible carrier

```text
C in |lP|,
P.Q=0,
```

disjointness on the smooth resolution implies that the defining section of `O_S(lP)` restricts to a nowhere-vanishing section on `Q`. Hence a necessary condition is

```text
O_Q(lP) ~= O_Q.
```

If `P|_Q` were nontrivial non-torsion this would exclude every `l`; if it had torsion order `n`, it would force `n|l`.

The exact representative computation shows neither happens: `P|_Q` is already trivial.

## 2. Every retained node is a hyperflex: H ~ 4p

Take a node

```text
p=(1:0:eps:delta)
```

in the `t=0` group. The hyperplane

```text
L_p = eps*y + delta*z - 2x = 0
```

meets `Q` only at `p`.

Indeed write

```text
Y=eps*y=x+A,
Z=delta*z=x-A
```

using `Y+Z=2x`. The two quadric equations give

```text
2xA+A^2=t^2,
-2xA+A^2=-t^2.
```

Adding yields `2A^2=0`, hence `A=0`, then `t=0`, and projectively the unique point is `p`.

Since a hyperplane section of the degree-four curve has total degree four,

```text
div_Q(L_p)=4p,
H|_Q ~ 4p.
```

For a node

```text
p=(0:1:eps:delta*i)
```

in the `x=0` group, put

```text
Y=eps*y,
W=-i*delta*z.
```

Then

```text
Y^2=t^2+x^2,
W^2=t^2-x^2,
```

and the hyperplane

```text
Y+W-2t=0
```

gives the identical calculation, so again

```text
H|_Q ~ 4p.
```

Thus all eight retained node points on the representative quartic are hyperflex points for the degree-four embedding.

## 3. Restriction of the hostile ray

A balanced support meets a zero-pairing quartic in exactly seven of its eight box nodes. Let `p` be the omitted node.

On `Q`,

```text
sum_(supported nodes on Q) p_i
  ~ D_8-p
  ~ 2H-p.
```

For

```text
P = 7H - 4 sum_(i in Sigma) E_i,
```

restriction to `Q` therefore gives

```text
P|_Q
 ~ 7H - 4(2H-p)
 = 4p-H
 ~ 0.
```

Hence

```text
O_Q(P) ~= O_Q
```

already at `l=1`, and consequently

```text
O_Q(lP) ~= O_Q
```

for every `l>=1`.
