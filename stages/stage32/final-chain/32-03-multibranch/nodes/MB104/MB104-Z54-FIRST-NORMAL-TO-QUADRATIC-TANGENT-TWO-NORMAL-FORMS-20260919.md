## 1. Coordinate normalization

Choose projective coordinates [x:y:z:w] so

```
L1 = {x=y=0},
L2 = {x=z=0}.
```

Then

```
I_(L1 union L2) = (x,yz).
```

Every tangent quadric belongs to

```
I_2 = span{x^2,xy,xz,xw,yz}.
```

Let P be the two-dimensional pencil generated by q1,q2.

Since the common reduced zero set is only L1 union L2, the pencil must contain a quadric with
nonzero yz coefficient.  Normalize it to

```
q2 = yz + x*l
```

for a linear form l.

The one-dimensional kernel of the yz-coefficient map on P is generated by a quadric

```
q1 = x*l1.
```

If l1 is not proportional to x, then q1=0 has a second plane l1=0 distinct from x=0.  Restricting
q2 to that plane gives a nonconstant quadric curve, producing an additional one-dimensional
component outside L1 union L2.  This contradicts the exact reduced support.

Hence

```
q1 = x^2
```

after scaling.

## 2. Eliminate inessential coefficients

Write

```
q2 = yz + a xy + b xz + c xw + d x^2.
```

Replacing

```
y -> y + b x,
z -> z + a x
```

kills the xz and xy terms, up to changing the x^2 coefficient.
Changing q2 by a multiple of q1 then kills x^2.

Thus

```
(q1,q2) ~ (x^2, yz + c xw).
```

If c=0 we obtain

```
T0 = (x^2, yz).
```

If c != 0, rescale w to obtain

```
T1 = (x^2, yz+xw).
```

These two cases are not projectively equivalent: in T0 the second pencil generator can be chosen
of rank two, while in T1 the corresponding yz+xw quadric has rank four; equivalently the pencil
rank/discriminant profile differs.

Therefore there are exactly two projective tangent-cone normal forms compatible with all retained
Z53 data:

```
T0: (x^2, yz),
T1: (x^2, yz+xw).
```
