## Locked statements

The level-eight modular curve is generated by the five theta functions

```text
theta00(z), theta10(z), theta01(z), theta00(2z), theta10(2z),
```

with the classical quadratic theta relations. The quotient group `Gamma[4]/Gamma[8] ~= (Z/2)^3` acts diagonally on these generators; the three displayed generators `T,T',R` act by sign changes.

For two variables, Theorem 2.4 identifies the box coordinates with explicit theta products. In the notation of the paper:

```text
Z1 -> theta01(z)theta01(w)
Z2 -> theta00(z)theta00(w)
Z3 -> theta10(z)theta10(w)
C  -> theta00(2z)theta00(2w)+theta10(2z)theta10(2w)
W1 -> theta10(2z)theta00(2w)+theta00(2z)theta10(2w)
W2 -> i(theta10(2z)theta00(2w)-theta00(2z)theta10(2w))
W3 -> theta00(2z)theta00(2w)-theta10(2z)theta10(2w).
```

The complex box variety is the diagonal modular quotient of the product of the two level-eight curves.

For a typical singular cusp represented by `(infinity,infinity)`, Proposition 2.5 uses the level-eight cusp parameters

```text
p=exp(2*pi*i*z/8),
q=exp(2*pi*i*w/8).
```

The stabilizer generator acts as

```text
(p,q) -> (-p,-q),
```

so the box node is locally

```text
(C^2,0)/{+1,-1}.
```

The paper further states that the Beauville double cover is locally `C^2 -> C^2/+-1`; after blowing up, the resolved double cover is ramified along the exceptional line.
