## 1. Differences detect hidden characteristic exponents, but not linearly uniformly

The previous counterexample

```
x=t^2,
y=t^(2k+1),
h1=x,
h2=x+y
```

shows why differences matter:

```
ord dh1 = ord dh2 = 1,
but
ord(h2-h1)=2k+1
```

and delta=k.

Thus bounded differences can recover high-order cancellation missed by individual ramification
orders.

However this does not extend to a uniform linear conductor bound for arbitrary multiplicity.
For a coprime branch

```
x=t^m,
y=t^n
```

the conductor is

```
c=(m-1)(n-1)
```

while the order of any fixed finite collection of bounded-degree polynomials in x,y grows only
linearly in max(m,n), with constants depending on their bounded degrees.

Therefore a local inequality of the form

```
conductor <= C * sum ord(F_alpha(x,y))
```

for one fixed finite bounded-degree family cannot hold uniformly over arbitrary m,n.

The existing global six-map ramification bound controls the multiplicity defect only linearly:

```
sum_q (m_q-1) <= 80l.
```

So a viable inequality would have to be multiplicative/bilinear in multiplicity and cancellation
order, not a simple sum-of-orders estimate.

Disposition:

```
DIFFERENCE-ORDER-ONLY = CLOSED.
```

## 2. 2x2 minors / generic polar recover the correct quadratic singularity scale

For a reduced plane-curve singularity in characteristic zero,

```
mu = 2 delta - r + 1.
```

A generic polar intersection is controlled by the Milnor/polar package and therefore detects
quadratic singularity complexity rather than only branch multiplicity.

The six relative polar generators locally generate the Jacobian ideal because the six fibration
differentials span the cotangent space.

Hence 2x2-minor / generic-linear-combination constructions are the correct local scale.

But the global degree preflight ties at leading order.

```

deg Delta=336l^2+112l,
deg(relative polar pullback)=336l^2+192l.
```

Thus the ambient polar budget has the same quadratic coefficient 336 as the different.
The extra 80l is exactly the projection ramification budget.

No single fixed generic-polar class produces a negative leading coefficient or a finite-l bound.

Disposition:

```

```

## 3. Cuboid quadratic syzygies do not change the scale by themselves

The six maps come from the four cuboid quadratic equations and heavily overlap in ambient
coordinates.  These relations are valuable because they reduce independent jet data.

But merely substituting those quadratic relations into bounded differences/minors cannot evade the
two structural facts above:

- linear-order families cannot uniformly dominate plane-branch conductor at arbitrary multiplicity;
- a genuine polar detector necessarily carries the quadratic singularity scale and the current
  global polar class has leading coefficient tied to 2 delta.

A useful cuboid relation must therefore remove some of the **linear 80l ramification slack** or
produce a genuinely smaller common global class, not simply rewrite the same polar ideal.

No such slack-removing identity was found in this shallow pass.

## 4. New candidate exposed by the scan: Jacobian/Tjurina scheme

Piene's ideal identity and the six-polar generation result show that the next natural global object
is not a chosen polar divisor but the zero-dimensional Jacobian/Tjurina scheme itself.

For a local plane hypersurface, its length is the Tjurina number tau.

Known Milnor--Tjurina inequalities give a uniform lower bound of the form

```
tau >= mu/2
```

for isolated hypersurface germs; for irreducible plane branches much stronger 4/3-type estimates
are known.

Since

```
mu = 2 delta - r + 1,
```

the total Jacobian scheme is forced to have quadratic scale on any carrier with
delta=168l^2+56l.

This suggests a fresh top-down question:

```
Can the Jacobian/Tjurina scheme of C in |lP| be bounded globally on the fixed cuboid surface,
using the fact that its Jacobian ideal is generated by the six cuboid polar directions?
```

A naive logarithmic-Chern preflight does not immediately close: the leading surface Chern terms
remain positive after inserting only tau >= mu/2.

So this is a new shallow weapon family, not a proved closer.
