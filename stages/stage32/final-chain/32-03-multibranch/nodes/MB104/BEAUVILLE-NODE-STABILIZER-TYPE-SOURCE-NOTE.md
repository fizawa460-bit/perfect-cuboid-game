## Published modular facts

Freitag--Salvati Manni, *Parametrization of the box variety by theta functions*, Sections 2 and 4, identify the box variety with the diagonal modular quotient and give

```text
G = Gamma[4]/Gamma[8] ~= (Z/2Z)^3
```

as the covering group of

```text
C8 x C8 -> B.
```

The 48 singular nodes are images of fixed points of `G`.  They lie over the three diagonal zero-dimensional cusps represented on `X(2) x X(2)` by

```text
(infinity,infinity), (0,0), (1,1).
```

At `(infinity,infinity)` the stabilizer is generated by the diagonal translation by `4`.

The same paper gives the theta parametrization

```text
Z1 = theta01(z) theta01(w),
Z2 = theta00(z) theta00(w),
Z3 = theta10(z) theta10(w).
```

At the cusp `infinity`, `theta10` vanishes, so this stabilizer type has `Z3=0`.  The modular `S_3 = PSL(2,Z)/Gamma[2]` symmetry permutes the three diagonal cusp types and the three theta-constant coordinates `Z1,Z2,Z3`.  Hence, up to the immaterial naming of the other two cusps, the three singular stabilizer types are exactly

```text
Z1=0,
Z2=0,
Z3=0.
```

The Stage32 canonical coordinate convention is

```text
(a1,a2,a3,b1,b2,b3,c)=(W1,W2,W3,Z1,Z2,Z3,C).
```

Thus the stabilizer type of a box node is read off by the unique zero among `b1,b2,b3`.

## Exact Stage32 node model

The retained 48-node model splits into six eight-node blocks.  Blocks `1,2,3` and `4,5,6` pair by the same zero diagonal coordinate:

```text
blocks 1 and 4: b1=0,
blocks 2 and 5: b2=0,
blocks 3 and 6: b3=0.
```

Therefore each stabilizer type has exactly `16` box nodes.

The retained explicit F1-P5 support uses block counts

```text
[0,0,0,5,5,4].
```

So it meets all three node-stabilizer types, with counts

```text
b1=0: 5,
b2=0: 5,
b3=0: 4.
```

## Group position relative to the Beauville free subgroup

The Beauville subgroup

```text
G0=Gamma'[4]/Gamma[8] ~= (Z/2Z)^2
```

is free on `C8`; therefore none of the three node-stabilizer involutions lies in `G0`.  They are three distinct elements of the four-element coset `G\G0`.

In the elementary abelian group `(Z/2)^3`, any three distinct elements of one coset of an index-two subgroup generate the whole group.  This elementary group fact will be used by the equality-rigidity continuation.
