## 1. Degree-56 base monodromy

On the set `{0,...,55}`, let `A`, `B`, `C` be involutions whose transposition edges are stored exactly in the certificate.

They have respectively

```text
A: 16 transpositions, 24 fixed points,
B: 24 transpositions,  8 fixed points,
C: 16 transpositions, 24 fixed points.
```

The exact verifier checks that the graph with edge set `A union B union C` is connected. Hence the subgroup generated by `A,B,C` is transitive.

Use the six branch permutations

```text
(A,A,B,B,C,C).
```

Their product is the identity because each involution occurs twice consecutively. Their indices sum to

```text
2*(16+24+16)=112.
```

For a degree-56 cover, Riemann--Hurwitz therefore gives

```text
2g-2 = -2*56 + 112 = 0,
g=1.
```

The fixed-point counts are exactly

```text
(24,24,8,8,24,24),
```

so the required pair totals `(48,16,48)` are realized.

By the Riemann existence theorem, a transitive permutation tuple with product one realizes a connected branched cover of the sphere with these local monodromies.

## 2. Exact extension to every l>=1

The base edge

```text
(30,32) in A
```

is certified to be a non-bridge of the connected graph `A union B union C`.

For `l>=2`, take `l` disjoint translated copies of the degree-56 construction. In each copy delete the translated `A` edge `(30,32)`. Each block remains connected. Then replace the deleted edges by the cyclic cross-block matching

```text
(32+56k, 30+56(k+1 mod l)),  k=0,...,l-1.
```

This changes neither the number of A-transpositions nor its fixed-point count, and it remains an involution. `B` and `C` are left block-diagonal.

The cross-block A-edges connect the `l` still-connected blocks in a cycle, so the generated action is transitive on `56l` letters.

Thus for every `l>=1` we have involutions `A_l,B_l,C_l` with

```text
A_l: 16l transpositions, 24l fixed,
B_l: 24l transpositions,  8l fixed,
C_l: 16l transpositions, 24l fixed,
```

and the six-tuple

```text
(A_l,A_l,B_l,B_l,C_l,C_l)
```

is transitive and has product one.

The total permutation index is `112l`; with degree `56l`, Riemann--Hurwitz again gives genus one.
