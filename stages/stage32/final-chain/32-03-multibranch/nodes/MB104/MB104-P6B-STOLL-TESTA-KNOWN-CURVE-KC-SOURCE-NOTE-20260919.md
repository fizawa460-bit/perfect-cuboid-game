## Known curves on S

Coordinates are

```
(a1,a2,a3,b1,b2,b3,c).
```

The verification source constructs:

- `C1s`: 32 conics, in four 8-element coordinate/sign families;
- `C2s`: 12 genus-one curves of degree 4, in the three `b_j=0` families;
- `C3s`: 48 further genus-one curves of degree 4, in six 8-element families.

For every one of these 92 curves the source computes the set of box singular points lying on the curve. Its intersection matrix uses

```
E_p.C = 1
```

when the known curve contains the box node `p`.

The exact formulas used by the P6B verifier are direct transcriptions of the displayed `C1s`, `C2s`, `C3s` definitions in the immutable source. The `C3s` formulas use `s^2=2`.

The same source verifies that the subgroup generated by these known curves together with the exceptional curves has rank 64 and then proves it is the full geometric Picard group. This does not assert that the 92 curves generate the effective cone.

## Kc quotient

For the quotient forgetting `c`,

```
Kc:
a1^2+a2^2=b3^2,
a1^2+a3^2=b2^2,
a2^2+a3^2=b1^2.
```

The singular model has 12 nodes.

The source constructs exactly 44 known conics on `Kc`:

- 12 coordinate-family conics;
- 8 branch conics;
- 24 further conics involving `sqrt(2)`.

It verifies:

```
Pic(Kc) is generated by the known curves,
every curve on Kc has even hyperplane degree,
there are no unknown conics.
```

Equivalently, every integral conic is one of those 44 explicit curves.

The paper/verification source also classifies degree-4 curves on `Kc`, but P6B does not need them because the current root-degree bounds leave only degrees below 4 on the Kc-type quotients.
