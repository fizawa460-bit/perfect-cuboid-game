## 1. The candidate class is already an integral Picard class

The archived formal Picard-realizability contract source-locks

```text
H, E_1,...,E_48 in Pic(S)
```

and hence every integer combination

```text
aH - sum b_i E_i
```

is an integral divisor class.

Therefore `P` itself is already an element of `Pic(S)`; it is not merely a vector in a rational or abstract numerical lattice waiting to be glued into the ambient Picard lattice.

This immediately changes the role of a discriminant-form calculation. Such a calculation could test whether an **abstractly proposed** orthogonal summand embeds integrally into `Pic(S)`, but it cannot exclude an ambient integral class that is already explicitly present.

## 2. Orthogonality to the null curves is already integral

For the retained zero-pairing quartics,

```text
P.Q=0.
```

For every unsupported exceptional curve `E_p`,

```text
P.E_p=0
```

because the coefficient of `E_p` in `P` is zero and the exceptional curves are pairwise disjoint with `H.E_p=0`.

Thus for the lattice `N` generated by any selected collection of zero-pairing quartics and unsupported exceptional curves,

```text
P in N^perp subset Pic(S)
```

already as an integral Picard class.

Passing to the primitive saturation `N^sat` does not create a new congruence that must be satisfied by `P`: the actual ambient class determines its image in the discriminant gluing of `N^sat` and its orthogonal complement automatically.

In particular, there is no logically available step of the form

```text
discriminant class of P must vanish before P can exist in Pic(S)
```

because `P` already exists in `Pic(S)`.

## 3. No divisibility obstruction on l follows

Even if `P` happened to be divisible inside `N^perp` or represented a nonprimitive vector there, that does not obstruct the existence of the classes

```text
lP in Pic(S), l>=1.
```

Conversely, a nonzero discriminant-group image attached to a chosen decomposition of `Pic(S)` cannot force `n|l` for the classes `lP`: the gluing class of each actual multiple is already realized by the ambient Picard lattice.

Therefore the proposed lattice-only output shapes

```text
l must be divisible by n,
P cannot glue to the null lattice,
P is excluded from the ambient Picard group
```

are unavailable.

## 4. Componentwise line-bundle restriction is also already compatible

Z33E gives

```text
O_Q(P) ~= O_Q
```

for every zero quartic `Q`.

For an unsupported exceptional component `E ~= P1`,

```text
deg O_E(P)=P.E=0,
```

hence

```text
O_E(P) ~= O_{P1}.
```

So the candidate line bundle is trivial on every individual retained null component.

The one issue not seen by the numerical lattice is the **gluing of these trivial component restrictions across a reducible null union**. If the dual graph has cycles, a degree-zero line bundle can be componentwise trivial yet carry nontrivial multiplicative gluing around a cycle. That is a `Pic^0` / generalized-Jacobian datum, not a discriminant-form datum.
