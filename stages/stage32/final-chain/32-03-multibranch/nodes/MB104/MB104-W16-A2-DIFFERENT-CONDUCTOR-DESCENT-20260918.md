## 1. The intrinsic different exists, but conductor division is not Cartier downstairs

For a locally complete-intersection finite map, the Kähler different is `Fitt_0(Omega)`; for a quasi-finite Gorenstein morphism it agrees with the different and is locally principal. See Stacks Project tags `0BVV`, `0BWJ`, `0C17`.

For the singular carrier map `f:C->P1`, pulling the different to the normalization gives the retained divisor identity

`nu^* Diff_f = A_cond + R_phi`.

On the normalization the conductor is Cartier, so formally dividing removes `A_cond` and recovers `R_phi` exactly.

On `C`, however, the conductor ideal is generally not invertible. Thus `Diff_f / conductor` is not a line-bundle quotient operation on the singular curve.

## 2. Exact node test

Take the minimal Gorenstein node model

`A=k[[x,y]]/(xy)`,
`B=k[[x]] direct_sum k[[y]]`,
`c=(x,y)`.

Let the base parameter be

`t=x^m+y^n`.

Presenting `A` as a complete intersection over `k[[t]]`, the Kähler different is generated by the Jacobian determinant

`D=(m x^m - n y^n)`.

After extension to the normalization,

`D B = (x^m) direct_sum (y^n)`

and hence

`D B = c B * ((x^(m-1)) direct_sum (y^(n-1)))`.

The second factor is exactly the normalization ramification ideal.

### Two simple ramification branches

Set `m=n=2`. Then the normalization ramification divisor has length `2`, one simple ramification point on each branch.

Downstairs:

`D:c = (x^2,y^2)=m_A^2`,

whose scheme length is `3`, while

`(D:c):c = m_A`,

whose scheme length is `1`.

So ideal quotients bracket the desired multiplicity `2` but do not recover it.

The same defect appears with Fitting pushforward. The ramification module at the two normalization points is `k direct_sum k`; by multiplicativity of zeroth Fitting ideals (Stacks tag `07ZA`),

`Fitt_0(k direct_sum k)=m_A^2`,

again giving length `3` rather than `2`.

This is an exact local warning: multiplicity-preserving different/conductor/Fitting descent is not the right W16 object.
