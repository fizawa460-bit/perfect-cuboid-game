# 材料の掲載範囲と次の移植単位

[全体索引](CATALOGUE.md) · [監査範囲](AUDIT-SCOPE.md)

## 今回掲載した実体

- 99管理IDのルートカード、元台帳の全記入フィールド、統合・履歴案内。
- 5つの管理索引スナップショット、機械可読JSON/CSV、R3研究記録330–393の概要・出典。
- この掲載範囲の整合・リンク・件数・元フィールド保持を検査する標準Python検証器。

**証明本文・多項式係数・全計算証書の実体を全ルートについて移したわけではありません。** 下表は移植の対象を整理したもので、未移植を掲載済みと表示しません。

| 材料群 | 現在の掲載 | 後続のまとまり |
|---|---|---|
| 元source・量化・写像・符号・原始性 | ルート要約と資料所在 | 結論を理解するための定義・必要な親証明を一式 |
| ±18、指定指数群、+30の排除 | R3記録367/368/369/376の概要と原資料リンク | 最終排除証明と、最大整環・類数・Selmer・2進障害・点分類等の必要な依存 |
| −30のMW/Selmer構造 | 記録370–375/381/382等の索引 | 曲線・数体・既知類・正規化・必要な検証証書 |
| 類群・非分岐部分・不同 | 記録385–393の索引と監査限定 | 最終格子・共通入力・不同トレース証書等を重複せず一度だけ |
| 既知7類の対数枠など再利用材料 | 記録361等への参照 | 定義・正規化・最小の検証可能な出力とコード |
| 方法の限界・試行した案・未完成案 | 全ルートに原文の到達点・障壁・再開条件 | 固有の考察は少なくとも要約、必要な反例・方式限定の論証を保持 |
| 大きな中間表・重複ログ・途中版 | 元資料への案内 | 固有の証拠がなければDriveに残し、所在を維持 |

## 保存判断

1. ないと主張を理解・検証できない、または他の研究で再利用する → GitHubへ本文と必要な証拠。
2. 研究の選択・停止・再開に影響する考察 → GitHubへ要約、Driveへ詳細原文。
3. 固有の意味がない重複・作業記録 → Drive保存でよい。

原本は削除しません。全ての考察が既にこの99管理IDのどれかに分類済みであるという全履歴の完全性は主張しません。
