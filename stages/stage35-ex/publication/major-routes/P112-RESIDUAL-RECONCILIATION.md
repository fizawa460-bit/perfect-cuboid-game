# P112旧残表からrow393現行LOW残9絶対・16 signedへの出典接続

**性質：2026-11-09の移植時点における、既存数学成果の集合演算上の整理。新しい排除定理・独立敵対的監査ではない。** R5-P112原資料の集合列挙を別のPython標準ライブラリ実装で再計算した。数学的な全称マスクの正当性はC181/R5-C212/S264と、後発のrow367/368/369/376・R0 C183の監査・成立条件に依存する。

## 0. 旧P112の対象と今の残表は別

旧P112はeven absolute nのLOW [12,154] 72個とMID [156,196] 21個を三つの*必要条件マスク*だけで分ける歴史的投影である。全歴史・全原始元sourceの最終排除数ではない。原資料：[R5-P112 rebin](proofs/foundations/R5-P112-rebin.md)、[C181](proofs/foundations/C181.md)、[R5-C212](proofs/foundations/R5-C212.md)、[S264](proofs/foundations/S264.md)。

各偶数nに対し j=n±1 として、旧三マスクを次の整数条件でコード化した。

- A = C181全labelled：3|j かつ j/3 のsquarefree kernelの各素因子が p=5 または p≡13,17 (mod20)。
- B = R5-C212全labelled：8∤n、jは3の倍数で、jの3,5,7以外の素因子は1個p≥11に限られ、p≡3,5 (mod8)。
- C = C181 A-evenのsupport：3|jかつ j/3 のsquarefree kernelの素因子が p=5 または p≡2,3 (mod5)。S264により8∤nの場合はB-even側も必要条件が破れ、両labelledを結合できる。A-even単独の条件を根拠なくall-labelledに転用しない。

## 2. signed残数の追加制約

上記の9絶対指数を両符号として扱うと18 signed枠。そこで別々の、元sourceの符号付き必要条件による排除を適用する。

- **+12のみ排除：** [R0 C183](proofs/foundations/C183.md)はC181のLOW実区間排除と、R5-C220のHIGH領域z≥18における元の正符号y(D_+12)>0とを統合して従属採択。R5-C220の元カードには正規化曲線の **−z と誤記** があり、正しくは **Y²=X³+zX²−zX**。[R5-C224訂正](proofs/foundations/R5-C224-erratum.md)とC183を優先する。**−12はOPEN。**
- **+30のみ排除：** [row376](../../materials/original-source-exclusions/row376/PROOF.md)の実符号証明は+30に限る。**−30はOPEN。**

よって18 signed枠 −2（+12,+30）＝**16 signed枠**。具体的には −12, −30, ±42, ±60, ±72, ±102, ±108, ±138, ±150 である。これは「残る必要条件の指数域」であり、16個の実在解や全物理解の候補列挙数ではない。

## 3. 適用上の境界と検証

[独立再集計スクリプト](tools/verify_p112_residual.py)は整数区間を全列挙してA/B/C集合と後発指数集合の差を検査し、実行結果が上記個数・集合と一致する。採否・独立監査を新規に付与しない。旧P112にある『LOW残36・MID残9』と、row393停止時の『LOW残9絶対・16 signed』は矛盾せず、**異なる資料集合・異なる時点での非被覆**である。

正式数学研究はrow393で停止。MID/HIGHの155/197は下界であり、P112のこの有限集計から一般物理解の不存在を結論しない。indexed→Bwide転送も未証。LOW全域・−30・Branch BはOPEN。
