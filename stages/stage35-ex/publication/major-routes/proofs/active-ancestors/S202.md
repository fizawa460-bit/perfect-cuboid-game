## Scope
Retain the finite-odd Branch-B physical packet and all S194-S201 firewalls. Let q be an odd prime with q|d and q not dividing AB, e=v_q(d)>=1, d=q^e d0, q not dividing d0. Keep
dQ=mP, gcd(d,m)=1,
Q-Q#=T0+nR,
Q+Q#=T0+Ptau,
dPtau=kR, gcd(d,k)=1,
X(Q#)=-X(Q)
on the integral model
E_int: Y^2=X(X-A^2)(X+C^2).


This section addresses only the split multiplicative high-valuation escape left by S200-S201.


## 1. H-side: q | H=A^2+C^2 has no physical q-primary component escape
Write delta=v_q(H)>0. S200 gives split type I_(2delta), with q=1 mod 8. Mod q,
E_int reduces to
Y^2=X(X-A^2)^2,
whose unique node is (A^2,0).


T0=(0,0) is nonsingular because the X-derivative at X=0 is a q-unit. P=(AC,ABC) is also nonsingular: AC congruent A^2 would imply C congruent A, hence C^2 congruent A^2, contradicting C^2 congruent -A^2 for odd q and q not dividing A. Therefore
T0, P, R=2P, D_n=T0+nR
all lie in E_0(Q_q).


Since Q-Q#=D_n, Q and Q# have the same component class. If this common class were nonzero, both points would reduce to the unique node, so
X(Q) congruent A^2,
X(Q#) congruent A^2 mod q.
But X(Q#)=-X(Q), forcing 2A^2 congruent0 mod q, impossible. Hence
Q,Q# in E_0(Q_q).
Then Q+Q#=T0+Ptau also gives
Ptau in E_0(Q_q).


Now dQ=mP gives
[q^e]([d0]Q)=[m]P.
Choose integers a,b with a m+b q^e=1. Then
V=a[d0]Q+bP
lies in E_0 and satisfies
[q^e]V=P.
Thus the physical q^e-division root can be chosen in E_0; the q-primary part of the component group cannot be the mechanism supporting this physical packet.


Because the split nonsingular quotient E_0/E_1 has order q-1, set
M_H=q-1.
Then q does not divide M_H and M_H kills E_0/E_1. Put
L_H=v_q(z([M_H]P)), z=-X/Y.
The physical packet necessarily satisfies
L_H>=e+1.
Moreover
P in [q^e]E_0(Q_q) iff L_H>=e+1.
Uniqueness here is only inside E_0; no claim is made that the whole local group has no q-primary component torsion when q|delta.


The Section201 symmetric identities sharpen with M_H:
v_q(z([M_H]Q))
=v_q(z([M_H]Q#))
=v_q(z([M_H]Ptau))
=L_H-e,
and
v_q(z([M_H]Q)-z([M_H]Q#))
=L_H+v_q(n),
hence
v_q(X([M_H]Q)/X([M_H]Q#)-1)
=e+v_q(n).


Therefore q|delta is NOT a remaining physical high-valuation residual.


## 2. C-side component structure
Now suppose q|C and put c=v_q(C)>0. S200 gives split type I_(4c), q=1 mod4, with node X=0.


Use the standard split-I_N component coordinate: for a nonidentity component j in Z/NZ, the node-coordinate satisfies
v_q(X)=min(j,N-j)
after choosing 0<j<N. This is a classical Neron/Tate input, not new theorem credit.


For P=(AC,ABC),
v_q(X(P))=c,
so the component of P is j_P=c or 3c. Thus P has component order4 and
R=2P
has component 2c. T0 is a nonidentity rational 2-torsion point, hence also has the unique nonzero order-2 component 2c. Therefore
component(D_n)=component(T0+nR)=2c(1+n) mod4c.


## 3. C-side with n even: q-primary component escape is also impossible
If n is even,
component(D_n)=2c.


Write j,j# for the component classes of Q,Q#. Since X(Q#)=-X(Q), the two x-coordinates have the same q-adic valuation. If one endpoint were in E_0, the other would also be in E_0: when the valuation is negative both are formal, and when it is zero both reduce away from the node X=0. That would make their component difference zero, contradicting component(D_n)=2c. Hence both endpoints are nonidentity components.


The split-I_(4c) valuation formula and equal x-valuations imply
j#=j or j#=-j mod4c.
The first option would give component(Q-Q#)=0 and is impossible. Thus j#=-j and
2j=2c mod4c,
so
j=c or 3c.
Therefore Q and Q# both have component order4. Their sum has component0, so from Q+Q#=T0+Ptau, Ptau has component 2c and order2.


Let Gamma_4 be the inverse image in E(Q_q) of the order-4 subgroup
< c >={0,c,2c,3c} in the component group.
Then
P,Q,Q#,Ptau are in Gamma_4.


As above, from dQ=mP choose a,b with a m+bq^e=1 and set
V=a[d0]Q+bP.
Then
[q^e]V=P
and V also lies in Gamma_4. Thus the physical q^e root has no q-primary component.


Set
M_C=4(q-1).
This kills Gamma_4/E_1 and q does not divide M_C. With
L_C=v_q(z([M_C]P)),
the physical packet requires
L_C>=e+1,
and
P in [q^e]Gamma_4 iff L_C>=e+1.


The Section201 symmetric identities also hold with M_C:
v_q(z([M_C]Q))
=v_q(z([M_C]Q#))
=v_q(z([M_C]Ptau))
=L_C-e,
v_q(z([M_C]Q)-z([M_C]Q#))
=L_C+v_q(n),
and
v_q(X([M_C]Q)/X([M_C]Q#)-1)
=e+v_q(n).


Hence q|c is NOT a remaining high-valuation escape when n is even.


## 4. Exact remaining split high-valuation residual
The H-side component residual is removed for all n.
The C-side component residual is removed for even n.


For C-side with n odd,
component(D_n)=0,
so Q and Q# have the same component. The sign symmetry X(Q#)=-X(Q) does not force that common component into the order-4 subgroup. A q-primary component can therefore still occur when q|c.


Thus the only split high-valuation residual left by S200-S202 is:
q|C,
n odd,
q|c=v_q(C),
so in particular q^q|C,
with q=1 mod4.


This is a narrowing of the residual channel, not its exclusion.
