## 1. Exact integral model and reduction partition
Use the rational isomorphism X=C^2 x, Y=C^3 y:
E_int: Y^2=X(X-A^2)(X+C^2), P_int=(AC,ABC).
Delta=16 A^4 C^4(A^2+C^2)^2;
c4=16(A^4+A^2 C^2+C^4).
Write H=A^2+C^2. For odd q outside AB the three cases are disjoint:
(G) q not dividing C H: displayed model has good reduction.
(C) q|C: c=v_q(C)>0; c4 is a q-unit and v_q(Delta)=4c. The reduced node at X=0 has tangent equation Y^2=-A^2 X^2. Since A^2+B^2=0 mod q with A,B nonzero, -1 is a square; hence q=1 mod4 and reduction is split multiplicative, type I_(4c).
(H) q|H: delta=v_q(H)>0; q not dividing AC, c4 is a unit and v_q(Delta)=2delta. At X=A^2=-C^2 the node has square tangent coefficient A^2, hence split multiplicative, type I_(2delta). Moreover a^2=-1 and b^2=2 mod q, so both -1 and 2 are squares and q=1 mod8.
The c4-unit cases are minimal integral models; thus these discriminant valuations are minimal and give the stated types. There are no other bad odd-prime cases outside AB. In particular q=3 mod4 outside AB is always good.
Two exact small-field consequences: q=3 cannot be outside AB in a primitive triple; q=5 outside AB necessarily divides C. Indeed F3 has only nonzero square1, incompatible with 1+1=C^2; F5 nonzero squares1,4 can sum to a square only as 1+4=0. The exhaustive residue certificates in replay independently confirm these two finite statements. Thus case G here has q>=7.

## 2. Prime-power division follows from the SAME shifted odd relation

## 3. Formal logarithm and finite-quotient lemma
For this integral minimal model at any odd q, z=-X/Y identifies E_1(Q_q), the kernel of reduction to the nonsingular identity, with the formal points q Z_q. Set E_r={W:v_q(z(W))>=r}, with O included.
The invariant differential has integral z-series with leading coefficient1, so its formal primitive is log(z)=z+sum_(j>=2) c_j z^j/j, c_j in Z_q. For v_q(z)>=1, every higher term has strictly larger valuation because (j-1)-v_q(j)>0 for odd q. The same estimate for differences makes log-id a strict contraction on q Z_q. Hence log is a bijective, valuation-preserving homomorphism E_1 -> q Z_q, with log([m]W)=m log(W). Therefore [q^e]E_1=E_(e+1). This applies to good and multiplicative reduction alike; no q=2 assertion is made.

Let M be a positive integer killing the finite quotient E(Q_q)/E_1(Q_q). If P=[q^e]V locally, M V is in E_1, so
[M]P is in E_(e+1).                                     (necessary)
If gcd(M,q)=1 this is ALSO SUFFICIENT: write [M]P=[q^e]W with W in E_1 using log, choose a0 M+b1 q^e=1, and put V=a0 W+b1 P. Then [q^e]V=P. In this coprime-M case E(Q_q)[q]=0, since both E_1 and its finite quotient have no q-torsion; the local q^e root is unique.
If q|M, the displayed depth condition remains necessary; neither sufficiency nor uniqueness follows from this lemma. Do not discard possible component q-torsion.

## 4. Explicit M_q and exact local exponent tests
In case G take M_q=#E_int(F_q). The four distinct rational two-torsion points survive reduction, so 4|M_q. Hasse gives 0<M_q<=q+1+2sqrt(q)<4q for q>=3. If q|M_q, the only multiples below4q are q,2q,3q, none divisible by4 for odd q. Thus gcd(M_q,q)=1 without an ordinary/supersingular assumption. This rules out an anomalous-reduction escape within this family, not rational q-division.
In case C take M_q=4c(q-1), the order of E(Q_q)/E_1; gcd(M_q,q)=1 iff q does not divide c.
In case H take M_q=2delta(q-1); gcd(M_q,q)=1 iff q does not divide delta.
For the split cases this quotient order is the component order times the nonsingular residue group order q-1. Its cyclicity is not required.

For any of these M_q define L_q=v_q(z([M_q]P_int)). It is finite because the retained P is non-torsion, and L_q>=1 because M_q kills the quotient. Every physical finite-odd packet satisfies
v_q(d)<=L_q-1.
In G, or C with q not dividing c, or H with q not dividing delta, there is the EXACT equivalence

If X([M_q]P_int)=J_q/B_q^2 in lowest terms with B_q>0, then L_q=v_q(B_q); equivalently q^(e+1)|B_q. The formal x expansion starts z^-2 with unit coefficient, giving v_q(X)=-2v_q(z), so this denominator formulation is exact.
For e=1, simple q|B_q is automatic after killing reduction and insufficient; q^2|B_q is required. More generally the exact congruence requires modulus q^(e+1), not just mod q.
The only split cases outside the coprime-M local theorem have q|c or q|delta. They therefore require respectively q^q|C or q^q|H. This is a high-valuation residual channel, not an exclusion: no q-free or squarefree assumption is available.
