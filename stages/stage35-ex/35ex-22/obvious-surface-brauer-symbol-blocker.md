# Stage35-EX 35EX-22 — obvious surface Brauer-symbol layer blocker

## Scope

Continue only from hostile-audited and merged #1531 / 35EX-21/21B. Work on the exact normalized surface

```text
S_PC:
p^2 = 1+x^2,
q^2 = 1+y^2,
z^2 = x^2+y^2,
w^2 = 1+x^2+y^2.
```

The source-compatible smooth open used in this leaf is

```text
U_PC = S_PC \ {x*y*p*q*z*w = 0}.
```

The positive Stage35-EX receiver chamber lies in `U_PC(R)`. This leaf tests only the finite **obvious 2-torsion quaternion-symbol layer** generated by the square radicands and the natural linear boundary factors. It does not compute `Br(U_PC)`, `Br(S_PC)`, or the Brauer group of any smooth compactification.

Source lock for the residue convention: for a DVR valuation `v`, the residue of a quaternion symbol `(f,g)` is represented by

```text
(-1)^(v(f)*v(g)) * g^v(f) / f^v(g)
```

in the residue-field squareclass group. This is the standard tame residue formula, e.g. Colliot-Thélène--Skorobogatov, *The Brauer--Grothendieck Group* (2021), formula (1.18), as reproduced explicitly in the 2026 paper *Brauer groups of conic bundles over elliptic curves*, Remark 2.2. Only this residue formula, bilinearity modulo squares, and the standard local Hilbert splitting criterion are used here.

## 1. The four displayed radicands give no symbol class

In `Q(S_PC)^*/Q(S_PC)^{*2}`,

```text
1+x^2       = p^2,
1+y^2       = q^2,
x^2+y^2     = z^2,
1+x^2+y^2   = w^2.
```

Hence every quaternion symbol having one slot in the squareclass span of these four radicands is already trivial. The first genuinely nontrivial obvious candidates must therefore come from boundary factors.

## 2. Finite natural boundary-factor presentation

Use the seven affine functions

```text
f1 = p+x,
f2 = q+y,
f3 = w+z,
f4 = z+x,
f5 = z+y,
f6 = w+p,
f7 = w+q.
```

Their conjugate partners give no additional squareclasses, because

```text
(p+x)(p-x)=1,
(q+y)(q-y)=1,
(w+z)(w-z)=1,
(z+x)(z-x)=y^2,
(z+y)(z-y)=x^2,
(w+p)(w-p)=y^2,
(w+q)(w-q)=x^2.
```

Thus, modulo constants and squares, the obvious quaternion presentation generated by `{-1,f1,...,f7}` is generated by the 28 symbols

```text
(-1,fi)       for 1<=i<=7,
(fi,fj)       for 1<=i<j<=7.
```

This is a presentation layer, not a claim that these 28 symbols are independent in the Brauer group.

## 3. Exact infinity-boundary residue diagnostic

Take the projective complete-intersection closure with homogenizing coordinate `h`:

```text
p^2=h^2+x^2,
q^2=h^2+y^2,
z^2=x^2+y^2,
w^2=h^2+x^2+y^2.
```

The generic `h=0` boundary has eight conic components

```text
D(eps,delta,eta):
h=0,
p=eps*x,
q=delta*y,
w=eta*z,
z^2=x^2+y^2,

eps,delta,eta in {+1,-1}.
```

On every such component every `fi` has odd valuation. With the rational parameterization

```text
x=1-T^2,
y=2*T,
z=1+T^2,
```

the leading units are

```text
U1 = 2*x              if eps=+1, else -1/(2*x),
U2 = 2*y              if delta=+1, else -1/(2*y),
U3 = 2*z              if eta=+1, else -1/(2*z),
U4 = z+x,
U5 = z+y,
U6 = eta*z+eps*x,
U7 = eta*z+delta*y.
```

Therefore

```text
res_D(-1,fi) = [-1],
res_D(fi,fj) = [-Ui*Uj]
```

in `Q(T)^*/Q(T)^{*2}`. Exact squarefree factorization over all eight components gives a `48 x 28` presentation residue matrix of `F2`-rank exactly `6` (six squareclass coordinates times eight components). Consequently this boundary diagnostic has a large presentation kernel; residue inspection alone does not kill the obvious layer. No dimension statement about an actual Brauer group is inferred from the `28-6` presentation-kernel count.

## 4. One exact rational specialization annihilates every obvious generator locally

Consider the smooth rational point of `S_PC`

```text
P0:
x = 272/225,
y = 0,
p = 353/225,
q = 1,
z = 272/225,
w = 353/225.
```

It lies outside `U_PC` only because `y=0`. The Jacobian has rank four there because `p,q,z,w` are nonzero.

At `P0`,

```text
(f1,f2,f3,f4,f5,f6,f7)
 = (25/9, 1, 25/9, 544/225, 272/225, 706/225, 578/225),
```

with rational squareclasses

```text
[1, 1, 1, 34, 17, 706, 2]
 = [1,1,1,2*17,17,2*353,2].
```

Here `17 == 353 == 1 (mod 8)`, and exact Hilbert-symbol evaluation at every relevant finite prime and at infinity gives

```text
(-1,fi)_v = +1               for all i and all places v,
(fi,fj)_v = +1               for all i<j and all places v.
```

The verifier recomputes these Hilbert symbols directly; the claim is not inferred from floating-point evaluation.

## 5. Move into the source-compatible open at every completion

Fix `x=x0=272/225` and `p=p0=353/225`. For every place `v`, choose a nonzero `y_v` sufficiently close to `0`. Then the three equations

```text
q_v^2 = 1+y_v^2,
z_v^2 = x0^2+y_v^2,
w_v^2 = p0^2+y_v^2
```

have roots near `1,x0,p0`, respectively: over `R` by ordinary continuity, and over each `Q_l` by the local square/Hensel neighborhood of the nonzero squares at `P0` (choosing `y_v` sufficiently small, with the usual stronger 2-adic smallness at `l=2`). Choose `y_v` also away from zero and away from the finitely many zeros of the seven `fi`.

The Hilbert symbol on nonzero local squareclasses is locally constant. Because all 28 generator evaluations at `P0` are split, `y_v` may be chosen small enough that the resulting point

```text
P_v=(x0,y_v,p0,q_v,z_v,w_v) in U_PC(Q_v)
```

still gives evaluation zero for every one of the 28 generators. For almost all odd primes the data can be chosen integral with `y_v` of positive valuation, so these `P_v` form an adelic point of `U_PC`.

Hence there exists

```text
(P_v)_v in U_PC(A_Q)
```

that annihilates the evaluation of every symbol in the full bilinear span of the 28 obvious generators. In particular, **any actual Brauer class on `U_PC` represented by an element of this obvious symbol span cannot by itself, nor together with other classes from the same span, cut out all adelic points.**
