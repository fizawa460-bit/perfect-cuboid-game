## 1. The four displayed radicands give no symbol class

In `Q(S_PC)^*/Q(S_PC)^{*2}`,

```text
1+x^2       = p^2,
1+y^2       = q^2,
x^2+y^2     = z^2,
1+x^2+y^2   = w^2.
```

Hence every quaternion symbol having one slot in the squareclass span of these four radicands is already trivial. The first genuinely nontrivial obvious candidates must therefore come from boundary factors.

## 2. Finite natural boundary-factor presentation

Use the seven affine functions

```text
f1 = p+x,
f2 = q+y,
f3 = w+z,
f4 = z+x,
f5 = z+y,
f6 = w+p,
f7 = w+q.
```

Their conjugate partners give no additional squareclasses, because

```text
(p+x)(p-x)=1,
(q+y)(q-y)=1,
(w+z)(w-z)=1,
(z+x)(z-x)=y^2,
(z+y)(z-y)=x^2,
(w+p)(w-p)=y^2,
(w+q)(w-q)=x^2.
```

Thus, modulo constants and squares, the obvious quaternion presentation generated by `{-1,f1,...,f7}` is generated by the 28 symbols

```text
(-1,fi)       for 1<=i<=7,
(fi,fj)       for 1<=i<j<=7.
```

This is a presentation layer, not a claim that these 28 symbols are independent in the Brauer group.

## 3. Exact infinity-boundary residue diagnostic

Take the projective complete-intersection closure with homogenizing coordinate `h`:

```text
p^2=h^2+x^2,
q^2=h^2+y^2,
z^2=x^2+y^2,
w^2=h^2+x^2+y^2.
```

The generic `h=0` boundary has eight conic components

```text
D(eps,delta,eta):
h=0,
p=eps*x,
q=delta*y,
w=eta*z,
z^2=x^2+y^2,

eps,delta,eta in {+1,-1}.
```

On every such component every `fi` has odd valuation. With the rational parameterization

```text
x=1-T^2,
y=2*T,
z=1+T^2,
```

the leading units are

```text
U1 = 2*x              if eps=+1, else -1/(2*x),
U2 = 2*y              if delta=+1, else -1/(2*y),
U3 = 2*z              if eta=+1, else -1/(2*z),
U4 = z+x,
U5 = z+y,
U6 = eta*z+eps*x,
U7 = eta*z+delta*y.
```

Therefore

```text
res_D(-1,fi) = [-1],
res_D(fi,fj) = [-Ui*Uj]
```

in `Q(T)^*/Q(T)^{*2}`. Exact squarefree factorization over all eight components gives a `48 x 28` presentation residue matrix of `F2`-rank exactly `6` (six squareclass coordinates times eight components). Consequently this boundary diagnostic has a large presentation kernel; residue inspection alone does not kill the obvious layer. No dimension statement about an actual Brauer group is inferred from the `28-6` presentation-kernel count.

## 5. Restricted-product repair: finite bad places plus integral good-prime points

The `P0`-local deformation is used only at a **finite** set of places. For almost all primes we instead construct an actual `U_PC(Z_l)` point.

### 5.1 Finite bad places

Let

```text
S_bad = {infinity} union {primes l < 173}.
```

For every `v in S_bad`, fix `x=x0=272/225` and `p=p0=353/225`, and choose a nonzero `y_v` sufficiently close to `0`. Then

```text
q_v^2 = 1+y_v^2,
z_v^2 = x0^2+y_v^2,
w_v^2 = p0^2+y_v^2
```

have roots near `1,x0,p0`: over `R` by ordinary continuity, and over each `Q_l` by the local square/Hensel neighborhood of the nonzero squares at `P0`. Choose `y_v` away from zero and the finitely many zero loci of the seven `fi`.

Hilbert symbols on nonzero local squareclasses are locally constant. Since all 28 generator evaluations at `P0` split, the deformation can be taken small enough that the resulting

```text
P_v in U_PC(Q_v)
```

still evaluates all 28 generators to zero. This construction is needed at only finitely many places and therefore creates no restricted-product problem.

### 5.2 Every prime l >= 173 has an integral open point

Fix a prime `l >= 173`. Work over `F_l`. Parameterize the first source conic

```text
B1: p^2-x^2=1
```

by `a in F_l^*`:

```text
p=(a+a^(-1))/2,
x=(a-a^(-1))/2.
```

The forbidden conditions

```text
x=0,
p=0,
x^2=1
```

occur only when

```text
a^2=1,
a^2=-1,
a^4-6*a^2+1=0,
```

respectively. Hence at most `2+2+4=8` parameters are forbidden. Since `l-1>8`, choose `a` with

```text
x != 0,
p != 0,
x^2 != 1.
```

For that base point, the normalized projective fiber is the degree-8 `(Z/2)^3` cover of `P1_y`

```text
q^2=y^2+1,
z^2=y^2+x^2,
w^2=y^2+p^2.
```

Because `l` is odd and `1,x^2,p^2=1+x^2` are pairwise distinct and nonzero in the required way, the three branch pairs are distinct and the three squareclasses are independent. Thus the fiber is a smooth geometrically integral genus-5 curve, exactly the specialization of the genus-5 construction from 35EX-21.

Hasse--Weil gives

```text
#C(F_l) >= l+1-10*sqrt(l).
```

The projective fiber has at most 40 points in the union of the loci that are unusable for `U_PC`:

```text
y=infinity: <=8,
y=0:        <=8,
q=0:        <=8,
z=0:        <=8,
w=0:        <=8.
```

At `l=173`, `174-10*sqrt(173)>40`, and the lower bound is increasing for `l>=173`. Therefore every prime `l>=173` has an `F_l`-point with

```text
x*y*p*q*z*w != 0.
```

At such a point the `4 x 4` Jacobian minor in the columns `(p,q,z,w)` is

```text
(2p)(2q)(2z)(2w)=16*p*q*z*w != 0 mod l.
```

Hence the point is smooth and lifts by Hensel/formal smoothness to a point

```text
P_l in U_PC(Z_l)
```

with the same nonzero reductions. In particular all six coordinates are `l`-adic units.

Moreover the conjugate-product identities from Section 2 show that all seven `fi(P_l)` are units: `f1*f1'=1`, `f2*f2'=1`, `f3*f3'=1`, while the remaining conjugate products are `x^2` or `y^2`, also units. For odd `l`, a quaternion algebra `(u,v)` with both entries `l`-adic units has Hilbert symbol `+1`. Thus every one of the 28 obvious generators evaluates to zero at every good prime `l>=173`.

### 5.3 The actual adele

Use the finite `P0`-local choices at `S_bad`, and for every prime `l>=173` use one of the integral points just constructed. Then

```text
P_v in U_PC(Q_v)                         for every place v,
P_l in U_PC(Z_l)                         for every l>=173,
all 28 obvious generator evaluations = 0 at every v.
```

Because all but finitely many components are integral points of the fixed model `U_PC/Z`, this family is a genuine restricted-product adelic point

```text

```

Hence there exists an adelic point annihilating the evaluation of every symbol in the full bilinear span of the 28 obvious generators. In particular, **any actual Brauer class on `U_PC` represented by an element of this obvious symbol span cannot by itself, nor together with other classes from the same span, cut out all adelic points.**
