# row387 再現

有限証書はPython 3.10以降の標準ライブラリだけで再現できる。

```sh
sha256sum -c SHA256SUMS
python verify_row387.py > replay_good.json
diff -u good_selmer387.json replay_good.json
python unit_correction387.py > replay_correction.json
diff -u unramified_correction387.json replay_correction.json
```

verify_row387.pyは、認証済み6奇素数の各々についてFとF′のgcd、二重一次因子を除いた次数103残部の平方自由性、F″(r)の非零性、F(r)/pの剰余非零を再計算する。親row386の固定二次式の512類判定、good単元投影の3類、既知有理8方向との次元関係、根対多項式の整数二変数恒等式も照合する。親入力5ファイルはコード内SHA256にも固定している。

unit_correction387.pyは55本の完全単元基底の局所座標に対する55×107左逆と107×107射影を再構成する。全55基底上の左逆、9単元Selmer基底のマスク一致、全107座標上の射影冪等性を照合する。これはI²=(α)の認証済み大域入力から非分岐Kummer類を作るための補正演算であり、任意の局所コードだけから大域類を認証するものではない。

norm_equations387.jsonは、M=Q(t,z)/(F(t),R(t,z))のRの全係数と、ηを入力とする一軌道のノルム方程式を固定する。Mが次数10920の体であることは親row383のS105を継承する。

全非分岐類がgoodであること、good類の大域完全分類、指数2のgood curve条件はPROOF.mdの奇素点・2進・無限素点とHasse–Minkowskiの議論を使う。有限プログラムだけで未知の類群基底や大域ノルム解を算出したという意味ではない。

今回もq★の値・真Sel4所属はUNDETERMINED。Cl[2]の全尽的基底、非自明ηの係数、対応するconic解、CTの実際の値は未構成。元signed新排除0。著者証書再現PASS、独立数学監査PENDING。

親row386の7056ノルムや全局所環計算を再監査するパッケージではない。それらの独立監査PASSを必要な入力として継承し、今回は新たに奇素点の可解性と大域good分類へ接続する。
