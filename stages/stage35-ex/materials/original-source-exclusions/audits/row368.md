# Stage35EX row368 独立数学監査

- 日付: 2026-11-06
- 対象: P23-R3-07-LOW、元indexed inner Branch B、偶数 signed 指数 \(12\le |n|\le154\) のうちrow368の列挙21絶対指数。
- 判定: **PASS — 対象21絶対指数・正負42 signed 枠の元source必要条件による排除**。全LOW / MID / HIGH / Branch B の排除ではない。
- 親前提: 元のS263（偶数 n の隣接整数Ward値 \(W_{|n|-1},W_{|n|+1}\) が別符号の平方）、S264（B偶なら8|n）、S321（元のW5因子）、C118（固定Xの有理点分類）、P112/C181/C212/C183、およびrow367の独立監査PASS。監査済み・既存数学命題の再証明を毎回要求しないが、その対象範囲は固定。

## 1. 今回の新しい数学的差分

Ward5に降りる14絶対指数:
24,36,54,56,64,66,84,94,96,104,114,124,126,144。

Ward3に降りる追加7絶対指数:
32,80,88,92,122,128,152。

各指数について A偶/B奇とA奇/B偶の両ラベルを、元の同一原始三つ組 \((A,B,C)\) のみで処理する。前半はW5の互いに素な同次3次因子 F,G をどちらも正の平方に強制し、C118の曲線の元source不可能性に帰着。p=23の例外はGの二分解・非平方の有限体計算で除外。B偶のn=24はp=5で他方の隣接W23の±平方条件と衝突。後半はW3の因子L±の平方性から有理点がない補助E1/E3の有理点へ帰着する。

## 2. 独立照合

原ZIPのSHA256SUMS.json記載6/6ファイルが完全一致。著者verify_row368.pyを実際に再実行し、row368_exact.jsonを再生成（各項目一致）。そのほか元スクリプトをインポートしない `/mnt/data/audit_row368/independent_row368.py` を作成・実行し、以下を別法で検証。

- Ward5= (z³+5z²+11z−1)(z³+z²−13z−5) を符号込み検算。
- 差分の積性 \(\operatorname{Res}(P,Q)=-2^{14}\), \(\operatorname{Res}(P,\Phi_5)=\operatorname{Res}(Q,\Phi_5)=2^{50}\), \(\operatorname{Res}(z-1,\Phi_3)=\operatorname{Res}(z+3,\Phi_3)=64\), \(\operatorname{Res}(G_+,G_-)=-2^7\) を、SymPy resultantと異なるSylvester整数行列の行列式で再計算。
- p=3,5,7,11,13,17,19,23,29、両ラベル、\(\mathbb P^1(\mathbb F_p)\) 全傾き18件を元スクリプトと異なる射影正規化で列挙。F/G消滅z類は原著表に一致。
- 各j=5mと3mの素因数集合を再生成し、mod8のすべての正負・平方自由候補を独立全列挙。W5のA偶すべてF/G正平方、B偶は24のみ候補−5。W3のA偶L+、B偶L−は正平方。
- p=23におけるG±/B6の2値は5,10（いずれも非平方）、p=5における±23は2,3（いずれも非平方）。
- E1の#F5,#F7=8,8; E3の#F3,#F11=4,8を、曲線の点直接列挙とは異なるLegendre記号和で再計算。2-isogenyの群論によるrank0、限定有理torsionから不可能性を検算。
- P112_SOURCE_EVIDENCE.jsonのthree_mask_not_covered=36を直接読込、C183 +12とrow367 ±18の3 signed 枠を先に控除。35絶対指数/69 signed 枠から今回21/42枠控除し、14絶対指数/27 signed 枠が残る。生成の288 signed×ラベル ledgerの残余 signed 集合と一致。

## 3. 監査範囲と限界

- 既存C118の有理点分類は、参照されている親数学命題として採用し、この監査で再び高種数JacobianのSelmer群やColeman積分をゼロから再演算していない。これは受け継ぐ親前提でありrow368の算術差分の新規計上ではない。
- 今回の21絶対指数は**元source必要条件の不存在**である。曲線の全有理点一般を分類したわけでも、元物理モデルから元sourceへの未閉鎖の上流アダプタを完成させたわけでもない。
- 「1絶対指数」を実際の整数解1個と数えてはいけない。今回42 signed index slotsを閉じたという意味。
- P112残存の14絶対指数・27 signed 枠は、現在照合したmaskに対する研究用残表。未照合の他の排除済み成果があり得るため、世界的/歴史的な厳密最小残余であるとは主張しない。
- ±48の具体的研究NEXT、R3-07 LOW / R2-01 MID/HIGHの分担、全LOW/Branch B OPENを変更しない。

## 4. 結論

**PASS (限定された元source排除証明)**。21絶対指数・42 signed 枠の対象限定排除を認証。既存S263/S264/S321/C118/P112とrow367の証明を依存として維持。重複加点なし。残表は14絶対指数、27 signed 枠。次の研究はrow368後のR0 ACTIVE_NEXTに従って固定±48のWard7/49障害を調べる。C番号の昇格・Branch B閉鎖は主張しない。
