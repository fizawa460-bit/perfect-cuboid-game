## Q1. 還元の正しさ

**判定：論理として完全ではありません。抜けているのは「非 indexed」の場合で、これは publication が明記している既知の穴です。**

構造（`PR1860-E3-LABEL-INDEXED-BRIDGE-AUDIT.md`、`PR1860-BRANCHB-PARTITION-AND-TORSION-PARENT-CHECK.md` による）：

- 完全直方体（辺 A, r, s）は、原始ピタゴラス三つ組 (A, B, C) と、楕円曲線 E: y² = x(x − A²)(x + C²) 上の点 Q_n = (−r², −rpq) を与えます。ここまでは恒等式です [proved、資料内の直接計算]。
- E には既知の点 P = (AC, ABC) があります。**indexed** とは、Q_n = T₀ + [2n]P と書ける場合です。
- (b) の LOW / MID / HIGH は、この n の大きさによる区分です。**全体が「indexed である」という仮定の下の話です。**
- Q_n が indexed でない場合は、E(Q) が E[2] + ZP より大きい基底（階数 2 以上、または P が割り切れる）で起こります。この場合には指数 n がなく、(b) の道具は何も使えません。

**一番危ないところ（上から順に）：**

1. **非 indexed の部分。** 還元がありません。「高々一方の向きが indexed」は示されていても、「少なくとも一方が indexed」は示されていません（`06-cross-lane.md`）。E1 の証明には、ここが丸ごと残ります。
2. **親の証明の連鎖が未監査。** S 系列、C174 の一様な高さ下界、S237 の formal depth。`MAJOR-PARENT-MATH-PAPER-CHECK.md` が独立に確かめたのは初等的な範囲だけです。155/197 の閾値は、この高さ下界にそのまま依存します。
3. **indexed の中の小さい指数と奇数。** C195 は |n| ≥ 6（現行は |n| ≥ 12）を仮定しています。|n| < 12 と奇数 n の扱いは、私は資料で確認していません（未確認の仮定）。
4. **名前の衝突。** 「Branch A/B」「Route2 finite-odd」「R2-01」が、文書によって別のものを指します。資料自身が注意しています。
5. **外部定理の適用**（Bérczes、de la Maza）。第 2 周で照合済みとありますが、私は再照合していません。

## Q2. Stage33 型の行き止まりがないか

**判定：あります。(a) の局所評価は、「空である」という結論を出せません。** [conditional：Stage33 定理 1（監査 PASS、修正 F1 つき）に依存]

- (a) の類は、Stoll の直方体曲面の開集合 U = {h ≠ 0} の上の代数的 Brauer 類 2 個です（`MAIN-STATE.json`：H¹(Pic) = Z/2 × Z/2、代表元 (−1, F_B)）。有限個です。
- この曲面には、滑らかな有理点 P₀ = (3,4,0; 4,3,5; 5) があります（退化した直方体）。U がどの稠密な開集合でも、P₀ は解消した曲面 S の有理点です。
- Stage33 の定理 1（`stages/stage33/STAGE33-FROZEN-20261112.md`）：Br(U) の任意の有限部分群 B に対して、U(A)^B は空でない。
- したがって、(−1, F_B) をどれだけ正確に局所評価しても、結果は「空でない」に決まっています。超越的な類（STATE では OPEN_NOT_COMPUTED）を足しても、有限個である限り同じです。

**「Master-Hit に限った局所評価なら別の話になるか」：なりません。** [outline]

- Master-Hit は Euler brick、つまり K3 曲面（空間対角線を忘れた商）の有理点です。完全直方体は、その点で関数 f_sp が平方になる場合です。
- これは二重被覆 S → K3 のねじれ S_d（d·w² = f_sp）への降下の問題です。完全直方体は d = 1 のねじれの有理点です。
- ところが、退化した有理点 P₀ は d = 1 のねじれ（S そのもの）の上にあります。局所条件や Brauer 類で「d = 1 には有理点がない」と結論することはできません。
- 一般に、アデール位相で連続な有限個の条件は、退化した点の近くの局所点を排除できません。

**(a) に残る意味。** 局所評価は、仮に完全直方体があった場合の合同条件のような制限を与える可能性はあります。しかし決着にはなりません。

## Q3. −30 の無条件化は現実的か

**判定：いまの道（小さい素イデアルを一つずつ消す）は、ゴールに届きません。** [estimate、根拠は下]

- 必要なのは「ノルム 2⁹⁴ 未満の素イデアルの類が、すべて 2 を法として消える」ことです。2⁹⁴ 未満の素数は約 3.0 × 10²⁶ 個あります（検算スクリプトの (3)）。毎秒 10⁹ 個処理しても約 10¹⁰ 年かかります。
- いま扱っているのはノルム 6768 までの 878 個です。形式残余 181 → 175 の改善は、この有限の表の中の話です。資料も「175 は真の類群の次元でも上界でもない」と書いています。
- つまり、残余が 0 になっても、無条件の結論にはなりません。足りないのは「小さい素イデアルが類群全体を生成する」という証明で、これは別の義務です。

**代わりの道の判定：**

| 道 | 判定 | 理由 |
|---|---|---|
| 別の降下・isogeny による MW 階数の上限 | 現実的でない [outline] | 曲線は種数 52 の超楕円型と読めます（105 次の体が 2-降下に現れる）。Galois 群が大きく中間体がない（row383）ので、Jacobian に使える isogeny は期待できません。高次の降下も同じ類群を必要とします（`04-minus30.md`：CT/q★ に全類群基底が必要）。 |
| 類群の 2 部分だけを別の方法で抑える | 現実的でない [estimate] | Cl[2] = 0 は「不分岐な 2 次拡大がない」ことと同値です。無条件に示す既知の方法は、(i) Minkowski 型の上界までの全数（上の 2⁹⁴）、(ii) 判別式の下界（Odlyzko 型）との比較、(iii) Hecke L 関数の零点の制御、です。(ii) は根判別式が小さいときだけ使えます。K の根判別式は約 44.5 です（`materials/negative30-mw-selmer/audits/row379.txt` の定数 C ≈ 0.11075 から逆算 [computed]）。この署名での漸近的な下界は、GRH つきで約 49.7、無条件で約 23.9 です（Odlyzko の定数 8πe^γ、4πe^γ などによる。数値は記憶からで、出典は未照合）。44.5 は無条件の下界よりずっと大きいので、無条件ではこの比較は何も言えません。GRH つきなら効く領域にちょうど入っており、row381 が GRH 条件付きで閉じたことと整合します。資料の `04-minus30.md` にある「無条件の解析方式ではスコアが負のまま」という障壁も同じ事情です。(iii) は GRH なしでは実用的な範囲に届きません。 |
| GRH 条件付きの結論を受け入れる | **現実的。すでに済んでいます**（row381） | この種数の Jacobian の 2-降下を GRH 条件付きで述べるのは、文献でも普通の扱いです（記憶による一般的な知識で、特定の定理の引用ではありません）。 |

**補足：−30 が無条件で閉じても、全体はほとんど進みません。** LOW の残りは 16 枠のうち 15 枠が残ります。

## Q5. E1 自体のリスク

**E1 は「完全直方体が存在しない」と同値です。** [conditional：逆向きは Stage29-08 の被覆定理に依存]

- `stage29/29-08/peschmann-exact-crosswalk.md` の記号で、e = U₁U₂、x = V₁U₂、y = U₁V₂ とします。Master 条件は「x² + y² が平方」（三つ目の面対角線）です。
- H = (W₁U₂)² + (U₁V₂)² = e² + x² + y² が恒等的に成り立ちます [proved、検算スクリプト (1)]。H は空間対角線の 2 乗です。
- ξ² + η² = H/g₀² なので、Master-Hit で ξ² + η² が平方 ⇔ その Euler brick が完全直方体。
- したがって：E1 が偽 ⇒ 完全直方体が存在する [proved、退化した組を Master-Hit に含めない定義の下で]。完全直方体が存在する ⇒ E1 が偽 [conditional：すべての原始 Euler brick が master tuple から来る、という Stage29-08 の監査済み定理]。
- 「完全直方体は存在しないが E1 は偽」ということは、この定義では起こりません。`MAIN-START-HERE.md` の「weaker replacement theorem」という表現は、強さについては不正確です。

**数値的な証拠の重み。** [estimate]

- 151,575 個の Master-Hit で確認済み、というのは「その範囲に完全直方体がない」という意味で、従来の完全直方体の探索と同じ種類の証拠です。
- 文献の探索はこれよりずっと広い範囲を調べています（最小の辺が 10¹⁰ を大きく超える範囲まで見つかっていない、という報告があります。数値は記憶によるもので、出典は未照合です）。
- どちらも有限の証拠で、E1 の真偽については「反例は小さい範囲にはない」以上のことは言えません。E1 が偽である可能性は、完全直方体が存在する可能性と同じで、現在の数学では否定も肯定もできません。

## Q6. 結論：Stage35-EX を凍結する

理由：

1. **目標が元の問題そのもの**（Q5）。「弱い代替」という前提が成り立ちません。
2. **(a) は原理的に決着しない**（Q2）。Stage33 と同じ曲面、同じ理由です。
3. **(b) は三重に届かない。** 非 indexed は手つかず（Q1）。indexed の中の HIGH・MID・奇数域は新しい定理が必要（Q4）。LOW は 1 枠ごとの費用が指数の 2 乗で増え、最初の 1 枠（−30）が無条件では閉じない（Q3）。
4. いまの作業（P953 の関係探し）は、成功しても「形式残余が減る」だけで、無条件の排除は 0 のままです。

**凍結するときに残す価値のあるもの**（新しい作業ではなく、既存の結果の整理）：

- 条件付き・対象限定の結果：±18、Ward3/5/7 の列挙された指数、+12、+30 の排除、−30 の GRH 条件付き排除、155/197 の下界。
- これらは「indexed な点について、指定した指数では起こらない」という限定つきの結果として、そのまま保存できます。

**再開の条件の案**（決めるのはそちらです）：

- 非 indexed の場合を indexed に帰着する定理、または非 indexed を直接扱う道具が出たとき。
- HIGH の相関上界に当たる一様な定理が出たとき。
- どちらもない状態で、LOW の個別の枠や −30 の関係探しを再開しない。

## 自己監査

**判定の弱点。**

1. (b) の連鎖（S 系列、C 系列、row 系列）は、整理本文（01〜06 章）と監査メモを読んだだけです。原証明の本文は読んでいません。「indexed の定義」「Branch A/B の区分」は、`PR1860-*` の 2 文書の記述に依拠しています。
2. Q3 の根判別式（約 44.5）は、row379 の監査メモにある定数からの逆算です。判別式そのものは見ていません。比較に使った Odlyzko 型の下界の数値（無条件で約 23.9、GRH つきで約 49.7）は漸近的な定数からの概算で、210 次という有限の次数での正確な値ではありません。無条件の下界が 44.5 を超えることはないので、判定は変わりません。
3. Q4 の「体の次数が指数の 2 乗で増える」は、2 点（±18 で 36、±30 で 105）からの外挿です。
4. Q2 は Stage33 定理 1 に全面的に依存しています。定理 1 の独立監査（Claude 以外による）が済んでいるかは、資料からは分かりません。
5. Q5 の「E1 ⇔ 非存在」は、Master-Hit の定義が退化した組（辺が 0 になる組）を含まないことを仮定しています。Peschmann の原論文の定義は確認していません。

**確かめていない仮定。**

- |n| < 12 と奇数 n の扱い。
- h の具体的な式（U = {h ≠ 0}）。定理 1 は U がどの稠密な開集合でも成り立つので、判定には影響しません。
- 完全直方体の探索範囲の文献値。
- 種数 52 の曲線が超楕円型であること（105 次の体が現れることからの推測）。

**独立監査で突かれそうな点。**

- 「非 indexed は元の問題と同じ難しさ」は概略です。非 indexed の基底が無限にあることの証明は示していません。
- 「GRH 条件付きは文献でも普通」は一般論で、特定の出典を挙げていません。
- 「(a) に意味が残らない」は「決着には使えない」という意味です。制限情報としての価値まで否定してはいません。
- 凍結の勧めは、Stage35-EX の個々の結果（±18 の排除など）の正しさを疑うものではありません。それらは判定の対象外です。
