増えた2行は、新しい有理素数の関係1行とαの関係1行。181は真の類群の次元でも、その上界でもない。新しい整数核や単元群の飽和計算を済ませたとの主張もない。

`dual_obstruction.py` は追加後の有限表示について全関係を消すF2線形汎関数 ℓ を構成し、ℓ(P827)=1 を検証する。`dual_obstruction.json` の非零列リストが完全な証書。

補題：任意の新しい列にはℓを0で延長する。追加関係を用いてP827を零化するなら、追加関係の少なくとも1本でℓの値が1になる。

証明：追加関係でも全てℓ=0なら、それらと旧関係の線形結合は全てℓ=0である。一方P827にはℓ=1なので、その行空間に含まれない。これは必要条件だけで、ℓ=1の関係を1本得ただけで零化できるとは限らない。またℓは有限表示の形式的汎関数であり、真の類群指標の存在を主張しない。

この線形代数補題自体は新しい理論ではない。今回の具体的な証書を、今後の候補の優先順位付けと「旧関係の組合せ」の排除に使う。
