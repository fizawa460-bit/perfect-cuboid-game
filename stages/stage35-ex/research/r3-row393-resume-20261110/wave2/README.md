## 検算可能な証人

新整元リストのindex355にある α は

    (α) = P_(67,0) P_(503,0) P_(1559,2) P_(2969,0) P_(3217,1)
    |N(α)| = 501822536690507
    α = h(ρ)/2^34

を満たす。`verify_key_relation.py` は、親の最大整環基底に関する整数係数表示、終結式、全5素数での1次GCDと単純根を検査する。この検査は収穫時のfull_profileと2進付値ルーチンを使わない。

このαと既存の62生成元を掛け合わせると、分数イデアルIについて

    product of the 63 principal ideals
      = P_(827,0) P_(2113,1) P_(2969,0) P_(2999,0) I^2

となる。従って実際の類群のmod 2商でも

    [P_(827,0)] + [P_(2113,1)] + [P_(2969,0)] + [P_(2999,0)] = 0.

62個の旧生成元の番号、新生成元index355、Iの全整数付値を `dependency_witness.json` に保持した。旧生成元番号は `analyse.py` / `verify_linear.py` のparents列順で連結したリストに対する0始まりの番号。旧行列の形式基底181方向のうち、P_(2999,0)が他の3方向に従属した。個別の主性・2可除性を新たに得たわけではない。

`verify_linear.py` は別実装の低位ピボットで基底像の次元181→180を確認し、この積イデアル恒等式を整数付値の直接加算で確認する。`dual_wave2.json` は追加後の全15681行を消し、P827には1を取る新しい形式的線形汎関数。真の類群指標の存在証明ではない。
