### 中核となる主イデアル

新リストの0始まり index 825 の整元 α=h(ρ)/2^34 は、符号付きノルム −101440747、絶対ノルム `67·457·3313` を持ち、次を満たす。

```text
(α) = P_(67,0) P_(457,0) P_(3313,2).
```

`new_relations_wave5.json` に h の全係数・探索基底での表示と各付値を、`key_verification.json` に整数基底表示、105次終結式、法pの単純な1次共通根を収録した。`verify_key.py` は収穫用 `full_profile` と2進局所付値ルーチンを用いずにこの整元を検算する。

`dependency_witnesses.json` と `certificate_wave5.json` は、旧生成元47個と新 index 825 を用いる `(3313,2)` の証人、旧生成元41個と同じ新整元を用いる `(4957,0)` の証人を保持する。いずれも有理素数の行を使わず、全付値の整数加算で「対象素イデアル × 分数イデアルの平方」という等式を検証した。新整元を相殺すると旧関係だけから両素点の像が等しいことも確認でき、2個の零化が形式残余の1次元減少に対応する理由が分かる。`verify_linear.py` がその旧関係を符号付き整数付値で検算する。

第4探索の `P_(2969,0) = P_(3313,2) + P_(6659,0)` と組み合わせると、Cl/2 で `P_(2969,0) = P_(6659,0)`。したがって P827 を零化する際の三項補集合は `P_(1277,3) + P_(2113,1) + P_(6659,0)` と書ける。この書き換え自体は追加の独立成果として数えない。
