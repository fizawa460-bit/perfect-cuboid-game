## 小基底に効かないことの直接証書

55個の新生成元は、それぞれちょうど1つの大素数p≥2^64を奇ノルムに持つ。そのpは他の54生成元のノルムにも、旧素イデアル支持にも現れず、ノルム指数は1。p上の素点は全て非分岐で、少なくとも2個ある。

新生成元が付値1を取る素点をQ、付値0を取る別の素点をTとする。Q,Tの2列だけを見ると、新主関係と有理数pの主関係はそれぞれ

    new principal row:  (1,0)
    rational-prime row: (1,1)

となる。他の旧関係と54組の新関係はその2列で0である。この2×2行列はF2上可逆なので、旧支持上だけに残る線形結合では、この2行の係数がともに0でなければならない。全55組で同じ議論ができる。

したがって、この110行の追加では旧座標空間に新しい関係を作れず、旧有限表示の商は拡大後の商へ単射となる。今回の55件に限って、小基底像180は厳密に不変。

`private_support.py` は全55大素数の素数性、G mod pの平方自由性と分解、gcd(G,h)の1次性、付値1と0の素点、pの旧支持不在・他行不在を確認する。大素数・ρの剰余・Q/Tラベルを `private_support_certificate.json` に保存した。これは真の類群が180次元である証明でも、今後これらの大素数を共有する関係が得られないという主張でもない。

`arbitrary_precision.py` はp<2^64では元のnmod_polyを保持し、それ以上でfmpz_mod_poly_ctxへ切り替える。特に既存の2進局所環の型を変更しない。親の因数分解・ラベル付け・Hensel付値のアルゴリズムは継承する。混在キャッシュを避けるため、切替時には親の因子分解キャッシュを消去する。

この処理が検証したのは提出55元とその素因子である。任意の数体・全分岐型・任意の大素数に対する汎用検証を済ませたとはしない。親の最大整環と局所算術証書への依存は残る。
