凍結判定が残した未完義務（ZF2、δ★ の4リフト、c_Cl の無条件確定）に

## 前提（監査済みの親成果）

- dim Sel²(J₂₉) = 9 + c_Cl、−30 source は rank ≥ 10 を要求する。
  よって無条件の c_Cl = 0、または rank ≤ 9 の認証で −30 は閉じる。
- row381：c_Cl = 0 は二次 Hecke GRH 条件付き（条件付きのまま扱う）。
- row383：Gal(L/Q) = S₁₀₅、無条件の明示公式により c_Cl ≥ 1 なら
  二次 Hecke 指標の L 零点が3つの帯に必要。
- row384：c_Cl ≥ 2 なら χ₁, χ₂, χ₁χ₂ のどれかが Ω₂ に零点を持つ。
  未完義務は ZF₂ と δ★ の4リフト不能。
