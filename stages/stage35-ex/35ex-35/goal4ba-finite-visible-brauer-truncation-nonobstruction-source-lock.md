## 3. Arbitrary finite visible truncation

Let

```text
Chi={chi_1,...,chi_m}
```

be any finite set of global finite-order characters. Define the finite subgroup

```text
F_Chi
 = < A, B, beta(chi_j,u_i) : 1<=j<=m, 1<=i<=3 >
   subset Br_a(U).                                    (BA-F)
```

We prove

```text
(A_src^loc)^(F_Chi) != empty                          (BA-NONEMPTY)
```

for every finite `Chi`.

Choose a finite set of places `S` containing:

- infinity and `2`;
- every prime `<173`;
- denominator/bad-model primes needed for `P*`, `A`, and `B`;
- every prime at which any `chi_j` is ramified.

Enlarge `S` if necessary so all relevant finite algebraic data spread out over `Z[1/S]`.

### Places in S

At each `v in S`, choose a 35EX-22 nonzero-`y` deformation `Q_v` in a common local-constancy neighborhood for the finite family

```text
A, B, beta(chi_j,u_i).
```

At `v=2`, also impose `(BA-2)`. At infinity impose `y>0`. Then for every generator `alpha` of `F_Chi`,

```text
inv_v alpha(Q_v)=inv_v alpha(P*).                    (BA-S)
```

### Finite places outside S

For every prime `ell notin S`, use the integral open point

```text
Q_ell in U_PC(Z_ell)
```

supplied by 35EX-22. The same certificate proves that all seven retained linear generators, hence in particular `u1,u2,u3`, are `ell`-adic units at `Q_ell`.

The rational values `(BA-PU)` are also `ell`-adic units because all their denominator/numerator exceptional primes were placed in `S`. Every `chi_j` is unramified at `ell`. Hence local reciprocity is trivial on the unit ratio

```text
u_i(Q_ell)/u_i(P*) in Z_ell^*.
```

Using `(BA-EVAL)`, the character-unit evaluation differences vanish:

```text
inv_ell beta(chi_j,u_i)(Q_ell)
 = inv_ell beta(chi_j,u_i)(P*).                      (BA-GU)
```

For `A,B`, the same equality follows from the spread-out integral-good-prime argument already used in Goal4AN/Goal4AO (indeed both evaluations vanish there after enlarging `S`). Therefore `(BA-S)` and `(BA-GU)` together give

```text
inv_v alpha(Q_v)=inv_v alpha(P*)
```

for every place `v` and every generator `alpha` of `F_Chi`.

## 4. Global reciprocity closes every finite truncation

Because `P*` is a rational point of the ambient affine receiver where all the retained classes above are evaluable, `alpha(P*)` is a class in `Br(Q)` for each generator `alpha`. Global Brauer reciprocity gives

```text
sum_v inv_v alpha(P*)=0.
```

Hence the constructed restricted-product adelic point `Q=(Q_v)` satisfies

```text
sum_v inv_v alpha(Q_v)=0
```

for every generator and therefore for every `alpha in F_Chi`. The real component is positive, the 2-adic component satisfies the source marking, and all but finitely many finite components are integral. Thus

```text
Q in (A_src^loc)^(F_Chi),
```

proving `(BA-NONEMPTY)`.

## 5. What this does and does not settle

This is stronger than the earlier two-class blocker: it handles **arbitrarily many but finitely many** global character-unit classes at once, together with `A,B`. Therefore no finite truncation of the exact visible family used by Goal4AQ can produce a Brauer--Manin obstruction on `A_src^loc`.

The contrast with Goal4AQ is exact:


This leaf does **not** prove that every finite subgroup of `Br_a(U)` or `Br(U)` is non-obstructing.
