# Stage27 StructureRadar re-match roadmap

Date: 2026-08-20
Status: ACTIVE_ROADMAP
Scope: Stage27-19 / Stage27-20

## Objective

Re-match the organized StructureRadar arsenal against both Stage27 upper and lower/support lines. Do not exhaust StructureRadar for its own sake. Advance a route while it produces a new legal adapter, fixed-power target, exact structural reduction, or theorem match; freeze it at a genuine theorem gate and move to the next route.

The frozen Stage27-20-r302 lane remains frozen. It is not a prerequisite for the routes below.

## Execution order

### 1. Stage27-20-r303 — T physical target-class weighted adapter

Side: UPPER.
Priority: P1 / active first.
StructureRadar match: primarily SR-STR-165, with Gaussian/ray-class normalization and same-measure firewalls from the existing Gaussian cards.

Goal: start from the physical target-class pushforward weight w(c), control exceptional target classes by a same-measure collision deficit, and then determine whether the collision relation admits genuine one-ideal / one-variable coefficient separation. If it does, attach the separated Gaussian/Hecke large-sieve technology. If it remains an arbitrary correlated matrix, do not pretend SR-STR-165 applies.

Success condition: a fixed-power weighted exceptional-class deficit strong enough to improve the current square-root upper exponent.
Stop condition: exact T parametrization proves that the required separation is unavailable and no alternative same-measure weighted theorem is present.

### 2. Stage27-19-r6b onward — occupied-R squareclass collision

Side: SUPPORT/UPPER interface on the Stage27-19 line.
Priority: P2.
StructureRadar match: SR-STR-164 + SR-STR-166.

Starting receiver already proved in r6a:

    sqf(AB-xy) = sqf(AB+xy),

with the primitive/canonical/exactly-two physical masks retained and only R^{o(1)} candidate representation pairs at fixed R.

Goal: run the squareclass-collision machinery legally: remove diagonal/symmetry/singular components, derive the charged-once eliminant, and test whether it produces a genuinely new determinant factor or exact inverse-fraction transform. Use lattice counting only for a new determinant factor; use Kloosterman-fraction technology only after a zero-loss transform.

Success condition: occupied-R support << B^(1/2-delta+o(1)).
Stop condition: the eliminant contains no new independent factor and continuation would charge the same common-core spacing twice.

### 3. Stage27-20-r304 — balanced-wall squareclass / eliminant bypass

Side: UPPER.
Priority: P3.
StructureRadar match: SR-STR-164 + SR-STR-166.

Goal: build a receiver independent of frozen r302 by asking whether balanced-wall packet collisions force a new squareclass equality, determinant factor, or independent second modulus. This is a bypass route, not a reformulation of the r302 same-H_phys operator deficit.

Success condition: a new independent arithmetic factor yields a fixed-power wall deficit.
Stop condition: no new determinant/modulus appears, or the route reduces back to the frozen r302 same-measure gate.

### 4. Stage27-19 lower/support occupancy lane — reciprocal-CRT moment to support

Side: LOWER / SUPPORT.
Priority: P4, deliberately before the next upper-only route.
StructureRadar match: SR-STR-173 and compatible reciprocal-CRT / nonnegative-witness cards.

Goal: use moments only on the exact charged physical measure. Convert a nonnegative witness moment into support/occupancy without treating ambient multiplicity as density. Search Stage27-19 for a receiver whose first/second moments are already on the same physical population and whose support conclusion strengthens the current lower-side information.

Success condition: a genuine new lower/support exponent, occupancy ratio, or fixed-power support statement on the intended Stage27 population.
Stop condition: the only available moment lives on an ambient or changed measure, or the conclusion requires the unresolved super-Kai individual-modulus Gaussian-prime theorem.

### 5. Stage27-20-r305 — coefficient-separation large-sieve route

Side: UPPER.
Priority: P5.

Goal: revisit T/wall correlations solely to test for an exact one-variable separation or a B^{o(1)}-rank separated decomposition. If legal separation is proved, apply quadratic/Jacobi or Gaussian-Hecke large-sieve weapons with full conductor/coprimality bookkeeping.

Success condition: separated blocks provide a fixed-power saving without a second unproved correlation saving.
Stop condition: coefficients remain a genuinely correlated W(u,v); arbitrary-matrix large-sieve substitution is forbidden.

### 6. Stage27-19 lower geometry/descent lane

Side: LOWER / SUPPORT.
Priority: P6.
StructureRadar match: SR-STR-163; reopen SR-STR-162 / SR-STR-223 only after the Stage27 receiver changes enough to satisfy their transfer tests.

Goal: exploit explicit Prym / rational-2-torsion / 2-isogeny / higher-descent structure for a concrete moving physical family. First derive an exact Stage27 family and physical height window; only then ask whether descent packets create a support-producing selector.

Success condition: a legal moving-family lower/support theorem or a new repo lemma that makes an existing external theorem applicable.
Stop condition: only fixed-fiber descent, local solubility, Selmer information, or ambient density-one family information is available.

    r303 upper
