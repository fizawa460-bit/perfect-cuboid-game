## L1-06. 解釈：なぜ Legendre ビットだけでは決まらなかったか

- 非 Legendre の部分は (e/p)\_4（p=p2 または p1）だけ。4乗剰余記号は p の Legendre 記号の関数ではないので、0G §7 の探索で決まらなかったことと整合する。
- R-8(c) の r=4u/729（r²≡2 mod p）を使うと e=729(1+r) なので **(e/p)\_4 = (3/p)·((1+r)/p)\_4**（734/734 で確認）。p2≡1 mod 3 では (3/p2)=+1。
- B=+1 は F(Y)=Y⁴−2Y²−1 が p で (1,1,1,1) 型であること（R-8(c)）。((1+r)/p)\_4=+1 は、その根 Y（Y²=1+r）が F\_p で平方、すなわち **Z⁸−2Z⁴−1 の分解のさらに一段上**の Frobenius 条件。R-8(c) の「1ビット＝固定四次式の Frobenius 型」の次の段（固定八次式）として読める。
- 構造：w1=χ\_e∪T1 なので、対は (−e, e, β'1) の三重の積（Rédei 記号型）になり、分裂する素点で4乗剰余記号が現れる（L1-03, L1-04(a)）。

- 既約性：一次式は自明。f4, f5 の u についての判別式はどちらも 32K² で平方でないので、Q 上既約。
- 最高次係数は正。
- 固定素因数がない：全体の次数は7なので、p ≥ 11 では ω(p) ≤ 7 < p。p ≤ 7（実際は p < 2×10⁶ の全て）で、積 f1…f5 の mod p の根の数 ω(p) < p を直接確認した。

仮説 H から、5つが同時に素数になる k が無限にあり、R-20 命題2 によりその u はすべて因数形でビット1、R-18 命題3 により rank 0 かつ E(Q) = E2。各 u から p = ±a/b, ±b/a の4点が除外され、u が異なれば a/b = 2u/(2u+729)（既約）も異なる。∎

### (3) 数値の裏付け（Bateman–Horn 予想との比較）

仮説 H の定量版（Bateman–Horn）は、k ≤ X での実現数を C·Σ 1/Π log f\_i(k) と予想する。C = Π\_p (1−ω(p)/p)(1−1/p)^{−5} を p < 2×10⁶ まで計算した（類によって C ≈ 1800〜2200）。

| 類（p0, q0）の数 | k ≤ 300,000 の予想 | 実際 |
| --- | --- | --- |
| 137/31 の2枝 | 14.2 | 7 |
| 他の12類（137 と 337、q0 = 47, 79, 103, 127, 167） | 58.0 | 75 |
| 合計14類 | **72.2** | **82** |

合計で予想と実際の差は約 +1σ（Poisson の標準偏差 ≈ 8.5）で、予想とよく合う。

### 到達点

- **有限に落ちたもの：** どの類でビット1が強制されるか（R-20 の表）。4乗剰余記号の部分は固定された16次の体の Frobenius（Chebotarev で密度 1/2）。
- **無限に残ったもの：** 5つの多項式が同時に素数になること（Schinzel の仮説 H）。これは n²+1 が無限に素数になるかという問題（未解決）を含む型で、現在の数論では証明できない。
- したがってこの経路では、「固定 p の除外が無限にある」ことは仮説 H に**還元された**（仮説 H ⇒ 無限）。無条件の証明は、この経路の外の新しい考え（素数の条件を外しても CT ビットを制御できる形）が必要。

**水準。** (1) の Galois 群・密度は PARI と数値、(2) は R-18・R-20 と既約性・固定素因数の確認からの証明、(3) は数値。外部査読なし。

**含意しないこと。** 無条件で無限に除外できること。全 p の除外。仮説 H の部分的な結果（Iwaniec の P2 定理など）がこの5つの同時条件に使えること（使えない：素数を5つ同時に要求している）。
