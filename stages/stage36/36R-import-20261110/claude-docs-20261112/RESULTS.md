## R-1. Campedelli 商と H-torsor の構造

- 符号被覆 pi : Sbar -> P^2 の商群は Gamma = F\_2^7/<1^7>、dim Gamma = 6。
- 7本の分岐線の慣性類は唯一の関係 e\_A1+e\_A2+e\_A3+e\_B3+e\_B2+e\_B1+e\_C = 0 を満たす。
- 全射 q : Gamma -> G=(Z/2)^3（7つの慣性像が G の非零元7個をちょうど1回ずつ）をとり H = ker(q) とおく。
- Cbar\_H := Sbar/H。Sbar -> Cbar\_H -> P^2 と分解し、deg(Sbar->Cbar\_H) = 8、deg(beta\_H) = 8。
- H の作用は正準モデル上で自由。Sbar -> Cbar\_H および解消後の S -> C\_H は次数 8 の有限エタール H-torsor。
- 幾何的には C\_H は Campedelli 曲面：q=0, p\_g=0, chi(O)=1, K^2=2, pi\_1 ≅ (Z/2)^3。

## R-22. C3\_p の e-降下による固定 p の除外法と、その成否を決める曲線 J₁, J₂ の root number　〔Stage38 ログ L2-09〜L2-0C〕
