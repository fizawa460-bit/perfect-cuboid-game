## 0F — Cassels–Tate 対の実装と、B=+1 の曲線への適用（2026-10-04）

**目的。** `dim Sel²=4`（因数形の `B=+1`）で rank を決める。`Sel²/E[2]` は2次元で、Cassels–Tate 対（交代形式）が非自明なら `rank=0` かつ `Sha[2]≅(Z/2)²`、自明なら Sel² の全元が 4-Selmer に持ち上がり、rank 2 か `Sha[4]` の大きさかの区別がつかない。

**公式の出典。** Cassels, "Second descents for elliptic curves"（Crelle 1998）。完全 2-torsion の場合の明示式を、Shukla–Stoll（arXiv:2302.01640）の式 (3.10) の形で使った。Sel² の元 `a=(β1,β2,β3)`（`β_i=[x-e_i]`）の2-被覆 `D_a: x-e_i=β_iΓ_i²T⁻²`（`i=1,2,3`）に対し、3つの円錐曲線 `H_i=(β_jΓ_j²-β_kΓ_k²)/(e_j-e_k)+T²=0`（`(i,j,k)` は巡回）の有理点 `q_i` での接線形式 `L_i` をとり、`⟨a,a'⟩ = Σ_v Σ_i (L_i(q_v), β'_i)_v`（`q_v∈D_a(Q_v)` は任意の局所点）。

**実装。** `code_ct_cassels.py`（Drive）。局所点はランダム標本、p進平方根は Hensel 持ち上げ、2進は逐次持ち上げ、実素点は mpmath（90桁）。`L_i` の係数を内容で割る正規化（Hilbert の相互律で補償）を使い、素点は「判別式の素数、β と β′ の素数、60 未満の素数、実素点」とした。

**検証（合同数曲線 `y²=x³-n²x`）。**

- n=17：`dim Sel²=4`、対の行列の階数 2（非退化）。17 は合同数でない（既知）ので整合する。
- n=34, 41, 65：`dim Sel²=4`、対の行列は零。n=34 は階数2の合同数として知られる。41 と 65 も階数2と記憶しているが、未確認。
- 一般的な性質：n=17 で、対称・交代・双線形（216組の3つ組）、トーション類が核に入る（全 Sel² 元との対が 0）、局所点・符号・乱数の取り方への非依存（各素点で値が一意）。
- 開発中に見つかった誤り：実素点を float で計算していたため、トーション類との対が 1 になった。mpmath に替えて解消。

**標的（K=729 族、`j<200000` の B=+1 の因数形 18 本）。**

- `Sel²` は `{トーション2つ, w1=(1,e), w2}`（`e=4u+729`、w2 は R-14 の核の4つ目の元）。商 `Sel²/E[2]` は `w1, w2` で張られ、対は交代なので `⟨w1,w2⟩` の1ビットで決まる。`w1` の円錐曲線の有理点は `q=(t+1,t-1,2)`（`t=16·K·d·f`）などの明示的なもの。
- 結果：**`⟨w1,w2⟩=1`（非退化）が7本**（j=25716, 29244, 95246, 102115, 115434, 120252, 135485）、`0` が11本（j=1430, 19252, 23725, 25663, 60040, 97020, 102005, 117055, 156364, 180772, 183768）。18本すべてで、トーション類との対は 0、乱数の取り方に依らない。
- 非退化の7本：`E(Q)/2E(Q)=E[2]` となり **rank 0、`Sha[2]≅(Z/2)²`**。`D` と `-D` が平方でなく、`ℓ=5` で `#E(F_5)` が 3 で割れないので `E(Q)[3]=0`、4-torsion もなし。よって `E(Q)=E[2](Q)≅(Z/2)²`。R-5 の受け皿の論法で「`dim Sel²=2`」を「rank 0」に置き換えると成り立つので、**固定 p の除外の新しい候補が7つ**（各 u に対応）。
- 自明な11本：rank 2 か、`Sha[4]` が大きいかは、この対では決まらない。
- 探索的な観察：対のビットは、三部グラフのデータ `(A,c1)` だけでは決まらない（`(A,c1)=(0,0)` の7本に 0 も 1 も現れる）。ほかの記号（q とのLegendre記号、`p mod 16` など）の1〜2個の和でも説明できない（18点、探索のみ）。Sel² のグラフに現れない `q1,q2` や `7` が、この対には効く可能性がある。

**状態。** 候補。RESULTS には昇格しない。理由：(1) 公式と実装は合同数曲線の4本と性質の検査で確認しただけで、外部査読がない、(2) 標的の曲線は局所点・円錐曲線の点を自前で構成しており、人手の確認がない、(3) 7本の除外は R-5 の論法の置き換えで、36-09 側の定理とは未照合。

**含意しないこと。** 自明な11本が rank 2 であること、因数形の実現が無限にあること、全 p の除外。対のビットを1ビットの Legendre の式で書けたわけではない。

**次の一段。** 0G：(1) 実装と標的の結果を外部査読用にまとめる、(2) 7本の除外の候補を、R-5 の条件と1つずつ照合し、固定 p の除外の登録簿（224件）との重複を確認する、(3) 対のビットがどのデータで決まるかの調査（`q1,q2`、4乗剰余記号を含む）。

## 17 — E\_τ の捩れ点補題（全有理 p）と有理 p への拡張準備

## 1N — 方針変更：一様な議論へ。標準形と、降下が効く理由

```latex

```

と双有理同値（f(t)(t²+1)⁴/t⁴ と k²X⁴+S² の比が平方であることを 300 例で確認）。**曲線は p に k² を通してしか依存しない**（p↔1/p, p↔c=(p+1)/(p−1) で k² 不変）。k=2n₀/H²、n₀=ab(a²−b²)（基本三角形 (P,Q,H) の面積の半分の関係）。既知点：X=±1（t=0,∞、自明類）、X=0（t=±1、境界類）。retained ⇔ X∉{0,±1}。言い換えると「有理角 φ で (k cos²φ, sinφ) が有理直角三角形の二辺になるもの」。

**2. なぜ Q(i) が使えるか。** 1−c²X² = s²+(cS)²、1−s²X² = c²+(sS)² はどちらも二平方和（Q(i) のノルム）。これは (P,Q,H) がピタゴラス数で H±P=2a²,2b²、H±Q=e²,f² が平方（の2倍）であることから来ており、全 p で成立する。

```latex
D(P) = \mathrm{sqf}\bigl(y + k(1+S^2)\bigr)
```

**4. 各降下の役割（標準形での統一的な読み方）。**

- 1G の Q 上の降下：1±cX, 1±sX の平方類（1−X の類を基準）。自明点と境界点が入る類は局所条件では決して消えない。実測では 85% の p でこの 2 類だけが残る。
- R 曲線：d1=d2, d3=d4 ⇔ 1−c²X² と 1−s²X² が個別に平方。
- 1I の K 方法：二つのノルムの因子 (s±icS), (c±isS) の組み合わせ方＝符号パターン。s\* は (s+icS)(c−isS) = k(1+S²)+imS に対応し、合同数曲線 E\_D を一様に与える。
- 1J：E\_D は CM を持ち、ひねり −1 が自分自身なので、他のパターンの曲線でも「二つのひねりの片方が rank 0」が効く場合がある。

**5. 悪い素数の構造（全 p）。** 局所条件が効く奇素数 ℓ は H, P, Q, P+Q, P−Q のどれか一つだけを割る（gcd(a,b)=1 より）。H の素因数は ≡1 mod 4、P±Q の素因数は (P+Q)²+(P−Q)²=2H² より ≡±1 mod 8。P±Q は角 θ∓45° に対応。

**6. 境界類の一様な消去の検証（仮説 H1）。** 「境界類の K の組は全て D=1」という仮説を a≤60 の無作為 120 個で検証。**偽**：5/4（H=41）、49/1（D=1201）、56/15（D=3361）などで D=H やその積の組が現れる。ただし多くの p では D=1 のみ。

**状態。** 1・2・3・5 は全 p に対する恒等式・補題（候補、数値と代数で確認）。一様な除外は未達。

**次の一段。** 局所像を「局所型」（ℓ が H, P, Q, P+Q, P−Q のどれを割るか、付値、Legendre 記号、ℓ mod 4）ごとに分類する。局所像は単位円上の点 (c,s) の ℓ 進的な位置だけで決まるので、型は有限個。各型の像を手で決定し、「Selmer 集合が自明類と境界類だけになる p の条件」を一様に述べる（無限族への定理）。

## 1P — 局所補題 A（ℓ≡3 mod 4）の証明と、一様化の限界

**記号。** A=u²+v², B=u²−v²（u,v 互いに素）。2Q1=HA−PB, 2Q2=HA+PB, Q3=HA−QB, Q4=HA+QB（Q3,Q4 は g で割る前の形）。A²−B²=(2uv)²。各 Q\_j の平方因子なし部分を δ\_j とする。

**補題 A（全 p、証明付き）。** ℓ を ≡ 3 mod 4 の奇素数とする。このときどの点でも ℓ は δ\_1,…,δ\_4 を割らない。

証明。−1 が mod ℓ で平方でないので、x²+y²≡0 mod ℓ なら x≡y≡0。よって A は単数。

- ℓ | P のとき：2Q1, 2Q2 ≡ HA（単数）。Q3+Q4=2HA が単数なので Q3, Q4 の少なくとも一方は単数。Q3Q4 = (2Huv)² + (PB)² は二平方和なので付値が偶数。したがって付値は全て偶数。
- ℓ | Q のとき：同様に Q3, Q4 は単数、Q1Q2 = ((2Huv)²+(QB)²)/4。
- ℓ | P±Q のとき（このとき ℓ≡7 mod 8）：Q1≡0 なら X=B/A ≡ H/P で、1−X² ≡ −Q²/P² ≡ −1（≡ 平方でない）。しかし 1−X²=(2uv/A)² は平方なので矛盾。Q2, Q3, Q4 も同様。よって全て単数。
- ℓ ∤ HPQ(P²−Q²)：普通の議論（二つの Q\_j が同時に ℓ で割れない）。∎

**系。** δ の奇素因数は「ℓ≡1 mod 4 で HPQ(P²−Q²) を割るもの」に限る（P±Q については ℓ≡1 mod 8）。これが 1O で見た「p によらない型」の理由。特に H の素因数は常に ≡1 mod 4 なので、境界類（δ に H が入る）は常に許される。

**結式の表（全 p、代数的に計算）。** K の一次形式 l\_1=bu+iav などの二つずつの結式は、ε·H、ε·2ab、ε·2ef、ε·P、ε·(P±Q)（ε は単数と 2）のどれか。特にパターン s\* の四つの形式は互いの結式が全て ±iH, 2iH。合同数補題の D の素因数は 2HPQ(P²−Q²) の素因数に限る。

**仮説 H2（偽）。** 「D は n₀^ε×（2 と ≡1 mod 4 の素数の積）」。a<70 の無作為 150 個で検証し、p=63/40（H=5569 素数、Q=2⁴·3²·5·7）で多数の反例（D=6, 14, 30, 42, 70, 210 など）。この p では Q(i) 上の Selmer 集合が大きい。

**評価。** 一様に言えること：標準形、合同数への帰着（D は悪い素数の積）、補題 A。一様に言えないこと：Selmer 集合の大きさと、残った類に対応する合同数曲線の rank。後者は「与えられた数が合同数か」という問題に帰着し、p によって答えが変わる。自明類は常に合同数 n₀ に当たるため、この経路だけでは全 p の除外には届かない。

**状態。** 補題 A と結式の表は証明付きの候補。H2 は反証。

**次の一段（候補）。** (1) ℓ≡1 mod 4 の型（P, Q, P±Q、H）の局所像を証明付きで分類し、Selmer 集合を「悪い素数の型」から計算する公式にする。(2) 自明類の壁：自明類の点が n₀ の合同数曲線のどの子集合に入るかを、虚数乗法 Z\[i\] の構造（点は「実の円」上にある）で一様に述べる。

## 1Q（2026-10-13）ℓ≡1 mod 4 の局所像：完全な分類（一様）

**結論**：奇素数 ℓ ごとの局所像 Im\_ℓ ⊂ (Q\_ℓ\*/□)^4 は、すべての p=a/b について「型・ℓ・n=v\_ℓ・符号1個」だけで決まる明示式で書ける。これで Selmer 集合は p の素因数の型データだけで決まる（一様な Selmer 公式）。

**型ごとの式**（χ=ルジャンドル記号、S=平方類、n=付値）

- 良い素数（ℓ∤2abH(P²−Q²)）：単数類のみ。
- ℓ≡3 mod 4：補題A（1P）で δ に現れない。
- P型（ℓ|a−b）：一般円盤 (χ(t²+1),χ(t²+1),S,S)、t≡0 で (S,S,S,任意)、t≡∞ で (S,S,任意,S)、t≡±i で Q1,Q2 の双子ブロック T(n,d)、d=χ(2b·(a−b)′)。ℓ|a+b は b→−b と Q3↔Q4。
- Q型（ℓ|a）：一般 (S,S,χ(t²+1),χ(t²+1))、t≡0 で Q1 任意、∞ で Q2 任意、t≡±i で Q3,Q4 の双子 T(n,d)、d=χ(a′b)。ℓ|b は a↔b と Q1↔Q2。
- P±Q型（ℓ≡1 mod 8 のみ起こる）：根が ±iα（Q1,Q4）、±i/α（Q2,Q3）の4つの双子。像は (ℓ, n mod 2, min(n,3), χ(H·(P±Q)′)) で決まる。
- H型（ℓ|H）：Q1..Q4 の根が t=±1 の近くで 1+ε·{−r, r, 1, −1}（r²=−1、v(ε)=n）。縮約は CM 曲線 y²=c(x⁴−1)。像は (ℓ, n, χ(2w))、w=(a/b−r)/ℓ^n で決まる。具体的には：対角 (k mod 2, ±1)（1≤k\<n）、(n mod 2, χ(2w)·(χ(x+r),χ(x−r),χ(x−1),χ(x+1)))（x∈F\_ℓ）、x が根のときはその成分が任意。

双子ブロック T(n,d)：対角 ((k,±),(k,±))（1≤k\<n）、((n, d·χ(y−1)), (n, d·χ(y+1)))（y≠±1）、片方が任意で他方が (n, d·χ(2))。

**証明**：各剰余円盤で Q\_j=A(t−ρ)(t+ρ) とし、遠い根の因子は円盤上で平方類が一定になる（厳密）。近い根は双子（H型だけは4つの根の塊）で、付値 n の層ごとに上の式が出る（ヘンゼル＋ニュートン多角形）。

**数値照合**（a<90、ℓ≤70、全件一致）：H型 2029/2029、P型 2000/2000、Q型 2044/2044、P±Q型 775/775。P±Q 型の「符号1個で決まる」は a<300、ℓ≤200 の 14773 件で衝突なし。

**大きい ℓ**：ℓ≥53 では文字のパターンが全部出る（双子は ℓ≥13、H型の16通りは ℓ∉{5,13,17,29,37,41}）。このとき像は (型, n mod 2, min(n,3), d, χ(2), χ(r)) だけで決まり、ℓ 自体によらない。確認方法：ℓ>2034 はヴェイユの評価、それ以下は計算（2600まで）。

**意味**：1G/1I/1J の降下で δ が死ぬかどうかは、p の素因数の型データ（＋2進・実の条件）だけで決まる有限の組合せ問題になった。

**残り**：(b) 自明類の壁。合同数曲線 E\_{n0} の Z\[i\] 構造を使う。
