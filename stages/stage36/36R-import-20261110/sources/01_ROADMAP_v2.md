## 3. Stage38 で変わったこと（再検討の根拠）

旧 ROADMAP の「再開してよい新しい材料」のうち、次が新しく入った。

1. **素因数の型で決まる降下の局所像**（本線 1P・1Q、未査読）：≡3 (mod 4) の素数は降下の類 δ を割らない（補題 A、証明つき）。≡1 (mod 4) の局所像は型（H/P/Q/P±Q）・付値・符号1個で決まる。→ 支持が動いても、Selmer 集合は **有限個の型データの関数**。36-05 の壁（有限 S がない）を「型による一様化」で迂回できる可能性。
2. **自明類の壁の同定**（1R、未査読）：自明類の点は種数2曲線 `X_λ : y² = −(B⁴+8B²−4λ²)(B²−λ²)`、`λ=(P²−Q²)/(PQ)`、`Jac(X_λ) ~ E_ρ × E_{n0}` に帰着。
3. **偶奇による限界の定理化**（R-19, R-21, R-22、査読1回）：rank 0 型の判定が原理的に使えない p が存在し（例 p=10, 23）、`E_σ` は全ての p で rank ≥ 1。「rank 0 だけで全 p」は不可能と確定。
4. **CT 対の閉じた式**（R-18, R-20, R-23）：dim Sel²=4 の部分族での rank 0 判定が式で書ける。ただし因数形という薄い部分族の話。

## 4. 新しい葉（優先順）

### 36-R1 — ADAPTER_QUANTIFIER_AUDIT（関門。最優先）

- 36-09I/J/O の式は 1D・1F で独立に検算済み。**残る依存は 36-09H 以前**（元の端点の式から common-Jminus 受け皿の定義まで）で、これは再監査していない。ここを独立に再監査する。
- 「全ての p で C3_p に retained 点がない」⇒ 何が閉じるのかを、S34-WF01 の形式で量化子まで書く（R29-CAMP2 全体か、その一部のセクターか）。
- 出力：`REPLACEMENT_TARGET_EXACT=<命題>`、`QUANTIFIER_MATCH=true/false/partial`。
- 理由：ここが曖昧なままだと、以降の一様定理が receiver の閉包に効くかどうかが決まらない。

### 36-R2 — TYPE_UNIFORM_SELMER_SET（新しい無条件定理の候補）

- 1N〜1Q を定理として整える：全ての p について、C3_p の 2-被覆降下の Selmer 集合が、悪い素数の型データ（どの因子 H, P, Q, P±Q を割るか、mod 4/8、付値の偶奇、符号）の関数であること。
- 目標の形：`Sel(C3_p) ⊆ {自明類} ∪ T(type(p))`、`T` は明示。
- 外部査読 → RESULTS（R-24 以降）。

### 36-R3 — TRIVIAL_CLASS_REDUCTION（厳密な還元）

- 1R を定理として整える：全ての p で、自明類の retained 点 ⇔ `X_λ(Q)` の非自明な点。
- これが通れば、受け皿の残りは「非自明類」（36-R4）と「X_λ の族」（36-R5）に分かれる。

### 36-R4 — NONTRIVIAL_CLASS_UNIFORM_ELIMINATION

- 非自明類 δ=d について、合同数補題（1K/1L：retained 点は合同数曲線 `E_d` の Q(i) 点を与え、d は合同数でなければならない）と局所像（36-R2）を組み合わせ、一様に消える型の条件を探す。
- 期待できる形：「型が X のとき、非自明類は局所的に消える」という有限の型表。消えない型は明示して残す。

### 36-R5 — X_λ FAMILY（残る壁）

- 固定 λ：二次 Chabauty ＋ Mordell–Weil 篩（1S, 1T：(1,1) 型 50本で決着、候補）。必要なこと：W（局所値の集合）の完全性の理論的証明、rank 合計 ≥ 3 の曲線への対策（a≤40 で 102本）。
- 一様：`E_{n0}`（n0=ab(a²−b²)、常に合同数で rank ≥ 1）のため、rank 0 型の議論は使えない。一様な定理は既知の方法の外にある可能性が高い。ここで止まる場合は、36-10 の `CLASS3_RETAINED_WITH_SHARPER_CAMPEDELLI_THEOREM` として「受け皿 ⇐ X_λ 族の命題」を記録する。

### 36-R6 — CT_ZERO_BRANCH（固定ファイバー、低優先）

- ビット0の曲線（177 + 1068 本）。Magma がないので 4-降下は使えない。代わりに **L(E,1) ≠ 0 ⇒ rank 0**（モジュラー性＋Gross–Zagier–Kolyvagin、無条件）が使える曲線を探す。dim Sel²=4 なので 2-parity から root number は +1 で、L(E,1)≠0 はあり得る。
- 数値の L 値は精度保証つきで記録する（計算証明書）。導手が大きい曲線は計算不能として残す。
- 因数形という薄い部分族の話なので、receiver への寄与は小さい。

### 36-R7 — REVIEW_BACKLOG（並行で消化）

未査読の候補を外部査読に回す：`a20_exclusion_summary_for_review.md`（a≤20 の126個）、1G〜1J のコード、1N〜1T、E_τ 捩れ点補題 v2（条件付き PASS、P1 依存）。
