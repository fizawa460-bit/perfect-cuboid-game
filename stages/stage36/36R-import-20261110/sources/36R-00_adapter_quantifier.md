## 1. 連鎖の正確な形（独立に再導出）

記号：辺 a1,a2,a3、x=a1², y=a2², z=a3²。チャート y=1 で t=x/y, s=z/y。7本の直線の値は
`t, 1, s, t+1, s+t, s+1, s+t+1`（辺3本、面対角線3本、体対角線）。

**端点**（29-02ha）：U(Q) = { 7つの値がすべて有理数の平方で、a1a2a3≠0 } ＝ 有理的な完全直方体。

**common-Jminus 受け皿 J**（36-09G/H）：
```text
J(Q) = { (t,s) ∈ Q² : t, t+1, s, s+t+1 は 0 でない有理数の平方、(s+1)(s+t) は有理数の平方 }
```
直方体の言葉では「辺3本・面対角線1本（a1a2 面）・体対角線が有理数で、残り2本の面対角線は **積** が有理数」。
端点から J へは、面対角線2本の平方条件を積の平方条件に弱めただけなので、**U(Q)≠∅ ⇒ J(Q)≠∅**（一方向）。

**媒介変数表示**（36-09H）：t=u², t+1=v², r=v+u；s=a², s+t+1=d², q=a/(d+v)。このとき
```text
(s+1)(s+t) = [ (r²−1) / (2r(1−q²)²) ]² · f_r(q),
f_p(t) = (t²+p²)(t²+p⁻²)(t²+c²)(t²+c⁻²),  c=(p+1)/(p−1)
```
よって J の点 ⇔ (p,t)=(r,q) で C3_p : y²=f_p(t) の有理点。

**命題 1（アダプタ、証明つき）.** 写像
`{ (p,t,y) : p∈Q∖{0,±1}, (t,y)∈C3_p(Q), t∉{0,±1} } → J(Q)` は全射で、
各ファイバーは符号の選び方（u,v,a,d の符号）だけの有限集合。したがって

```text
(T)  全ての p∈Q∖{0,±1} で C3_p(Q) の点は t∈{0,±1,∞} のみ   ⇔   J(Q)=∅
```

証明：J の点が与えられたとき、u≠0 なので r=v+u∈Q*、r≠±1。d の符号を d+v≠0 となるよう選ぶ（d,v≠0 なので可能）。
a≠0 より q≠0。q=±1 なら a²=(d+v)² で、d²−a²=v² と合わせて v(v+d)=0 となり矛盾。よって (r,q)∈(Q∖{0,±1})²、
上の恒等式から f_r(q) は平方。逆に (r,q)∈(Q∖{0,±1})² で f_r(q) が平方なら、u,v,a,d はすべて定義され 0 でなく
（r²+1, 1+q² >0）、t=u², t+1=v², s=a², s+t+1=d² は 0 でない平方、(s+1)(s+t) は平方。∎

恒等式はすべて `scripts/36R-00_verify_chain.py` で端点の式から直接確認した（出力 `outputs/36R-00_verify_chain.out`、ALL PASS）。
36-09I/J/O の正規形（p, c, h=p−1/p）とも一致する。C3_p の自明点：t=0（f=1）、t=±1（f=4(p²+1)⁴/(p(p²−1))²）、t=∞。
これらは円錐曲線の境界（a=0 や無限遠）に対応し、J の点ではない。

## 3. 量化子：(T) が示せたら何が閉じるか

**命題 2.** (T) ⇒ J(Q)=∅ ⇒ U(Q)=∅ ⇒ 全ての監査済み核 H（10個すべて）で q_H(U(Q))=∅。

- これは 36-09 の `sufficient_replacement_target` の第2形（「q_H(U(Q))=∅ を監査済みの H の1つで示す」）に、
  **セクターの限定なしで** 一致する。3つの代表すべてで同時に成り立つ。
- U(Q)=∅ は「有理的な完全直方体が存在しない」と同じ命題。つまり **(T) は端点そのものを閉じる強さ** を持つ。
  R29-CAMP2 だけを閉じる中間的な命題ではない。
- (T) から **出ないもの**：U_H(Q)=∅、C_H(Q)=∅（ROADMAP §0 の第1形）。商の有理点については何も言わない。
- (T) は必要条件ではない。完全直方体が存在しなくても J(Q)≠∅ はあり得る（J は端点より弱い条件）。

```text

  「q_H(U(Q))=∅ for one audited H」形 …… true（全 H、セクター限定なし）
  「U_H(Q)=∅ / C_H(Q)=∅」形 …………… false（(T) からは出ない）
  逆向き（目標 ⇒ (T)）……………………… false（(T) の方が強い可能性がある）
```

**帰結（優先順位に関わる）.**
1. (T) の全 p での証明は、完全直方体の非存在を含意する。したがって 36-R5 の「X_λ 族の一様な定理」は
   完全直方体問題と同等以上に難しい。36-10 の現実的な到達点が「より鋭い Class-3 定理」であるという
   ROADMAP §5 の見立ては、この監査と整合する。
2. 固定 p の除外（R-5, R-17, R-22, 本線 1G〜1T）は「J のうち r=p のファイバーに点がない」という意味を持つ。
   受け皿の閉包には全 p が必要で、有限個の p では何も閉じない（防火壁のとおり）。
3. フラグを立てる場合の記録先は R29-CAMP2 だけでなく ENDPOINT にも及ぶので、(T) を主張するときは
   端点の主張として扱う必要がある。
