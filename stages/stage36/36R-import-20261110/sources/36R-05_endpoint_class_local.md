## 1. 問題

36R-04 命題 4：U(Q)≠∅ ⇔ ある p で E_p（y1²=G1G2, y2²=G3G4、種数 5）に retained 点がある。
その点の C3_p の類は端点型 δ=(d1,d1,d3,d3)。36R-01 系 1・3 より d1=2^ε·h·α、d3=2^ε'·h·β
（h|H、α|a²−b²、β|ab、奇素因数はすべて ≡1 mod 4）。この有限集合を T_end(p) とする。

問い：全ての位で局所像を通る端点の類（端点 Selmer 集合 Sel_end(p)）は、自明類 (1,1) と境界類 (sqf H, sqf 2H) だけか。

## 2. 方法（`scripts/36R-05_endpoint_selmer.py`）

各 p=a/b（a>b≥1、互いに素。p→1/p, −p の対称性で一般性を失わない）、各候補 (d1,d3)∈T_end(p) について、
(d1,d1,d3,d3) の Q_v での類が局所像 Im_v(C3_p) に入るかを判定。

| 位 | 判定 |
|---|---|
| ∞ | 自動（G_j>0, d_j>0） |
| 2 | 厳密な像。円盤分割で、テイラー係数の付値に 3 の余裕（単数部分が mod 8 で一定）を要求。G_j の根は Q_2 にない |
| 悪い奇素数（2ab(a²−b²)(P²−Q²)H を割る） | 厳密な像（36R-01 と同じ円盤分割。ℓ≡3 mod 4 は根なし） |
| 良い奇素数 ℓ<1163 | 単数類の像を F_ℓ の剰余から厳密に計算（根の円盤では積条件で類が決まる） |
| 良い奇素数 ℓ≥1163 | 自動。降下曲線 {d_j z_j²=G_j(t)} は P¹ の (Z/2)⁴ 被覆（8点で分岐）で種数 17、ℓ で良い還元。ℓ+1−34√ℓ>0（ℓ≥1163）なので F_ℓ 点があり、Hensel で持ち上がる |

健全性：自明類と境界類は実際の有理点（t=0 と t=±1、E_p(Q) の点）を持つので、必ず生き残るはず。全ての p で生き残った。

rank は PARI `ellrank` の上下界一致（L 関数による裏取りはしていない）。

**補題（F1, F2 による除外。固定 p で有効）.** F1 : Y²=X(X+p²)(X+p⁻²)、F2 : Y²=X(X+c²)(X+c⁻²)。
E_p の点 (t,y1,y2) は (t², t·y1)∈F1(Q)、(t², t·y2)∈F2(Q) を与える（36R-01 系 3）。
F1 の捩れは少なくとも Z/4×Z/2 で、その 8 点の X は {∞, 0, −p², −p⁻², 1, −1}（X=±1 は (0,0) の半分点：y²=±(1±p²)(1±p⁻²) が平方）。
よって rank F1=0 かつ捩れがちょうど Z/4×Z/2 なら、E_p の点は t∈{0,±1,∞} のみ。F2 も同じ。
a<40 の 473 個で rank F1=0 または rank F2=0 は 314 個（66%）（`outputs/36R-05_F12_ranks_A40.out`）。

**観察（同種類）.** a≤30 の無作為な 30 個の p で、F1・F2 は E_ρ, E_σ, E_τ, E_{n0} のどれともフロベニウスの跡（ℓ<400）が一致しない（`outputs/36R-05_F12_identify.out`）。
Jac(E_p) ~ F1 × F2 × E_ρ × E_σ × E_τ（次元 5 で整合。E_p→C3_p の Prym が F1×F2）と考えられるが、同種の分解はここでは証明していない。

## 4. 結論（36-R4e）

1. **一様な主張は偽.** 「全ての p で Sel_end(p) = {自明類, 境界類}」は p=53/8 で反例がある（全ての位で厳密な局所像を通る第3の類 (5185,34)）。
   型表による一様な局所消去だけで端点の類を 2 つに絞る定理は成り立たない。成り立つ一様な主張は 36R-01 の形の定理（T_end(p)）と系 4 の Legendre 条件まで。
2. **経験的には強い.** a<70 では 99.7%（1465/1469）で Sel_end = {自明類, 境界類}。例外の 4 個（と範囲外の対称な 2 個）は、固定 p の rank 0 で第3の類が消える。
3. **局所論法の原理的な限界（証明つき）.** 全ての p で自明類と境界類は Sel_end(p) に入り、しかも E_p(Q) の実際の点（t=0,∞ と t=±1）を含む。
   したがって、この被覆の段のどんな降下（局所条件）でも、この 2 類は消せない。消すには、同じ類の中で retained 点と既知点を区別する大域の議論（固定 p の rank 0、Chabauty、QC、MW 篩）が要る。
4. **R1〜R5 の一様な道具はこれで尽きた.** 階数に依らず ∀p に効く段は R2（形）・R4e（局所）で、どちらも上の 2 類を残す。残る ∀p の命題は (T')「全ての p で E_p(Q)⊂{t=0,±1,∞}」そのもので、36R-04 命題 4 により U(Q)=∅ と同値。

## 5. 36-09・36-10 に従った判断

- **代替定理の研究を続けるか.** R29-CAMP2 の決定的な帰結 q_H(U(Q))=∅ を含意する命題は、どれも U(Q)=∅ 以上に強い（36R-04 §3(a)）。
  R1〜R5 の枠内には、これより弱くて受け皿を閉じる候補はもう残っていない。36-09 の候補台帳では B5（Brauer）は 36-09A で BLOCKED_UPSTREAM_BR2A_BR2B_INCOMPLETE、
  B2・B3・B7 は UNTESTED のまま（`stages/stage36/36-09/replacement-breadth-gate.json`、`36-09A/camp4-brauer-compatibility-preflight.json`）。
- **保留の候補（確定ではない）.** `CLASS3_RETAINED_WITH_SHARPER_CAMPEDELLI_THEOREM`。保留時に記録する「より鋭い定理」は次の証明済みの部分からなる：
  1. q_H(U(Q))=∅（全ての監査済み H）⇔ U(Q)=∅ ⇔ (T')（36R-00 命題 1、36R-04 命題 3・4）。
  2. Im_U = Im_J ∩ Im_H、J 上で H-トルソル条件は δ1δ2=平方 の 1 本に尽きる（36R-04 命題 3）。
  3. retained 点の類は T_end(p) の中の、局所像を通るもの（36R-01 系 1・3・4、本ログ §2）。この集合は常に自明類と境界類を含み、両者は実際の点を持つ（§4.3）。
  4. 未解決の命題（Class-3 障害）：(T')。固定 p では F1/F2 の rank 0（66%）、組曲線、X_λ/Y_λ の QC などで除外できるが、∀p には届かない。
- **手続き.** 36-09 の規則では、保留の前に Cycle Exploration Safety Protocol（EXHAUSTIVE_VIEW_AUDIT ＋ BLIND_REDISCOVERY）による保留監査が要る（`parking_audit_complete=false`）。
  したがって **次の課題は保留監査**：36-09 の候補台帳 B1〜B10 を 36R-00〜05 の結果で再分類し（B4・B6・B10 は 36R-04 で更新済み）、
  UNTESTED の B2・B3・B7 と BLOCKED の B5 について「新しい材料で再開できるか」を判定する。そこで LIVE が残らなければ、上の形で Class-3 として保留する。
  保留は研究管理上の決定であって、receiver の閉鎖ではない。

## 6. 維持したもの・限界

- 既存の成果は全て維持。LOG 1G の観察「多くの p で Selmer 集合は自明類と境界類の 2 つ」（全ての類について、a≤100 で 85%）は、端点の類に限ると 99.7% に上がる（a<70）。矛盾なし。
- rank 0 は PARI `ellrank` のみ（L 関数の裏取りなし）。2 進の像は円盤分割の実装に依存し、外部査読前。
- Hasse–Weil の閾値は種数 17 による。降下曲線が幾何的に既約（4 つの G_j が Q̄(t) で平方類として独立）であることを使った。
- 第3の類が現れる p の特徴づけ（どの型のとき現れるか）はしていない。

## 7. 報告

1. **示したこと**：端点 Selmer 集合を a<70 の全 1469 個で厳密に計算。99.7% で自明類＋境界類だけ。反例 53/8 により一様な局所消去の定理は偽。
   自明類と境界類は全ての p で実際の点を持つので、局所論法では原理的に消せない（§4.3）。F1/F2 による新しい固定 p の除外条件（66%）。
2. **解消した障害**：「36-R4 の一様な型表で非自明な端点の類が消えるか」という問いに、否定的な答え（反例つき）と、例外の固定 p での処理を与えた。
3. **残った阻害条件**：(T')（U(Q)=∅ と同値）。R1〜R5 の一様な道具は尽きた。
4. **次の段**：36-09 の保留監査（36R-06）。結果によって、代替定理の候補を再開するか、Class-3 として保留する。
