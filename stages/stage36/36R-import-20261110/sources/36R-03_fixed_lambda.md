## 1. W（局所値の集合）の完全性 —— 抽出をやめて厳密に決定

**背景.** 1S・1T の2次 Chabauty は、v≠q の局所項 κ1(f1P)−κ2(f2P)+ord_v B(P) が取りうる値の集合 W_v を
Q_v 点の抽出で作っていた（完全性は未証明）。

**方法**（`scripts/xqc/wcert.py`）.
1. κ は Silverman の局所高さアルゴリズム（定理 5.2、極小モデル、Δ/12 の項を除く）で x 座標だけの関数として書ける。
   特異点への還元は「x が整で x≡x0 (mod v)」と同値、ψ2², ψ3 は x の多項式。よって局所項は B だけの関数。
2. P¹(Q_v)={B∈Z_v}∪{1/B∈vZ_v} を v 進円盤に再帰分割し、円盤上で各多項式の付値が一定であることを
   テイラー係数（ord c_0 < min_{j≥1} ord c_j）で判定する。B→0, ∞ では ord B の項が相殺することを式で処理する。
3. 各ピースに Q_v 点があるか（g(B²) が平方か、g の Q_v 根を含むか）も厳密に判定する。得られるのは W_v そのもの。
4. 調べる素数は有限：v が奇数で、生のモデルが v 整・判別式が v 単数・c0 が v 単数なら局所項は恒等的に 0。

**結果.** 1T の (1,1) 型 50 本すべて、(λ,v) 460 組で、厳密な W_v = 抽出による W_v。|W| も 50 本すべて一致。
元コードの bad に入っていない素数では W_v={0}。**1T の結論は W を差し替えずにそのまま有効**。
一覧 `outputs/xqc/w_certificate.txt`、生データ `outputs/xqc/wcert_out/`。

**引き継ぎコードの照合.** `x_pipeline_code.txt` を切り出して CHECK を実行し、期待値と一致
（`bad [2,3,5,7,17,31] q 13`、`TOTAL hits 25 W 4`、`SUMMARY cands 20 surviving 0`）。

**1T の記述の訂正（結論には影響しない）.** 篩の「素数 ≤3000」「≤20000」は、コード上は PARI の `primes(n)`、
つまり「最初の n 個の素数」（3000 個なら 27,449 まで）。

## 2. Y_λ 上の2次 Chabauty ＋ Mordell–Weil 篩（36R-02 の新しい商）

**一般化.** パイプラインを y²=g(B²)（g は 3 次、最高次係数 ±1）に一般化した（`XKIND=X|Y`）。
f1: x=c3·B²（E_a）、f2: x=c0/B²（E_b）。X_λ での回帰テスト（4/3）は元と同じ出力。W は最初から §1 の厳密版を使う。
Y_λ には有理点 (±λ,±λ(λ²+4)) と ∞± があるので、既知点の扱いを足した：
- アフィンの既知点は一般の剰余円盤の根として現れる。篩を生き残ること（健全性）と、その円盤・その W の組で
  Strassmann の個数 N と見つかった相異なる根の個数が一致すること（根が単純）を確認する。
- ∞ は B=∞ の円盤の v=0 の根。

**対象.** 36R-02 §3 の 10 類（X_λ は使えず、Y_λ が (rank E_σ, rank E_{n0})=(1,1)）。

q² 以上近い偽の根が出る確率が高い。対策の候補：(a) 既知点の円盤だけ精度を上げて根の分離を直接証明する、
(b) 2つの q の情報を同時に使う篩。どちらも未実装。

## 3. 前提と、言っていないこと

- rank は ellrank の上下界一致（[1,1]）。飽和は 1000 まで。篩は q と 17 以下の素数の位数しか使わないので十分。
- Silverman の定理 5.2 と PARI（ellminimalmodel, polrootsmod, polrootspadic, ellpadicheight）の正しさ。
- 2次 Chabauty の恒等式の局所項が上の κ であること：1S の 13 桁の数値照合と、抽出版 κ と Silverman 版 κ の 460 組の一致。
  Y_λ では、既知点が W の値に入り篩を生き残ることが整合性の確認になっている。
- q 進の精度は 14 桁。根の単純性は Strassmann の個数と根の個数の一致で判定。区間演算による厳密な誤差評価はしていない。
- これは自明類だけの決着。非自明類は別（降下、36-R4）。全 p の主張ではない。
