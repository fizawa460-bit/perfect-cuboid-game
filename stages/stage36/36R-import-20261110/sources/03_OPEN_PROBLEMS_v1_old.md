## A. CT=0 分岐（ビット0の曲線、177 + 1068 本）

- **分かっていること**：dim Sel²=4、CT 対が零。rank 2 か Sha[4] が大きいかは未決。2-isogeny 降下では区別できない（L1-17）。
- **足りないもの**：4-降下（Magma の FourDescent 相当）。Magma は使えない。
- **新しい手**：`L(E,1) ≠ 0 ⇒ rank 0`（モジュラー性＋Kolyvagin、無条件）。2-parity から root number は +1 なので、L(E,1)≠0 の曲線はあり得る。PARI の `lfun` / `ellanalyticrank` で精度つきで判定できる曲線から片付ける（36-R6）。
- **注意**：薄い部分族（因数形）の固定ファイバーの話で、receiver への寄与は小さい。L 値の数値は誤差評価を記録する。

## B. 一般の有理パラメータへの拡張

- **分かっていること**：
  - 任意の u（進行上）で dim Sel² は三部グラフの nullity（R-11）。
  - 全ての p で root number の閉じた式（R-19, R-21, R-22）。
  - 本線の降下（1G〜1J、候補）は a≤100 で 90.7% を除外。
- **足りないもの**：p ごとではなく全ての p に通用する命題。
- **新しい手**：降下の局所像が **素因数の型** で決まる（1P・1Q）。これは支持の大きさに依らない。→ 36-R2。
- **注意**：「特殊な部分族で成功」を「全パラメータ」に広げない。B の目標は「全 p で Selmer 集合が型データで決まる」という定理であって、「全 p の除外」ではない。

## C. H-torsor の一様な閉包（moving ramification support）

- **ブロック理由（W-2）**：点ごとに素因子の台が動き、有限 S が取れない。`H¹(Q,H)` は有限でない。
- **新しいもの**：有限 S の代わりに「有限個の **型**」で Selmer 集合を記述する（1Q）。素数そのものは動くが、局所像は型だけで決まる。
- **再検討の価値**：36-05 の「有限 S」という入口条件は満たさないが、36-06 の目的（有限で網羅的なツイスト族）を「型で添字づけられた有限族」に置き換えられるかを試す価値がある。ただし、これは C3_p の降下（楕円商の連鎖）の上での話で、Campedelli 商の H-torsor そのものに直接移るかは別問題（36-R1 の監査で確認）。
- **阻害条件の候補**：自明類（d = n0）は全ての型で生き残る（1L）。型だけでは自明類を消せない → 36-R3, 36-R5 に回す。

## D. 物理的な有理点条件との接続（rank が正のとき）

- **分かっていること**：
  - rank が正でも、retained 点（t ∉ {0,±1,∞}）が無いことは示せる場合がある：MW 篩（0Y〜0Z）、e-降下（R-22）、Q(i) 降下（1I, 1J）、二次 Chabauty（1S, 1T）。
  - 合同数補題（1K, 1L）：retained 点は合同数曲線の Q(i) 点を与える。
- **足りないもの**：これらを全ての p で同時に使える形。
- **新しい手**：自明類 → X_λ（1R）。X_λ は双楕円の種数2曲線で、Jac ~ E_ρ × E_{n0}。rank が (1,1) なら二次 Chabauty が使える（1S, 1T）。
- **阻害条件**：rank 合計 ≥ 3（a≤40 で102本）。W（局所値の集合）の完全性が理論的に未証明。全 λ で一様な方法は知られていない。
