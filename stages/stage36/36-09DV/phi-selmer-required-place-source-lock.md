# Stage36 36-09DV Phi-Selmer required-place source lock

## Exact-green input

36-09DU exact-green fixes the explicit `Phi` connecting coordinates on `J=Jac(C3_2)` with constant kernel `K=ker(Phi)=(Z/2Z)^3` and rational functions `F1,F2,F3`.

## Selmer unramified-outside-S principle

For an isogeny over a number field, a standard finite Selmer computation takes `S` to contain the archimedean places, primes dividing the isogeny degree, and primes where the relevant abelian varieties/isogeny data have bad reduction. Outside `S`, the local Kummer image is unramified, so global Selmer classes lie in the subgroup of `H^1(Q,K)` unramified outside `S`. This is the standard isogeny-descent/functions-on-the-curve framework used in E. F. Schaefer, *Computing a Selmer group of a Jacobian using functions on the curve*, Math. Ann. 310 (1998), 447--471, and related explicit descent literature.

36-09DV uses only this containment; it does not replace the local-image tests at places in `S`.

## Exact arithmetic support

For the fixed hyperelliptic and quotient RHS polynomials, direct discriminant calculation gives

- `disc(C3_2 RHS)=5^24*7^8/3^20`,
- `disc(E_tau quartic RHS)=5^12*7^4/(2^4*3^10)`,
- `disc(E_sigma quartic RHS)=5^8*7^4/3^8`,
- `disc(E_rho quartic RHS)=5^12*7^4/(2^4*3^10)`.

All displayed coefficients lie in `Z[1/6]`. Therefore, for every finite prime `p` outside `{2,3,5,7}`, the displayed models are p-integral and their RHS discriminants are p-units. The degree-eight isogeny has 2-primary kernel, so its degree is also a p-unit there. This certifies the conservative required-place set

`S={infinity,2,3,5,7}`.

No claim is made that every place in this set is individually necessary in a minimal implementation; only that no place outside it is needed for the unramified-outside-S Selmer search.

## Global squareclass ambient group

For `Q`, a squareclass unramified outside the finite primes `{2,3,5,7}` is generated by `[-1],[2],[3],[5],[7]`. Hence

`Q(S,2)=<-1,2,3,5,7> subset Q*/Q*^2`

has F2-dimension 5, and with the fixed rational basis of `K`,

`H^1_S(Q,K) ~= Q(S,2)^3`

has F2-dimension 15 and cardinality `2^15=32768`.

## Credit boundary

This source lock certifies only the finite required-place set and the finite global unramified ambient search space. It does not compute the local Kummer images at `infinity,2,3,5,7`, the global `Phi`-Selmer group, pro-Selmer cokernel size, `T_2 Sel(J)`, retained-open intersection, Brauer-Manin obstruction, fixed-p exclusion, receiver closure, or endpoint closure.
