## 1. Freeze the near-maximal quotient

On the near-maximal branch of 4em,

```text
RS/C = B^o(1),
Delta = X1*Y2-X2*Y1 = q C,
0<|q|=B^o(1).
```

There are only `B^o(1)` possible integer `q` values, so freeze one `q` without fixed-power loss.

## 2. Exact affine-line parameterization

Fix the first primitive vector

```text
v1=(X1,Y1),
gcd(X1,Y1)=1.
```

Choose Bezout integers `(A,B)` with

```text
X1*B-A*Y1=1.
```

Then every integer solution of

```text
X1*Y2-X2*Y1=qC
```

is exactly

```text
X2=qC*A+t*X1,
Y2=qC*B+t*Y1,
t in Z.
```

Indeed one displayed pair is a particular solution and the kernel of the determinant map is the integer line generated by the primitive vector `(X1,Y1)`.

```text
FIXED_FIRST_VECTOR_DETERMINANT_SOLUTIONS_FORM_ONE_AFFINE_INTEGER_LINE=true
```

## 3. A frozen dyadic physical box contains only O(1) line points

The two candidates lie in the same frozen archimedean cell

```text
|X_j|~R,
|Y_j|~S.
```

Two admissible parameters `t,t'` differ by

```text
(X2(t)-X2(t'),Y2(t)-Y2(t'))
=(t-t')*(X1,Y1).
```

Since `|X1|~R` and `|Y1|~S`, while the frozen coordinate windows have lengths `O(R)` and `O(S)`, only `O(1)` integer values of `t` can keep the second vector in the same cell. The finite chart/unit/reciprocal decorations contribute only `B^o(1)` extra multiplicity.

Therefore, for fixed first candidate and fixed near-maximal `q`,

```text
# admissible second candidates = B^o(1).
```

Summing over the `B^o(1)` quotient dictionary gives total genuine off-diagonal collision mass

```text
OffDiag_near <= M_C B^o(1).
```

But 4el shows a saturating concentrated exact modulus requires

```text
OffDiag_C >= M_C^2 B^(-o(1))
```

with polynomial `M_C`. These are incompatible.

## 4. Surviving concentrated branch

Any saturating concentrated exact-modulus branch must therefore lie in a polynomially separated determinant regime:

```text

```

for some fixed `eta>0`, where the quotient `q` has a genuinely polynomial range and cannot be frozen by elementary pigeonhole.
