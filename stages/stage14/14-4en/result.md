## 1. Freeze the near-maximal mover quotient

On the near-maximal genuine-mover branch of 4em,

```text
RS/C=B^o(1),
Delta=X1*Y2-X2*Y1=qC,
0<|q|=B^o(1).
```

There are only `B^o(1)` possible integer `q` values, so freeze one `q` without fixed-power loss.

## 2. Exact affine-line parameterization

Fix the first primitive vector

```text
v1=(X1,Y1),
gcd(X1,Y1)=1.
```

Choose Bezout integers `(A,B)` with

```text
X1*B-A*Y1=1.
```

Then every integer solution of

```text
X1*Y2-X2*Y1=qC
```

is exactly

```text
X2=qC*A+t*X1,
Y2=qC*B+t*Y1,
t in Z.
```

The kernel of the determinant map is the integer line generated by `(X1,Y1)`.

```text
FIXED_FIRST_VECTOR_DETERMINANT_SOLUTIONS_FORM_ONE_AFFINE_INTEGER_LINE=true
```

## 3. Same-scale physical box has only B^o(1) mover degree

The two candidates lie in the frozen cell

```text
|X_j|~R,
|Y_j|~S.
```

Two parameters differ by

```text
(X2(t)-X2(t'),Y2(t)-Y2(t'))=(t-t')*(X1,Y1).
```

Since `|X1|~R` and `|Y1|~S`, a same-scale coordinate box contains only `O(1)` admissible `t`. Finite chart/unit/reciprocal decorations add only `B^o(1)`.

Thus for fixed first candidate and fixed near-maximal `q`,

```text
# admissible genuine-mover second candidates=B^o(1).
```

After summing the `B^o(1)` quotient dictionary,

```text
K_mov,near(C) <= M_C B^o(1).
```

But on the genuine-mover saturation alternative merged s7-77 requires

```text
K_mov(C)=M_C^2 B^(-o(1))
```

with polynomial `M_C`. Hence the near-maximal mover branch cannot carry the required energy.
