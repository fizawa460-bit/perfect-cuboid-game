## 2. X37 abstract lemma — fibered bounded-multiplicity multiplication has no fixed-power compression

Let `T_B` be a finite set of triples `(e,d,v)` with all integer coordinates of polynomial Stage14 height. Define

```text
Phi(e,d,v)=(e,d*v).
```

For every output `(e,m)`, the number of preimages satisfies

```text
#Phi^{-1}(e,m) <= tau(|m|)=B^o(1).
```

Hence

```text
#Phi(T_B) <= #T_B
```

and also

```text
#Phi(T_B) >= #T_B / B^o(1).
```

Therefore

```text
#Phi(T_B)=#T_B*B^(-o(1))
```

at exponent scale. In particular, if

```text
#T_B=B^(kappa_pair+o(1)),
```

then the fibered distinct-product image has the same exponent `kappa_pair`.

This is uniform in the outer label `e`; keeping `e` in the image prevents cross-`e` collisions from being charged.
