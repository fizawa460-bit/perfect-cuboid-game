# Stage14-s1 — exact 2-descent / Selmer interface

## Purpose

Stage14-s1 attacks the arithmetic bottleneck left by the main rank-jump/Kummer track. For a primitive oriented Pythagorean face

\[
F=(S,X,H),\qquad S^2+X^2=H^2,
\]

the rational Stage14 fiber

\[
E_t:y^2=x(x-1)(x+t^2),\qquad t=X/S,
\]

is replaced by the integral model

\[
\boxed{E_F:Y^2=Z(Z-S^2)(Z+X^2)}.
\]

This keeps the exact full rational 2-torsion visible and avoids coefficient denominators.

## Exact full-2-torsion interface

The three nonzero 2-division x-coordinates are

```text
0, S^2, -X^2.
```

The full-2-torsion Kummer map is recorded as

\[
[P]\mapsto
(Z,\ Z-S^2,\ Z+X^2)
\in(\mathbf Q^*/\mathbf Q^{*2})^3,
\]

with product constrained to be a square class. Writing the three square classes as `d1,d2,d3`, the associated split covering interface is

\[
\boxed{d_1u_1^2-d_2u_2^2=S^2},
\qquad
\boxed{d_3u_3^2-d_1u_1^2=X^2},
\]

with `d1*d2*d3` square in `Q*/Q*^2`.

The integral discriminant is

\[
\boxed{\Delta=16S^4X^4H^4}.
\]

Thus only the real place and primes dividing `2SXH` can enter the nontrivial local 2-cover analysis. This is the exact local-support interface for Stage14-s2.

## Deterministic finite Selmer/rank-bound audit

The implementation deliberately does not invent a repository-local p-adic solver. Instead it calls the mature PARI/GP `ellrank(E,0)` implementation of 2-descent plus the 2-part of the Cassels pairing.

PARI documents the unconditional output

```text
[r1,r2,s,L]
```

with

\[
r_1\le \operatorname{rank}E(\mathbf Q)\le r_2.
\]

Writing `C=dim Sel_2(E)`, `T=dim E[2](Q)=2`, PARI's documented relation is

\[
r_2=C-T-s,
\]

so Stage14-s1 records

\[
\boxed{C=r_2+2+s}.
\]

No equality between Selmer rank and Mordell--Weil rank is assumed. `ellrootno(E)` is recorded but never used to tighten the unconditional rank interval.

The deterministic audit uses the exact merged Stage14 graph enumerator through `B=2,000,000`, reproduces the locked `490` active oriented first-face states, and selects:

```text
96 active fibers
96 inactive control fibers
```

The inactive controls are primitive Pythagorean faces selected in the same face-hypotenuse strata. Here *inactive* means only that no physical Stage14 partner with `d<=2,000,000` was found; it does not mean Mordell--Weil rank zero.

The generated JSON report contains, for every sampled fiber:

```text
face (S,X,H)
first physical height mu(F), when active
integral curve coefficients
unconditional PARI rank lower/upper bounds
2-Selmer rank reconstructed from r2,T,s
Cassels-pairing s quantity
root number
whether the rank interval closes exactly
```

The CI artifact is generated by `stages/stage14/scripts/14-s1/selmer_interface_audit.py` using PARI effort `0`, avoiding randomized point search.

## What s1 does and does not prove

Stage14-s1 locks the exact arithmetic interface needed for a real local-density calculation. It does **not** prove a positive-rank density, an average Selmer theorem for the Pythagorean-base family, or a square-root law for active vertices.

In particular:

```text
SELMER_RANK_USED_AS_MW_RANK_EQUALITY=false
ROOT_NUMBER_PARITY_USED_AS_RANK_EQUALITY=false
BSD_USED=false
PARITY_CONJECTURE_USED=false
AVERAGE_SELMER_THEOREM_IMPORTED=false
```

The finite comparison is diagnostic: it asks whether active and inactive physical fibers are already strongly separated at the 2-Selmer/rank-bound level. A theorem-level interpretation of local survival frequencies belongs to s2.
