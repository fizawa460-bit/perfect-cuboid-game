# Stage14-num-alpha11-diag10 — finite-count shell heterogeneity test

This stage tests whether the shell-to-shell second-face-survival volatility isolated in diag9 exceeds what is expected from the small exactly-two counts alone.

Two calibrations are used:

1. conditional permutation with fixed shell totals and pooled pair-direction totals;
2. source-adjusted parametric plug-in using the B=1m empirical survival profile and each shell's frozen raw-source composition.

The statistical boundary is deliberately conservative: failure to reject finite-count noise is not a proof of homogeneous arithmetic, and no asymptotic exactly-two direction law is inferred.

Final numerical values are frozen after the dedicated CI replay.
