## 1. Common nested-support form on all heavy complementary-dilation branches

Every live heavy branch now has a charged outer family `Omega`, a bare arithmetic shadow `B(x)`, and a physical acceptance predicate `A(x)` satisfying

```text
A(x) <= B(x),
```

where `B` retains all already-charged outer/local masks and the short unitary-divisor existence condition, and removes only the still-unopened canonical/reverse completion predicate.

The three concrete outer families are:

```text
F:  x=m,              E=E0 fixed;
P0: x=E,              polynomial E and fixed m=m0,u=u0;
P+: x=(E,m),          polynomial E and polynomial m.
```

For each branch `j in {F,P0,P+}` write

```text
S_bare,j = B^(sigma_j+o(1)),
S_phys,j = B^(tau_j+o(1)),
delta_j  = sigma_j-tau_j >= 0.
```

A heavy survivor on branch `j` requires exactly

```text
sigma_j-delta_j=tau_j >= mu.              (1)
```

This is the minimal exponent ledger.  The inner unitary multiplicity has already been exhausted and does not appear in (1).

```text
ALL_HEAVY_BRANCHES_NESTED_BARE_PHYSICAL_SUPPORT_FORM=true
HEAVY_INNER_UNITARY_MULTIPLICITY_EXHAUSTED=true
HEAVY_SURVIVAL_BUDGET=sigma_j_minus_delta_j_ge_mu
```

## 2. Two genuinely different possible saving mechanisms

Equation (1) separates two noninterchangeable mechanisms.

### Mechanism U — bare short-unitary shadow sparsity

Prove on every relevant branch that

```text
sigma_j <= mu-delta_U
```

for some fixed `delta_U>0`, or an equivalent absolute support estimate strong enough to contradict (1).

This mechanism ignores canonical/reverse completion only in the legal upper-bound direction.  It is the only part to which q14/Ford-type divisor-in-an-interval technology can even be compared directly.

### Mechanism C — conditional canonical/reverse completion deficit

For a branch whose bare shadow has exponent `sigma_j`, prove

```text
delta_j > sigma_j-mu
```

uniformly, or equivalently

```text
S_phys,j <= S_bare,j * B^(-delta_j+o(1))
```

with enough fixed-power loss to push the physical support below `B^mu`.

This is a Stage14-specific physical-completion problem.  It cannot be replaced by generic divisor density, because the completion predicate is precisely what was removed in passing from `A` to `B`.

```text
BARE_AND_COMPLETION_SAVINGS_INDEPENDENT_ASSUMED=false
```
