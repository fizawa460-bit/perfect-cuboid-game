# Literature radar — 14-t

Current frontier: Stage14-t is waiting for concrete `M`-degree-4 bisections from `14-4`. Generic restriction of the third-square double cover to such a rational bisection has branch degree 8 and genus 3; only special branch contact can lower this to genus 0/1.

## DIRECT / NEAR

### Ezome--Miayoka Moussolo--Freguin Babindamana — genus-3 rank-zero quotient strategy
- Link: https://arxiv.org/abs/2302.03986
- Theorem: algorithm for genus-3 curves over `Q` admitting a degree-2 map to a genus-1 curve of rank 0
- Gives: complete rational-point determination via a rank-zero elliptic quotient.
- Stage14 hook: first post-`14-4ai` test for any explicit genus-3 triple lift: detect a second involution from branch symmetry, construct the elliptic quotient, and test rank 0.
- Fit: NEAR (actionable once explicit bisections arrive)
- Missing: biellipticity is not automatic.
- Checked: 2026-08-09

### de Frutos-Fernandez--Hashimoto — rank-zero genus-3 hyperelliptic curves
- Link: https://arxiv.org/abs/1909.04808
- Gives: an exact Chabauty--Coleman route when a candidate lift is hyperelliptic with rank-zero Jacobian.
- Stage14 hook: second branch of the post-bisection decision tree.
- Fit: NEAR
- Missing: candidate must first be shown hyperelliptic and rank zero.
- Checked: 2026-08-09

### Katz--Rabinoff--Zureick-Brown — Uniform bounds for rational points on curves of small Mordell--Weil rank
- Link: https://arxiv.org/abs/1504.00694
- Theorem: uniform bounds when Jacobian rank `r <= g-3`
- Gives: for genus 3, rank zero yields a uniform per-curve rational-point bound.
- Stage14 hook: fallback when no useful elliptic quotient exists but the full Jacobian rank can be proved zero.
- Fit: NEAR
- Missing: no rank-zero theorem across the Stage14 lifts yet.
- Checked: 2026-08-09

### Dimitrov--Gao--Habegger — Uniform bound for rational points on a pencil of curves
- Link: https://arxiv.org/abs/1904.07268
- Gives: a family-level bridge from Jacobian-rank control to rational-point control.
- Stage14 hook: relevant only if the eventual explicit bisections organize into a manageable pencil/family.
- Fit: NEAR
- Missing: family and rank control not yet available.
- Checked: 2026-08-09
