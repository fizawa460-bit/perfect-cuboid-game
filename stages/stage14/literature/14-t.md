# Literature radar — 14-t

Current frontier: Stage14-t is waiting for concrete `M`-degree-4 bisections from `14-4`. Generic restriction of the third-square double cover to such a rational bisection has branch degree 8 and genus 3; only special branch contact can lower this to genus 0/1.

## DIRECT / NEAR

### Ezome--Miayoka Moussolo--Freguin Babindamana — Genus 3 curves from the rank-0 quotient strategy
- Link: https://arxiv.org/abs/2302.03986
- Theorem: algorithm for any genus-3 curve over `Q` admitting a degree-2 map to a genus-1 curve whose Jacobian has rank 0
- Gives: complete determination of rational points via a rank-zero elliptic quotient; tested on large databases of genus-3 curves.
- Stage14 hook: this is now the clearest *post-4ai decision tree*: for each explicit genus-3 triple lift, search first for an involution/degree-2 elliptic quotient; if its elliptic Jacobian has rank zero, the rational lifts become algorithmically controllable.
- Fit: NEAR (actionable once explicit bisections arrive)
- Missing: a generic Stage14 restricted double cover of a rational bisection need not be bielliptic. The involution/quotient must be exhibited from the branch divisor of each candidate bisection.
- Checked: 2026-08-09

### de Frutos-Fernandez--Hashimoto — Computing rational points on rank 0 genus 3 hyperelliptic curves
- Link: https://arxiv.org/abs/1909.04808
- Theorem: Chabauty--Coleman computation for genus-3 hyperelliptic curves with Jacobian Mordell--Weil rank 0
- Gives: an independent exact-computation route when a Stage14 genus-3 restriction is hyperelliptic and its full Jacobian rank is zero.
- Stage14 hook: complements the elliptic-quotient route; after `14-4ai`, candidate lifts can be classified as bielliptic/hyperelliptic/general before choosing the rational-point method.
- Fit: NEAR
- Missing: no theorem that Stage14 lifts are hyperelliptic or rank zero; this is a per-candidate tool after the geometry is explicit.
- Checked: 2026-08-09

### Katz--Rabinoff--Zureick-Brown — Uniform bounds for rational points on curves of small Mordell--Weil rank
- Link: https://arxiv.org/abs/1504.00694
- Theorem: explicit uniform bounds for `#X(F)` when Jacobian rank satisfies `r <= g-3`
- Gives: unconditional uniform rational-point bounds in the small-rank range.
- Stage14 hook: for genus 3, rank zero activates the theorem and yields a uniform per-curve bound.
- Fit: NEAR
- Missing: Stage14 lacks rank-zero control across relevant lifts, and per-curve bounds must still be summed over candidate bisections.
- Checked: 2026-08-09

### Dimitrov--Gao--Habegger — Uniform bound for rational points on a pencil of curves
- Link: https://arxiv.org/abs/1904.07268
- Theorem: family-level rational-point bound depending on fiber-Jacobian rank
- Gives: a family-level bridge from rank control to rational-point control.
- Stage14 hook: useful if explicit `14-4ai` bisections themselves form a manageable one-parameter pencil of genus-3 lifts.
- Fit: NEAR
- Missing: rank control and the precise family structure are not yet available.
- Checked: 2026-08-09
