## 2. Primary projection forces zero-coordinate divisibility

Fix one cell component, for example `R`.  Put

```text
D_R=d_H/d_R.
```

Since `gcd(D_R,d_R)=1`, the `R`-primary projection of the character `c/d_H` is obtained by multiplying the numerator by a unit modulo `d_R`.  On the other hand the `R`-primary dual subgroup is generated by the reduction of

```text
rho_R=(0,1,0,-lambda_R).
```

Therefore the two zero coordinates of `rho_R` force

```text
d_R | c1,
d_R | c3.                                         (2.1)
```

The same argument for the other three generators gives the exact support-divisibility table

```text
R component: d_R | c1,c3,
J component: d_J | c2,c4,
S component: d_S | c1,c4,
T component: d_T | c2,c3.                          (2.2)
```

Equivalently,

```text
d_R*d_S | c1,
d_J*d_T | c2,
d_R*d_T | c3,
d_J*d_S | c4.                                      (2.3)
```

No size estimate has been used here.  This follows only from the exact direct-product CRT dual and the sparse support of its four row generators.

This is the missing cellwise support constraint in s7-22.

## 4. Any two nonzero normal coordinates are already impossible

For each coordinate define the forced divisor from (2.3):

```text
D1=d_R*d_S,
D2=d_J*d_T,
D3=d_R*d_T,
D4=d_J*d_S.                                        (4.1)
```

If `c_i!=0`, then

```text
|c_i|>=D_i.                                         (4.2)
```

Take any two distinct nonzero coordinates `c_i,c_j`.

### 4.1 Complementary pairs

For `(i,j)=(1,2)` or `(3,4)`,

```text
D_i*D_j=d_H.                                        (4.3)
```

Hence

```text
|c_i*c_j|
 >= d_H
 >= B^(21/16-o(1)).                                 (4.4)
```

But (3.4) gives

```text
|c_i*c_j|<=B^(6/16+o(1))=B^(3/8+o(1)),             (4.5)
```

which is impossible.

### 4.2 The four crossed pairs

For the remaining four pairs one has exactly one repeated component and one omitted component.  For example

```text
D1*D3
 =(d_R*d_S)(d_R*d_T)
 =d_H*(d_R/d_J).                                    (4.6)
```

Using the uniform component window (3.1)-(3.2),

```text
d_R/d_J >= B^(1/16-1/2-o(1))
           =B^(-7/16-o(1)).                         (4.7)
```

Thus

```text
D1*D3>=B^(21/16-7/16-o(1))
       =B^(14/16-o(1))
       =B^(7/8-o(1)).                               (4.8)
```

The same lower bound holds for

```text
D1*D4,
D2*D3,
D2*D4.                                              (4.9)
```

Consequently any crossed pair of nonzero normal coordinates satisfies

```text
|c_i*c_j|>=B^(7/8-o(1)),                            (4.10)
```

again contradicting the normal-height upper bound

```text
|c_i*c_j|<=B^(3/8+o(1)).                            (4.11)
```

Therefore

```text
boxed:
a rank-three endpoint normal can have at most one nonzero coordinate. (4.12)
```

The exponent margin is at least

```text
7/8-3/8=1/2.                                        (4.13)
```

Thus the contradiction is stable under all Stage14 `B^o(1)` dyadic widths.
