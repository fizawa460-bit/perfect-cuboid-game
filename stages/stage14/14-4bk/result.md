# Stage14-4bk — physical compact denominator selector and second-leg cofactor reduction

## Purpose

Merged Stage14-4bj reunified the temporary L/S split and identified a least-denominator statistic `D_min` for an abstract bounded-height global witness.  The remaining weakness was still a quantifier mismatch: `D_min` is chosen after passing to an enlarged globally-soluble packet family, while the physical count concerns actual two-face cuboid edges.

Stage14-4bk returns to the **exact physical point** of merged Stage14-s3 and replaces `D_min` as the primary main-track selector by an explicit torsion-normalized physical denominator.

The key outcome is exact:

> if `P` is the physical point attached to a raw two-face edge and `T_- = (-X^2,0)`, then `Q=P+T_-` is a compact nonzero mod-2 point retaining exact physical reconstruction, and the reduced denominator `D_phys` of its `Z` coordinate satisfies
>
> `D_phys | X2`,
>
> where `X2` is the nonshared leg of the primitive partner face.

Thus the post-local denominator is no longer an arbitrary polynomial-height variable.  It is a divisor of an actual physical Pythagorean leg.

The stage also proves an exact half-angle/root-sign law for the odd good part of `D_phys`, and uses the merged Stage14-4ag subpolynomial graph-degree theorem to close all physical edges whose partner leg is below `B^(41/84)` at square-root scale.  The residual small-denominator sector therefore carries a genuine large square cofactor `C_phys^2` with

`C_phys > B^(1/84)`.

No full `delta_post>0` is claimed yet.

## 1. Physical raw-edge normalization

Take one primitive raw cuboid candidate `(a,b,c,d)` contributing an edge between two integer face diagonals sharing the raw edge `a`.  Put

```text
g1 = gcd(a,b),
g2 = gcd(a,c),
```

and primitive oriented faces

```text
F  = (S ,X ,H ) = (a/g1, b/g1, sqrt(a^2+b^2)/g1),
F2 = (S2,X2,H2) = (a/g2, c/g2, sqrt(a^2+c^2)/g2).
```

Primitive cuboid normalization gives `gcd(a,b,c)=1`, hence `gcd(g1,g2)=1`.  Therefore

```text
g = gcd(S,S2) = a/(g1*g2).
```

Set

```text
r = g*d.
```

Directly from `d^2=a^2+b^2+c^2`,

\[
\boxed{r^2=H^2S_2^2+S^2X_2^2.}
\tag{BK.1}
\]

Using `H2^2=S2^2+X2^2` and `H^2=S^2+X^2`, the same identity is

\[
\boxed{r^2=H^2H_2^2-X^2X_2^2.}
\tag{BK.2}
\]

Equivalently,

\[
(r-HS_2)(r+HS_2)=S^2X_2^2,
\tag{BK.3}
\]

\[
(HH_2-r)(HH_2+r)=X^2X_2^2.
\tag{BK.4}
\]

These identities use only the exact raw-edge gluing already generated by the Stage14 graph audit.

## 2. Simplifying the exact Stage14-s3 physical coordinate

Merged Stage14-s3 defines

```text
q   = X2/(H2+S2),
z   = r/(H*H2),
Yq  = z*(1+q^2),
X0  = (Yq+1)/q^2,
A0  = 1-2*(X/H)^2,
x   = (A0+X0)/(2*(S/H)^2),
Z_P = S^2*x.
```

Because

\[
q^2=\frac{H_2-S_2}{H_2+S_2},
\qquad
1+q^2=\frac{2H_2}{H_2+S_2},
\]

one obtains

\[
X_0=
\frac{H(H_2+S_2)+2r}{H(H_2-S_2)}.
\]

Since

\[
A_0=\frac{S^2-X^2}{H^2},
\]

straight simplification gives

\[
\boxed{
Z_P=
\frac{S^2H_2+X^2S_2+Hr}{H_2-S_2}.
}
\tag{BK.5}
\]

Two shifted factors simplify even further:

\[
\boxed{
Z_P-S^2=
\frac{H(HS_2+r)}{H_2-S_2},
}
\tag{BK.6}
\]

\[
\boxed{
Z_P+X^2=
\frac{H(HH_2+r)}{H_2-S_2}.
}
\tag{BK.7}
\]

The s3 formula also gives `Z_P>S^2` for every positive physical edge.

## 3. Use the compact 2-torsion point `(-X^2,0)`

On

\[
E_F: W^2=Z(Z-S^2)(Z+X^2),
\]

let

```text
T_- = (-X^2,0).
```

The standard addition formula at this rational 2-torsion point gives

\[
\boxed{
Z(P+T_-)
=-X^2\frac{Z_P-S^2}{Z_P+X^2}.
}
\tag{BK.8}
\]

Because `Z_P>S^2`,

\[
-X^2<Z(P+T_-)<0.
\]

Thus

```text
Q = P+T_-
```

lies on the compact/nonidentity real component.  Since doubling maps `E(R)` into the identity component,

```text
Q notin 2E(R),
```

hence `Q notin 2E(Q)`.

Translation by rational torsion is an involution, preserves non-torsion and Neron--Tate height, and recovers the exact physical point by `P=Q+T_-`.  Therefore every physical edge supplies directly

```text
compact global witness
+ nonzero Kummer class
+ logarithmic canonical-height window
+ exact physical reconstruction.
```

No maximal repeated halving is required for this physical upper majorant.

## 4. Exact physical denominator formula

Insert (BK.6)--(BK.7) into (BK.8):

\[
Z_Q
=-X^2\frac{r+HS_2}{r+HH_2}.
\tag{BK.9}
\]

From (BK.2),

\[
(r-HH_2)(r+HH_2)=-X^2X_2^2.
\]

Therefore

\[
\boxed{
Z_Q=
\frac{(r+HS_2)(r-HH_2)}{X_2^2}.
}
\tag{BK.10}
\]

Put

```text
N_Q = (r+H*S2)*(H*H2-r) > 0,
```

so `Z_Q=-N_Q/X2^2`.

Write the reduced coordinate as

\[
Z_Q=\frac{A_Q}{D_{\rm phys}^2},
\qquad
\gcd(A_Q,D_{\rm phys})=1,
\qquad D_{\rm phys}>0.
\]

The square-denominator shape is the merged s6-01 monic-Weierstrass denominator theorem.  Since the unreduced denominator in (BK.10) is already `X2^2`,

\[
\boxed{D_{\rm phys}^2\mid X_2^2}
\]

and hence

\[
\boxed{D_{\rm phys}\mid X_2.}
\tag{BK.11}
\]

This is the central 4bk improvement over the abstract polynomial denominator box.

Define

\[
C_{\rm phys}=\frac{X_2}{D_{\rm phys}}\in\mathbf Z_{>0}.
\]

Reduction of (BK.10) gives the exact square cancellation identity

\[
\boxed{
C_{\rm phys}^2
=\gcd(X_2^2,N_Q).
}
\tag{BK.12}
\]

In particular,

\[
\boxed{C_{\rm phys}^2\mid (r+HS_2)(HH_2-r).}
\tag{BK.13}
\]

The former least-denominator statistic remains valid, but for the packet reached by the physical point one has

\[
D_{\min}\le D_{\rm phys}\le X_2\le H_2\le d\le B.
\]

The physically meaningful main-track selector is now `D_phys`, not an arbitrary least representative.

## 5. Odd half-angle/root-sign law

Let an odd prime satisfy

```text
ell^e || X2,
ell not dividing H.
```

Because `F2` is primitive,

```text
gcd(S2,X2)=gcd(H2,X2)=1.
```

Also

\[
X_2^2=(H_2-S_2)(H_2+S_2)
\]

and the two factors have no common odd prime.  Hence the full `ell^(2e)` lies in exactly one of the two half-angle factors.  Define

```text
epsilon_ell = +1  if ell^(2e) | H2-S2,
epsilon_ell = -1  if ell^(2e) | H2+S2.
```

From (BK.1), modulo `ell^(2e)`,

\[
r^2\equiv H^2S_2^2.
\]

Since `ell` is odd and does not divide `H*S2`, there is a unique sign

```text
delta_ell in {+1,-1}
```

such that

\[
r\equiv \delta_\ell H S_2\pmod{\ell^{2e}}.
\tag{BK.14}
\]

Now inspect the numerator factors in (BK.10):

```text
r+H*S2,
H*H2-r.
```

A four-case check gives:

- if `epsilon_ell=+1`, one numerator factor is always divisible by `ell^(2e)`; therefore `ell` never survives in `D_phys`;
- if `epsilon_ell=-1` and `delta_ell=-1`, the denominator again cancels completely;
- if `epsilon_ell=-1` and `delta_ell=+1`, both numerator factors are units mod `ell`, so the full `ell^e` survives in `D_phys`.

Thus

\[
\boxed{
\ell^e\mid D_{\rm phys}
\iff
\ell^{2e}\mid H_2+S_2
\text{ and }
r\equiv +HS_2\pmod{\ell^{2e}},
}
\tag{BK.15}
\]

for every odd `ell|X2` with `ell\nmid H`.

So away from the explicit cross-prime set `ell|H`, the odd denominator is supported only on the `H2+S2` half-angle column and is selected by one exact square-root sign.  The `H2-S2` half-angle column cancels automatically.

This gives a much sharper receiver for the existing root-sign / norm-sieve machinery than the abstract `D_min` statistic.

## 6. Physical-edge count with a small partner leg is already below square root

Let

```text
F(Y;B)
```

be the number of primitive oriented Pythagorean faces `(S2,X2,H2)` with

```text
H2<=B,
X2<=Y.
```

Primitive triples have the standard parameterization by coprime opposite-parity `m>n` with legs

```text
m^2-n^2=(m-n)(m+n),
2mn.
```

For the even-leg possibility `2mn<=Y`, summing over the smaller parameter gives `O(Y log(2B))` possibilities.  For the odd-leg possibility `(m-n)(m+n)<=Y`, put `u=m-n`, `v=m+n`; the divisor-hyperbola count is again `O(Y log(2B))`.  Hence

\[
\boxed{F(Y;B)\ll Y\log(2B).}
\tag{BK.16}
\]

Merged Stage14-4ag proves the maximum physical graph degree is `B^o(1)`.  Therefore the number of raw physical edges incident to any partner face with `X2<=Y` is

\[
\boxed{E_{X_2\le Y}(B)\ll Y B^{o(1)}.}
\tag{BK.17}
\]

This is a genuine physical-edge estimate, not a coordinate-density statement.

Take

\[
\boxed{\kappa=\frac1{84}.}
\]

Since the critical denominator exponent from 4bj is

\[
\frac{10}{21}=\frac{40}{84},
\]

put

\[
Y=B^{41/84}.
\]

Then

\[
\boxed{
E_{X_2\le B^{41/84}}(B)
\ll B^{41/84+o(1)}
=o(B^{1/2+\epsilon}).
}
\tag{BK.18}
\]

Thus every square-root-relevant residual edge has

\[
\boxed{X_2>B^{41/84}.}
\tag{BK.19}
\]

## 7. The small-denominator residual now has a large physical square cofactor

Consider the 4bj small-denominator threshold, but with the physical selector:

\[
D_{\rm phys}<B^{10/21}=B^{40/84}.
\]

After removing the already-controlled small-partner-leg sector (BK.18), one has `X2>B^(41/84)`.  Therefore

\[
C_{\rm phys}=\frac{X_2}{D_{\rm phys}}>B^{1/84}.
\]

Together with (BK.13),

\[
\boxed{
C_{\rm phys}>B^{1/84},
\qquad
C_{\rm phys}\mid X_2,
\qquad
C_{\rm phys}^2\mid(r+HS_2)(HH_2-r).
}
\tag{BK.20}
\]

This is the exact main-track replacement for the vague phrase "small least denominator".

The physical post-local problem is now split into only two square-root-relevant sectors:

```text
A. D_phys >= B^(10/21)
   -> exact denominator-square incidence modulus D_phys^2,
      now attached to an invertible physical selector;

B. D_phys < B^(10/21), X2>B^(41/84)
   -> large cancellation cofactor C_phys>B^(1/84),
      C_phys|X2 and C_phys^2 divides the explicit physical product
      (r+H*S2)(H*H2-r).
```

The partner-leg sector `X2<=B^(41/84)` is already square-root controlled.

## 8. Status of the packet-existence quantifier gap

Stage14-4bk does **not** claim that the coordinate rectangle saving from 4bj/s6-04 can simply be multiplied by `B^(41/42)`.

What changes is the counting object:

- 4bj used an abstract globally-soluble packet and a least witness chosen after an upper-majorant relaxation;
- 4bk uses one explicit torsion translate of the exact physical point;
- the selector is invertible back to the physical edge;
- `D_phys` is an actual divisor of the partner leg `X2`;
- by merged 4ag, counting physical edges or active vertices changes no power exponent.

Thus the next stage can work directly on physical edge variables and no longer needs an existence-to-coordinate transfer theorem for an arbitrary packet family.

The unresolved issue is now a concrete physical incidence count for the two sectors in Section 7.
