# Stage14-tH17 R2 — matched-rectangle signed TT*/dual large-sieve audit

## Purpose

The first tH17 result audited the broad signed state-space receiver created by merged t61. While that audit was running, merged Stage14-t62 compressed each t59 orthogonal-rectangle family to its exact matched block frame. R2 imports t62 and replaces the over-strong ambient state-space target by the exact projected receiver now required by the live route.

The original tH17 result remains valid as a sufficient ambient formulation. It is no longer the minimal downstream contract.

The t62 objects are, for one orthogonal-rectangle family

\[
\mathcal R=\{R_j=A_j\times B_j\}_{j\in J},\qquad m_j=|A_j||B_j|,
\]

\[
E_j=\frac{{\bf1}_{R_j}}{\sqrt{m_j}},\qquad z_j=\sqrt{m_j}.
\]

Because the row projections and column projections are pairwise disjoint, the `E_j` are Hilbert--Schmidt orthonormal and

\[
\|z\|_2^2=\sum_jm_j=:R_{\mathcal R}.
\]

For distinct split auxiliary primes `p,q`, define

\[
\kappa_{pq,j}=\langle E_j,K_{pq}\rangle
=\frac1{\sqrt{m_j}}\sum_{s\in R_j}K_p(s)K_q(s).
\]

Then the signed physical trace is exactly

\[
T_{\mathcal R}(p,q)=\sum_jz_j\kappa_{pq,j}.
\tag{R2.1}
\]

No polar absolute value is used.

## 1. Exact projected analysis operator

Define

\[
\mathcal K_{\mathcal R}((p,q),j)=\kappa_{pq,j}.
\]

Then the exact physical target is

\[
\boxed{
\|\mathcal K_{\mathcal R}z\|_2^2
\ll P^2\|z\|_2^2B^{o(1)}.
}
\tag{R2.2}
\]

This is the theorem named

```text
PhysicalMassVectorKummerRayleighBound.
```

A stronger standard dual-large-sieve theorem is

\[
\boxed{
\|\mathcal K_{\mathcal R}c\|_2^2
\ll P^2\|c\|_2^2B^{o(1)}
\quad\text{for every }c\in\ell^2(J).
}
\tag{R2.3}
\]

This is

```text
MatchedRectangleProjectedKummerDualLargeSieve.
```

It implies the physical theorem by taking `c=z`, but is strictly stronger.

Thus the latest theorem hierarchy is

```text
minimal physical target:
  PhysicalMassVectorKummerRayleighBound

stronger clean dual target:
  MatchedRectangleProjectedKummerDualLargeSieve

ambient arbitrary-state large sieve:
  sufficient but not required
```

## 2. Matched block projection is an exact isometry

Let

\[
S_{\mathcal R}=\bigsqcup_jR_j
\]

and define

\[
D_{\mathcal R}:\ell^2(J)\to\ell^2(S_{\mathcal R}),
\qquad
(D_{\mathcal R}c)(s)=c_j/\sqrt{m_j}\quad(s\in R_j).
\]

Disjointness gives

\[
\boxed{D_{\mathcal R}^*D_{\mathcal R}=I.}
\tag{R2.4}
\]

Let the full signed two-prime physical analysis matrix be

\[
\Phi_{\mathcal R}((p,q),s)=K_p(s)K_q(s).
\]

Then

\[
\boxed{\mathcal K_{\mathcal R}=\Phi_{\mathcal R}D_{\mathcal R}.}
\tag{R2.5}
\]

Hence matched projection creates zero coefficient-energy loss. Conversely, asking for an operator theorem on arbitrary state coefficients is unnecessary enlargement of the coefficient space.

```text

AMBIENT_STATE_SPACE_LARGE_SIEVE_REQUIRED=false
```

## 3. One-pair block Bessel is zero-loss but analytically insufficient

For any function `F` on the physical union,

\[
\boxed{
\sum_j\frac1{m_j}\left|\sum_{s\in R_j}F(s)\right|^2
\le\sum_{s\in S_{\mathcal R}}|F(s)|^2.
}
\tag{R2.6}
\]

For `F=K_{pq}` this gives

\[
\sum_j|\kappa_{pq,j}|^2\le R_{\mathcal R}.
\]

Together with `||z||_2^2=R_R`, ordinary Cauchy gives only

\[
|T_{\mathcal R}(p,q)|^2\le R_{\mathcal R}^2,
\]

and summing over auxiliary pairs gives the trivial `P^2R_R^2` scale. Thus t59/t62 have removed projection and rectangle-count losses, but a factor `R_R` of arithmetic cancellation is still required across the auxiliary-pair family.

```text
MATCHED_BLOCK_PROJECTION_BESSEL_ZERO_LOSS=true
ONE_PAIR_BLOCK_BESSEL_ALONE_CLOSES_SECOND_MOMENT=false
```

## 4. TT* / dual large sieve after matched projection

Set

\[
\mathcal G_{\mathcal R}=\mathcal K_{\mathcal R}^*\mathcal K_{\mathcal R}.
\]

Then

\[
\|\mathcal K_{\mathcal R}c\|_2^2=c^*\mathcal G_{\mathcal R}c.
\tag{R2.7}
\]

Therefore the exact physical theorem is only

\[
\boxed{z^*\mathcal G_{\mathcal R}z
\ll P^2z^*zB^{o(1)},}
\tag{R2.8}
\]

whereas the projected dual large sieve is the stronger operator statement

\[
\boxed{\|\mathcal G_{\mathcal R}\|_{op}\ll P^2B^{o(1)}.}
\tag{R2.9}
\]

TT*/duality is therefore useful and quantifier-safe, but duality by itself supplies no arithmetic estimate for `G_R`.

## 5. Exact arithmetic Gram formula

For physical states `s,t`, define

\[
H(s,t)=\sum_{r\in\mathcal P}K_r(s)K_r(t),
\]

\[
D(s,t)=\sum_{r\in\mathcal P}K_r(s)^2K_r(t)^2.
\]

Since the auxiliary second moment uses ordered `p\ne q`, exactly

\[
\sum_{p\ne q}K_p(s)K_p(t)K_q(s)K_q(t)
=H(s,t)^2-D(s,t).
\tag{R2.10}
\]

Consequently

\[
\boxed{
\mathcal G_{jk}
=\frac1{\sqrt{m_jm_k}}
\sum_{s\in R_j}\sum_{t\in R_k}
\bigl(H(s,t)^2-D(s,t)\bigr).
}
\tag{R2.11}
\]

This is the exact TT* output for Stage14-t63. The matched rectangle averages remain inside the Gram entry; no ambient state-pair Schur majorant has been taken.

Equal-squareclass principal pairs remain visible: on every common good auxiliary prime,

\[
K_r(s)K_r(t)=1,
\]

so `H(s,t)=P-B^{o(1)}`. Thus matched projection may weaken the necessary theorem compared with arbitrary-state Bessel control, but it does not remove principal coherence automatically.

```text
MATCHED_GRAM_EXACT_H2_MINUS_DIAGONAL_FORMULA_PROVED=true
PRINCIPAL_COHERENCE_SURVIVES_MATCHED_PROJECTION=true
```

## 6. Geometry-only counterguard

Take a single matched rectangle of mass `m` and an abstract coherent packet with `K_r(s)=1` for every auxiliary prime and every state in the rectangle.

All t59/t62 source-side structure is then perfect:

- rectangle orthogonality is vacuous;
- aspect balance is exact;
- normalized block projection is an isometry;
- block Bessel is sharp.

But

\[
\kappa_{pq}=\sqrt m,\qquad z=\sqrt m,\qquad T_{pq}=m,
\]

so

\[
\sum_{p\ne q}|T_{pq}|^2=P(P-1)m^2,
\]

against target scale `P^2mB^{o(1)}`. Thus geometry alone can miss by a factor comparable with `m`.

This is only a logical countermodel; it is not a claim that the actual physical Kummer packet has a fully coherent rectangle.

```text
T59_T62_GEOMETRY_ALONE_IMPLIES_PROJECTED_CANCELLATION=false
```

## 7. Same-modulus horizontal bilinear / trace large sieve

The support obstruction is much better after t59/t62: every block is a genuine Cartesian rectangle and only one scalar per rectangle survives projection. But the local kernel is unchanged:

\[
K_r(t,x)
=\chi_r((x^2-t^2)(1-t^2x^2))
=A_r(x/t)A_r(tx).
\tag{R2.12}
\]

It remains a rank-one bivariate Kummer kernel.

The already-audited Ping Xi arbitrary-set theorem is a one-finite-field theorem for separated bilinear forms with a one-variable trace kernel such as `K(mn)` under bountiful/special trace-sheaf hypotheses. t59 rectangularization fixes support shape but does not turn (R2.12) into that theorem shape.

Likewise the recent Fouvry--Kowalski--Michel--Sawin type-I/II trace technology is one-field trace-function machinery under geometric correlation hypotheses. The current shared-two-prime rank-one packet has not been certified as a direct instance.

Trying to apply a one-prime theorem at `p` while treating `K_q(t,x)` as a coefficient fails ordinary row/column coefficient separation because `K_q` is still bivariate. Expanding `K_q` into the full Mellin packet restores separation only by returning to the full same-modulus character-space loss already rejected in tH16 unless a new signed matrix theorem is proved.

## 8. Operator-valued large sieve

After t62 the correct operator is

\[
\mathcal K_{\mathcal R}:\ell^2(J)\to
\ell^2\{(p,q):p\ne q\},
\]

not the horizontal one-modulus Mellin matrix `C_r` and not the full physical state-space operator.

The operator-valued theorem

\[
\|\mathcal K_{\mathcal R}\|_{op}^2\ll P^2B^{o(1)}
\]

is mathematically well-defined and is exactly `MatchedRectangleProjectedKummerDualLargeSieve`. Abstract Hilbert-space large-sieve duality identifies it with (R2.9), but still leaves the arithmetic estimation of the Gram constant to be proved.

The t61 horizontal estimate `||C_r||op=O(r^{-1/4})` acts between complete character spaces at a fixed modulus. It does not transfer to the projected operator across varying auxiliary prime pairs.

## 9. Role of t59 aspect-energy balance

The t59 aspect balance remains exact:

\[
\left(\sum_j|A_j|^2\right)
\left(\sum_j|B_j|^2\right)
\le2\left(\sum_jm_j\right)^2.
\]

It was crucial in t60 when the receiver was split into row-side and column-side fourth moments. After t62, however, the matched frame already gives `||z||_2^2=R_R` exactly and no row/column norm product appears in the minimal Rayleigh statement.

Therefore aspect balance is preserved and may be reused by a future side-splitting proof, but it is not itself the missing projected Gram cancellation.

## 10. Direct downstream contract

Stage14-t63 should import:

```text
matched block:
  E_j = 1_Rj/sqrt(m_j)
  <E_j,E_k>_HS = delta_jk

physical mass vector:
  z_j = sqrt(m_j)
  ||z||_2^2 = physical mass

projected trace:
  kappa_pq,j = <E_j,K_pq>
  T_R(p,q) = sum_j z_j*kappa_pq,j

projected Gram:
  G = K_projected^* K_projected
  G_jk = (m_j*m_k)^(-1/2)
         sum_{s in R_j,t in R_k}(H(s,t)^2-D(s,t))

minimal target:
  z^*Gz <= P^2*z^*z*B^o(1)

stronger sufficient theorem:
  ||G||op <= P^2*B^o(1)
```

The recommended next decomposition is:

1. exact state diagonal;
2. same-row physical pairs;
3. same-column physical pairs;
4. transverse equal-squareclass principal pairs;
5. transverse nonprincipal pairs.

Use t36/t38/tH15 on row/column parts only where their hypotheses match. Do not first replace (R2.11) by an entrywise absolute Schur majorant, because that can discard block-level cancellation and simply reproduce the unresolved principal energy.
