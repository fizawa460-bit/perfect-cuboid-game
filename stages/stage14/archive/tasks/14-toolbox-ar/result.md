# Stage14-toolbox-ar — receiver-ready import certificates and stale-contract guard

Stage14-toolbox-ar consumes merged toolbox-aq and the newer s7-19 / t55 boundaries. It turns receiver separation into a mechanical import rule: an input is ready only when its current receiver identity, coefficient space, preserved labels, proved output, open output, scale, and forbidden operations all match.

## Current receiver certificates

The old `PrimePairProjectiveSlopeDispersion` name is stale. Merged s7-18 removed same-split critical collisions, and merged s7-19 reduced the live cross-split object to `LargeSwitchPrimitivePythagoreanTwoLegIncidence`. Direct import is licensed only for exact positive pair-level data `(H0,L0,W0,K_switch,K_agree,xi0)`, including primitivity and the three divisibilities. No statewise Gaussian character bridge is inferred.

The broad tH15 receiver `SharedUPhysicalBipartiteDispersion` has been narrowed by merged t55. The invisible/invisible complete `P1 x P1` trace and constant-density mean are proved. The live receiver is `SharedUInvisibleCenteredProjectiveSelectorDispersion`. Import retains fixed primitive `U`, divisor fan, `delta`, branch, interval/reconstruction masks, centered selector, distinct auxiliary primes, and the single mixed-branch block separately. Complete trace cancellation does not imply sparse physical-selector cancellation.

The tH14 R2 quadratic large-sieve adapter remains conditional on `PhysicalWeightedSquareclassFiberEnergy`; neither current receiver promotes it.

## Import-ready rule

A certificate is `READY` exactly when canonical receiver id and supersession source, exact coefficient space and sign type, preserved labels, proved component, remaining theorem and scale, auxiliary family and centering, forbidden operations, and claim strength all match. Otherwise it is `STALE`, `ADAPTER_ONLY`, or `REJECT`; a missing field never defaults to compatibility.
