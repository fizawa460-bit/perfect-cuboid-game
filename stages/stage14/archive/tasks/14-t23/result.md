# Stage14-t23 — torsion / positive-rank dichotomy on active directions

## Purpose

Stage14-t22 replaced the scale multiplicity of a fixed reduced direction `(D,C)` by a uniform `B^{o(1)}` elliptic-quotient bound. The remaining collision target is the partition second moment of **active reduced directions**.

Before treating every active direction as a positive-rank specialization, one must remove a logically distinct possibility: the physical point on the t22 elliptic quotient could be torsion.

Stage14-t23 classifies that torsion branch. The result is unusually rigid:

> A physical quotient point can be torsion only if it has exact order `8`. In that case `D`, `C`, and `D-C` are all integer squares, so the reduced direction itself comes from a primitive Pythagorean triple of size `sqrt(D)`.

Consequently the torsion-active direction first moment is `B^{1/2+o(1)}`. Outside that explicit order-8 locus, every active direction carries a non-torsion rational point and therefore has positive Mordell-Weil rank.

This does not yet prove the required active-direction second-moment power saving.

## 1. Shift the t22 quotient to its rational-4-torsion model

The t22 quotient is

\[
V^2=(U-1)(-C^2U^2+4D^2U-4D^2).
\]

Put

\[
z=1-U,\qquad y=V/C.
\]

Then

\[
\boxed{
E_{D,C}:\quad y^2=z\left(z^2+\left(4\frac{D^2}{C^2}-2\right)z+1\right).
}
\]

Write

\[
A=4D^2/C^2-2.
\]

The point

\[
P_4=\left(1,\frac{2D}{C}\right)
\]

is rational because `A+2=(2D/C)^2`. For the standard model

\[
y^2=z(z^2+Az+1),
\]

the duplication formula is

\[
x(2P)=\frac{(z^2-1)^2}{4z(z^2+Az+1)}.
\]

At `z=1` this gives `x(2P_4)=0`, so `2P_4=(0,0)`. Hence every direction quotient contains a rational point of exact order four.

This strengthens the t22 statement “has rational 2-torsion”: the family is actually a rational-`4`-torsion family.

## 2. Physical points live in the nontrivial `[-1]` Kummer class

For a physical edge choose one orientation and normalize

\[
X=x/g,\qquad Y=y/g,
\]

with

\[
Q^2=D^2-X^2,
\qquad
Y^2=D^2-C^2-X^2.
\]

The t22 map gives

\[
U=\frac{2D}{D-X}.
\]

Therefore

\[
z=1-U=-\frac{D+X}{D-X}.
\]

But

\[
Q^2=(D-X)(D+X),
\]

so

\[
\boxed{
z=-\left(\frac{D+X}{Q}\right)^2.}
\]

In particular

\[
z<-1,
\qquad
[z]=[-1]\in\mathbf Q^\times/\mathbf Q^{\times2}.
\]

For `y^2=z(z^2+Az+1)`, the standard rational-2-isogeny Kummer map is represented by the squareclass `[z]` away from `(0,0)`. Thus every physical quotient point occupies the fixed nontrivial Kummer class `[-1]`.

## 3. Mazur plus the Kummer class leaves only order 8

Mazur's rational torsion theorem gives the complete list of possible torsion groups over `Q`. Since our family already contains a rational point of order four, the only possibilities are:

- with exactly one nonzero rational 2-torsion point: `Z/4`, `Z/8`, or `Z/12`;
- with full rational 2-torsion: `Z/2 x Z/4` or `Z/2 x Z/8`.

Reference: Barry Mazur, *Modular curves and the Eisenstein ideal*, Publ. Math. IHES 47 (1977), 33--186.

Now use the physical conditions.

### Cyclic `Z/4`

The exact order-four points lie over `z=1`; the physical range has `z<-1`. So a physical point is not order four.

### Cyclic `Z/12`

Let `G` generate the cyclic torsion group. Its unique order-four subgroup is generated by `3G`, which is `±P_4`. The Kummer map has exponent two, hence

\[
\delta(G)=\delta(3G)=\delta(P_4)=[1]=1.
\]

Therefore every torsion point in the cyclic `Z/12` case has trivial Kummer class. A physical point has class `[-1]`, so it cannot be torsion here.

### `Z/2 x Z/4`

Every order-four point doubles to the same rational two-torsion point `(0,0)`. Solving `x(2P)=0` from the duplication formula gives

\[
z=\pm1.
\]

Again the physical range `z<-1` excludes these points; physical points are also nonzero in `y`, so they are not order two.

### The only surviving torsion possibility

The only remaining groups are `Z/8` and `Z/2 x Z/8`, and a physical torsion point must have

\[
\boxed{\operatorname{ord}(P)=8.}
\]

This is an exact theorem-level torsion/positive-rank dichotomy, not a finite observation.

## 4. Exact order-8 condition

For a physical point, substitute the normalized equations into the duplication formula. Direct simplification gives

\[
\boxed{
x(2P)=\left(\frac{CX}{QY}\right)^2.}
\]

Thus `x(2P)` is itself a nonnegative rational square.

If `P` has order eight, `2P` has order four. The possible order-four `x`-coordinates relevant to doubling `(0,0)` are `+1` and, in the full-2-torsion case, `-1`; the latter cannot occur because `x(2P)>=0`. Hence

\[
x(2P)=1.
\]

Algebraically

\[
x(2P)-1
=
-\frac{(CD-D^2+X^2)(CD+D^2-X^2)}
{(D-X)(D+X)(C^2-D^2+X^2)}.
\]

All physical quantities make the second numerator factor nonzero, so

\[
\boxed{X^2=D(D-C).}
\]

Then the physical equations force

\[
Q^2=CD,
\qquad
Y^2=C(D-C).
\]

Because `(D,C)=1`, rational square roots of these positive integers are integral and coprimality separates the factors. Therefore

\[
\boxed{
D=a^2,\qquad C=b^2,\qquad D-C=c^2
}
\]

for coprime positive integers `a,b,c`, and

\[
\boxed{a^2=b^2+c^2.}
\]

So every torsion-active reduced direction lies over a primitive Pythagorean triple whose hypotenuse is `sqrt(D)`.

## 5. Torsion-active first moment is square-root size

Under the physical height cutoff `d=gD<=B`, one has `D<=B`, hence

\[
a=\sqrt D\le\sqrt B.
\]

For each `a`, the number of primitive representations

\[
a^2=b^2+c^2
\]

is bounded by a divisor function of `a^2`, hence `a^{o(1)}` uniformly. Summing gives

\[
\boxed{
A_{\rm tor}(B)=O(B^{1/2+o(1)}).
}
\]

This is a genuine family-level power saving for the **first moment** of torsion-active directions.

It is not yet a second-moment theorem: concentration of many torsion directions in the same split partition could still make the torsion partition energy as large as `B^{1+o(1)}` under this bound alone.

## 6. The order-8 branch becomes two explicit quartic squareclass packets

Parameterize the primitive Pythagorean triple by

\[
a=m^2+n^2,
\]

with legs

\[
2mn,\qquad m^2-n^2,
\]

where `(m,n)=1` and `m,n` have opposite parity.

Recall the t20 partition

\[
D-C=h\alpha r^2,
\qquad
D+C=h\beta u^2.
\]

There are two orientations.

### Even leg squared is `C`

Take

\[
C=(2mn)^2,
\qquad
D=(m^2+n^2)^2.
\]

Then

\[
D-C=(m^2-n^2)^2,
\qquad h=1,\qquad \alpha=1,
\]

and

\[
\boxed{
\beta=\operatorname{core}(m^4+6m^2n^2+n^4).
}
\]

### Odd leg squared is `C`

Take

\[
C=(m^2-n^2)^2,
\qquad
D=(m^2+n^2)^2.
\]

Then

\[
D-C=(2mn)^2,
\qquad h=2,\qquad \alpha=2,
\]

and

\[
\boxed{
\beta=\operatorname{core}(m^4+n^4).
}
\]

Thus the entire possible torsion branch is supported on two explicit quartic squarefree-kernel packets:

\[
F_1(m,n)=m^4+6m^2n^2+n^4,
\qquad
F_2(m,n)=m^4+n^4.
\]

This is exactly the kind of polynomial squareclass object for which the q4/q6 square- or polynomial-sieve weapon becomes eligible. The earlier stop rule “do not invoke a polynomial square sieve before an explicit compatible polynomial appears” is now satisfied for the torsion branch.

No polynomial-sieve estimate is claimed in t23 itself.

## 7. Rank/torsion second-moment split

For each split partition define

\[
A_{\alpha,\beta}(B)
=A^{\rm rank}_{\alpha,\beta}(B)
+A^{\rm tor}_{\alpha,\beta}(B),
\]

where `rank` means the active direction carries a physical non-torsion quotient point and `tor` means it lies on the order-8 torsion locus.

Then

\[
Q_{\rm active}(B)
=\sum_{\alpha,\beta}A_{\alpha,\beta}(B)^2
\le
2Q_{\rm rank}(B)+2Q_{\rm tor}(B),
\]

with

\[
Q_{\rm rank}=\sum(A^{\rm rank}_{\alpha,\beta})^2,
\qquad
Q_{\rm tor}=\sum(A^{\rm tor}_{\alpha,\beta})^2.
\]

Therefore t22's target is now split into two mathematically different problems:

1. **rank branch:** count generalized-Pell directions whose quotient acquires a non-torsion rational point in the physical small-height window;
2. **torsion branch:** bound squarefree-kernel collisions of `F_1` and `F_2` on primitive opposite-parity `(m,n)`.

Any fixed power saving for both second moments gives one for `Q_active`, then for `Q_split`, then `Q_edge=o(B)`, and finally `T(B)=o(sqrt(B))`.

## 8. Frozen finite audit
