## Q2. 分母の道（M3(B) ≫ B^{1/2+δ}）

**答え: 「本当に手がつかない」。より正確には、偽と予想されます。ただし、弱めた形（≫ B^{1/2} または B^{2/5}）には、現実的な新しい構成の可能性が残っています（未確認）。**

### 2.1 既知の上界と下界（リポジトリ内）
- B^{1/3} ≪ M3(B) ≪ B(log B)^{5−1/50}（`stage20/final.md`、`28-50-r2`）[conditional（未再監査）]。
- 実測: M3(2000)=7、M3(10⁴)=18、M3(5·10⁴)=42、M3(2·10⁵)=82、M3(10⁶)=219（`stage20/final.md` §2）。
  区間ごとの増え方の指数は 0.59、0.53、0.48、0.61 で、M3(B)/B^{1/2} は 0.16〜0.22 にとどまります [proved（検算スクリプトで計算）]。
  10⁶ では、Saunderson の族から来るのは 219 個のうち 10 個前後です [estimate]。

### 2.2 有理曲線 1 本でできること
- 有理曲線で、(a:b:c) が次数 n の斉次式で書けるものは、B^{2/n} 個の brick を与えます。Saunderson は n=6 で B^{1/3} です。
- B^{1/2+δ} には n ≤ 3 が必要です。
- **補題 L** [proved]: n ≤ 3 の退化していない族は、有理数体上に存在しません。
  - 道具: g = gcd(a,b) とすると、(a+ib)/g と (a−ib)/g は互いに素で積が平方なので、それぞれ平方。したがって n − deg g は偶数（手計算）。
  - n=1: すべての組が比例し、定点になる。
  - n=2: 解は a²+b²+c² ≡ 0（実点なし）か、a = ±b（a²+b² = 2a² は有理数の平方でない）だけ（スクリプト）。
  - n=3: 3 つの gcd がすべて 1 次で互いに素になり、連立方程式の解は c ≡ 0（退化）だけ（スクリプト、Gröbner 基底）。
- **n = 4、5 は調べていません。** リポジトリの `28-50-r2/classical-family-degree-inventory.md` は既知の族（次数 6、8）を並べただけで、非存在の証明ではありません。

### 2.3 K3 曲面の一般論
- Batyrev–Manin 予想（K3 版）: 任意の ε>0 に対し、空でない Zariski 開集合 U(ε) があって N_{U(ε),L}(B) = O(B^ε)。
  出典: D. McKinnon, "Vojta's Conjecture implies the Batyrev–Manin Conjecture for K3 surfaces", arXiv:1011.5825, Conjecture 4.1。同論文 Corollary 4.3 で、Vojta の主予想から従うことが示されています（PDF の本文で確認）。
- これを認めると、U(ε) の外は有限本の曲線です。種数 1 以上の曲線は B^ε 以下、有理曲線は B^{2/n} で、補題 L により n ≥ 4 です。したがって
  **M3(B) ≪ B^{1/2} + B^ε** [conditional（Batyrev–Manin 予想 + 補題 L）]。
  - 細かい点: 予想は豊富な因子についての主張です。R の高さは特異モデルでは豊富ですが、解消した K3 では nef かつ big です。高さの比較で埋まるはずですが、書き下していません [outline]。
- つまり、**分母の道の目標 B^{1/2+δ} は、標準的な予想と矛盾します。** 楕円ファイバー空間（15 本）を使っても変わりません。切断は有理曲線なので上の議論に含まれ、ファイバーごとの点は B^ε 以下です [outline]。
- K3 の有理点の数を無条件で下から押さえる定理で、有理曲線 1 本より強いものは、私は知りません（記憶のみ）。

### 2.4 残る現実的な問い
- 実測値が B^{1/2} に近いことと、補題 L が n=4 を排除していないことから、**n=4（または 5）の族があるかどうかは、決める価値があります。**
  - n=4 の族があれば M3(B) ≫ B^{1/2} [proved になる]。必要な分子は o(B^{1/2}) になります。
  - n=5 なら M3(B) ≫ B^{2/5}。
  - どちらもなければ、族による下界は B^{1/3} が上限です。
- これは有限の計算です。場合分けは gcd の次数の組（n=4 なら 0 か 2）で、補題 L と同じ方法（Gröbner 基底）か、K3 の Picard 格子（階数 20）での (−2) 類の列挙でできます [estimate: 手元の PC で数時間〜数日]。
- ただし、n=4 の族が見つかっても、目標は閉じません。Stage14 は「B^{1/2} を真に下回る評価」を未解決の門として記録しています（`stage14/final.md` の UNPROVED 表）。

## Q3. 分子の道に既知の一般論は効くか

**答え: 「本当に手がつかない」。一般論の指数は、既存の 1/2 より弱いです。**

- 立方体曲面は P⁶ の次数 16 の曲面で、高さ d は P⁶ の普通の高さと定数倍の範囲で同じです [proved（各座標 ≤ d）]。
- Salberger, "Counting rational points on projective varieties", Proc. London Math. Soc. 126 (2023) 1092–1133:
  - Theorem 0.8（幾何的に整な射影曲面、次数 d、Pⁿ）: N(U;B) = O(B^{3/√d+ε} + B^{3/(2√d)+2/3+ε} + B^{1+ε})。
  - Theorem 0.9: O(B^{3/(2√d)} log B + 1) 本の補助曲線があり、それに乗らない点は O(B^{3/√d+ε}) 個。
  - d=16 では 3/4、25/24、1 です。**どれも 1/2 より大きい**です。
  - 注意: PDF から抜き出した文字が崩れていて、式は私が組み立て直しました。U の定義（直線の補集合のはず）と各項は、原典で照合してください [conditional]。Theorem 0.5、0.6（指数 3/√d のみ）は P³ の非特異曲面と P⁴ の完全交叉が対象で、この曲面（P⁶、A1 特異点 48 個）には当てはまりません。
- **Stage32 と組み合わせても変わりません。** 3/4 の項は「補助曲線に乗らない点」の数で、例外の曲線を消しても残ります。補助曲線の本数だけでも B^{3/8} で、1/3 を超えます [proved（指数の計算）]。
- 種数 2 以上の例外曲線は、1 本ごとには有限個（Faltings）ですが、本数と高さについて一様な評価がなく、数え上げには使えません（記憶のみ）。
- Heath-Brown、Walsh、Castryck–Cluckers–Dittmann–Nguyen の改良は、ε や定数の d への依存を良くするもので、指数 3/√d は変えません（記憶のみ、未照合）。

**条件付きなら目標は成り立ちます** [conditional]。
- Bombieri–Lang 予想を認めると、有理点は有限本の曲線に乗ります。次数 δ の有理曲線は B^{2/δ} 個、種数 1 以上は B^ε 以下です。
- Stage32 の記録（次数 16 以下の有理曲線・楕円曲線には完全直方体がない、PR #1859）を認めると、δ ≥ 18 なので P(B) ≪ B^{1/9+ε} = o(B^{1/3}) です。
- したがって「P/M3 → 0」は Bombieri–Lang 予想 + Stage32 から従います。無条件の証明に足りないのは、Bombieri–Lang の内容そのもの（点が曲線に集まること）です。これは新しい定理ではなく、既知の予想の言い直しなので、成果としては数えないでください。
