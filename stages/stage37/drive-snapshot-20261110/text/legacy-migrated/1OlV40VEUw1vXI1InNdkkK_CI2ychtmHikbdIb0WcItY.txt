## 1. Exact normalized square-root carrier


Retain
C_u=kappa*T^2, kappa=sf(C_u),
M=M_rel,
S_sq=M*T,
Rrel=M*Nrel,
where Nrel=Rrel/M is supported on the fixed content-prime set.


Since 0<=v_p(C_u)<=2v_p(M), one has T|M. Define


A_car = tau0^3*Rrel^2/(M*T)
      = tau0^3*Nrel^2*(M/T).


This is a positive integer because M*T | M^2 | Rrel^2.


Audited 116 gives
K_car=W_car/S_sq^2
with W_car=2*L*tau0^6*Rrel^4.
Therefore exactly


K_car = 2*L*A_car^2.


Equivalently, if Q_S=M^2/C_u is the retained complementary conductor quotient, then


(M/T)^2 = kappa*Q_S,


so


A_car = tau0^3*Nrel^2*sqrt(kappa*Q_S).


Thus every live psi endpoint lies on one fixed packet squareclass of K_car; all moving dependence is carried by the single integer A_car.


## 2. Uniform fixed-A_car physical fiber


Fix A_car=A. Then K_car=2*L*A^2 is fixed in the packet.


Every endpoint satisfies
V_norm*J_car=K_car
with V_norm,J_car positive integers. Hence J_car must be a positive divisor of K_car. Since K_car is polynomially bounded on the retained physical range,


tau(K_car)=B^o(1).


For each such J_car,
d=sf(N_u)=sf(2*L*J_car)
is fixed. Audited 113 gives B^o(1) physical psi endpoints for fixed d, uniformly over the retained polynomial physical range.


Therefore


# {physical psi endpoints with fixed A_car} << B^o(1).


If A_support(B) denotes the number of active A_car values in one fixed packet, then


A_support(B) <= E_psi(B) <= B^o(1)*A_support(B).


Hence endpoint count and active A_car support have the same polynomial exponent.


For X>=1 in the polynomial range,


E_psi(B; A_car<=X) << X*B^o(1).


This is an L-normalized support window. It is not the same statement as K_car<=K0 when L itself moves polynomially between packets.


## 3. Extreme odd surplus is packet-supported


Let p^lambda || M_rel and suppose the corrected capped conductor is extreme:
c_p=v_p(C_u)=2lambda.


Corrected 111 gives
min(v_p(N_u),4lambda)=4lambda,
so v_p(N_u)>=4lambda.


Because p lies in the fresh relative conductor, p does not occur in tau0 or in the content-supported Nrel=Rrel/M. From audited 115,


N_u | W_car=2*L*tau0^6*Rrel^4,


and therefore


v_p(N_u) <= 4lambda + v_p(2L).


Consequently any positive extreme excess
v_p(N_u)-4lambda
is supported only at primes dividing 2L. In particular, if the excess parity is odd, then p|2L.


Thus the 115 factor


e_ext = product_(p|M_rel, c_p=2lambda_p, v_p(N_u) odd) p


satisfies


e_ext | rad(2L).


This does NOT assert e_ext=1. It asserts that e_ext is fixed-packet-supported.


Since Delta_pkt already contains rad(2L), the support compression of 115 can be sharpened from


d | Delta_pkt*rad(tau0^sharp)*kappa*e_ext


to


d | Delta_pkt*Xi0,


where


Xi0 = rad(tau0^sharp)*kappa.


Therefore fixed Xi0 has B^o(1) physical endpoints, and Xi0<=Z gives Z*B^o(1), without treating extreme surplus as an independent moving support coordinate.


## 4. Xi0 is subordinate to A_car


Set U=M/T. If p|kappa, then c_p is odd. Since c_p<=2lambda_p, oddness forces c_p<2lambda_p, hence
floor(c_p/2)<lambda_p
and p|U.


Therefore
kappa | rad(U).


Also
rad(tau0^sharp) | rad(tau0).


Because
A_car=tau0^3*Nrel^2*U,


one obtains the exact support containment


Xi0=rad(tau0^sharp)*kappa | rad(A_car).


Hence


Xi0 <= rad(A_car) <= A_car.


So the moving support variable from 115 is not independent of the new normalized carrier. Large Xi0 forces large A_car. The converse need not hold: A_car can be large through even conductor-defect powers in U that are invisible to kappa.


## 5. New minimal receiver and remaining blocker


The psi population now has a one-dimensional exact moving-support receiver:

# {active A_car values} << B^(1/12-delta)


for some fixed delta>0,


or prove an equivalent same-measure occurrence/correlation theorem.


Because fixed A_car fibers are B^o(1), such a theorem would give the required psi support saving directly.


The factorization

This card does not prove small A_car globally, does not prove a total psi saving, and does not close the Stage37 primary gate.
