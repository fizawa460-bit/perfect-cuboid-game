2. One four-dimensional CRT lattice


For fixed atom data and fixed orientations rho, define
  L_rho subset Z^4
by the four homogeneous congruences (229AZ.1).


Consider the homomorphism
  Phi: Z^4 -> Z/a x Z/b x Z/c x Z/d
given by
  Phi(x0,x1,x2,x3)
   = (x1-rho_a x3,
      x0-rho_b x2,
      x1-rho_c x2,
      x0-rho_d x3).                                (229AZ.3)


Phi is surjective.


Indeed, for arbitrary target residues:
- set x2=x3=0;
- choose x1 by CRT to hit independently the residues modulo a and c;
- choose x0 by CRT to hit independently the residues modulo b and d.


Pairwise coprimality of a,b,c,d is exactly the needed hypothesis.


Therefore
  L_rho = ker Phi
has exact lattice index
  [Z^4 : L_rho] = abcd = G.                        (229AZ.4)

3. Q-matching joint count


Let the four roots lie in positive intervals/dyadic boxes of lengths/scales
  X0,X1,X2,X3.


Fix x2 and x3.


The two congruences involving x1 are
  x1 == rho_a x3 mod a,
  x1 == rho_c x2 mod c.
By CRT there is exactly one residue class modulo
  ac=Q_-.


Hence the number of admissible x1 in its interval is
  O(1+X1/Q_-).


Likewise the two congruences involving x0 give exactly one residue class modulo
  bd=Q_+,

  O(1+X0/Q_+)

4. P-matching joint count
