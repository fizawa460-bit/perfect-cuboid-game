4. Positive central gap


Define the new central short-gap difference
  lambda := U+V-R-e.                              (229AQ.7)


This lambda is positive.


Indeed,
  A = U-e = x^2/(U+e),
  D = R-V = x^2/(R+V).
Since R>U and V>e,
  R+V > U+e,
so
  A>D.
Thus
  lambda=A-D>0.


Similarly,
  B = y^2/(V+e),
  C = y^2/(R+U),
and R+U>V+e, so B>C and
  lambda=B-C.


Therefore
  A=D+lambda,
  B=C+lambda.                                    (229AQ.8)


Also
  0<lambda<A<R-e,
so
  lambda<R-e.                                    (229AQ.9)

5. Central-gap hyperbola identities


Use
  x^2=A(U+e)=D(R+V).
Substitute A=D+lambda and
  R+V-(U+e)=2C+lambda.
Then
  (D+lambda)(U+e)=D[(U+e)+(2C+lambda)].
After cancellation,
  lambda(U+e)=D(2C+lambda).


Since U=e+D+lambda, this becomes
  lambda(2e+D+lambda)=2CD+D lambda,
hence
  lambda(2e+lambda)=2 C D.                       (229AQ.10)


The y-side gives the same identity.


Using A=D+lambda and B=C+lambda,
  A B
   = (D+lambda)(C+lambda)
   = C D + lambda(C+D)+lambda^2.
Combine with (229AQ.10) and
  R=e+C+D+lambda
to obtain
  lambda(2R+lambda)=2 A B.                       (229AQ.11)


Thus the two short-gap products satisfy the exact paired hyperbola system
  2(R-U)(R-V)
    = lambda(e+U+V-R),                            (229AQ.12)
  2(U-e)(V-e)
    = lambda(R+U+V-e).                            (229AQ.13)


Here
  2e+lambda = e+U+V-R,
  2R+lambda = R+U+V-e.

8. Divisor chart and a genuine scoped same-physical count

Moreover, given positive integers C,D,lambda from a physical endpoint,
  e = (2CD/lambda-lambda)/2,                     (229AQ.24)

  U=e+D+lambda,
  V=e+C+lambda,
  R=e+C+D+lambda.                                (229AQ.25)


Once e,U,V,R are fixed, positive x,y,z, if they exist, are uniquely determined by
  x^2=U^2-e^2,
  y^2=V^2-e^2,
  z^2=R^2-e^2.
