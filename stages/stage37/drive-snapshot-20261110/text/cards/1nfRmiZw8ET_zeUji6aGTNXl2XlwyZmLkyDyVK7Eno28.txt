1. Exact projective-content identity inside the 228 four-chart model

    B=L2M1,
    C=L1M2.

    gcd(A,B,C)=gcd(L1,L2)=g.                       (229C.2)


Proof.
Fix a prime p and put a=v_p(L1), b=v_p(L2), u=v_p(M1), v=v_p(M2).
Primitive-face coprimality gives
    a>0 => u=0,
    b>0 => v=0.
The p-adic valuation of gcd(A,B,C) is
    min(a+b, b+u, a+v).
If a,b>0 this is min(a+b,b,a)=min(a,b).
If exactly one of a,b is positive one of the last two entries is zero, so the minimum is zero.
If a=b=0 it is zero.
Thus the minimum always equals min(a,b), proving (229C.2).


Consequently

4. New degree-four thin-set theorem test


A genuinely new current theorem species is:
T. Buggenhout, R. Cluckers, P. Salberger, T. Santens, F. Vermeulen,
“Serre's question on thin sets in projective space,” arXiv:2506.13471v2.


Their affine theorem gives, for the stated absolutely irreducible weighted-top-form setup, a degree-d type-II cover in n affine base variables:
    d>=5:  O(B^(n-1)),
    d=4:   O(B^(n-1) log(B)^O(1)),
    d=2,3: O(B^(n-2+2/sqrt(d)) log(B)^O(1)).


Apply only a favorable exponent preflight, not a certified transfer.
In a regular balanced 228 chart with all four raw Euclid parameters of scale T and with g=O(1), the quadratic primitive legs L_i,M_i have scale T^2, so

Thus physical R<=B corresponds to the favorable balanced scale
    T <= B^(1/4+o(1)).                              (229C.7)


Granting a valid n=4,d=4 affine reduction of the simultaneous two-square locus, the theorem would give at best
    T^3 log(T)^O(1)
      = B^(3/4) log(B)^O(1).                        (229C.8)


This does not close Stage37.
The current certified denominator corridor contains only

Therefore this powerful new degree-four theorem does not satisfy any 229 restart contract by black-box application.
