2. Exact pre-endpoint directional host


Fix one missing-face direction j.


The audited directional host is


    H_j(B) = M2,j(B) disjoint_union M3(B),


with exact primitive/canonical physical height R<=B.


Write a physical state in this direction as positive edges


    (x,y,z),


where x is the distinguished shared edge and the two already-required faces satisfy


    x^2+y^2 = q_y^2,
    x^2+z^2 = q_z^2


for integers q_y,q_z.


No condition is imposed yet on y^2+z^2 or on x^2+y^2+z^2.


Define Boolean selectors on this SAME H_j measure:


    F(E) = 1_{y^2+z^2 is a square},
    S(E) = 1_{x^2+y^2+z^2 is a square}.


Thus F is the missing-third-face selector and S is the space-diagonal selector before either is conditioned away.


This is exactly the pre-endpoint population required by M3-A-001 and avoids the endpoint-conditioned saturation of159 by construction.


3. Exact linked-square normal form


Put


    e(E) = y^2+z^2.


Then on every E in H_j,


    F(E) = 1_square(e),
    S(E) = 1_square(e+x^2).                         (226.1)


Therefore the two terminal selectors form an exact LINKED-SQUARE pair whose radicands differ by the square x^2.


No ambient box, residue replacement, or extra density assumption is used in (226.1).


In particular, on F=1 with d^2=e, the remaining S condition is exactly


    d^2+x^2 = square,


so endpoint completion is a second Pythagorean completion on the same physical object. This identity is structural only; it is not charged as a new saving.


4. Global centered score and exact root normalization


Let


    H = |H_j(B)| = M2,j+M3,
    alpha = E_H[F] = M3/H,
    beta  = E_H[S] = (N2,j+P)/H.


Define the raw centered score


    Z_j(B)
      = sum_{E in H_j(B)} (F(E)-alpha)(S(E)-beta).  (226.2)


Let


    D_j = M2,j*P - M3*N2,j.


The directional 2x2 table gives exactly


    Z_j = H*Cov_j(F,S)
        = D_j/H.                                    (226.3)


Also define the unnormalized selector variances


    V_F = sum_H (F-alpha)^2
        = H*alpha*(1-alpha),


    V_S = sum_H (S-beta)^2
        = H*beta*(1-beta).                          (226.4)


Then the Pearson coefficient in M3-A-001 is exactly


    rho_j = Z_j / sqrt(V_F V_S).                    (226.5)


Consequently the M3-A-001 sufficient budget becomes the raw-score target


    |Z_j|
      << B^(-1/12-delta) sqrt(V_F V_S)              (226.6)


for some fixed delta>0, with the inherited log/epsilon bookkeeping.


The one-sided root receiver is even simpler:


    Z_j^+ = o(M3)                                   (226.7)


is sufficient for P/M3 -> 0, because
Cov_j(F,S)_+=Z_j^+/H and alpha=M3/H.


Equations (226.2)–(226.7) are on the exact pre-endpoint physical measure.


5. Partition by the actual shared edge


For each positive integer x define the exact physical fiber


    H_{j,x}(B)
      = {E in H_j(B): shared edge(E)=x},


and let


    n_x = |H_{j,x}|.


For n_x>0 define


    alpha_x = E[F | x],
    beta_x  = E[S | x],
    gamma_x = E[FS | x].


Then


    sum_x n_x alpha_x = H alpha,
    sum_x n_x beta_x  = H beta,
    sum_x n_x gamma_x = P.


The law of total covariance gives the exact split


    Z_j = C_within + C_between,                     (226.8)


where


    C_within
      = sum_x n_x (gamma_x-alpha_x beta_x),         (226.9)


and


    C_between
      = sum_x n_x (alpha_x-alpha)(beta_x-beta).     (226.10)


This is the first exact moving-family decomposition of the M3-A centered score on its audited pre-endpoint host.


It separates two logically different tasks:


A. within-x linked-square correlation;
B. moving-x covariance of the two selector survival rates.


Neither term may be dropped or renamed as the other.


6. Uniform fixed-x physical fiber bound


For fixed x, every positive y with x^2+y^2=q_y^2 satisfies


    (q_y-y)(q_y+y)=x^2.                             (226.11)


Hence the number of possible y is at most the divisor count of x^2 up to an absolute parity/order factor:


    #y << tau(x^2).


The same holds for z. Therefore


    n_x << tau(x^2)^2 = B^o(1)                     (226.12)


uniformly for x<=B.


All primitive/canonical/height masks only reduce the count, so (226.12) is valid on the exact physical directional host.


This is not a density saving for H_j: the B^o(1) fibers move through polynomially many x.


7. Exact moving-rate dispersion receiver


Define between-fiber dispersion energies


    V_F^btw
      = sum_x n_x (alpha_x-alpha)^2,


    V_S^btw
      = sum_x n_x (beta_x-beta)^2.                 (226.13)


Cauchy on the SAME x-weighted physical measure gives


    |C_between|
      <= sqrt(V_F^btw V_S^btw).                    (226.14)


The Bernoulli variance decomposition is exact:


    V_F
      = sum_x n_x alpha_x(1-alpha_x) + V_F^btw,


    V_S
      = sum_x n_x beta_x(1-beta_x) + V_S^btw.      (226.15)


Thus


    eta_F = V_F^btw/V_F,
    eta_S = V_S^btw/V_S


lie in [0,1], and the normalized between-fiber contribution satisfies


    |C_between|/sqrt(V_F V_S)
      <= sqrt(eta_F eta_S).                         (226.16)


Therefore a sufficient moving-family theorem for the BETWEEN part is


    eta_F eta_S
      << B^(-1/6-2delta)                            (226.17)


for some fixed delta>0.


Equivalently it is enough to power-control one of the two moving survival-rate dispersions strongly enough, since the other eta is at most1.


This is an explicit 1/12-plus-margin coefficient-energy budget, not generic squareclass energy.


8. Fixed-x complete-sum / sparse-L1 architecture is insufficient


The fixed-x fibers satisfy only


    n_x=B^o(1).


Therefore a method that:

2. transfers it to the actual physical H_{j,x} by taking only the L1 mass of that sparse fiber;
3. then sums over x,

Hence the fixed-x-complete-sum + sparse-L1 architecture supplies no required global power deficit.
