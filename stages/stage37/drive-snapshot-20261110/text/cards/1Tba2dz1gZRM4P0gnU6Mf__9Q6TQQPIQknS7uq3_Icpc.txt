3. Uniform fixed-prime-support counting lemma
LEMMA (uniform polynomial-height S-smooth integers): For fixed A,C>0, uniformly over all integers 1<=m<=B^C, the number of positive n<=B^A whose prime factors all divide m is B^{o(1)} as B tends to infinity. The implicit o(1) depends only on A,C, not on m.
PROOF: Set S={p:p|m}; the standard primorial bound gives |S|=omega(m)=O_C(log B/log log B). For any fixed sigma>0, a Rankin bound gives
  #{n<=B^A:supp(n) subset S}
   <= B^{A*sigma} prod_{p|m}(1-p^{-sigma})^{-1}
   <= B^{A*sigma}(1-2^{-sigma})^{-omega(m)}
   = B^{A*sigma+o(1)} uniformly for m<=B^C.
Given any eta>0 choose sigma=eta/(2A), then this number <=B^{eta/2+o(1)}=O(B^eta). Since eta is arbitrary, the claimed B^{o(1)} follows. m=1 is immediate. End proof.
