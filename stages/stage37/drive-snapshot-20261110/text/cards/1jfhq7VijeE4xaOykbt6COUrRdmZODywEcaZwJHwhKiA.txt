3. Single missing-face Pythagorean host already has B^(1/2-o(1)) large Sigma_xy values


Let P_xy(B) be the ambient set of positive integer triples
x^2+y^2=z^2,
z<=B.
No other Stage37 selector is imposed in this section.


For large B set
M=floor(sqrt(B)/4).
For every odd prime p in
M<=p<=3M/2,
take
x_p=2p,
y_p=p^2-1,
z_p=p^2+1.                                                    (CI.8)


Then x_p^2+y_p^2=z_p^2 and z_p<B for all sufficiently large B.


Define
s_p=rad(x_p y_p)=rad(2p(p^2-1)).                              (CI.9)


The values s_p are pairwise distinct.
Indeed let p!=q be primes in [M,3M/2].
If q|p^2-1, then q|(p-1)(p+1), so q divides p-1 or p+1.
But 0<p+1<2M<=2q for large M, hence the quotient would have to be 1; this is impossible because p±1 is even and q is odd.
Thus q does not divide 2p(p^2-1).
In particular s_p contains p and does not contain any other prime q from the chosen interval, proving distinctness.


By the prime number theorem,
#{p prime:M<=p<=3M/2} >> M/log M >> B^(1/2)/log B.            (CI.10)


Also
s_p>=p>=M>>B^(1/2).                                           (CI.11)


Therefore
#{Sigma_xy values on P_xy(B) exceeding c B^(1/2)}
 >> B^(1/2)/log B                                             (CI.12)
for an absolute c>0.


RESULT_229CI_SINGLE_MISSING_FACE_SIGMA_XY_OCCUPANCY_FLOOR=B^(1/2-o(1)).


4. Single outer Pythagorean host already has B^(1/2-o(1)) large Sigma_R values


Let P_R(B) be the ambient set of positive integer triples
e^2+z^2=R^2,
R<=B.
Again no other Stage37 selector is imposed.


For every prime p in [M,3M/2], use
e_p=2p,
z_p=p^2-1,
R_p=p^2+1.                                                    (CI.13)


Put
t_p=rad(e_p R_p)=rad(2p(p^2+1)).                              (CI.14)


We extract a large subset with distinct t_p.
Build a graph on the primes in [M,3M/2], joining p!=q if
q|p^2+1 or p|q^2+1.


For fixed p, p^2+1<3M^2 for large M, so it has at most two distinct prime divisors q>=M.
Conversely q^2==-1 mod p has at most two residue classes modulo p, and the interval [M,3M/2] has length <p, so there are at most two q in the interval with p|q^2+1.
Thus the graph has maximum degree at most 4.


A greedy independent set therefore contains at least one fifth of the vertices.
By the prime number theorem it has
>>M/log M>>B^(1/2)/log B                                     (CI.15)
primes.


For distinct p,q in this independent set, q does not divide 2p(p^2+1), so t_p contains p but not q. Hence the t_p are pairwise distinct, and
t_p>=p>=M>>B^(1/2).                                           (CI.16)


Therefore
#{Sigma_R values on P_R(B) exceeding c B^(1/2)}
 >> B^(1/2)/log B.                                            (CI.17)


RESULT_229CI_SINGLE_OUTER_SIGMA_R_OCCUPANCY_FLOOR=B^(1/2-o(1)).


5. Quantitative consequence for the 229CH threshold


The 229CH balanced J threshold is
S_CH=T^(11/10)/(2sqrt3)
    =B^(11/30-(11/10)delta)/(2sqrt3).                         (CI.18)


For every fixed delta>0,
11/30-(11/10)delta < 1/2.
Thus the explicit ambient families in Sections 3-4 lie above S_CH for all sufficiently large B.


Consequently each single Pythagorean host by itself has
>>B^(1/2)/log B
distinct occupied receiver values in the 229CH large-tail range, far above B^(1/3).


Therefore a one-third theorem CANNOT be obtained from either of the following data alone:
- x^2+y^2=z^2, z<=B, Sigma_xy=rad(xy), and fixed-Sigma_xy B^o fiber;
- e^2+z^2=R^2, R<=B, Sigma_R=rad(eR), and fixed-Sigma_R B^o fiber.


RESULT_229CI_SEPARATE_DUAL_RECEIVER_OCCUPIED_TAIL_ATTACK=QUANTITATIVELY_FALSE_ON_THE_SINGLE_PYTHAGOREAN_HOSTS.


Critical scope firewall:
