1. Scope


229O reduced the current preferred whole-endpoint gate to


  K_*(E)=sf(gcd(eR,xy)),


and asks, for some fixed δ>0,


  #{primitive positive physical endpoints R<=B :
      K_*(E)>B^(1/3-δ)}
    = o(B^(1/3)).                                  (229P.1)


This card tests a tempting theorem species that was not yet quantitatively closed by 229O: geometric/Ekedahl sieve on a quadric or on the fixed 4A1 toric base.


The outcome is twofold.


First, there is an exact rank-6 quadric enlargement on which the Browning–Heath-Brown geometric sieve is genuinely applicable to the large-prime common-divisor subtail. The resulting ambient exponent is nevertheless far too large for Stage37.


Second, even granting an ideal squarefree-modulus codimension-two estimate on the 229F/229K base, the ordinary divisor-union mechanism misses the B^(1/3) target. Thus merely obtaining a nonsplit analogue of a standard codimension-two geometric sieve on the BASE would not by itself close (229P.1). A future sieve must use the selector lift / twist-support compression / another genuinely stronger same-physical mechanism.


No endpoint exponent is improved here.


2. Exact rank-6 quadric containing every physical endpoint


Use the positive physical endpoint variables


  e,x,y,U,V,R


with


  e^2+x^2=U^2,
  e^2+y^2=V^2,
  e^2+x^2+y^2=R^2.                                (229P.2)


Define


  Q1=e^2+x^2-U^2,
  Q2=e^2+y^2-V^2,
  Q3=e^2+x^2+y^2-R^2,


and take their fixed sum


  Q=Q1+Q2+Q3
   =3e^2+2x^2+2y^2-U^2-V^2-R^2.                  (229P.3)


The diagonal quadratic form Q has six nonzero diagonal coefficients, hence


  rank(Q)=6.                                       (229P.4)


Every physical endpoint satisfies Q=0.


There is no height loss. From (229P.2),


  U^2=R^2-y^2,
  V^2=R^2-x^2,


so on the positive chamber


  0<e,x,y,U,V<=R.


Therefore the exact physical cutoff R<=B implies


  ||(e,x,y,U,V,R)||_∞ <= B.                       (229P.5)


Also any common divisor of all six coordinates divides e,x,y, so the retained primitive condition gcd(e,x,y)=1 makes the six-coordinate vector primitive. Browning–Heath-Brown counts all integral vectors anyway, so primitiveness is not needed for the upper-bound inclusion.

3. Exact codimension check for F1=eR and F2=xy


Set


  F1=eR,
  F2=xy.                                           (229P.6)


Then the current 229O common divisor is exactly


  gcd(F1,F2)=gcd(eR,xy).


Consider


  Z={Q=F1=F2=0} subset P^5.


The equations eR=0 and xy=0 split into four codimension-two coordinate linear spaces:


  L_ex : e=x=0,
  L_ey : e=y=0,
  L_Rx : R=x=0,
  L_Ry : R=y=0.


On these four spaces the restriction of Q is respectively


  2y^2-U^2-V^2-R^2,
  2x^2-U^2-V^2-R^2,
  3e^2+2y^2-U^2-V^2,
  3e^2+2x^2-U^2-V^2.                              (229P.7)


None is the zero polynomial. Hence Q cuts each P^3 component by one genuine equation, so every component of Z has dimension at most 2. Therefore


  codim_{P^5}(Z) >= 3.                             (229P.8)


Together with rank(Q)=6, this verifies the hypotheses of Browning–Heath-Brown, Theorem 1.2, for Q,F1,F2.

4. Browning–Heath-Brown controls a large-prime subtail, but at the wrong scale


For a quadratic form in n+1 variables with n=5, Browning–Heath-Brown gives, for the number N(B,M) of integral points on Q=0 for which F1,F2 have a common prime divisor p>M,


  N(B,M)
   << B^(4+ε)/(M log M) + B^(4-1/5+ε)
    = B^(4+ε)/(M log M) + B^(19/5+ε).             (229P.9)


All positive physical endpoints in the corresponding large-prime event are a subset of these ambient points by Sections 2–3.


At the Stage37 radical threshold


  M=B^(1/3-δ),


(229P.9) is only


  << B^(11/3+δ+ε)/(log B) + B^(19/5+ε),           (229P.10)


which is enormously above the required o(B^(1/3)) scale.


Moreover the theorem only catches the event that gcd(eR,xy) has one prime divisor p>M. The current tail K_*>M can also occur when K_* is a product of many primes all <=M. Therefore the direct theorem does not even cover the entire radical tail before the exponent issue is considered.

5. Base-only codimension-two divisor-union ceiling


The previous failure might suggest transferring a Huang-style or other effective codimension-two geometric sieve directly to the fixed nonsplit 4A1 toric base X0 of 229F/229J/229K, where the exact physical height is R and the retained anticanonical dense-torus base count is B^(1+o(1)) up to polylogarithmic factors.


Grant a theorem stronger than what is currently available: for every relevant squarefree modulus m, uniformly through the required range,


  N_m(B)
   := #{base points H<=B : m|eR and m|xy}
   << B^(1+o(1))/m^σ.                             (229P.11)


For a pure codimension-two local-density model one expects σ=2.


Let


  Y=B^(1/3-δ).


If K_*=sf(gcd(eR,xy))>Y, then the squarefree integer m=K_* itself satisfies m>Y and m|eR, m|xy. Hence the direct divisor-union estimate gives


  # {base points : K_*>Y}
    <= sum_{m>Y} N_m(B)
    << B^(1+o(1)) sum_{m>Y} m^(-σ)
    << B^(1+o(1)) Y^(-(σ-1))                      (229P.12)


for σ>1.


To beat B^(1/3), (229P.12) requires


  1-(σ-1)(1/3-δ) < 1/3,


equivalently


  σ > 1 + 2/(1-3δ).                               (229P.13)


In particular:


- σ=2 gives only B^(2/3+δ+o(1));
- σ=3 gives only B^(1/3+2δ+o(1));
- for every fixed δ>0, the required decay is strictly stronger than cubic in m.


Thus even an ideal composite-modulus version of ordinary codimension-two base equidistribution, with m^(-2) density and perfect uniformity, cannot close the current one-third radical gate through a direct divisor-union argument.
