sum H_i^2 + sum bar(H_i)^2 + 2R^2 = 0
implies pi^2 | C for r=2 and v_pi(C)=2n for r=3. Since C != 0 and N(C) <= r^2 m^4, one obtains p <= 2m^2 for r=2 and p^n <= 3m^2 for r=3, hence p <= 3m^2 for every p|R. The prime-power-R exclusion follows.
