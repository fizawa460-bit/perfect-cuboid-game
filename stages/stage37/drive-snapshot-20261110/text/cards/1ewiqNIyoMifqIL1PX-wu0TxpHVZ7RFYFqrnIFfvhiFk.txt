4. New exact c21 square-neutrality theorem


Let the 4bn pair be written in half-angle coordinates:
    H2-S2 = kappa2 a^2,   H2+S2 = kappa2 b^2,
    H3-S3 = kappa3 c^2,   H3+S3 = kappa3 d^2,
with gcd(a,b)=gcd(c,d)=1 and kappa_i in {1,2}.


The Stage14 cross-square detector is
    Delta0
    =(ad-bc)(ad+bc)(bd-ac)(bd+ac).             (224.4)


Put
    h = gcd(H2,H3) = c21.
Primitive Pythagorean hypotenuses are odd, so h is odd.


Claim:
    h^2 | Delta0.                                (224.5)


Proof prime-power by prime-power.
Let p^e|h. Since p is odd and p^e divides H2,H3,
    a^2+b^2 == 0 mod p^e,
    c^2+d^2 == 0 mod p^e.
Primitivity gives p not dividing abcd. Hence p==1 mod4 and there is a root rho^2==-1 mod p^e such that, after choosing rho,
    a == rho b mod p^e.
The second face has
    c == sigma d mod p^e
with sigma=+rho or -rho.


If sigma=+rho, then
    ad-bc == 0 mod p^e,
    bd+ac == bd(1+rho^2) == 0 mod p^e.


If sigma=-rho, then
    ad+bc == 0 mod p^e,
    bd-ac == bd(1+rho^2) == 0 mod p^e.


Thus p^e divides two distinct factors in (224.4), so p^(2e)|Delta0. Multiplying over all prime powers of h proves (224.5).


More precisely, h admits a coprime orientation split
    h=h_same h_opp
such that
    h_same | gcd(ad-bc,bd+ac),
    h_opp  | gcd(ad+bc,bd-ac).                  (224.6)


Therefore the second cross-gcd factor c21 is an AUTOMATIC SQUARE FACTOR of the raw square detector. Large c21 cannot be charged as an independent square-sieve/root-line density.


This is analogous to, but distinct from, Stage14-s6-08's good half-angle gcd-matrix square factor. Here the divisor is the full common hypotenuse gcd gcd(H2,H3) appearing directly in M3-XG-008.
