2. Explicit rational squareclass representative for a norm-square element


LEMMA 229M.1.
Let K=Q(i), let zeta in K^* be non-real, and suppose
  N(zeta)=r^2
with r in Q_{>0}.
Then the rational squareclass in the Hilbert-90 descent of 229L may be represented by
  2r+Tr(zeta).


Proof.
Set
  w=r+zeta.
Since zeta is non-real, w is nonzero. From zeta*conj(zeta)=r^2,
  zeta/r = (r+zeta)/(r+conj(zeta)) = w/conj(w).
Hence
  zeta = [r/N(w)] w^2.
But
  N(w)=r(2r+Tr(zeta)),
so the rational coefficient is
  1/(2r+Tr(zeta)).
An element and its inverse have the same class in Q^*/Q^{*2}, proving the claim.

4. Elementary Pythagorean content-squareclass lemma


LEMMA 229M.2.
Let
  A^2+B^2=C^2
be a positive integral Pythagorean triple with content
  c=gcd(A,B)=gcd(A,B,C).
Write A=c A0, B=c B0, C=c C0 with the primitive triple (A0,B0,C0).
Then
  [C-A]=[c]        if A0 is even,
  [C-A]=[2c]       if A0 is odd
in Q^*/Q^{*2}.


Proof.
For a primitive triple:
- if A0 is the even leg, A0=2mn and C0-A0=(m-n)^2;
- if A0 is the odd leg, A0=m^2-n^2 and C0-A0=2n^2.
Multiplying by c proves the claim.
