3. Candidate A — Ostmann weighted large-gcd removal


SOURCE_PATHS:
lean/OAI/NumberTheory/Ostmann/QuadraticSieveLargeGcd.lean
lean/OAI/NumberTheory/Ostmann/QuadraticSieveLargeGcdBound.lean
lean/OAI/NumberTheory/Ostmann/QuadraticSieveLargeGcdBasic.lean


The theorem weighted_large_gcd_removal is an exact large-gcd descent for a weighted Jacobi-character energy. In compressed form, for odd-squarefree columns S<=N, nonnegative row weights omega, and coefficients a, it bounds


weightedNumeratorEnergy(W,S,omega,a)


by


sum_{d<=D} ||weightedGcdCorrelation(W,S,omega,a,d)||
+
C N^epsilon weightedNumeratorNorm(W, oddSquarefreeUpTo(N/D), omega)
  * coefficientEnergy(S,a).


The proof genuinely separates gcd strata and sends the d>D tail to a shorter quotient-support norm. It is not a heuristic density statement.


CLASSIFICATION_229CD_A=ADAPTER_NOT_DIRECT.


Reason for no direct transfer:
Stage37 currently has endpoint multiplicities and the scalar support condition
J=rad_odd(gcd(Omega,S)),
but no proved map from the exact physical endpoint source to a Jacobi matrix whose weightedNumeratorEnergy is bounded below by the J-large endpoint population and whose gcd stratum d is exactly, or boundedly-fibered by, the Stage37 J receiver. The theorem controls an analytic energy after such a matrix has been constructed; it does not itself count arbitrary pairs with large gcd radical.


Required bridge:
J_ENERGY_BRIDGE=
construct, on the exact selector source, odd-squarefree columns n(P), row parameters m, nonnegative weights omega, and coefficients a such that
(i) J-large endpoints force a quantitative lower bound for weightedNumeratorEnergy,
(ii) the relevant gcd strata encode J or a bounded-multiplicity divisor of J,
(iii) the quotient-support norm at N/D is controlled in the same R-height/selector measure,
(iv) all losses are o(B^(1/3)) at a threshold comparable to the 229CC branch threshold.


Without this bridge, importing weighted_large_gcd_removal does not create global counting credit.

PublishedQuadraticLargeSieve is the finite odd-squarefree Heath-Brown quadratic-large-sieve input retained explicitly by the repository.
quadratic_biased_kernel_count converts a common amplified quadratic-character bias into a quantitative bound on the number of signed squarefree kernels.
eventual_affine_kernel_count upgrades this to actual affine values m*x-h: under a strong common-prime bias and scale hypotheses, the number of distinct biased squarefree kernels is exp(o(L)) in the manuscript regime.


This machinery would be very strong if one of the Stage37 support buckets were already a squarefree kernel of a controlled affine value and carried the required common-prime character bias.


CLASSIFICATION_229CD_B=ADAPTER_WITH_MISSING_BIAS_AND_HOST_IDENTIFICATION.


Current firewall:
J is the odd radical of a gcd, not the squarefree kernel of one affine value.
tau is the support of the full pair-gcd router with square-modulus root-line constraints, not presently a squarefree kernel of one affine value.
M_U,M_V,M_z are stripped opposite-matching support products, again not presently affine kernels.
The 229CB square-modulus root lines provide deterministic congruence/root information, but no theorem currently in Stage37 turns that information into the uniform common-prime quadraticPrimeMean lower bound required by quadratic_biased_kernel_count or eventual_affine_kernel_count.


Required bridge:
KERNEL_BIAS_BRIDGE=
represent a selected Stage37 bucket (or a bounded-fiber image of it) as the signed squarefree kernel of a controlled affine value, and prove a common-prime quadratic-character bias on the exact physical selector source with the quantitative scales required by the quadratic large sieve.


No such bridge is currently proved.


5. Candidate C — generic collision-energy to sparse-moduli lemma


SOURCE_PATH:
lean/OAI/NumberTheory/EgyptianFractions/RoughModulusCollision.lean


The generic theorem moduli_rpow_energy_card_le is not character-specific.
For a common finite set A, a modulus set I, maps a -> a mod q, and a divisor predicate Q, it gives a larger-sieve style bound


|I| <= 2 X^theta R


provided:
q<=X for q in I,
|A| is large enough,
each q has collision energy
|A|^2 <= q^theta * #collisionPairs_q(A),
and every nonzero difference has at most R admissible divisors q<=X satisfying Q.


This is a genuine potential adapter for the 229CB tau router because it can count occupied moduli without summing all moduli independently.


CLASSIFICATION_229CD_C=ADAPTER_PROMISING_FOR_TAU_OCCUPIED_SUPPORT_BUT_BRIDGE_MISSING.


The missing step is concrete:
TAU_COLLISION_BRIDGE=
construct one common selector-conditioned set A_B and a realized modulus family I_B from the physical endpoints (for example a bounded-fiber image of the g_i^2 root-line moduli) such that every q in I_B has a proved collision-energy lower bound on A_B, while each off-diagonal difference has only B^o(1) admissible q-divisors.


The current root-line statement “a physical endpoint lies on one of the allowed residue lines modulo g_i^2” does not by itself imply high collision energy for a common A_B. Therefore the generic larger-sieve lemma cannot yet be invoked to count tau-large endpoints.


Quantitative adapter target:
if one can arrange X^theta R = o(B^(1/3)) and bounded endpoint-to-modulus fiber on the exact R<=B source, this route would give the required occupied-modulus saving without forbidden unrestricted modulus summation.
