1. Pair weights on the exact physical image


Let


    W_B = {(X,D): there exists E in M3(B) with physical pair (X,D)},


and for q=(X,D) in W_B define the exact physical multiplicity


    m_B(q) = #{E in M3(B): pair(E)=q}.


M3-XD-001 gives uniformly on the exact physical population


    1 <= m_B(q) <= B^{o(1)}.                       (229G.1)


The endpoint predicate depends only on q:


    S(q)=1  iff  X^2+D^2 is an integer square.      (229G.2)


Define


    E_B={q in W_B:S(q)=1}.


Because every M3 object above the same q has the same endpoint state,


    M3(B) = sum_{q in W_B} m_B(q),                 (229G.3)
    P(B)  = sum_{q in E_B} m_B(q).                 (229G.4)


Hence


    |W_B| <= M3(B) <= B^{o(1)} |W_B|,              (229G.5)
    |E_B| <= P(B)  <= B^{o(1)} |E_B|.              (229G.6)


Therefore


    B^{-o(1)} |E_B|/|W_B|
      <= P(B)/M3(B)
      <= B^{o(1)} |E_B|/|W_B|.                     (229G.7)
