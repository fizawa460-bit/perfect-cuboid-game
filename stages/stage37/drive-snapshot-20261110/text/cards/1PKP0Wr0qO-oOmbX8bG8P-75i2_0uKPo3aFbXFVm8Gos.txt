1. Exact pair measure


Let M3(B) denote the exact primitive canonical M3 population at physical height R<=B.


For every occupied physical pair (X,D), define
    mu_B(X,D)
      = #{E in M3(B): E maps to (X,D)}.


Let
    W_B = {(X,D): mu_B(X,D)>0}.


By M3-XD-001, fixed-(X,D) multiplicity is uniformly B^o(1). Therefore
    1 <= mu_B(X,D) <= B^o(1)                    (PAIR.1)
uniformly on W_B.


Hence
    |W_B| <= M3(B) <= B^o(1)|W_B|.              (PAIR.2)


The endpoint predicate is exactly
    X^2 + D^2 is an integer square.
It depends only on the pair.


Define
    E_B = {(X,D) in W_B: X^2+D^2 is a square}.


Then the endpoint count satisfies
    |E_B| <= P(B) <= B^o(1)|E_B|.               (PAIR.3)


Thus the occupied-pair measure and the exact M3 object measure are subpower-equivalent for fixed-power density questions.
