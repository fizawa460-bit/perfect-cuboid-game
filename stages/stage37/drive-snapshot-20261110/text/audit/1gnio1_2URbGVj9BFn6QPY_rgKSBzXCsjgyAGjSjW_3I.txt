## 2. Fixed-A_car physical fiber — PASS

## 3. Scope correction: exact A_A<=E_psi is not justified


The original provisional card wrote
A_A(B) <= E_psi(B).
That exact inequality silently assumes one retained A_car value per endpoint. Earlier cards explicitly allow nonunique retained core representations, so that exact inequality is not licensed.


It is replaced by a power-scale statement.


For fixed canonical tau, the number of possible A_car values is B^o(1):
- the four-core norm partition tau=tau0*tau1*tau2*tau3 has at most 4^omega(tau)=B^o(1) prime-power allocations;
- M_rel and Nrel are then determined by the fresh/content split of the relative cores;
- T|M_rel, so the number of possible T values is at most tau(M_rel)=B^o(1).


Hence


A_A(B) <= B^o(1)*A_tau(B).


Conversely, choose one endpoint and one retained A_car representation for each active canonical tau. For a fixed A_car, Section 2 gives only B^o(1) endpoints, and each physical endpoint has one canonical tau from the Stage37 physical data. Therefore


A_tau(B) <= B^o(1)*A_A(B).


Section 19 already gives


A_tau(B) <= E_psi(B) <= B^o(1)*A_tau(B)


on the fixed packet. Thus


A_A(B), A_tau(B), and E_psi(B)


have the same polynomial exponent.


This restores the intended power-scale equivalence, but it also changes the interpretation: A_car is an alternate one-dimensional arithmetic coordinate for the already-existing active-tau gate, not a newly smaller support set by itself.
