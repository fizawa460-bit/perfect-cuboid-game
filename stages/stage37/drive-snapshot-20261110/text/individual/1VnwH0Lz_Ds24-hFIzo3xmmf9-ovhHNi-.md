TYPE: EXACT_STRUCTURE

CLAIM:
The late Stage14 fixed-U projective receiver can be unfolded from one fixed projective cofactor class to ordinary Gaussian residue coordinates.
First, one D4 normalization sector is frozen at O(1) cost and the cofactor weight becomes a primitive Gaussian norm-representation count in one broad sector and one fixed raw projective class.
Next, the projective cofactor coset contains only B^o(1) ordinary invertible Gaussian residues, so one exact cofactor residue can be frozen without losing a fixed-power depletion exponent.
The selected prime projective class can then likewise be frozen to one exact Gaussian prime residue.
After these steps the opaque scalar cofactor weight is unfolded to an actual primitive Gaussian cofactor set, and the target is an explicit fixed-residue cofactor/prime reciprocal hyperbola.
