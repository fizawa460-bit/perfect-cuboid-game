Thus each u_i is a leg of a primitive Pythagorean triangle whose hypotenuse is D_i.


3. Fixed-leg hypotenuse multiplicity


Fix a positive integer u.


Every positive primitive solution
u^2 + v^2 = D^2
satisfies
(D-v)(D+v)=u^2.


If u is odd, both factors are positive odd integers. Every solution determines a factor pair alpha*beta=u^2, alpha<beta, and
D=(alpha+beta)/2,
v=(beta-alpha)/2.


If u is even, primitive parity forces v,D odd. Put
alpha=(D-v)/2,
beta=(D+v)/2.
Then
alpha*beta=u^2/4,
and again the factor pair determines D,v.


Therefore the number of possible primitive hypotenuses D for a fixed leg u is at most
d(u^2),
where d is the divisor function.


No height theorem is used here.


4. Exact fixed-L_free fiber bound


Fix
Lambda := L_free.


Because
lcm(u1,u2,u3)=Lambda,
each u_i divides Lambda. Hence there are at most
d(Lambda)^3
ordered triples (u1,u2,u3).


For each fixed u_i, Section 3 gives at most d(u_i^2) possible D_i. Since u_i|Lambda,
d(u_i^2) <= d(Lambda^2).
Thus the number of possible ordered sextuples
(u1,u2,u3,D1,D2,D3)
is at most


d(Lambda)^3 * d(Lambda^2)^3.


Now use the retained endpoint triangle-content theorem M3-T11-004. For any endpoint-consistent D-triple,
tau = gcd(D1,D2,D3),
c_i = D_i/tau,
and
c1=h2*h3,
c2=h1*h3,
c3=h1*h2.


Therefore the positive h_i are uniquely recovered, when consistent, by
h1^2 = c2*c3/c1,
h2^2 = c1*c3/c2,
h3^2 = c1*c2/c3.


After h_i are recovered,
R=H*tau,
e_i=h_i*u_i,
and the opposite face diagonals are h_i*v_i.
Hence the endpoint is uniquely determined by the sextuple, subject to the remaining physical/canonical consistency filters. Those filters can only remove candidates.


Consequently the exact physical endpoint fiber satisfies


m_Lfree(Lambda;B)
:= #{primitive canonical endpoints at R<=B with L_free=Lambda}
<= d(Lambda)^3 d(Lambda^2)^3.

Lambda <= u1*u2*u3 < B^3.
The elementary divisor bound therefore gives, uniformly for every Lambda occurring at height B,

This is a same-measure endpoint anti-concentration theorem. It does not pass through an ambient raw-edge host.
