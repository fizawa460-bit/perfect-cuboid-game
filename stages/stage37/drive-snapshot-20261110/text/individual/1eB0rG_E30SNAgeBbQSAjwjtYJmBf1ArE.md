## 1. Restrict139's eliminant to an affine family


Let R(t),A_1(t),A_2(t),A_3(t) be rational polynomials of degree<=1. At physical points R>0, primitive integer A, and all A_i!=0. Put
 Z=R^2,
 q_i=2R^2-A_i^2,
 Q_i=A_i^2*q_i,
 D=Z^4+sum_i Q_i^2-2Z^2*sum_i Q_i-2sum_(i<j) Q_i*Q_j,
 P=D^2-64Z^2*Q_1*Q_2*Q_3.
By139,
 P=product_(epsilon in {+1,-1}^3)(R^2+sum_i epsilon_i*A_i*sqrt(q_i)).
This is an exact algebraic identity, including coincident squareclasses. In the affine parameter degree(P)<=16. In homogeneous line parameters it is a homogeneous binary form of degree16. Any full signed lift Y_i^2=q_i,sum A_iY_i=-R^2 requires P=0; no converse is claimed.
If P is NONZERO, there are at most16 finite parameter values, and at most16 projective values including infinity in the homogeneous formulation. This bound does not depend on B, coefficient size, content, or the Pell discriminants. The issue is to classify P IDENTICALLY ZERO, which is addressed next rather than silently assumed away.


## 2. Squareclass trace forces a constant-ratio coordinate


Assume R and all A_i are nonzero polynomials. Since the coefficients are rational and R!=0, q_i cannot vanish identically: A_i^2=2R^2 would require the rational function A_i/R to equal +/-sqrt(2), impossible over Q(t).
Work over K=C(t) and its multiquadratic extension generated by the sqrt(q_i). If P=0 identically, one of the eight signed factors vanishes in this FIELD. Absorb its signs into Y_i; then
 sum_i A_iY_i=-R^2.
For a q_i not square in K, a sign-changing Galois automorphism exists, so the field trace of Y_i is0. For a square q_i, Y_i is in K. Taking the normalized trace shows the sum of the SQUARE-class-trivial terms is -R^2. There must be at least one such term.
More generally, distinct squareclasses are distinct character eigenspaces of the multiquadratic Galois group; applying the character projections shows terms belonging to different nontrivial classes cannot cancel. This remains true when the three classes are dependent (for example their product is square). No generic independence assumption is used.


For degree<=2 q_i, being square in C(t) means every polynomial zero has even multiplicity, hence q_i is a square polynomial over C (a nonzero constant is included). Write R=r*t+s,A_i=a_i*t+b_i. Its discriminant is8(r*b_i-s*a_i)^2 from143. Thus q_i square implies r*b_i=s*a_i; for r=0,s!=0 this says a_i=0. In either case A_i=c_i*R with a rational constant c_i. This uses C(t) to classify roots; no claim that sqrt(2-c_i^2) is rational is made.


## 3. Complete identity classification on the relevant rational lines


There cannot be exactly TWO trivial q_i classes: the remaining nontrivial term is nonzero and cannot cancel. ZERO trivial classes is excluded by trace. Thus either all THREE are trivial or exactly ONE is trivial.


If all three are trivial, every A_i/R is constant. The image [A_1:A_2:A_3:R] is a single projective point, not a genuine projected line. For primitive integer A and R>0, there is at most one distinct (A,R) candidate, as in144. A constant coefficient family is covered by this case.


If exactly one class, say q_k, is trivial, trace gives
 A_kY_k=-R^2,
 hence A_k^2*(2R^2-A_k^2)=R^4,
 so (A_k^2-R^2)^2=0 and A_k=+/-R.
The other two terms must have the same nontrivial class and cancel. Squaring their cancellation gives
 A_i^2*q_i=A_j^2*q_j,
 equivalently (A_i^2-A_j^2)*(2R^2-A_i^2-A_j^2)=0.
The polynomial ring is a domain. In the second alternative A_i^2+A_j^2=2R^2. Since the coefficients are real and linear, its coefficient Gram matrix has rank1, forcing A_i and A_j proportional to R (the same elementary sum-of-squares argument as143). This would make both q_i,q_j trivial, a contradiction. Therefore
 A_i=+/-A_j.


Conclusion: when R and every A_i are nonzero polynomials, a nonconstant rational projected line contained in P=0 has the boundary pattern
 A_k=+/-R, A_i=+/-A_j.
Conversely that pattern makes a signed factor identically0 by taking Y_k=-R^2/A_k and cancelling the equal-root pair. This includes nonlinear minus-root branches. Example R=t,A=(t,t+1,t+1): P=0 identically, but the two remaining roots are sqrt(2t^2-(t+1)^2), generally nonlinear. Thus143's unsigned LIFTED no-line result alone could not justify this projected-line classification.
If R is identically0, there is no physical R>0 point. If an A_i is identically0, there is no point in the original138/139 nonzero-plus mask. These cases are explicitly empty for the population being counted, whatever their polynomial P is. No classification of complex lines or irrational-coefficient real lines is claimed.


## 4. The contained boundary lines have NO positive physical lift, even at exceptional parameters


At any real signed lift satisfying139, let e_i=(A_i+Y_i)/2. Then
 sum_i e_i^2=(sum_i(A_i^2+Y_i^2)+2sum_i A_iY_i)/4=R^2.
On A_k=+/-R the square equation forces Y_k=+/-R. Hence e_k is0 or+/-R. If e_k=0, positivity fails. If e_k=-R, positivity fails. If e_k=R, the displayed sum forces all other e_i=0. Consequently no branch at ANY real parameter with R>0 has all e_i>0.
This handles isolated root collisions and alternate sign branches; it is stronger than saying only the generic identity branch has a zero edge. Zero q_i at isolated parameters is allowed in this check. Original packet/content/canonical masks can only reduce the population further.


## 5. Uniform line occupancy and what it does to144's cover proposal


Every genuine rational projective line contains at most16 relevant positive physical projection points [A:R]. Lines contained in P=0 contribute0, while noncontained lines meet the nonzero binary degree16 form at at most16 points. Primitive integer A and R>0 choose at most one (A,R) representative per projective point. A degenerate affine family whose projective image is one point contributes at most one primitive candidate. This is a coefficient-independent bound for the FULL signed population;144's logarithmic bound remains valid for the larger UNSIGNED population.
For each (A,R) there are at most8 signed Y triples, hence at most8 reconstructed canonical endpoints; use this factor once. Therefore any J genuine rational lines covering the required physical projections give

The weaker L^4*log cost in144 is no longer required for FULL signed line occupancy. There is still no supplied family cover and no global J(B) estimate.


Moreover, for a finite physical pair set of size S, the minimum number J_min of rational lines covering it satisfies

The upper bound chooses a line through each point; it is an existence statement, NOT an algorithm or noncircular research construction. Thus line-cover number and physical pair support have the SAME exponent, within constants. Reducing the problem to an economical line list does not itself create an exponent gain. An independent, noncircular estimate for J could still be useful, but a line-cover restatement of the unknown support is not progress toward global counting.
