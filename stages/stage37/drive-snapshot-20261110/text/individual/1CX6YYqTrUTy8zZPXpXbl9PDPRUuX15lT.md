CLAIM:
The late Stage14 fixed-U projective receiver admits three successive exact contractions.
For real/order-two projective characters, generic Gaussian orientation is invisible: conjugate Gaussian choices have the same real-character value, leaving a completely multiplicative scalar norm phase.
For nonreal characters, orientation dependence remains but compresses to a B^o(1)-sized norm-fiber Fourier coefficient attached to the polynomial scalar norm n.
Finally, the nonnegative class decomposition shows that any principal-scale fixed-power depletion localizes to one exact projective cofactor class at only B^o(1) cost, with the target prime class then fixed as its inverse.
Thus the minimal cofactor-side receiver is a fixed projective cofactor class scalar-norm weight against reciprocal fixed projective-prime-class depletion; the moving selected-class and real/nonreal cofactor splits are no longer minimal receivers.
