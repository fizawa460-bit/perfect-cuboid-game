## M3-HIST14-ROOT-DISC-001
TYPE: EXACT_STRUCTURE
STATUS: PROVED_EXACT


CLAIM:
On the Stage14 canonical reciprocal-root receiver, stratify the common-core modulus by
C0=B^(kappa+o(1)).
For squarefree split-supported C0, the oriented primitive root line has model principal density
rho_root(C0)=C0^(-1+o(1))=B^(-kappa+o(1)).
Writing the physical root indicator exactly as
1_root = rho_root(C0) + Delta_C0,
gives an exact principal-plus-centered-discrepancy decomposition on the correlated physical sequence.
For kappa>0 the principal term is already fixed-power small, so any saturating polynomial-core cell must be carried by exponent-zero centered discrepancy.
For kappa=0 the principal term is only B^(-o(1)), so root density alone gives no fixed-power saving and the obstruction returns to canonical allocation density.
