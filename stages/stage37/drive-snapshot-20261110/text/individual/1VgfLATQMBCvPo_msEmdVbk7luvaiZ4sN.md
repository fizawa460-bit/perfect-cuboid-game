## M3-ONE-005
TYPE: THEOREM
STATUS: PROVED_EXACT


CLAIM:
Fix one nondegenerate primitive Euclid source triple and one admissible gcd stratum delta.
The system
S^2=F(t),
X1^2=Q(t)/delta
is a smooth genus-3 curve.
Its Jacobian is, up to Q-isogeny,
E_Master x E_+ x E_-,
where the genus-2 reciprocal quotient splits into two explicit smooth elliptic quotients E_+,E_-.
Hence each fixed first source and fixed delta contains only finitely many one-factor Master-Hits.


POPULATION:
fixed-source slices of Master-Hit + L_-=square.


HEIGHT:
fiberwise finiteness only; no uniform moving-source count.


DEPENDS_ON:
M3-ONE-GATE-001 and the disjoint branch loci of F and Q.


IMPLIES:
no fixed first source triple can be an accumulating one-factor stratum.


ALIASES:
FixedSourceOneFactorGenusThree;
FixedSourceThreeEllipticSplit.


DUPLICATE_OF:
none.


SUPERSEDES:
attempts to explain one-factor abundance by one fixed Master source.


DO_NOT_REPEAT:
Faltings on each fixed source does not sum over the moving source family.


REOPEN_CONDITION:
a uniform quantitative theorem across moving first-source triples.


DETAIL_DOC:
LEGACY-COLD Section90, Theorems 90-F through 90-H.
