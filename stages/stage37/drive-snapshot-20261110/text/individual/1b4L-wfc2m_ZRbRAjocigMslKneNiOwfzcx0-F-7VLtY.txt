2. Local Euclid-root size versus one content


For each primitive space triangle
u_i^2+v_i^2=D_i^2,
D_i=c_i*tau,
write the two positive coprime Euclid roots from M3-T11-167 as a_i,b_i, and put
t_i=max(a_i,b_i).


If u_i is even,
D_i=a_i^2+b_i^2.
If u_i is odd,
D_i=(a_i^2+b_i^2)/2.


In both parity cases one has the uniform absolute comparison


D_i/2 <= t_i^2 <= 2D_i.


Let
r=max(t_1,t_2,t_3)
and let
c_max=max(c_1,c_2,c_3).


Choose i_* with t_i*=r. Then
r^2 <= 2D_i* <= 2 c_max*tau.


On the other hand, choose j with c_j=c_max. Since
t_j^2 >= D_j/2,
we have
r^2 >= t_j^2 >= c_max*tau/2.


Therefore the exact global comparison is


c_max/2 <= r^2/tau <= 2 c_max.        (168.1)


Thus the ratio r^2/tau is not a new independent large parameter: it is the existing maximum cyclic content, up to a bounded factor.


In particular:
- c_max>C implies r^2/tau>C/2;
- c_max<=C implies r^2/tau<=2C.


This gives a direct translation between the current Euclid-root language and the old cross-gcd/content split.


3. Three-hypotenuse product identity


Retain
c_1=h_2*h_3,
c_2=h_1*h_3,
c_3=h_1*h_2,
H=h_1*h_2*h_3,
R=H*tau.


Since D_i=c_i*tau,


D_1*D_2*D_3
=
(c_1*c_2*c_3)*tau^3
=
H^2*tau^3
=
R^2*tau.                                      (168.2)


Because every local maximum t_i is <=r and D_i<=2t_i^2<=2r^2,


D_1*D_2*D_3 <= 8r^6.


Combining with (168.2),


r^2 >= (R^2*tau/8)^(1/3)
     = (1/2) R^(2/3) tau^(1/3).               (168.3)


This inequality is on the exact same endpoint. No face independence is used.

6. Fixed-(r,tau) same-measure fiber bound


Fix positive integers r and tau and restrict to endpoints for which r is the canonical global maximum Euclid root.


Choose the selected face and root sign/parity; this costs only an absolute constant.


Let s<=r be the companion Euclid root on the selected face.


In both parity cases integrality of c_i implies


s^2 == -r^2 mod tau.


Because gcd(r,tau)=1 and every prime of tau is split (p==1 mod4), the congruence has at most
2^omega(tau)=B^o(1)
residue classes modulo tau.


Hence the number of possible positive s<=r is at most


(1+r/tau) B^o(1).                              (168.10)


Once s is fixed, c_i is fixed by
c_i*tau=r^2+s^2
in the even-u_i case, or
2*c_i*tau=r^2+s^2
in the odd-u_i case.


The factorization
c_i=h_j*h_k
has B^o(1) ordered coprime choices for (h_j,h_k).


For the remaining h_i, global maximality of r gives
D_j,D_k<=2r^2,
hence


h_i*h_k*tau<=2r^2,
h_i*h_j*tau<=2r^2.


Therefore


h_i <= 2r^2/(tau*max(h_j,h_k)).


Since max(h_j,h_k)>=sqrt(c_i), while the selected-face comparison gives
c_i>=r^2/(2tau), one obtains


h_i <= 2*sqrt(2)*r/sqrt(tau).                  (168.11)


For fixed h_i,h_j,h_k,tau, the remaining D_j,D_k are fixed primitive Pythagorean hypotenuses. By the standard divisor/Gaussian representation bound, their oriented primitive directions contribute only B^o(1) candidates. The endpoint sphere and reconstruction constraints are post-filters.


Consequently


m_(r,tau)(B)
:=
#{exact primitive canonical endpoints with canonical max root r and common residual tau}
<=
(1+r/tau)(1+r/sqrt(tau)) B^o(1).               (168.12)


On the current small-c branch, (168.1) gives
r^2/tau<=2C.


Moreover, for fixed small eta,xi satisfying
eta+(5/2)xi<1/4,
the retained tau lower bound implies tau/C -> infinity, so r<tau for all sufficiently large B.


Then (168.12) simplifies to


m_(r,tau)(B) <= C^(1/2) B^o(1).                (168.13)


At C=B^(1/6+xi),


m_(r,tau)(B)
<=
B^(1/12+xi/2+o(1)).


This is a genuine same-measure fixed-pair fiber theorem. It does not control the number of occupied (r,tau) pairs.


7. Interpretation against the retained active-tau route


M3-T11-017 already proves B^o(1) multiplicity for fixed labeled content triple and fixed tau. The present theorem forgets the content triple and retains only (r,tau), so the residual C^(1/2) fiber cost in (168.13) is expected: one content direction remains movable.


Therefore the pair (r,tau) is a useful compression, but not automatically a stronger receiver than the retained fixed-content active-tau/triple-spin route.

- the ratio r^2/tau is essentially c_max;

Thus 168 rules out treating the near-B conductor r^2*tau in (168.8) as an independent density gain. A new theorem must bound occupied pair support, or exploit the retained triple-spin selector on that support.
