## M3-XD-LOCAL-001
TYPE: INTERMEDIATE_LEMMA
STATUS: PROVED_EXACT


CLAIM:
For an odd prime p define
Omega_p
=
{[x:d] in P^1(F_p): x^2+d^2 is a square in F_p},
with zero counted as a square local value.
Then exactly
|Omega_p|
=
(p+2+chi_p(-1))/2.
In particular, for every inert prime p==3 mod4,
|Omega_p|=(p+1)/2,
so the endpoint local necessary condition accepts exactly one half of the projective residue classes.


POPULATION:
projective physical (X,D) residue classes modulo p.


HEIGHT:
pure local finite-field statement.


DEPENDS_ON:
the identity
sum_{w in F_p} chi_p(1+w^2)=-1.


IMPLIES:
the fixed-q occupied-(X,D) route has an exact local half-set at inert primes; the remaining difficulty is the distribution of the occupied M3 image across that half-set.


ALIASES:
inert-prime projective half-set;
physical XD local half law.


DUPLICATE_OF:
M3-LOCAL-003 concerns half-angle terminal factors on the local Euler-square measure; this card is directly on physical projective (X,D).


SUPERSEDES:
heuristic "about one half" statements for the inert-prime endpoint base condition.


DO_NOT_REPEAT:
Do not infer that exact physical M3 points are uniformly distributed on P^1(F_p) from this local set size alone.


REOPEN_CONDITION:
none.
