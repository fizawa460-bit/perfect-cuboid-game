# stage32-ex1 — V6 equigeneric / contact ledger

## 目的

V6 の Picard class をもつ**既約・整**曲線が、幾何種数 1 に必要な種数欠損 \(\delta=472\) と、解消上の exceptional 接触・既知140分解を同時に満たせるかを、局所/大域を混同せず調べる。

## ゴール

次のいずれか一つを、参照と量化域を固定して出す。

1. V6 全体、または明記した一枝への正確な不可能性補題。
2. 残る正規化の fibre 型・局所枝型の有限台帳（次の探索の入力）。
3. 現在の数値だけでは決まらない自由度を、必要な追加データとして特定。

\(47\) positive exceptional support の総量 \(266\) を、そのまま \(\delta\) と同一視する結論はゴールに含めない。

## 簡易ロードマップ

1. V6 の \(D^2=758\)、\(K\cdot D=186\)、\(p_a=473\)、\(g=1\Rightarrow\delta=472\) と、解消/既知140の入力を source-lock する。
2. 曲面特異点上・滑らかな周囲での曲線特異点・解消後に別点へ分離する枝を、別々の局所変数として定義する。
3. 正規化 fibre と exceptional 接触から使える局所不等式だけを証明し、\(\delta\) への寄与を区別して合算する。
4. 大域交叉式と照合し、残る fibre/枝型を有限表に落とす。
5. 空なら排除補題、空でなければ「次に実現すべき局所モデル」を最小入力として出す。

## 最初の停止条件

局所モデルを特定せずに \(266\) を \(472\) に代入する段階で止める。非全単射な正規化が surface node にしか起きない、と仮定しても止める。
